    天象 · 宏观情绪门禁¶

    模块定位：本模块负责回答「今天能不能做」。它是整个分析流程的第一道门禁 —— 一票否决权的持有者。在它给出 A/B/C/D 评级之前，任何个股分析都不应开始。

    一、为什么这是第一个模块¶

    仓位上限不由个股质量决定，由市场环境决定（第一性原理二：覆巢之下无完卵）。

    在系统性下跌中，所有个股的相关性趋近于 1，分散化失效。此时唯一的保护是低仓位。

    这一步的投入产出比是全流程最高的：1 分钟的判断决定后续所有分析结果的可用范围。

    二、四个采集维度¶

    维度 指标 数据含义
    情绪高度 最高连板数 情绪的绝对高度
    情绪广度 涨停家数 / 跌停家数 情绪的覆盖面
    赚钱效应 上涨家数 ÷ 全市场交易家数 大多数人是否赚钱
    资金意愿 全市场成交额 增量资金是否在场

    辅助维度：北向资金净流向、融资余额变化、主要指数位置、炸板率。

    三、环境四级评级¶

    评级 特征 总仓位上限 开新仓
    A 进攻 连板高度 ≥5；跌停 <10 家；成交额放大；北向连续净流入 ≤100% ✅ 正常
    B 中性 分歧期；成交额 8000-10000 亿；主线清晰但轮动快 ≤70% ✅ 正常
    C 谨慎 退潮前兆；赚钱效应转弱；炸板率上升 ≤30% ⚠️ 瓶颈等级 <3 级则跳过
    D 防守 冰点；跌停 >50 家；赚钱效应 <20%；成交量萎缩 ≤10% 🛑 禁止开新仓

    强制降级条件（任一触发）¶

    □ 最高连板数降至 3 板以下
□ 炸板率 > 35%
□ 赚钱效应 < 20%
□ 单日跌停家数 > 50
□ 北向连续 3 日净流出 > 50 亿

    四、六段情绪周期¶

    情绪如四季轮回。识别当前处于哪一季，比分析个股更重要。

    冰点 ❄️ → 启动 🌱 → 发酵 🌿 → 高潮 🔥 → 退潮 🌊 → 冰点 ❄️
    阶段 连板高度 涨停家数 炸板率 赚钱效应 仓位建议
    ❄️ 冰点 ≤2 <30 >40% <20% ≤10%（试错仓）
    🌱 启动 3 30-50 30-40% 20-40% 10-20%
    🌿 发酵 4-5 50-80 20-30% 40-60% 30-50%
    🔥 高潮 ≥6 >80 <20% >60% 30-50%（逐步减仓）
    🌊 退潮 3-4（下降） 30-50（下降） 30-40%（上升） 20-40%（下降） ≤20%

    情绪温度计¶

    情绪温度 = 连板高度分 × 25%
         + 涨停家数分 × 20%
         + 炸板率逆分 × 20%
         + 赚钱效应分 × 25%
         + 昨日涨停表现分 × 10%

各指标归一化到 0-100 分：
  连板高度分   = min(连板高度 / 7 × 100, 100)
  涨停家数分   = min(涨停家数 / 100 × 100, 100)
  炸板率逆分   = 100 − min(炸板率 / 50% × 100, 100)
  赚钱效应分   = 赚钱效应比例 × 100
    温度 阶段 操作指引
    0-20 ❄️ 冰点 休息或极轻仓试错
    20-40 🌱 启动期 轻仓介入首板/二板龙头
    40-60 🌿 发酵期 中仓追赶主线龙头
    60-80 🔥 高潮期 持仓不动或逐步减仓
    80-100 沸点/赶顶 坚决减仓，不开新仓
    从 60 降至 40 🌊 退潮确认 清仓，等下一个冰点

    五、三个核心量化指标¶

    指标 计算 判读
    连板晋级率 今日晋级数 ÷ 昨日基数 >25% 环境好；15-25% 正常；<15% 冰点；<10% 极端冰点
    炸板率 盘中曾涨停但收盘打开 ÷ 盘中涨停总数 <20% 封板坚决；20-30% 正常分歧；30-40% 退潮可能；>40% 冰点确认
    昨日涨停今表现 昨日涨停股今日涨幅均值 >+3% 溢价良好；−1%~+1% 分歧；<−1% 亏钱效应

    六、全周期操作原则¶

    阶段 原则 具体动作 心法
    冰点 空仓或极轻仓试错 连板 ≤2 板 → 空仓等待；昨日涨停股大部分低开 → 冰点确认；可轻仓试错「破局者」 弱市不做最强股，做反抽不做接力
    启动 确认转暖，早盘轻仓介入 昨日涨停股有溢价 + 晋级率 >20%；第一个换手二板即破局者；板块有 ≥3 个涨停确认方向 早盘首板是信号，换手二板确认方向
    发酵 主升浪开启，中仓跟随 主线已确认（3 天持续发酵）；龙头 4-5 板换手充分可重仓；出现补涨龙 → 方向确认 分歧转一致是最佳买点，一致转分歧是减仓信号
    高潮 情绪最热时开始减仓 6 板+ → 情绪随时崩溃；大面积一字板开板回封 → 筹码松动；后排跟风股率先走弱 → 退潮前兆 买在分歧，卖在一致。全场看多时，危险就在转角
    退潮 只出不进，清仓为主 龙头断板 → 退潮确认；炸板率 >35% + 晋级率 <15% → 退潮加速 退潮期不做接力、不做低吸、不做反包

│  炸板率:   XX%         [信号]             │
│  赚钱效应: XX%         [信号]             │
│  成交额:   XXXX 亿     [分级]             │
│                                           │
│  情绪温度: XX/100 → [阶段]                │
│  情绪周期: [冰点/启动/发酵/高潮/退潮]      │

    八、与其他模块的接口¶

    接口方向 模块 传递内容
    输出 → 弓矢（风控执行） 环境评级 → 总仓位天花板
    输出 → 司南（冲突仲裁） D 级 → 一票否决开新仓
    输入 ← 经纬（数据采集） 情绪与资金原始数据
    输入 ← 新闻雷达 政策与事件的冲击分级
    协同 望远镜（题材判定） 环境 × 题材级别共同决定仓位

    九、检查清单¶

    □ 六个采集维度是否全部取到（连板/涨停/跌停/炸板率/赚钱效应/成交额）？
□ 情绪温度是否计算？处于哪个阶段？
□ 环境评级是否输出？总仓位上限是多少？
□ 是否检查了五项强制降级条件？
□ 若为 D 级，是否已明确「禁止开新仓」？
