    紫苏 · 产业链瓶颈深挖¶

    模块定位：本模块是整个体系的收敛点。它在多维证据之上，回答唯一一个决定性问题： 这家公司是否占据了产业链上一个不可替代的物理环节？

    详细方法论见 04-产业链瓶颈方法论，本文补充模块视角的执行细节。

    一、为什么瓶颈是「单一锚点」¶

    其他维度的信号都可以被解释成多种含义：

    信号 可能的解释
    毛利率高 可能是瓶颈，也可能是一次性涨价
    资金流入 可能是看好，也可能是被动配置
    技术领先 可能是瓶颈，也可能只是暂时领先

    只有瓶颈是结构性的：全球只有一家能做，这件事不随时间、情绪、资金流动而改变。

    因此：瓶颈判断错了，其他判断再对也没用。

    二、五级分级（判据必须客观可核查）¶

    等级 判据 单只仓位上限
    🍃🍃🍃🍃🍃 全球独家 + 认证 ≥2 年 + 空间足够 25%
    🍃🍃🍃🍃 全球 2 家 + 认证 ≥2 年 + 客户锁死 20%
    🍃🍃🍃 全球 2-3 家 + 工艺或材料独家 15%
    🍃🍃 全球 3-4 家 + 单一产品领先 8%
    🍃 全球 4 家以上但有差异化 3%

    判据展开¶

    n = 全球可供应商数量（能大规模量产 + 有客户认证记录）
cert = 认证周期（年）

n = 1 且 cert ≥ 2  → 5 级
n = 1              → 4 级（独家但壁垒未被时间验证）
n ≤ 2 且 cert ≥ 2  → 4 级
n ≤ 3              → 3 级
n ≤ 4              → 2 级
n ≤ 8              → 1 级
n > 8              → 0 级

    「全球可供应商」的严格定义：

    ✅ 计入：能大规模量产 + 有客户认证记录
❌ 不计入：实验室有样品
❌ 不计入：宣布产能但未投产
❌ 不计入：能做出但良率过不了
❌ 不计入：只有技术储备无产品

    放宽这个定义，会让所有公司都变成瓶颈。

    三、四项自动降级触发¶

    瓶颈是状态，不是属性。

    □ 出现可量产替代品，或第二供应商放量
□ 客户合同到期未续约
□ 实控人减持，或质押率超过 40%
□ 行业资本开支同比增长超过 50%（扩产竞赛预警）

    任一触发 → 等级自动降一级。

    四、十二步瓶颈狩猎流程¶

    Phase 0 · 前置检查¶

    □ 资本开支周期口径验证（FY / CY 确认）
□ 反方研究搜索：查找**真实存在**的看空观点
  （不是假设的空头，是确实有人写过的看空报告）

    Phase 1 · 绘制产业链地图¶

    从终端需求出发，逐层追问「这一层缺什么不可？」
目标：拆到 5-7 层（核心环节可到 10 层）
方向：从需求往上游拆，保证每层都是「为做出最终产品而必须存在」

    Phase 2 · 数清全球真实玩家¶

    对每一层统计「能大规模量产 + 有客户认证」的供应商数量

    Phase 3 · 五维深度验证¶

    维度 检查内容
    不可替代性 有无等效替代方案？替代方案的成本差？
    产能上限 现有产能能否满足需求增长？扩产周期多长？
    客户结构 前五大客户占比？是否有长期协议？
    技术护城河 与全球第一的技术代际差距（<1 代才是候选）
    估值错配 当前估值是否反映了瓶颈地位？

    Phase 4 · 魔鬼代言人八问¶

    □ 技术真的不可替代吗？
□ 客户真的换不掉吗？
□ 产能真的不足吗？
□ 需求真的持续吗？
□ 毛利率真的能维持吗？
□ 管理层真的可靠吗？
□ 估值真的便宜吗？
□ 我做空的话，最强的三个理由是什么？

判定：≥5 问无法有力反驳 → 终止（T3）

    Phase 5 · 全球竞对深度对比¶

    技术代际差距 < 1 代 → 瓶颈候选
技术代际差距 ≥ 1 代 → 排除
对比维度：制程 / 精度 / 良率 / 产能 / 客户 / 成本

    Phase 6 · 资金周期阶段判断¶

    无人问津 → 早期发现 → 主流确认 → 拥挤共识
目标：买在「主流确认之前」

    Phase 7 · 另类数据挖掘¶

    不看 PE / ROE / 常见研报，看：
□ 专利引用数据
□ 海关进出口数据
□ 环评文件（产能扩张的真实进度）
□ 招聘岗位（在招什么人，暴露技术方向）

    Phase 8 · 错误定价类型判定¶

    类型 含义
    传统瓶颈 市场未认识到瓶颈地位
    相对价值错判 与错误的可比公司比较
    行业分类错位 被归入错误行业
    机械性错位 指数调整、被动卖出造成
    时机期权 未对未来催化定价

    Phase 9 · 物理与地缘坐标¶

    □ 生产基地位置
□ 关键原材料来源
□ 制裁 / 出口管制状态
□ 关键里程碑时点

    Phase 10 · 六维测试¶

    # 测试 检查内容
    T1 盈利质量 应计比率、M-Score
    T2 现金转化 经营现金流 / 净利润
    T3 真实增长 收入增长是否有现金支撑
    T4 估值消化 增长能否消化当前估值
    T5 竞争地位 相对全球玩家的位置
    T6 绝对规模 空间是否足够大

    T1 或 T2 不通过 → 红色预警（画饼），严禁推荐。

    Phase 11 · 三类情景框架¶

    情景 定价逻辑 适合
    A 动量 资金与情绪驱动 短线
    B 价值 基本面与估值驱动 长线
    C 催化剂 事件驱动 事件窗口

    同一只股票可能同时存在三种定价逻辑，明确当前是哪一种，才能选对持有周期。

    Phase 12 · 风险矩阵与退出条件¶

    □ ≥8 类风险
□ 每类配量化监测指标
□ 止损 / 减仓阈值明确

    五、四项配套审查¶

    瓶颈等级评定后，必须再通过四项审查。

    审查一 · 画饼预警¶

    盈利质量 或 现金转化 任一项不通过 → 红色预警 → 严禁推荐
    逻辑：独家产品不赚钱或赚的是应收账款 —— 这个瓶颈没有商业价值。

    审查二 · 空间天花板¶

    市场空间天花板 = 全球市占率上限 × TAM

若当前市值已反映超过天花板的空间 → 估值不成立
    逻辑：全球独家的特种材料，TAM 可能只有 10 亿。独家 ≠ 大生意。

    审查三 · 治理审查¶

    信号 后果
    实控人清仓式减持 否决
    审计非标意见 否决
    质押率 > 40% 且有平仓线 致命降级
    高管集体离职 降级
    关联交易频繁不透明 降级

    审查四 · 泡沫压力测试¶

    情景：行业资本开支削减 30%
若标的收入暴露度 > 50% → 降级
    逻辑：下游扩产放缓时，瓶颈环节的订单会被推迟，而不是取消。 但暴露度过高说明标的的业绩高度依赖扩产节奏。

    六、产业链拓扑分析¶

    除分级外，还需回答「标的站在产业链的什么位置」。

    问题 意义
    标的 = 瓶颈本身？还是在瓶颈上游/下游？ 决定能否直接受益
    瓶颈环节处于利润池的什么位置？ 肥美层 vs 贫瘠层
    利润池过去 5 年的迁移方向？ 判断趋势
    瓶颈是「制约产能」还是「提升良率」？ 决定议价能力

    利润池排序： 

    各层按（利润规模 × 利润率）排序 → 找到肥美层
标的在肥美层 + 是瓶颈 → 理想组合
标的在贫瘠层 + 是瓶颈 → 稀缺但生意规模小
标的在肥美层 + 非瓶颈 → 竞争会侵蚀利润

    七、输出格式¶

    ## 产业链瓶颈分析

### 瓶颈分级
| 项 | 内容 |
|---|---|
| 最强瓶颈层级 | [层名]（第 X 层 / 共 Y 层） |
| 全球供应商数 | X 家 |
| 认证周期 | X 年 |
| **紫苏叶等级** | 🍃🍃🍃🍃（4 级） |
| 单只仓位上限 | 20% |

### 证据链
1. [供应商数量的统计口径与来源]
2. [认证周期的证据]
3. [客户结构的证据]

### 自动降级触发检查
| 触发条件 | 是否命中 |
|---|---|
| 出现可量产替代品 | ❌ |
| 客户未续约 | ❌ |
| 实控人减持 / 质押 >40% | ❌ |
| 行业 capex 同比 >50% | ⚠️ 命中 → 降一级 |
| **最终等级** | 🍃🍃🍃 |

### 四项配套审查
| 审查 | 结果 |
|---|---|
| 画饼预警 | ✅ 通过 |
| 空间天花板 | 天花板 X 亿，当前市值隐含 Y 亿 → ✅/❌ |
| 治理审查 | ✅ 通过 |
| 泡沫压力测试 | 暴露度 X% → ✅ 通过 |

### 利润池位置
标的位于 [肥美层/贫瘠层]，该层利润规模 X 亿 × 利润率 Y%

    八、与其他模块的接口¶

    接口方向 模块 传递内容
    输入 ← 02 经纬 产业链、行业、客户数据
    输入 ← 03 司书 反方证据
    输入 ← 08 潜渊 治理与质押信息

    输出 → 11 弓矢 瓶颈等级 → 仓位上限
    输出 → 05 朝议 瓶颈依据 → 派系评审输入

    九、检查清单¶

    □ 产业链是否拆到 ≥7 层？每层是否为具体工序？
□ 每层是否标注全球供应商数（严格定义）与单件价值量？
□ 竞争者排除矩阵是否 ≥5 家，逐家有实质理由？
□ 产能→收入量化桥梁的五个字段是否齐全？
□ 瓶颈分级是否给出三项证据（数量/认证/客户）？
□ 是否检查了四项自动降级触发条件？
□ 四项配套审查是否全部执行？
□ 是否定位了标的在利润池中的位置？
