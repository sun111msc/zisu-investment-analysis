    二、分层结构（逐层判据与阈值）¶

    2.1 第一层 市场微观结构（market-microstructure.md）¶

    集合竞价暗语系统 

    9:15-9:20 的"烟雾弹时间":
  规则: 此阶段可以挂单，也可以撤单
  后果: 主力在此阶段大量挂单制造假信号，然后9:19:55秒大规模撤单
  ★★★ 识别方法:
    1. 9:19:30 观察委托量
    2. 9:19:55 刷新委托量
    3. 如果5秒内委托量减少50%以上 → 主力在制造假信号
       - 大幅减少 = 之前的"大量买单"是诱多
       - 反向挂单(之前大买单失踪+突然出现大卖单) = 主力要砸盘

9:20-9:25 的"真心话时间":
  规则: 此阶段只能挂单，不能撤单
  信号: 9:20之后新增的委托 = 真实意图
  ★★★ 关键信号:
    - 9:20后出现大量新增买单 → 真实做多意愿
    - 9:20后价格从高位回落 → 主力没有真实买盘，虚高
    - 9:24:55秒出现大单拉高 → 制造高开假象，开盘即砸

尾盘集合竞价 (14:57-15:00):
  规则: 最后3分钟集合竞价，不能撤单
  ★★★ 尾盘拉高（2%以上）的分辨:
    ├─ 有利好预期 + 成交量大 → 真正的资金抢筹（次日大概率高开）
    ├─ 无利好 + 成交量小 → 主力做收盘价（次日大概率低开回归）
    └─ 连续3天尾盘拉高 → 主力在出货（拉高是为了次日出）
  ★★★ 尾盘砸盘（-2%以上）的分辨:
    ├─ 有重大利空 → 真实抛盘
    ├─ 无利空 + 成交量小 → 主力洗盘（故意制造低收盘价）
    └─ 连续5天尾盘砸 → 大资金在撤退

    盘口语言·委托单暗语 

    "托单"——主力在扛，还是在出货？
1. 真托单（主力在吸筹）:
   - 大单在买五/买四位置（不直接成交） / 价格被压着不跌，但成交量在萎缩 /
     持续时间 > 30分钟 → 应对: 可以跟随买入
2. 假托单（主力在出货）:
   - 大单在买一/买二位置（很容易被成交） / 随价格下跌，托单不断下移 /
     成交量放大但价格在跌 / ⚠️ 主力一边挂托单一边在小单卖出 → "隐身出货"
     → 应对: 立即离场
3. "托单森林"（头部信号）:
   - 买一到买五全是巨大托单 / 但卖一价位不断被蚕食 / 价格不涨反跌
     → 应对: 100%出货信号

"压单"——主力在吸筹，还是在砸盘？
1. 真压单（在出货）:
   - 卖一价位大单迟迟不被吃掉 / 成交量萎缩，买单稀少 / 价格缓慢下行 → 离场
2. 假压单（在吸筹）:
   - 卖一/卖二有大单压着 / 但买单持续侵入，大单被蚕食 / 价格不跌，或有小幅度上涨 /
     成交量在放大 → 主力在吃货 → 应对: 这是最佳买入信号

    量化资金的 10 种收割手法

    ⚠️ 注意: 2026年6月证监会量化交易四大新规落地后，以下部分手法的有效性正在降低（高频刷单/虚假报撤/分仓马甲已被规则锁死）。但存量量化的中低频策略仍在运行。

    1. 止损单狩猎 (Stop Hunting): 量化通过L2数据识别散户集中挂单的价格位置 → 集中资金砸穿该价位
   → 触发止损单 → 低价接回筹码
   防御: 不要挂止损单在整数位 / 明显支撑位
2. 价格笼子狙击: A股"价格笼子"规则（±2%有效报价）被量化利用 → 股价涨到7.9%时，大量卖单压制在8%位置
   → 散户的涨停板预期被击碎 → 被迫低价抛售
   防御: 不在7-8%的涨幅位置追涨停板
3. 假突破陷阱: 量化识别关键阻力位 → 集中资金小幅突破 → 吸引散户跟风 → 散户入场后大量砸盘
   防御: 等确认回踩（而不是立即追突破）
4. 对倒制造假量: 量化用两个账户同时买入/卖出同一只股票 → 制造"放量上涨"假象
   防御: 检查成交量中主动买单/卖单的比例
5. 盘中假信号: 量化在关键时间点（10:00, 10:30, 14:00）→ 突然拉高或砸低0.5-1% → 测试散户反应（试盘）
   防御: 关键时间点不操作，等15分钟确认
6. 尾盘收割: 14:50 小幅拉高 → 散户认为明天要涨 → 尾盘追入 → 次日开盘直接低开 → 散户被迫止损
   防御: 不在尾盘5分钟内做买入决策
7. 集合竞价陷阱: 9:15-9:20 挂大买单 → 9:19:55 大单全部撤掉 → 开盘跳水
   防御: 9:20前不做任何判断
8. 新闻事件前置交易: 量化在利好新闻正式发布前的几秒钟扫描到 → 瞬间大量买入 → 价格秒拉2-5%
   防御: 不追突发新闻的第一波
9. 板块联动套利: 某龙头涨停 → 量化毫秒级扫描同板块所有股票 → 买入尚未反应的跟风股 → 3-5分钟后卖出
   防御: 跟风龙头板块的第二波（而非第一波）
10. ETF 申赎套利: 当ETF折溢价偏离时 → 量化同时做ETF和成分股的套利 → 导致ETF成分股异常波动
    防御: 避免交易流动性差的ETF成分股

    散户对量化防御的通用策略（6条） 

    1. 不做日内交易 → 量化在日内的优势是碾压级的
2. 不挂止损单在整数位 → 量化在整数位设了陷阱
3. 不在9:20前做判断 → 那是量化的烟雾弹时间
4. 不在收盘前5分钟操作 → 尾盘是量化高频博弈的高峰
5. 不用市价单 → 量化能"看到"你的市价单并提前抢跑
6. T+1环境下慎重追涨停 → 你今天买的明天才能卖，量化今天就能砸

    涨停板的微观信号 — 封板强度的四要素 

    1. 封单量/总成交量比例:
   - >3倍: 超强封板（次日大概率继续涨停）
   - 1-3倍: 中等封板（次日可能高开）
   - <1倍: 弱封板（随时可能炸板）
2. 封板时间:
   - 9:30 前一字板 → 最强
   - 9:30-10:00 → 强力（机构级别）
   - 10:00-11:30 → 中等
   - 13:00-14:30 → 偏弱
   - 14:30-15:00 → 最弱（尾盘封板往往是出货）
3. 封板前换手率:
   - 一字封板（0换手）→ 外部不可参与，明天有溢价但无法追
   - 5-10%换手后封板 → 换手充分，明天有接力空间
   - 20%+换手后封板 → 换手过度，抛压重
4. 炸板次数:
   - 炸板0次 → 最好
   - 炸板1-2次重新封回 → 可接受
   - 炸板3次+ → 放弃

    价格笼子（±2%）的深层影响 

    规则: 买入/卖出委托价格不能偏离最新成交价 ±2%
量化利用价格笼子的陷阱:
1. "两跳陷阱": 量化在最新成交价+1.98%位置挂大卖单；散户的+2.0%买单无效（超出价格笼子）；
   量化在1.99%位置成交 → 散户被"卡住"
2. "笼子锁死": 量化用连续小单把价格推到笼子上限 → 然后大量卖单压制在笼子边缘
   → 散户无法再往上挂单 → 形成"天花板"
防御: 当发现价格被卡在笼子边缘时，不追

    2.2 第二层 资金链风险（capital-chain-risks.md）¶

    A股有3套互相关联的杠杆系统，任何一个断裂都可能引发连锁反应。这是最隐蔽的系统性风险——Price Action 完全看不到它。

    一、融资盘踩踏机制 

    融资余额 = 散户/游资的"放大器"
牛市: 融资余额↑ → 资金涌入 → 价格上涨 → 吸引更多融资 → 正反馈
熊市: 价格↓ → 维持担保比例↓ → 券商强平 → 被迫卖出 → 价格↓ → 更多人暴仓

融资盘风险三层预警（维持担保比例）:
绿色区间（> 200%）: 安全，无平仓风险；融资余额增加 = 杠杆情绪升温的信号
黄色区间（150-200%）: 开始警惕；跟踪个股的融资余额/总市值比；
  超过10%的个股应当标记为"融资拥挤股"
红色区间（130-150%）: 即将触发强平；此时出现大量"被动卖出"；
  即使主力想拉升，融资盘的卖出压力也无法抵抗
黑色区间（<130%）: 强制平仓已启动；加速下跌 → 更多强平 → 进一步下跌
  （2015年股灾和2024年初的微观机制）

    二、股权质押连锁反应 

    "质押-平仓-下跌-更多质押暴仓"的死亡螺旋（六步）:
第一步: 大股东质押股票换现金（质押率通常50-60%）
第二步: 股价跌至平仓线（通常下跌25-35%）
第三步: 券商/银行要求补仓或强平
第四步: 大股东无力补仓 → 强制平仓
第五步: 大量股票被强行卖出 → 股价进一步暴跌
第六步: 更多质押触及平仓线 → 新一轮强平

个股质押风险的量化识别（质押风险评分）:
1. 质押比例 > 40% → 高风险（+3分）
   注: 大股东质押超过其持股的50%以上要高度重视
2. 股价距离质押平仓线 < 15% → 高风险（+3分）
   平仓线通常 = 质押时股价 × 质押率 × 130%
   注: 可通过上市公司公告中的"预警线/平仓线"计算
3. 公司处于 ST / 亏损 → 高风险（+2分）
4. 股价连续下跌 > 20%（近3个月）→ 中风险（+1分）
5. 行业整体下行 → 中风险（+1分）
总分≥5分 = 该股存在质押平仓的"定时炸弹"，即使PA信号看多也不应入场

数据获取: ftshare pledge-detail / pledge-summary；东方财富公告搜索"质押/补充质押/解除质押"；
          通达信 个股资料→股东研究→股权质押

    三、私募清盘线的"被动砸盘" 

    规则: 私募产品净值跌至0.7-0.8（清盘线）→ 强制平仓清算
后果: 私募无法"扛一扛"，必须卖；清盘时无论价格多低都必须出
重点: 市场规模最大的私募（百亿+）清盘 → 市场冲击剧烈；小私募清盘 → 影响有限

先行指标:
信号1: A股市场连续下跌 > 15% → 大量私募接近清盘线
信号2: 中证500/中证1000 连续暴跌 → 量化私募重仓区踩踏
信号3: 对冲基金信息平台出现"暂停赎回"公告 → 拐点
信号4: 小盘股出现无量下跌 → 可能是私募在被迫出清持仓

    四、公募基金赎回的负反馈 

    "净值下跌→赎回→被动卖出→净值下跌"螺旋（五步）:
第一步: 市场下跌 → 基金净值下降
第二步: 投资者恐慌赎回
第三步: 基金经理被迫卖出持仓应对赎回
第四步: 卖盘增加 → 市场进一步下跌
第五步: 更多基金投资者恐慌 → 更多赎回

负反馈强度的观察指标:
1. ETF 份额变化（最直接观测点）: 份额增加 → 资金流入（越跌越买 = 底部信号）；
   份额减少 → 赎回潮（负反馈加速 = 远离）
2. 公募基金季报中的"持有集中度": 大量资金集中在少数几家基金 → 赎回冲击更强
3. 基金重仓股异动: 基金重仓股出现"无基本面理由"的大跌 → 可能是基金在应对赎回

    五、配资与场外杠杆 

    配资繁荣（风险积累期）: 场外配资广告增多(百度/抖音推送配资信息)；民间"代客理财"活跃；
  微信投资群出现大量"配资优惠"；两融余额快速上升
配资崩盘（风险释放期）: 证监会开始查处配资平台；配资公司突然"暂停业务"；微信投资群突然安静；
  小盘股出现"闪崩"（配资账户被强平）；成交量突然萎缩（配资资金被清退）

    交叉风险矩阵（原文）

    杠杆类型 触发价格 连锁反应 2024年一级预警 散户对策
    融资盘 维持担保 <130% 被动强平 融资余额 >2万亿 远离融资拥挤股

    2.3 第三层 制度套利（structural-arbitrage.md）¶

    一、定增套利 

    规则: 定增发行价通常为市价的80%（8折）
后果: 定增价格 = 机构和大股东的成本底线；股价跌到定增价附近 → 参与方有强烈动力拉升股价；
     股价跌破定增价30%以上 → 参与方亏损严重，可能"放弃"
★★★ 套利机会:
  定增破发（Price < 定增价×0.85）+ 解禁前3个月
  → 参与方需要解禁后卖出获利 → 有强烈动力拉升股价回到定增价以上
  → 历史统计: 破发定增股在解禁前2-3个月平均反弹10-15%

定增+融券套利:
  旧版套路（2024年之前广泛存在）: 机构以8折价参与定增（锁定6个月）+ 同时从大股东处融券
  （借券卖出）→ 锁定20%差价作为无风险收益 → 6个月后定增股解禁 → 还给大股东
  新版规则（2024年后）: 定增锁定期内的融券被限制 → 但大宗交易+融券的组合仍然存在
  → 识别: 定增公告 + 同期融券余额大增

定增的"利益输送"信号:
  定增价远低于市价（7折甚至更低）→ ⚠️极大可能向大股东或其关联方输送利益 → 长期看跌
  定增对象是"战略投资者"但无产业背景 → ⚠️可能是大股东的"马甲"
    → 识别: 搜索定增对象的股东背景、注册时间

    二、限售股解禁 

    解禁前后的价格行为规律:
解禁前1个月: 股价往往被拉升（配合解禁出货）；如果解禁前不拉升 = 参与方放弃
解禁当日: 正常交易量 × 3-5倍；价格冲击: -3% ~ -8%（大额解禁）
解禁后1个月: 快速清仓 → 股价持续下跌（避开）；仅少量减持 → 可能是假减持（配合预期管理）
解禁后3个月: 股价回归正常波动

关键指标:
1. 解禁股占总股本比例: <2% → 冲击小，可忽略；2-10% → 有一定冲击；>10% → 重大冲击
2. 解禁股东类型: 大股东 → 通常不会大幅减持（怕失去控制权）；
   战略投资者/机构 → 大概率会减持；员工持股计划 → 大概率减持（员工获利了结）
3. 解禁股东的成本 vs 当前价格: 成本<<当前价格 → 强烈减持意愿；
   成本≈当前价格 → 可减可不减；成本>当前价格 → 不会减持（破发不会卖）

    三、大宗交易：机构的"隐形通道"（六种套路） 

    1. 高溢价大宗（溢价>5%）→ "诱多": 收盘后以高于市价成交 → 散户第二天看到"有人溢价接盘"→ 跟风买入
   → 但接盘方已经把筹码拆分在二级市场卖出了 → 第二天股价可能反而下跌
2. 折价大宗 + 二级市场卖出: 大股东以5-8%折价将股票大宗卖给关联方 → 关联方在二级市场分拆卖出
   → 大股东"隐身"减持 → 总减持量难以追踪
3. 大宗交易 + 质押套现: 大股东通过大宗交易转让股票 → 受让方用股票质押融资
4. 基金"左手倒右手": 基金A把亏损股票大宗卖给基金B → 基金A年底净值做高 → 基金B接手后继续亏
5. 大宗交易折价套利: 折价8%买入 + 分批在二级市场以折价较小卖出 → 利用制度创造差价
6. 溢价大宗（真实信号）: 机构愿意溢价接盘且长期未减持 → 真正看好 → 需从后续龙虎榜/股东变化验证

信号的"去伪存真":
排除假信号: 大宗交易后5天内龙虎榜出现"卖出"→ 出货；
  大宗交易价格偏离市价>8% → 大概率是利益输送而非正常交易；
  大宗交易量/日均成交量 > 20% → 冲击太大
确认真信号: 溢价大宗 + 后续北向/机构加仓 = 真看好；
  折价大宗 + 大股东未减持 = 正常流通（非利空）；
  连续多笔大宗交易且价格稳定 = 有机构在分批建仓

    四、ST制度与"保壳"套利 

    ST规则: 连续2年亏损 → ST；ST后1年继续亏损 → *ST；*ST后1年仍亏损 → 退市
⚠️ 2026年7月6日起，主板ST股涨跌幅从±5%调整为±10%
  - 与正常股票涨跌幅一致；波动率翻倍，ST股单日最大亏损空间从5%扩大到10%；风险显著上升
保壳手段: 卖资产（卖楼、卖子公司）→ 一次性收益扭亏；政府补贴；债务重组；资产重组
"摘帽"行情: 年报披露扭亏后 → 申请摘帽 → 摘帽公告 → 短期涨幅10-30%
  （仅限真正好转的公司，卖楼扭亏不可持续）

"避雷"清单:
绝对不碰: *ST + 净资产为负；*ST + 审计非无保留意见；ST + 股权质押>50%；ST + 近3年变更过实控人
可以关注（但不交易）: ST + 政府明确表示支持；ST + 有确定性的资产注入方案；ST + 净资产转正 + 营收>1亿

    五、上市公司公告的隐藏信号速查（原文表）

    公告类型 表面意思 真实含义 操作含义
    "变更会计师事务所" 审计师正常轮换 ⚠️ 可能: 公司有问题不被前任认可 查前任审计意见
    "收到交易所问询函" 监管例行询问 有监管层看不下去的问题 立即查看问询内容

    "回购股份用于股权激励" 看好公司前景 中性: 回购量通常很小 留意回购实际执行
    "实际控制人变更" 正常调整 ⚠️ 重大不确定性 避免立即交易

    "开展转融通业务" 增加持股收益 做空子弹 (+利空) 短期回避

    2.5 第五层 机构伪装（institutional-masks.md）¶

    一、北向资金的三张脸 

    北向资金 = 三种不同性质的资金混在一起:
1. 真外资（长期配置型）: 海外养老金、大学基金、主权财富基金
   风格: 低换手、长期持有、偏好消费龙头 → 持续买入+低位放量 = 强烈看多信号
2. 假外资（中资绕道）: 内地资金通过香港离岸机构再回来
   体量: 市场估计占北向的 20-40%；风格: 高频交易、概念炒作、短线追逐
   → 买入后3-5天卖出 = 假外资在折腾
3. 量化北向: 海外量化基金通过北向做A股；程序化交易、对冲策略
   → 买入同时融券卖出（看似多，实则是对冲）

"去伪存真":
看多信号（真实）: 北向连续5天+净买入；买入标的是消费/金融/新能源龙头（非概念股）；
  买入时成交量大但不涨停 → 真外资在建仓；结合QFII重仓股 → 协同效应
看多信号（可能是假外资）: 北向单日大额买入+次日巨额卖出；买入标的是当日热门概念股（非龙头）；
  买入后当日即涨停；北向买卖量与龙虎榜游资席位高度重叠
结论: 北向连续+非概念标的 = 真信号；北向脉冲+热门概念 = 假信号

    二、龙虎榜：真假机构的"变形记" 

    真机构(机构专用): 买入金额大（2000万+）；当日买入但次日不卖（持有周期长）；
  结合公司基本面：持仓股票通常有基本面支撑；不会在涨停板追高
假机构(游资借机构通道): 买入金额中等（500-1500万）；买入后次日必卖；
  买入时点: 涨停板上追；公司基本面: 无任何支撑
  操作: 今日机构买入→散户次日追涨→假机构次日砸盘
识别方法: 当日"机构买入"+次日龙虎榜"机构卖出" = 假机构；
  龙虎榜买入金额 + 公司近3年利润增速不匹配 = 假机构；
  "机构买入"同时"游资卖出" = 假机构接盘游资出货

龙虎榜最强的三类共振:
1. 机构+游资共振（最强）: 机构净买入+知名游资净买入 → 3-7天持有期，胜率70%+
2. 北向+机构共振（中期最强）: 北向连续3天净买入 + 机构首次龙虎榜买入 → 持有1-3个月，胜率80%+
3. 单一游资封板（最危险）: 次日游资出货概率 80%+ → 散户次日追入 = 确定性亏损

    三、国家队操盘手法 

    1. 尾盘护盘（最常见）: 14:50-15:00 突然出现大单买入；不拉板（避免龙虎榜暴露）；
   标的: 银行/保险/券商/央企（上证50成分股）→ 信号: 尾盘放量+权重股集体异动
2. ETF 申购（隐身模式）: 国家队通过申购大型ETF（沪深300ETF/上证50ETF）而不直接买入个股
   → 不会被龙虎榜捕捉 → 信号: ETF份额突然大增
3. "围魏救赵"（最隐蔽）: 大盘在跌，国家队大量买入银行股/保险股 → 稳定指数 → 减缓恐慌抛售
   → 信号: 大盘跌但银行股走强
4. 窗口指导（最不可见）: 证监会私下通知公募基金"不要净卖出" / 通知券商"限制某些账户的卖出"
   → 信号: 连续缩量下跌后突然缩量横盘

    四、大宗交易折溢价的六种信号 

    正常折价(2-5%): 大股东正常减持，无特殊含义；接盘方身份很重要
  ├─ 机构接盘 → 中性偏多；├─ 游资接盘 → 短期有炒作空间；└─ 未知账户接盘 → 隐蔽通道，可能是利益输送
高折价(8-10%): ⚠️ 大股东急于套现；股价可能在接下来1-3个月大幅下跌；也可能是"避税减持"（年末常见）
溢价大宗交易: ★★★ 强烈看多信号；有人愿意溢价接手 → 看好后市；机构溢价接盘 → 向上空间大
平价大宗: 中性信号；主要关注接盘方的身份

    2.11 🆕 融资盘健康检查（v6.5·Lesson 5 — 增量拐点比绝对值重要）¶

    核心原则: 融资余额的方向比绝对值重要。"增量→存量"的拐点先于价格顶部出现。 来源教训: 寒武纪日度融资净买入加权·2025年8月以来融资增量的建仓成本约 897 元·按除权后口径计·现价 1400 元·平均浮盈缓冲约 56%·融资盘眼下离强平线很远。但真正的脆弱之处在于接续而非成本——融资余额 6 月中旬见顶后已回落约 46 亿元·杠杆资金从增量转为存量·这个转折比任何强平线都更早出现。

    触发条件 

    - 持仓审视时（每周/每月）；- 标的融资余额占流通市值 > 3%
- 标的近 60 日融资净流入或净流出显著变化；- 出现"融资盘踩踏"相关新闻/讨论

    指标体系（原文表）

    指标 计算方式 健康阈值 警示阈值 数据源
    融资余额方向 近 60 日净流入累计 正（还在加杠杆） 零或负（开始降杠杆） ftshare-market-data: margin
    融资余额占比 融资余额 / 流通市值 < 5% > 10% ftshare
    融资成本缓冲 现价 / 融资加权建仓成本 - 1 > 30% < 10% 日度融资净买入加权计算
    融资周转率 近 30 日融资买入额 / 融资余额 < 50% > 100% 东方财富
    融资集中度 融资余额 / 日均成交额（日） 低 > 5 天（需 5 天以上成交才能完成平仓） 融资余额 / (近 20 日均成交额)

    执行流程 

    Step 1 - 获取融资融券日度数据（ftshare-market-data: margin）:
  □ 融资余额序列（近 6 个月）；□ 融资净买入日度数据
Step 2 - 计算趋势方向:
    近 60 日净买入累计 > 10 亿 → 增量阶段
    近 60 日净买入累计 0 ~ 10 亿 → 稳态
    近 60 日净买入累计 < 0 → 存量阶段(⚠ 警示)
Step 3 - 计算成本缓冲:
  将最近 6 个月的每一笔日度融资净买入视为一次加仓:
    融资加权成本 = Σ(每日净买入金额 × 当日均价) / Σ每日净买入金额
    缓冲 = 现价 / 融资加权成本 - 1
Step 4 - 计算融资集中度:
  融资集中度 = 融资余额 / 近 20 日均成交额
  → 表示"如果所有融资盘同时平仓·需要几天才能完成"
  → > 5 天 = 警示（流动性不足以快速平仓·踩踏风险高）
Step 5 - 综合评级:
  🟢 健康: 增量阶段 + 缓冲 > 30% + 集中度 < 3 天
  🟡 警示: 稳态 + 缓冲 10-30% + 集中度 3-5 天
  🔴 危险: 存量阶段 + 缓冲 < 10% + 集中度 > 5 天

    二、量化交易监管四大新规（2026-06-07落地） 

    2.1 收紧高频交易阈值
  核心变化: 每秒申报/撤单频次上限大幅压缩；新增单日撤单率量化考核标准；
    纯高频刷单、虚假报撤策略彻底失效
  对量化: 过去一秒数十次挂撤单 → 不再可行；全天数万笔无效申报 → 触发监管；纯速度优势策略 → 淘汰
  对散户: 盘中无逻辑脉冲、瞬间闪崩减少；虚假突破、虚假破位减少；盘面走势更贴合真实资金供需

2.2 全面穿透式监管
  核心变化: 所有程序化交易账户全覆盖穿透式备案；
    同一控制人下的多账户合并计算交易频次/持仓/申报额度；完整量化交易实名备案制度
  对量化: 分仓马甲模式 → 彻底失效；数百个关联账户隐蔽交易 → 被穿透识别；
    零备案/隐形量化交易 → 直接认定为违规
  分析提示: 过去通过"股东户数骤降"识别量化吸筹的方法需要调整；
    穿透式监管实施后，分仓操作减少，股东户数变化信号更加可信

2.3 差异化交易成本调节
  核心变化: 高频/高撤单率/高波动量化 → 提高交易经手费+申报成本；中低频/合规量化 → 维持原标准
  影响: 高频套利策略盈利空间被压缩 → 主动退出市场

2.4 压实机构合规风控
  核心变化: 量化机构需建立严格内控+交易约束机制；市场剧烈震荡时主动收紧交易频次；
    违规从重处罚(罚款/暂停交易/限制展业/失信名单)；坚决杜绝"机器碾压人工"的不公平格局

Step 4: 信息真实性验证（2分钟）— 近期公告是否有"暗语"信号？分析师预测是否有"一窝蜂"修正？
        互动易有无关键信息？
Step 5: 资金行为验证（2分钟）— 龙虎榜:最近谁在买/卖？是真机构还是游资？北向:是连续流入还是脉冲？
        大宗交易:是折价还是溢价？接盘方是谁？
Step 6: 日历/环境验证（1分钟）— 当前时间窗口:顺风还是逆风？最近有无重大事件(两会/经济工作会议/期货交割)？
        基金排名战是否临近？
Step 7: 综合评分与决策（1分钟）— 用交叉分析矩阵计算总分
        ≥15分 → 可以入场 ；0-14分 → 减仓或等待 ；<0分 → 离场
总耗时: 约12分钟/只股票

    3.5 快速复习：最容易被忽视的5条致命规则（原文）¶

    1. 质押比>40%的股票永远不做多 — 这是一个定时炸弹，不管K线多漂亮
2. 北向单日大买+次日不持续 = 假信号 — 真外资从来不这样玩
3. 定增破发30%+且即将解禁 = 利益方非常可能拉升 — 这不是偶然，是A股的制度套利
4. 交易所问询函 = 公司存在监管层都看不下去的问题 — 散户凭什么认为自己比监管层更懂？
5. T+1环境下追涨停 = 今天买明天才能卖，而量化今天就能砸 — 这是一个结构性劣势
