    一、定位¶

    回答什么问题：A股原生价格行为分析体系。核心哲学是「A股 ≠ 美股/外汇」——布鲁克斯框架的原始背景是深度流动性·T+0·无涨跌停·可做空·机构博弈为主；A股的真实世界是 70%散户·T+1·±10%·非融券·政策市·主力主导。因此 Brooks 框架在 A股需要「制度翻译」+「量价验证」。

    在整体分析流程中的位置： 

    底层: 量价关系四阶段模型(建仓→洗盘→拉升→出货) + 拉升效率E引擎
中层: 均线系统(5/10/20/60/120/250) + SMC结构(FVG/OB/BOS/ChoCH) + 大形态(头肩/双顶/三角/楔形) + 缺口理论
上层: 布鲁克斯市场协议模型(Always-In/L1-L5/H-L段数/信号K线) 用于精确出入场
资金层: 龙虎榜游资席位 + 主力资金 + 北向 + 融资融券 + 筹码分布 + 大宗交易
验证层: MACD背离 + RSI + KDJ + 布林带 + ATR + OBV + VWAP 多指标共振
顶层: A股制度约束(T+1/涨跌停/融券/政策市) + 事件驱动(IPO抽血/解禁/减持/业绩预告)

    铁律升级（6条） 

    1. 每向下一层，必须获得上一层的"上下文许可"。量价不配合时，任何形态信号都视为噪音。
2. 【v4.0】Layer -1是总开关: 大盘环境为"高风险"时，所有做多信号降一级处理。
3. 【v4.0】Layer 0.5是急停开关: 出现主跌浪/千股跌停特征时，跳过常规分析直接进入极端应对流程。
4. 【v4.0】Layer 2.5是反向过滤器: 主力资金净流出+北向连续3日净卖出，所有做多信号无效。
5. 【v4.0】Layer 4.5是预判层: 重大事件(大IPO/解禁/业绩预告)前5个交易日，进入"事件防御模式"。

    二、分层结构（逐层判据与阈值）¶

    Layer -1【环境】大盘环境层（v4.0新增·总开关）¶

    "覆巢之下无完卵" — A股4000+个股中80%与大盘同向。不从大盘看个股 = 蒙眼开车。 7·13教训：7月13日上证-2.06%背景下，4600只个股下跌，176只跌停，任何"个股形态良好"的做多信号全部失效。

    -1.1 三级风险等级判定 

    🟢 绿灯·正常交易环境 (满足≥3条):
  □ 上证指数在MA20上方
  □ 全市场涨跌家数比 > 1.5 (上涨家数/下跌家数)
  □ 当日涨停>30只且跌停<10只
  □ 两市成交额 > 5日均量的90%
  □ 北向资金当日净流入或小幅净流出(<-30亿)
  □ 主力资金净流出 < 200亿
  → 操作:正常做多，所有PA信号按标准执行

🟡 黄灯·谨慎环境 (满足≥2条):
  □ 上证指数跌破MA20但守MA60
  □ 涨跌家数比 0.6-1.5
  □ 跌停 10-50只
  □ 成交额 < 5日均量80%
  □ 北向净流出 -30~-80亿
  □ 主力资金净流出 200-500亿
  → 操作:所有做多信号降一级(8分→9分入场)，仓位上限70%

🔴 红灯·高风险环境 (满足≥2条立即触发):
  □ 上证跌破MA60或MA120
  □ 涨跌家数比 < 0.6 (暴跌日)
  □ 跌停 > 50只 (千股跌停前兆)
  □ 北向净流出 > -80亿
  □ 主力资金净流出 > 500亿
  □ 上证连跌3日且加速
  → 操作:禁止开新多仓·持仓减至30%以下·只做防御或观望
  → 7·13案例:7月13日同时满足5条红灯条件，正确操作是开盘即减仓

    -1.2 指数PA先行原则 

    A股铁律:指数PA > 个股PA
  - 指数破位→个股形态再好也要先减仓
  - 指数主跌浪→个股"洗盘"判定全部无效(实际是出货)
  - 指数千股跌停→所有做多信号失效·只能等反弹

指数PA快速判定(沿用Layer 0-3方法学，应用于上证/创业板指):
  1. 指数量价四阶段判定(指数处于什么阶段?)
  2. 指数均线排列(MA5/10/20/60/120/250状态)
  3. 指数SMC结构(最近的BOS/ChoCH/FVG)
  4. 指数趋势强度L1-L5(主跌浪=L5反向)
  5. 指数是否出现极值反转K线(金针探底/十字星/锤头线)

7·13案例:上证指数7月13日收盘3913点
  - 跌破MA5/MA10/MA20，逼近MA60
  - 跌停176只→红灯条件
  - 北向-86.72亿→红灯条件
  - 主力净流出1092亿→红灯条件
  → 五重红灯·正确操作:开盘后30分钟内减仓至30%以下

    -1.3 风格切换识别 

    📈 成长→价值切换信号 (防御型):
  □ 上证50/沪深300强于创业板指/科创50 (连续2日)
  □ 银行/煤炭/石油/中药/电力 逆势上涨
  □ 北向资金流入上证50权重股
  □ 高股息率板块(股息率>5%)整体走强
  → 持仓调整:减成长股·加红利股·降Beta

📈 价值→成长切换信号 (进攻型):
  □ 创业板指/科创50强于上证50 (连续2日放量)
  □ 半导体/AI/算力/光模块板块率先反弹
  □ 北向资金回流科技龙头
  □ 两市成交额恢复到万亿以上
  → 持仓调整:加成长股·减红利股·提Beta

  → 经典"成长→价值"防御切换·应增持红利·减持科技

    -1.4 涨跌家数比(ADR)与市场情绪温度计 

    ADR (Advance/Decline Ratio) = 上涨家数/下跌家数

ADR分级:
  > 3.0   极度乐观·警惕见顶 (散户亢奋·主力开始派发)
  1.5-3.0 健康上涨·正常做多
  0.6-1.5 中性·震荡市
  0.2-0.6 偏弱·谨慎
  < 0.2   极度恐慌·关注超跌反弹 (7·13当天约0.17)

ADR背离预警 (高级):
  - 指数创新高但ADR递减 → 顶背离·少数权重撑指数·多数个股已跌
  - 指数创新低但ADR递增 → 底背离·恐慌衰竭·反弹临近

情绪温度计(综合指标):
  ┌─ 涨停/跌停比 (当日)
  ├─ 连板高度 (最高几连板)
  ├─ 炸板率 (涨停打开/全部涨停尝试)
  ├─ 涨停溢价率 (次日涨停股平均表现)
  └─ 龙虎榜游资活跃度 (上榜家数+席位数)

  综合得分>80:情绪过热·警惕
  综合得分50-80:正常
  综合得分<30:情绪冰点·关注反弹
  综合得分<15:极度冰点·重大底部区域 (7·13约20)

    Layer 0【基础】量价关系 + 四阶段模型（A股最底层逻辑）¶

    0.1 量价八宫格（核心决策矩阵）

    价升 价平 价跌
    量增 ✅ 健康上涨·真实买盘 ⚠️ 高位=出货·低位=吸筹 🔴 恐慌抛售或主动砸盘
    量平 🟡 温和上涨·筹码稳定 横盘蓄力·方向待选 自然回调·趋势未改
    量缩 🔴 量价背离顶！高位必跌 无人关注·冷门股 ✅ 洗盘/健康回调·主力未跑

    A股量价口诀（原文） 

    口诀1: 放量突破+缩量回踩 = 最佳做多信号
  → 突破日成交量 > 近5日均量×1.3
  → 回踩日成交量 < 近5日均量×0.7
  → 回踩不破突破K线的50%或关键均线

口诀2: 高位放量滞涨 = 出货（最可靠的离场信号）
  → 连续3-5日高位换手率>10%但价格不创新高
  → 成交量维持天量水平但K线实体缩小
  → 这是主力在分批出货，立即减仓！

口诀3: 低位缩量止跌+温和放量 = 建仓（最佳入场背景）
  → 价格在近半年低位区域
  → 成交量极度萎缩（<近20日均量×0.5），价不再跌
  → 随后出现温和放量阳线（非暴量）

口诀4: 量价顶背离 = 趋势衰竭
  → 价格创新高但成交量递减
  → 出现在L3-L5强势趋势后更可靠
  → 不一定立即反转，但是减仓信号

口诀5: 量价底背离 = 下跌动能衰竭
  → 价格创新低但成交量递减
  → 出现在长期下跌后更可靠
  → 观察等放量阳线确认

    量价配合度评分（0-10分，判断趋势健康度）

    得分 条件 含义
    8-10 放量涨+缩量跌，连续3个循环+ 🔥 极强趋势，放心持仓
    5-7 多数时间量价配合，偶有背离 ✅ 正常趋势
    3-4 量价分歧增多，背离出现 ⚠️ 趋势减弱，收紧止损
    0-2 量价背离主导，无配合 🔴 趋势即将反转或已失效

    0.3.1 量能标尺（放缩量判定基准）

    尺子 公式 判定标准
    换手率 当日成交量 ÷ 流通股本 × 100% <1%地量 / 1–3%正常 / 3–7%活跃 / 7–10%高度活跃 / >10%过热（随流通市值调整）
    量比 当日每分钟均量 ÷ 前5日每分钟均量 <0.8缩量 / 0.8–1.5正常 / 1.5–2.5温和放量 / 2.5–5明显放量 / >5剧烈放量
    相对均量 当日量 ÷ 前5–10日均量 ≥150%放量 / ≤60–70%缩量

    0.3.2 拉升效率 E：价格对成交量的弹性 

    E = 当日涨幅% ÷ 当日换手率%
含义: 每消耗 1% 换手，能买到多少涨幅（价格-成交量弹性）

参考区间:
  E > 1.5   高效(惜售/控盘)     |   0.5 – 1.5  正常
  0 – 0.5   低效(放量滞涨)      |   < 0        负(价格下跌·抛压主导)

核心用法(5条):
 1. 只看趋势不看单日: 3–5日平滑E曲线，观察中枢方向
 2. E持续下行 + 换手中枢抬升 = 密度边际恶化 = 顶部最早信号(领先价格下跌)
 3. 高位缩量创新高: E高但背离 → 必须回到位置判定，不可单看E
 4. 剥Beta: 系统性行情用"个股量比 ÷ 指数量比"修正E
 5. 涨跌停日E失真(封板换手率不代表真实分歧) → 剔除

    0.3.3 量价形态 → E 映射表（统一语言）

    量价形态 换手 涨幅 E 水平 核心解读
    缩量上涨 ↓ ↑ 高 惜售/控盘 · 高位警惕背离
    放量上涨 ↑↑ ↑ 中 资金进场 · 高位警惕天量
    放量下跌 ↑↑ ↓ 负 抛压释放 · 低位或最后一跌
    缩量下跌 ↓ ↓ 低 回踩健康 · 阴跌显弱
    放量滞涨 ↑↑ → 骤降 = 密度边际恶化 · 顶部最早信号
    堆量 缓↑持续 缓↑ 稳 主力持续建仓 · 最可靠
    脉冲放量 单日暴量 一日游 回落 对倒/游资 · 追高易套

    三语言同一信号: 放量滞涨(量价) ≡ 密度边际恶化(筹码) ≡ E骤降(效率)。E 就是量价与筹码的统一数字刻度。

    0.3.4 密度边际恶化识别流程（顶部最早信号） 

    1. 每日计算 E = 涨幅% ÷ 换手率%，3–5日平滑
2. 同时满足: E中枢持续下行 + 换手中枢持续抬升
3. 交叉验证: 涨幅收窄(放量滞涨) / 获利盘>85% / 筹码峰停止上移
4. 满足2条以上 → 按顶部最早信号处理: 先减仓 + 设确认条件(跌破均线/放量长阴再离场)

    1.5.1 六大顶部反转形态 

    【1. 头肩顶】结构:左肩(高点)→头部(最高点)→右肩(次高点)→跌破颈线
  A股特征: 头部天量·右肩缩量(量价背离)；跌破颈线后回踩颈线=最后逃命点；
           跌幅目标=头部到颈线距离的1:1
  操作: 右肩成型即减仓50%·跌破颈线清仓
【2. 双顶/M顶】结构:两个相近高点·中间有回调
  特征: 第二顶缩量(常见)；跌破中间低点确认；跌幅目标=高点到中间低点的1:1
  操作: 第二顶缩量即减仓·跌破中间低点清仓
【3. 三重顶】三个相近高点；罕见·但出现即重磅·跌幅目标更大；第三顶减仓·跌破颈线清仓
【4. 圆弧顶】缓慢上涨→横盘→缓慢下跌·弧形
  特征: 主力长期派发·持续数月；成交量随弧度递减；跌破弧形右沿加速
  操作: 弧形右沿成型即减仓
【5. 岛型反转】跳空上涨→横盘→跳空下跌·形成"孤岛"
  特征: 极强反转信号·通常由利好/利空触发；跳空缺口不回补
  操作: 确认后立即反向操作
【6. 扩散顶/喇叭顶】高点更高·低点更低·振幅扩大
  特征: 情绪极端化·散户疯狂；主力借震荡派发
  操作: 减仓·等方向明确

    1.5.2 六大底部反转形态 

    【1. 头肩底】左肩(低点)→头部(最低点)→右肩(次低点)→突破颈线

  操作: 右肩缩量止跌试探仓·突破颈线加仓
【2. 双底/W底】两个相近低点·中间有反弹
  特征: 第二底缩量(常见·抛压枯竭)；突破中间高点确认；涨幅目标=低点到中间高点的1:1
【3. 三重底】罕见·主力强力吸筹·涨幅更大
【4. 圆弧底】缓慢下跌→横盘→缓慢上涨；主力长期吸筹·持续数月；成交量随弧度递增；
  突破弧形右沿加速；操作:弧形右沿成型即建仓

【6. 岛型反转底】跳空下跌→横盘→跳空上涨；极强反转·通常由利空出尽触发

    1.5.3 持续形态（中继形态） 

    【1. 上升三角形】水平阻力+上升支撑线 → 买盘渐强·突破概率大 → 突破阻力位+放量·追入
【2. 下降三角形】水平支撑+下降阻力线 → 卖盘渐强·跌破概率大 → 跌破支撑·减仓
【3. 对称三角形】上升支撑+下降阻力·收敛 → 方向待选 → 不预判·突破后追入
【4. 上升旗形】急涨后小幅回调·旗形 → 强趋势中继 → 旗形下沿买入·止损跌破
【5. 下降旗形】急跌后小幅反弹·旗形 → 弱趋势中继 → 旗形上沿减仓
【6. 矩形/箱体】水平支撑+水平阻力 → 震荡·等方向 → 箱底买·箱顶卖·突破跟随
【7. 楔形】上升楔形:两线向上收敛·看跌；下降楔形:两线向下收敛·看涨 → 楔形末端·等突破方向

    1.5.4 缺口理论（A股特殊意义） 

    A股缺口类型:
  1. 普通缺口: 震荡区·短期回补 → 操作:忽略
  2. 突破缺口: 突破关键阻力/支撑·形成缺口；通常不回补(与美股不同·A股突破缺口回补率约40%)
     → 操作:突破方向追入·不等待回补
  3. 中继缺口: 趋势中段·顺势跳空；加速信号·趋势延续 → 操作:顺势加仓
  4. 衰竭缺口: 趋势末段·最后跳空；通常快速回补·反转信号 → 操作:缺口回补后反向操作
  5. 涨停缺口(A股特有): 涨停一字板·形成缺口；强庄控盘·通常不回补
     → 操作:不开板继续持有·开板放巨量减仓
  6. 跌停缺口(A股特有): 跌停一字板·形成缺口；恐慌宣泄·可能继续跌停
     → 操作:不抄底·等跌停打开

A股缺口实战规则:
  - 向上跳空缺口+放量 = 强势·不回补可追
  - 向上跳空缺口+缩量 = 弱势·大概率回补
  - 向下跳空缺口+放量 = 恐慌·可能继续跌
  - 向下跳空缺口+缩量 = 利空出尽·可能反弹
  - 三空见底 (连续3个向下缺口) = 恐慌衰竭·关注反弹
  - 三空见顶 (连续3个向上缺口) = 极度亢奋·警惕

7·13缺口分析: 上证7·13开盘即跳空低开 → 跳空缺口+全天单边下跌 = 突破缺口(向下)
  → 通常不回补·趋势延续·确认下跌趋势

  - 高位筹码分散 + 放量滞涨 = 出货信号
  - 低位筹码锁定 (不向低位转移) = 主力控盘·可持有
  - 高位筹码向低位转移 = 主力出货·减仓

    2.5.6 大宗交易确认（v4.2新增·场外暗盘层） 

    大宗交易 = 盘后场外成交·无法被盘口对倒直接伪造·最诚实的"聪明钱"证据
折溢价率 = (大宗成交价 − 当日收盘价) ÷ 当日收盘价

判定规则:
  - 折价 > 5% 且持续多笔 → 大股东/机构急于出货 → 危险信号
  - 平价/溢价 + 买方为知名机构 → 大资金抢筹 → 确认利好
  - 同一席位既买又卖(左手倒右手) → 疑似做局·警惕
  - 与减持公告联动检查: 减持计划 + 大宗折价 = 出货确认

与盘面信号交叉确认(共振才动手·背离即认错):
  低位放量上涨 + 大宗平价/溢价+北向流入+机构净买 → 确认吸筹 → 机会
  低位放量上涨 + 大宗持续折价+龙虎榜机构净卖   → 证伪 → 诱多概率大
  高位放量滞涨 + 龙虎榜机构净卖+融资余额见顶   → 确认派发 → 离场
  高位缩量新高 + 大宗折价出货+北向流出         → 确认背离 → 警惕

数据源: 交易所每日盘后披露·东方财富/同花顺大宗频道
渠道可信度(防造假): 龙虎榜机构席位 > 大宗折溢价 > 两融余额 > 北向(滞后) > 盘面量价(单日最易伪造)

    Layer 2.75【验证】经典技术指标验证层（v4.1新增·信号验证层）¶

    "技术指标是PA的辅助工具，不是替代品"。定位: Layer 2.5（资金行为）→ Layer 2.75（指标验证） → Layer 3（精确执行）。 多指标与PA形成闭环：量价→均线→SMC→资金→指标验证→执行

    2.75.0 验证层铁律 

    Rule V1: 不独立决策。技术指标只用于确认或否决Layer -1~2.5形成的PA判断。
Rule V2: 多指标共振提升置信度，分歧时降仓。≥3个指标同向=强共识；2个分歧=观望。
Rule V3: 技术指标的优先级低于量价关系和资金行为。MACD金叉但主力流出→不买。
Rule V4: 指标背离是PA信号的最强验证——MACD/RSI的背离可独立否决PA信号。
Rule V5: 单指标参数不可过度优化。用标准参数(N=12/26/9, 14, 9/3/3, 20/2)。
Rule V6: 任何指标信号都需要"量价配合"才能用于决策。

    2.75.1 MACD — 趋势跟踪与背离之王

    参数: 快线EMA12 / 慢线EMA26 / 信号线SMA9 / 柱状图DIF-DEA

    【用途1：趋势方向判定】
  DIF > 0 且 DEA > 0 + 柱状图正值放大 = 多头趋势
  DIF < 0 且 DEA < 0 + 柱状图负值放大 = 空头趋势
  DIF 在零轴上方且向上 = 多头强势；DIF 在零轴下方且向下 = 空头强势
  DIF 在零轴附近缠绕 = 趋势不明·观望

【用途2：金叉/死叉信号】
  金叉 (DIF上穿DEA):
  - 零轴上方金叉 = 强势延续·回调结束信号 → 配合缩量回踩MA线更可靠
  - 零轴下方金叉 = 弱势反弹·可能只是反弹不是反转
  - 背离后的金叉 = 趋势反转信号（最强！）
  死叉 (DIF下穿DEA):
  - 零轴上方死叉 = 趋势减弱·减仓信号
  - 零轴下方死叉 = 继续下跌·空仓信号
  - 顶背离后的死叉 = 趋势终结信号（立即离场）

【用途3：MACD背离 — PA最强验证工具】
  顶背离 (价格新高·MACD未新高):
  - 价格创新高但DIF/柱高点递减 → 趋势衰竭的量化确认 → 配合Layer 4·至少减仓50%
  底背离 (价格新低·MACD未新低):
  - 价格创新低但DIF/柱低点抬高 → 下跌动能耗尽的量化确认 → 配合Layer 0.5·可建试探仓
  A股MACD背离实战规则:
  - 日线级别背离 > 60分钟级别背离（周期越大越可靠）
  - 出现2次背离后更可靠（A股常见双重背离）
  - 背离必须配合量价背离（价新高量递减→MACD背离更可靠）
  - 底背离后需等放量阳线确认，不能单独入场
  - 顶背离后可直接减仓，不等死叉确认

【用途4：柱状图动量分析】
  柱状图由长变短 = 动量衰减·趋势可能转折；由短变长 = 动量增强·趋势加速
  由正转负 = 多头衰竭·减仓信号；由负转正 = 空头衰竭·准备入场
  柱状图二次放大 = 第二波趋势启动（强势特征）

【用途5：多周期MACD共振】
  周线MACD多头 + 日线MACD回调结束 + 60分钟MACD金叉 = 最佳入场时机
  周线MACD空头 + 日线MACD反弹 + 60分钟MACD死叉 = 反弹结束·减仓

MACD与PA各层结合:
  - MACD金叉 + Layer 0缩量回踩MA20 + Layer 2 H2回调 = 高置信度做多信号
  - MACD顶背离 + Layer 1.5头肩顶 + Layer 2.5主力流出 = 清仓信号
  - MACD底背离 + Layer 0.5恐慌衰竭≥3条 + Layer 0.5超跌反弹条件满足 = 抄底准备

    2.75.2 RSI — 超买超卖与动量背离

    参数: 标准RSI(14) / 短期RSI(9) / 长期RSI(21) 多周期组合

    【用途1：超买超卖区间】
  RSI > 80: 严重超买·警惕回调（A股修正）
    配合Layer 1.5高位反转形态+Layer 2.5主力流出→减仓
    不单独作为卖出信号（强势股可长期RSI>80）
  RSI < 30: 超卖·关注反弹（Layer 0.5已覆盖）
    配合Layer 0.5恐慌衰竭信号+底背离→更可靠；不单独作为抄底信号（熊市可长期RSI<30）
  RSI 30-70: 正常区间·按PA信号操作
  RSI 50: 多空分界线·RSI>50=多头主导·RSI<50=空头主导

【用途2：RSI背离 — 与MACD背离形成信号闭环】
  看跌背离（顶背离）: 价格创新高 + RSI未创新高（甚至走低）→ 上涨动量衰竭
    PA验证: 配合Layer 1.5顶部形态+Layer 2.5资金流出
    操作: 至少减仓30%，若同时MACD也背离→减仓70%
  看涨背离（底背离）: 价格创新低 + RSI未创新低（甚至走高）→ 下跌动量衰竭
    操作: 放量阳线确认后入场
  双重背离验证:
  - RSI背离 + MACD背离同时出现 = 最强技术信号，概率>80%

【用途3：多周期RSI共振】
  周线RSI>50 + 日线RSI回调到50附近 + 60分钟RSI<30超卖 = 回调入场
  周线RSI<50 + 日线RSI反弹到70附近 + 60分钟RSI>80超买 = 反弹结束

【用途4：RSI趋势线突破】
  RSI跌势线突破（斜率由负转正）= 价格可能见底
  RSI涨势线跌破（斜率由正转负）= 价格可能见顶
  可提前1-3根K线发出信号

RSI与PA各层结合:
  - RSI(14)<30 + Layer 0.5恐慌衰竭≥3 + 底背离 = 超跌反弹可入场
  - RSI日线背离 + 周线背离 + 量价背离 = 三重背离·趋势已死
  - RSI>80 + Layer 1.5顶部形态 + Layer 2.5主力流出 = 顶部分析确认

    2.75.3 KDJ — A股短线超买超卖首选

    参数: K(9,3,3) / D(9,3,3) / J = 3K-2D

    【用途1：超买超卖区域】
  K/D值: > 80: 超买·短线回调概率增大 ；< 20: 超卖·短线反弹概率增大
  J值（KDJ最敏感的线）:
  J > 100: 极值超买·警惕短线回调 ；J < 0: 极值超卖·短线反弹随时出现
  J > 120: 极度超买·次日高开减仓（A股实战经验） ；J < -20: 极度超卖·准备抄底

【用途2：金叉死叉】
  金叉 (K上穿D): 短线买入信号 — 低位(<30)金叉更可靠；配合RSI同时金叉 = 共振
  死叉 (K下穿D): 短线卖出信号 — 高位(>70)死叉更可靠

【用途3：KDJ背离（短线验证）】
  顶背离→配合Layer 4离场 ；底背离→配合Layer 0.5入场
  注意: KDJ背离周期短于MACD/RSI，日线以下更适用

【用途4：KDJ钝化与强势股】
  KDJ在超买区反复钝化=强势股特征（不因超买而做空）
  KDJ在超卖区反复钝化=弱势股特征（不因超卖而抄底）
  → 此时应以均线+量价为主，KDJ仅供参考

KDJ与PA各层结合:
  - KDJ低位金叉 + Layer 0缩量止跌 + MA支撑 = 短线入场信号
  - KDJ高位死叉 + Layer 1.5顶部形态 + 量价背离 = 短线离场
  - J>100 + Layer 2.5主力流出 + 高位换手 > 均线多头优先级（矛盾时以资金面为准）

    2.75.4 布林带Bollinger Bands — 波动率与挤压突破

    参数: 周期20 / 标准差2 / 中轨=MA20

    【用途1：轨道含义】
  价格触及上轨 → 强势但短线可能超买；价格触及下轨 → 弱势但短线可能超卖
  价格沿上轨行走 → 强势趋势·不做空；价格沿下轨行走 → 弱势趋势·不做多
  价格在中轨之上 → 多头主导；价格在中轨之下 → 空头主导
  中轨方向 = MA20方向 = 中期趋势方向

【用途2：布林带挤压（Squeeze）】
  布林带宽度极度收窄（近半年最窄）: 低波动·蓄力·即将突破
  - 对应Layer 2: 蓄力阶段→方向突破
  - 突破方向判断: 配合Layer 0量价+Layer 1均线
  - 操作: 挤压末端不预判方向·突破放量方向追入
  - A股实战: 挤压时间越长→突破力度越大
  布林带开口扩大: 波动扩张·趋势启动确认 → 沿开口方向操作

【用途3：布林带与MA系统结合】
  布林带中轨 = MA20 = Layer 1趋势生命线
  布林带上轨 = PA超买阻力参考；布林带下轨 = PA超卖支撑参考
  缩口 + 均线粘合(Layer 1.3) = 多周期共振的强信号
  结合策略:
  - 布林带缩口 + Layer 1均线粘合(<5%) = 主力建仓完毕
  - 布林带开口 + Layer 0放量突破 = 拉升启动
  - 价格突破上轨3日 + Layer 2.5资金流出 = 假突破陷阱

    2.75.5 ATR — 波动率量化与止损锚定

    参数: ATR(14) 或 ATR(20)

    【用途1：趋势强度判断】
  当前ATR > 近20日ATR均值×1.5 = 波动放大·趋势加速
  当前ATR < 近20日ATR均值×0.5 = 波动萎缩·蓄力
  ATR递增 + 价格沿MA5上行 = 强势趋势 ；ATR递减 + 价格横盘 = 蓄力或洗盘末期

【用途2：ATR止损设置】
  做多止损 = 入场价 - N × ATR
  N值选择: 短线(追涨停/打板): N=1×ATR / 中线(波段持有): N=2×ATR / 长线(趋势持仓): N=3×ATR
  优势: 根据个股波动率自适应（高波动宽止损·低波动窄止损）；避免固定百分比止损被"震出去"

【用途3：ATR目标位设定】
  目标1 = 入场价 + 1×ATR (短线)；目标2 = +2×ATR (中短线)；目标3 = +3×ATR (波段)
  盈亏比(R:R)计算: 预期涨幅/止损幅度(以ATR为单位)

【用途4：波动率过滤】
  ATR < 近60日均值×0.4 = 地量波动·不参与（无波动空间）
  ATR极大(>均值×2) + 方向不明 = 不适合入场（风险过大）

ATR与PA各层结合: Layer 3精确入场价 + ATR止损距离 = 标准止损位；1:3盈亏比 = 收益目标/ATR止损 至少3倍

    2.75.6 OBV能量潮 — 量能趋势的前瞻验证 

    公式: 今日OBV = 昨日OBV + (当日涨幅>0? +成交量 : 当日跌幅<0? -成交量 : 0)

【用途1：趋势验证】
  OBV与价格同向上升 = 量价配合·趋势健康 → 确认Layer 0量价八宫格的"健康上涨"
  OBV下降+价格上涨 = 缩量上涨·上涨动力不足·警惕 → 对应量价背离
  OBV上升+价格横盘 = 资金暗中吸筹·即将启动 → 配合Layer 0四阶段建仓期判断
  OBV下降+价格横盘 = 资金暗中出货·警惕下跌 → 配合出货期判断

【用途2：OBV背离】
  看跌背离: 价格创新高 + OBV未创新高（甚至走低）→ 上涨缺乏成交量支撑·即将见顶
    优先级: OBV背离 > MACD/RSI背离中的任何单一指标背离
    （因为成交量(OBV)直接反映资金行为，而MACD/RSI是价格的二次计算）
  看涨背离: 价格创新低 + OBV未创新低（甚至走高）→ 下跌中资金暗中买入·即将见底
    配合Layer 0.5恐慌衰竭抄底信号

【用途3：OBV趋势线突破】
  OBV自身的趋势线突破往往比价格趋势线突破早1-3日:
  - OBV突破下降趋势线 = 资金率先入场·买入信号
  - OBV跌破上升趋势线 = 资金率先离场·卖出信号

【用途4：OBV均线交叉】
  OBV的MA30/MA60均线: OBV上穿MA30=资金趋势转多；下穿MA30=转空；OBV在MA60上方=中长期资金面健康

OBV与PA各层结合:
  - OBV背离 + MACD背离 = 双重背离·极高可靠度
  - OBV率先突破 + Layer 0放量阳线 = 买入信号加速确认
  - OBV走平 + Layer 1均线粘合 = 蓄力阶段·准备突破
  OBV的优势: 它是Layer 2.5资金行为在PA层的"提前指标"体现

    2.75.7 VWAP — 日内多空分界线与机构成本 

    公式: VWAP = Σ(价格×成交量) / Σ(成交量)  日内累积计算

【用途1：日内多空分界线】
  价格在VWAP上方 = 多头日内主导·偏强；下方 = 空头日内主导·偏弱；围绕VWAP震荡 = 日内方向不明
  VWAP斜率向上 = 日内多头趋势·沿VWAP做多；斜率向下 = 日内空头趋势·沿VWAP做空(如有融券)

【用途2：VWAP的回测验证】
  价格跌破VWAP后回测VWAP不破 = 支撑确认·可入场
  价格突破VWAP后回测VWAP不破 = 突破确认·可加仓
  价格远离VWAP(>3×ATR) = 超买/超卖·可能回归

【用途3：机构行为识别】
  VWAP稳步上行 + 成交量放大 = 机构买入；VWAP快速上行后回落 = 机构买入后散户跟风
  尾盘价格背离VWAP = 操纵·警惕

【用途4：VWAP与Layer 0量价结合】
  放量突破VWAP + 价格站稳 = 日内趋势确认；缩量回踩VWAP不破 = 日内回调入场

VWAP与PA各层结合: 主要用于日内短线交易（超短线/做T/盘中决策）
  - Layer 3执行层面: VWAP作为入场/离场的实时锚点
  - Layer 2.5机构资金行为在日内尺度的体现

    2.75.8 多指标共振引擎 

    当≥3个技术指标发出同向信号时，形成"强共振"，大幅提升PA信号的置信度。

做多共振条件 (满足≥3条):
  □ MACD金叉或零轴上方多头运行
  □ RSI>50且无顶背离
  □ KDJ金叉或K/D>50
  □ 价格在布林带中轨上方
  □ ATR温和（>20日均值×0.5）
  □ OBV与价格同向上升
  □ VWAP上行+价格在上方（日内）

做多共振评分:
  7/7 = 🔥极强做多共振·满仓做多
  5-6/7 = ✅强共振·正常做多
  3-4/7 = 🟡中共振·半仓操作
  1-2/7 = ⚠️弱分歧·观望或减仓
  0/7 = 🔴共振失败·重新评估

做空共振条件 (满足≥3条):
  □ MACD死叉或零轴下方空头运行 ；□ RSI<50且无底背离 ；□ KDJ死叉或K/D<50
  □ 价格在布林带中轨下方 ；□ ATR递减中 ；□ OBV与价格同向下降 ；□ VWAP下行+价格在下方（日内）

共振信号应用铁律:
  1. 共振 = 辅助确认PA信号，不能替代PA
  2. PA信号与共振方向一致→执行
  3. PA信号与共振方向矛盾→降低仓位
  4. PA信号无明确方向+共振方向明确→观望
  5. PA+资金+指标三者全方向一致→最高置信度

7·13应用: 7·13前若MACD顶背离+RSI顶背离+量价背离 → 三重背离=极强做空共振

    3.5 A股特有陷阱规避（六大陷阱） 

    陷阱1: 尾盘30分钟拉升陷阱（最经典的诱多）
  → 全天弱势，尾盘突然放量拉升
  → 90%是主力出货前制造"明天会涨"的假象
  → 对策: 尾盘拉高不追！等次日开盘验证

陷阱2: 集合竞价试盘（9:15-9:25）
  → 9:15挂涨停 → 9:20撤单 → 真实意图暴露
  → 9:20后不能撤单的挂单才是真实意愿
  → 对策: 只关注9:20后的集合竞价变化

陷阱3: 涨停板诱多（打板族最怕的）
  → 涨停打开+放巨量 → 主力在涨停板上出货
  → 涨停封单量急剧减少 → 次日大概率低开
  → 对策: 涨停封单减少>50%+换手>10% → 次日开盘离场

陷阱4: T+1制度下的"假突破"
  → 当日强势突破 → 散户追入 → 次日直接低开套牢
  → 为什么: T+1下当日无法反手，次日才能卖
  → 对策: 突破后等待回踩确认（至少次日！）再入场

陷阱5: 缩量跌的两种截然不同含义
  → 洗盘: 缩量砸盘 → 主力没跑 → 洗盘结束会快速回
  → 阴跌: 缩量阴跌 → 无人关注 → 可能跌很久
  → 区分: 洗盘有"急跌+急回"特征，阴跌是"慢跌+不回"

陷阱6: 高换手+高涨幅后的"次日闷杀"
  → 前天大涨+超高换手(>10%)
  → 次日高开低走 → 游资出货
  → 特征: 利好/题材催化，连续上涨后换手暴增
  → 对策: 持仓者在超高换手次日开盘减仓50%+

    Layer 3.5【联动】板块联动PA（v4.0新增）¶

    3.5.1 板块情绪温度计 

    🔥 极热板块 (涨停>10只·板块涨幅>5%): 主升浪中·但警惕过热 → 已持有继续·追高谨慎
🟠 偏热板块 (涨停5-10只·板块涨幅2-5%): 强势·可操作 → 龙头回调入场
🟡 正常板块 (涨停<5只·板块涨幅-2%~2%): 震荡·观望 → 个股机会·板块不强
🟢 偏冷板块 (板块跌幅2-5%): 弱势·回避 → 不碰
❄️ 极冷板块 (板块跌幅>5%·跌停>5只): 主跌·严禁抄底 → 等止跌

板块情绪轮动规律: 极热 → 偏热 → 正常 → 偏冷 → 极冷 → 偏冷 → 正常 → ...
板块轮动节奏:
  - 一个板块极热通常持续3-5日
  - 极热后必冷却·回调20-30%
  - 板块间跷跷板:科技热→消费冷→周期热

    3.5.2 龙头股战法 

    A股铁律:做板块必做龙头
龙头股识别: 🥇绝对龙头(板块涨幅第一·涨停最早·封单最大) 🥈准龙头(涨幅第二·跟随龙头) 🥉龙三(涨幅第三·跟风)
战法1: 龙头首阴战法 — 板块连续上涨·龙头首次收阴；缩量回调·不破MA5；次日反包·继续上涨 → 首阴次日反包时追入
战法2: 龙头回调战法 — 回调到MA10/MA20；缩量止跌·出现反转K线；板块情绪未死 → 回调位介入·止损破MA20
战法3: 龙头切换战法 — 老龙头滞涨·新龙头启动（新龙头通常是老龙头的替代）→ 卖老买新
战法4: 龙头补涨战法 — 龙头停牌或一字涨停·买不进 → 找龙二·龙三补涨·短线
龙头股禁忌:
  ❌ 龙头滞涨·龙三四还在涨 = 板块见顶信号·减仓
  ❌ 龙头放量跌停 = 板块死亡·清仓所有相关股
  ❌ 龙头连续3日不创新高 = 板块走弱·减仓

    3.5.3 板块跷跷板效应 

    经典跷跷板组合: 科技↔消费 / 成长↔价值 / 周期↔防御 / 新能源↔传统 / 小盘↔大盘

    Layer 4.5【事件】事件驱动PA（v4.0新增·预判层）¶

    "事件是催化剂，PA是结果" — A股是政策市+事件市，重大事件能瞬间改变PA结构。 7·13案例:长鑫存储295亿IPO是7·13暴跌的核心催化剂之一，机构为打新抛售科技股。

    4.5.1 重大事件类型与PA影响 

    【1. IPO抽血】(7·13核心催化剂) 影响:短期(1-2周)·负面
  机制: 大额IPO吸走市场流动性；机构为打新抛售存量持仓；抽血效应集中在申购日前5个交易日
  PA表现: 前期热门板块放量下跌；大盘缩量(流动性被抽走)；龙头股领跌
  应对: 大额IPO(>100亿)前5个交易日减仓；IPO申购日当天不抄底；IPO结束后2-3日观察流动性恢复
  7·13案例: 长鑫存储295亿IPO，7月13日启动网下询价，机构集中抛售科技股回笼资金
            + 韩股熔断 + 中报验证期 三重共振

【2. 限售股解禁】影响:短期(解禁前后5日)·负面
  机制: 解禁股可流通·供给增加；解禁股东可能减持；心理压力大于实际减持
  PA表现: 解禁前5日股价滞涨·主力撤离；解禁日放量下跌；解禁后可能反弹(利空出尽)
  应对: 大额解禁(>流通市值20%)前5日减仓；解禁日不抄底；解禁后3日观察是否企稳

【3. 股东减持】影响:短期(1-3月)·负面
  PA表现: 减持公告日低开·放量；减持期持续弱势；减持结束可能反弹
  应对: 减持公告日减仓；减持期内不重仓；减持结束观察

【4. 业绩预告/财报】影响:中期(1-3月)·双向
  PA表现: 超预期=跳空高开+放量·趋势启动；业绩雷=跳空低开+放量·趋势终结；符合预期=短期震荡
  应对: 业绩预告前5日减仓规避不确定性；超预期放量阳线确认后追入；业绩雷跌停板挂单卖出
  7·13特殊背景: 7月15日中报预告强制披露截止日 → 资金提前避险·抛售高估值成长股

【5. 政策事件】影响:中长期(1-6月)·双向
  PA表现: 重大利好=跳空高开+涨停潮；重大利空=跳空低开+跌停潮；政策预期=板块提前启动
  应对: 重大会议前1月布局政策受益板块；政策落地利好出尽减仓；政策超预期加仓

【6. 海外事件传导】(7·13核心催化剂) 影响:短期(1-3日)·负面居多
  PA表现: 海外暴跌次日A股低开；北向资金大幅流出；与海外联动强的板块跌幅最大
  应对: 海外暴跌当晚评估A股影响；次日开盘观察是否跳空；
        跳空低开+放量→减仓；跳空低开+缩量→观望
  7·13案例: 韩KOSPI-8.95%熔断、SK海力士-15.37%、A股存储/光模块/CPO全线暴跌、北向-86.72亿

    4.5.2 事件日历PA管理 

    月度事件日历必看项:
  □ IPO时间表 (大额IPO>50亿重点标注)
  □ 解禁日历 (大额解禁>流通市值10%重点标注)
  □ 业绩披露时间表 (1月/4月/7月/10月预告·4月/8月/10月财报)
  □ 重要会议时间 (中央经济工作会议·两会·美联储议息·国常会)

事件防御模式 — 重大事件前5个交易日:
  - 持仓减至50%以下 ；- 不开新仓 ；- 收紧止损至EMA ；- 准备应对方案 (利好/利空/中性三套)

  - 开盘前评估事件结果 ；- 利好:等回踩入场·不追高 ；- 利空:开盘减仓·不抄底 ；- 中性:按原计划

    4.5.3 政策市PA特征 

    【1. 政策底vs市场底】
  政策底: 政府出台利好·指数短期反弹
  市场底: 政策底后·指数再次下跌·真正见底
  时间差: 通常1-3个月 ；空间差: 市场底通常比政策底低5-10%
  应对: 政策底出现不急抄底；政策底后的反弹减仓；市场底确认(地量+长下影)抄底

【2. 救市政策类型】
  - 降准降息:中期利好·但短期可能不涨 ；- 限制做空:短期利好·但中期无效
  - 汇金增持:强烈信号·通常见底 ；- 暂停IPO:强烈信号·流动性改善 ；- 降低印花税:强烈信号·短期大涨

  决策: 红灯→禁止做多·黄灯→降级操作·绿灯→正常操作

第一步：数据获取（并行）

  → 计算拉升效率E(涨幅÷换手率·5日平滑)+量比+换手率序列 (v4.2新增)
  → 获取龙虎榜/北向/融资融券数据 (资金行为层)
  → 获取大宗交易折溢价数据 (v4.2新增·场外暗盘层)
  → 查询事件日历 (IPO/解禁/业绩/政策)

  输出: 当前处于建仓/洗盘/拉升/出货的哪个阶段？

第九步：A股陷阱扫描

  大盘风险等级×板块情绪×个股PA×指标验证 = 最终仓位

    3.2 A股原生PA铁律（A1-A20，原文标注为"十二大铁律(v4.0升级)"但实际列至A20）¶

    Rule A1: 量在价先。任何没有量能确认的K线信号 = 噪音。
Rule A2: 先定阶段，再定方向。建仓/洗盘/拉升/出货 → 阶段决定策略。
Rule A3: 均线多头=牛市思维，均线空头=熊市思维。不逆均线方向。
Rule A4: 放量突破+缩量回踩=最佳入场。放量滞涨+高位换手=立即走。
Rule A5: T+1下不追日内突破。等次日回踩确认。错过大涨比套在山顶好。
Rule A6: 涨停板的K线信号不可读取。制度失真的K线没有任何分析价值。
Rule A7: 缩量下跌≠趋势反转。在拉升期中，缩量急跌=洗盘（加仓信号！）
Rule A8: 尾盘急拉的阳线是诱多。90%是主力为次日出货做准备。
Rule A9: 不猜顶不抄底。等结构确认。利润=趋势的中间80%。
Rule A10: 出手前问三遍：量价配合吗？均线多头吗？主力在出货吗？
Rule A11 (v4.0新增): 大盘红灯不开多仓。覆巢之下无完卵。
Rule A12 (v4.0新增): 主力+北向双流出，所有做多信号无效。资金真相>形态表象。
Rule A13 (v4.0新增): 重大事件前5日，强制减仓至50%以下。事件是最大的不确定性。
Rule A14 (v4.0新增): 主跌浪中所有"洗盘"判定无效。暴跌不是洗盘，是出货。
Rule A15 (v4.0新增): 千股跌停首日绝不抄底。等恐慌衰竭信号≥3条。
Rule A16 (v4.1新增): 指标不独立决策。MACD/RSI/KDJ等经典指标只用来验证PA信号，不能替代量价+资金。
Rule A17 (v4.1新增): 多指标背离是最强验证。MACD+RSI+OBV三重背离可独立否决PA做多信号。
Rule A18 (v4.1新增): PA与指标共振时执行，分歧时降仓。多指标7维评分<3分时降低仓位50%。
Rule A19 (v4.2新增): 拉升效率E是量价的第一标尺。E持续下行+换手上行=密度边际恶化=顶部最早信号，领先于放量滞涨形态本身。
Rule A20 (v4.2新增): 堆量>暴量。单日暴量可被对倒伪造，连续堆量+E稳定才是真实建仓；脉冲放量(次日打回原形)一律规避。
