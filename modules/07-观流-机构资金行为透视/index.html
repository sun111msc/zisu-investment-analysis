    二、分层结构（逐层判据与阈值）¶

    第一层 Gamma暴露与做市商对冲（gamma-dealer-mechanics.md）¶

    做市商的根本约束 

    做市商(Market Maker/Dealer):
  - 利润来源: 买卖价差(Bid-Ask Spread)，而非方向性押注
  - 核心约束: 必须保持Delta中性（方向性风险为零）
  - 被动角色: 投资者买Call → MM必须卖Call（永远是交易对手方）
  - 库存管理: 持有的期权头寸=库存，Delta偏离零时必须对冲
核心洞察: 做市商不是"预测者"，他们是"对冲机器"
  他们被迫的对冲行为 = 市场上最可靠的买入/卖出压力来源

    做市商对冲的"镜像规则" 

    投资者的操作      做市商的库存变化     做市商的对冲行为
──────────────────────────────────────────────────
买入Call          Short Call          买入标的(正Delta对冲)
卖出Call          Long Call           卖出标的(负Delta对冲)
买入Put           Short Put           卖出标的(负Delta对冲)★
卖出Put           Long Put            买入标的(正Delta对冲)

★ 关键: Short Put = 做市商持有正的Delta风险
  → Put变得更实值 → Delta绝对值增大 → 正Delta更大 → 做市商必须卖出更多标的
  → 这就是为什么Put Wall附近存在强大的"顺势卖出压力"

    Gamma 暴露（GEX） 

    GEX (Gamma Exposure) = 做市商全市场净Gamma头寸的总和
Long Gamma (>0):
  ├─ 做市商整体持有多头Gamma
  ├─ 对冲行为: 价格涨→卖出、价格跌→买入（高抛低吸）
  └─ 市场效应: 抑制波动、均值回归
Short Gamma (<0):
  ├─ 做市商整体持有空头Gamma
  ├─ 对冲行为: 价格涨→买入、价格跌→卖出（追涨杀跌）
  └─ 市场效应: 放大波动、趋势加速

    零Gamma水平 — 市场的"分水岭" 

    价格 > 零Gamma水平 → Long Gamma体制
  ├─ 做市商高抛低吸
  ├─ 市场特征: 低波动、均值回归、区间交易
  └─ 策略: 铁鹰(Iron Condor)、区间交易
价格 < 零Gamma水平 → Short Gamma体制
  ├─ 做市商追涨杀跌
  ├─ 市场特征: 高波动、趋势加速、暴涨暴跌
  └─ 策略: 顺势交易、对冲、关注波动率突破
关键: 零Gamma水平每天变化——取决于期权OI分布
      每周五/每月第三个周五(期权到期日)有大变动

    GEX的日内动态 

    早晨: 0DTE期权新鲜出炉 → 新的Gamma暴露形成；做市商建立初始对冲；
  9:30-10:30 是最容易被Gamma推动的时段
下午: 0DTE Gamma逐渐衰减(Charm效应)；做市商减少对冲；14:00-15:00 尾部Gamma效应最弱
A股特别: A股期权交易时间 9:30-11:30, 13:00-15:00
  期权到期日: 每月第四个星期三
  到期日前2-3天Gamma效应最强(时间衰减加速)

    Put Wall — 最强大的机构行为信号 

    Put Wall = 拥有最大未平仓合约(Open Interest)的Put行权价
标准信号: 约占93%的交易日在Put Wall上方收盘；市场难以有效跌破Put Wall；
  跌破Put Wall = 重大结构性变化
为什么Put Wall是支撑？不是"因为大家觉得这里有价值"，
  而是因为做市商的库存结构制造了物理性的买入压力

三阶段动力学:
阶段1: 价格逼近Put Wall（加速下跌）
  ├─ Gamma状态: Short Gamma
  ├─ 做市商: Put越来越实值 → Delta绝对值增大 → 卖出更多标的对冲
  └─ 市场: 价格加速滑向墙体
阶段2: 价格触及Put Wall（暴力反弹）
  ├─ 机制A: 机构获利平仓Put → 做市商的Short Put被消除 → 空头回补
  ├─ 机制B: Vanna效应 → IV下降 → Delta减小 → 买回空头
  ├─ 机制C: Charm效应 → 时间衰减 → OTM Delta归零 → 减少对冲
  └─ 市场: V型反弹（通常十分剧烈）
阶段3: 价格跌破Put Wall（自由落体）
  ├─ 触发: 有效跌破支撑(通常伴随重大利空)
  ├─ 做市商: 需要为"下一个Put Wall"(更低行权价)建立新对冲
  ├─ 买方: Put获利平仓 → 滚仓至更低价位
  └─ 市场: 自由落体，直到下一个Put Wall

    Call Wall — 上涨的"天花板" 

    Call Wall = 拥有最大未平仓合约的Call行权价
镜像机制:
  ├─ 价格上涨逼近Call Wall → Short Gamma → 做市商买涨 → 加速
  ├─ 价格触及Call Wall → 卖方获利平仓 → 做市商卖出 → 冲高回落
  └─ 价格突破Call Wall → 空头回补 + Gamma Squeeze → 暴力拉升
A股特性: 在牛市环境中，Call Wall被突破后往往触发Gamma Squeeze
  → 做市商必须大量买入标的来对冲Short Call → 越是买入价格越涨 → 形成正反馈循环

    Vanna 与 Charm 

    Vanna 效应 = Delta对隐含波动率(IV)变化的敏感度
  机制: IV↓ → Put Delta绝对值↓ → Short Put的正Delta敞口↓
    → 做市商原先的空头对冲"过多" → 必须买回部分空头 → 产生买盘压力
  典型场景: 恐慌大跌后 → IV飙升 → 触及支撑后恐慌消退 → IV回落
    → Vanna驱动做市商买回空头 → 反弹加速

Charm 效应 (Delta Decay) = Delta对时间流逝的敏感度
  机制: 时间流逝(尤其到期日前2-3天) → OTM期权Delta自然衰减
    → Short Put的敞口减小 → 做市商减少空头对冲 → 产生持续的被动买盘
  最重要的时段: 到期日前最后3天 + 每日14:30-15:00
  对散户的意义: 到期日前2-3天做多胜率高于其他时间；
    尾盘经常出现"无原因"的上涨 = Charm在行动

    A股Gamma分析的实用方法 

    数据获取:
  1. 获取50ETF/300ETF期权链的所有OI数据
  2. 计算每档行权价的Gamma(通过Vibe-Trading analyze_options)
  3. 汇总: Long Gamma = 所有Call+Put的OI × (每张Call的Gamma - 每张Put的Gamma)
           Short Gamma = -Long Gamma
简化方法:
  1. 找到Put Wall = Max OI Put行权价
  2. 找到Call Wall = Max OI Call行权价
  3. 当前价格与Put Wall/Call Wall的关系 = Gamma体制的大致判断
     当前价格 > Call Wall → Short Gamma风险
     价格在Put Wall和Call Wall之间 → 基本上Long Gamma
     价格 < Put Wall → 极端Short Gamma
数据来源: 东方财富期权频道 option.eastmoney.com / 上交所 sse.com.cn/assortment/options/ /
  Vibe-Trading mcp__vibe-trading__analyze_options

A股特有局限:
  ├─ A股没有0DTE期权(最近到期的是当月合约)
  ├─ 期权市场规模远小于美股(2024年日均 < 500万张 vs SPX 2000万+张)
  ├─ 参与门槛高(50万资金+考试)
  ├─ 做市商数量有限(仅10余家)
  └─ 个人投资者参与比例低(<5%)
含义: ①A股的Gamma效应弱于美股(但并非不存在) ②50ETF/300ETF的Gamma效应最为显著
  ③到期日前2-3天的Charm效应明显 ④由于做市商少，个别做市商的行为可能产生不成比例的影响

    第二层 波动率结构（volatility-structure.md）¶

    VIX 的真相 

    VIX 不是"恐慌指数"，它是做市商库存压力的代理变量。
VIX 的传统错误理解: "市场恐慌程度"
VIX 的正确理解: "标普500期权30天隐含波动率的加权平均值"
为什么VIX和恐慌相关？恐慌时投资者大量买入Put → 做市商Short Put库存膨胀
  → 做市商要求更高的"风险补偿"(IV上升) → VIX升高
VIX是"做市商的风险补偿价格"，不是"市场情绪"

    A股的恐慌指数: iVIX（上证50ETF波动率指数，基于50ETF期权计算） 

    正常水平: 15-20
轻度恐慌: 20-25
中度恐慌: 25-30
极度恐慌: >30
极度平静: <12
历史极值: 2024年2月 ~35(市场暴跌时) / 2020年3月 ~40(疫情冲击) / 2015年股灾 ~65(极端恐慌)
数据来源: 上交所官网 / 东方财富期权频道 option.eastmoney.com / 万得终端(Wind)

iVIX的分位数策略:
iVIX < 15分位数(极度平静):
  → 市场共识过度乐观；做市商库存轻，容易产生Gamma Squeeze
  → 反向操作: 买入看跌期权或减少做多仓位
iVIX > 85分位数(极度恐慌):
  → 市场共识过度恐慌；做市商库存沉重，IV均值回归
  → 反向操作: 卖出看跌期权或增加做多仓位
  → ⚠️ 前提: 确认不是系统性风险(如2015年股灾)
iVIX在两者之间: 正常环境；Vanna/Charm效应正常发挥作用

    波动率微笑（Volatility Smile） 

    标准波动率微笑: OTM Put IV > ATM IV > OTM Call IV
  原因: 市场对下跌风险的定价高于上涨风险
A股的波动率微笑特征: 左偏更严重(Put IV比美股更贵)
  → A股投资者对下跌的恐惧更深 → 反映A股"牛短熊长"的制度性特征
  → 当左偏变得极端时(OTM Put IV远超ATM IV) → 可能出现反转(市场过度对冲)
Skew(偏斜度) = OTM Put IV - ATM IV
  ├─ 正常: 3-5个百分点
  ├─ 偏高: 8-10个百分点 → 过度恐慌 → 可能反转
  └─ 偏低: <2个百分点 → 过度乐观 → 注意风险

    波动率期限结构 

    Contango(期货溢价): 远月IV > 近月IV；正常状态；市场预期长期风险高于短期
Backwardation(现货溢价): 近月IV > 远月IV；⚠️异常状态，短期恐慌；市场预期当前有重大不确定性
交易含义: Backwardation → 不追涨(风险在眼前)；Contango → 可以持有(风险在远处)

    VIX/Gamma联动："VIX越低，越容易暴涨"的真相 

    机制链: VIX降低 → 隐含波动率低 → 期权便宜 → 更多投资者买入期权
  → 做市商Short期权库存增加 → 市场Gamma暴露(绝对值)增加
  → 一旦价格突破某个阈值 → 做市商被迫大量对冲 → Gamma Squeeze
  → 价格暴涨 / VIX暴涨(波动率事件)
这就是为什么: VIX在低位(12-15)时，往往很快出现"意外"的大行情
  2018年2月Volmageddon(波动率末日)就是这个机制

    A股的"波动率事件"触发 

    1. 政策突发(降准、政治局会议通稿): IV从极低 → 瞬间飙升 → 最典型的"波动率意外"
2. 期权到期日的Gamma效应: A股期权到期日=每月第四个星期三；
   到期前2-3天Gamma最大(接近1/时间)；到期日下午Charm驱动的价格异常
3. 国家队护盘与波动率: 国家队入场 → 市场止跌 → IV从高位回落
   → Vanna驱动的反弹 → 形成"政策底"的Gamma基础

    第二层补充 VIX期限结构进阶（vix-term-structure.md）¶

    核心概念 

    VIX 指数 = SPX期权价格推导的30天预期波动率(年化%)
  ├─ VIX=20 → 月波动≈5.8%、日波动≈1.26%
  └─ 不可直接交易
VIX 期货 = 市场对"未来某天VIX应该是什么"的定价
  ├─ M1 = 最近月合约 ；├─ M2 = 次近月合约 ；└─ M3-M6 = 更远的月份

    Contango（期货升水·常态·80%时间） 

    形态: 远月 > 近月 (M1=15, M2=17)
含义: 市场预期波动率会从当前低位回升
三个驱动力: ①VIX均值回归特性 ②Short VIX方收取风险溢价 ③远期不确定性>近期
在不同VIX水平下的含义完全不同:
VIX=12-15 + 陡峭Contango(M1-M2>2):
  ⚠️ 深度自满信号 → 保护成本极低 → 但这是大型vol事件的前兆
  → 历史上VIX低位+陡峭contango=波动率爆发前夜
VIX=20-25 + 温和Contango(M1-M2=0.5-1.5):
  → 正常环境 → Short VIX策略可收割roll yield → 但需警惕突发事件
Roll Yield 公式:
  Short VIX: 以M1=15做空，到期滚至M2=17 → 获利2个vol点/月（如果市场不变）
    → 这是Short Vol产品的核心收益来源
  Long VIX: 以M1=15做多，到期滚至M2=17 → 每月损失2个vol点
    → VIX需每月上涨>2点才能保本 → 这就是为什么VXX等产品长期归零

    Backwardation（期货贴水·危机信号·10-15%时间） 

    形态: 近月 > 远月 (M1=25, M2=20)
含义: 当前恐慌 > 预期未来恐慌，市场认为近期风险异常
两种触发情境: ①正在发生的危机(Realized Vol > 已定价水平) ②迫近的已知事件
极端Backwardation (M1-M2 > 5):
  → 股票市场最强危险信号之一
  → 但同时也是最佳中期入场点
  → 历史上，极端倒挂后3-6个月市场显著回升
交易信号:
  Backwardation出现 → 不追跌
  Backwardation加深(M1-M2>5) → 准备抄底
  Backwardation收窄 → 确认入场

    GEX 与 VIX 期限结构的联动 

    GEX深度为正(Long Gamma): 做市商高抛低吸 → 压制Realized Vol → IV走低 → VIX低位 → Contango
  → 市场: 低波动+均值回归
GEX翻转为负(Short Gamma): 做市商追涨杀跌 → 放大Realized Vol → IV走高 → front-month VIX上行
  → 曲线前端倒挂 → Backwardation
关键洞察: GEX是先行指标，VIX期限结构是滞后指标
  实时监控GEX → 提前预警期限结构变化
  当VIX已倒挂时，结构性原因(GEX转负)早已发生
联合框架:
  GEX为正 + Contango  = 做空Vol环境
  GEX为负 + Backwardation = 极度危险，但也是反转前夜
  GEX转负 + Contango = 危险正在酝酿(未爆发)
  GEX转正 + Backwardation = 恐慌触顶信号

    A股对应概念: 股指期货基差（IF/IC/IM/IH 的升贴水 = A股的"VIX期限结构"） 

    A 股没有VIX期货，但有股指期货基差:
  ├─ IF(沪深300) / IC(中证500) / IM(中证1000) / IH(上证50)
  └─ 基差 = 期货价格 - 现货价格
升水(Contango): 期货 > 现货 → 市场乐观，预期上涨 → 正常状态
贴水(Backwardation): 期货 < 现货 → 市场悲观，预期下跌 → ⚠️悲观信号
  → 极端贴水: IC基差 > -2% → 过度恐慌 → 可能反转
贴水收窄: 悲观情绪改善 → 可能预示反弹
席位持仓分析（中金所前20会员）:
  ├─ 净多单增加 → 投机资金看多
  ├─ 净空单增加 → 投机资金看空
  └─ 需要区分: 套保盘 vs 投机盘
数据来源: 东方财富期货 qhweb.eastmoney.com/lhb/dkcc/cffex/IF /
  新浪财经 vip.stock.finance.sina.com.cn (中金所持仓) / 中国金融期货交易所 cffex.com.cn

    第三层 暗池与机构暗流（dark-pool-institutional.md）¶

    A股的三种"暗交易"机制 

    A 股没有美股的正式暗池(Dark Pool)制度，但存在功能等价物:
1. 大宗交易系统 (盘后 15:00-15:30)
   ├─ 深圳: 最低 30 万股 / 200 万元
   ├─ 上海: 最低 30 万股 / 200 万元
   ├─ 不进入连续竞价，不实时显示
   ├─ 收盘后才披露(有时延迟至次日)
   └─ 对接: 机构对接盘→大股东减持的主通道
2. "暗盘资金" (同花顺概念)
   ├─ 定义: 机构通过拆单、对倒等手法隐藏的大额资金
   ├─ 特征: 明盘显示大单净流出，暗盘显示大单净流入 → 主力在"隐身吃货"
   └─ 识别: 需要L2数据 + 逐笔成交分析
3. 盘后固定价格交易 (科创板/创业板)
   ├─ 15:05-15:30 以收盘价交易
   └─ 成交量不显示在当日K线中，但次日会计入

    暗盘资金识别方法 

    大单拆分为小单的检测:
1. 逐笔成交中出现大量同方向、同时间戳的小单
   → 100个 100股的买单 <1秒内 → 1万股的大单被拆了
2. 每分钟成交笔数 vs 每分钟成交量:
   若成交笔数暴增但单笔均量骤降 → 拆单信号
3. "冰山订单": 买一/卖一价位反复被吃掉但价格不动
   → 有机构在用冰山算法(每次只显示委托量的一小部分)

对倒(洗售)检测:
对倒 = 同一主力用两个账户同时买和卖；目的: 制造虚假的成交量或价格
1. 同一时间戳、相同数量、相同价格的买卖单 → 大概率对倒
2. 股票的"异常成交量"发生在没有新闻的日子 → 可能是对倒制造假量
3. 买一和卖一钱同时出现巨量大单，一方被吃掉后另一方也消失 → 对倒换手
数据需求: L2行情或逐笔成交；工具: futuapi 的 tick数据 / 通达信L2

托单/压单背后的机构意图 — 量化指标:
1. 买盘深度不对称 = (总买盘量 - 总卖盘量) / (总买盘量 + 总卖盘量)
   > 0.2 → 偏买盘 ；< -0.2 → 偏卖盘
2. 大单净压力 = 大单主动买入金额 - 大单主动卖出金额
   来源: 东方财富资金流/同花顺大单统计
3. 净主动买入率 = (主动买入 - 主动卖出) / 总成交额
   > 10% → 机构在主动吃进 ；< -10% → 机构在主动出货

    明盘 vs 暗盘资金对比 

    A股独特信号: 同花顺"暗盘资金"
当股票出现以下模式时，意味着机构在"隐身建仓":
明盘(Level-2可见): 大单净流出 -2000万
暗盘(拆单隐藏):    大单净流入 +5000万
                               →
                   主力在吸筹，散户在卖 → 这是最强烈的看多信号之一

  自建检测: L2逐笔成交 → 拆单检测

    北向资金的微观结构 

    1. 配置型 vs 交易型:
   配置型(真外资): 低换手、长期持有、偏好消费/金融龙头 → 信号: 连续净买入 >5天 → 中期看多
   交易型(假外资+量化): 高频、短线、概念追逐 → 信号: 单日买入+次日卖出 → 短期噪音
2. 北向的"委托流"分析:
   ├─ 买入委托量/卖出委托量 > 1.5 → 偏多
   ├─ 实际成交/委托总量 < 0.5 → 大量撤单(机构在试盘)
   └─ 委托集中在尾盘 → 可能在配合第二天策略
3. 北向的"Gamma联动":
   北向买入 + 50ETF期权OI中Put Wall上移
   → 外资在同时做多标的并买入看跌保护 → 信号: 谨慎看多

    机构持仓变化追踪 

    季报/年报中的机构行为:
1. 机构数量变化: 机构数增加+股价下跌 → 机构在低位建仓；机构数减少+股价上涨 → 机构在高位出货
2. 机构类型变化: 公募减仓+社保加仓 → 长期资金在接盘 → 中期看多；
   游资增仓+公募减仓 → 短期炒作 → 注意风险
3. 十大流通股东变化: 新进机构持仓占比 >1% → 新资金入场；
   连续两季度增仓的机构 → 真看好

    第四层 CTA与趋势跟踪（maxpain-cta-gamma.md 前半 + 拥挤度）¶

    CTA 的基本机制 

    CTA (Commodity Trading Advisor): 趋势跟踪型机构投资者
  核心策略: 追涨杀跌（与做市商的Long Gamma策略相反）
CTA 的仓位驱动:
  ├─ 多仓触发: 价格突破N日均线或波动率突破阈值
  ├─ 空仓触发: 价格跌破N日均线或波动率下降
  ├─ 止损: 回撤超过X%自动平仓
  └─ 仓位规模: 与近期波动率成反比(波动越大，仓位越小)

    CTA 与 Gamma Flip 的共振（四阶段正反馈循环） 

    阶段1: Long Gamma + CTA中性
  → 做市商高抛低吸(压制波动) → 价格在区间内稳定 → 低波动诱使CTA逐步加仓
阶段2: 价格突破区间
  → 做市商从Long Gamma翻转为Short Gamma → 开始追涨杀跌
  → CTA趋势信号同时触发(追涨)
阶段3: 做市商+CTA同时追涨 = Gamma Flip共振
  → 两个最大的机构买方同时入场 → 价格暴涨（远超基本面能解释的幅度）
  → 这就是"闪崩"和"闪电牛"的机构行为根源
阶段4: CTA止损+做市商Short Gamma
  → 趋势反转 → CTA触发止损 → 做市商Short Gamma加剧下跌 → 双杀 → 市场自由落体

    如何检测 CTA/Gamma 共振 

    A 股检测:
  1. 中金所股指期货持仓: IF/IC/IM前20会员净持仓变化
     → 净多/净空持仓急剧变化 = CTA/投机资金转向
  2. 50ETF/300ETF期权Gamma暴露
     → Put Wall被突破 = Gamma Flip发生
  3. 成交量激增 + iVIX飙升
     → 共振确认
数据源: 东方财富期货(qhweb.eastmoney.com) 中金所持仓分布 /
  东方财富期权频道 OI数据→计算Gamma Flip / 新浪期货 席位持仓

    A股机构仓位拥挤度 

    公募基金拥挤度:
  重仓股拥挤度 = 某股票在公募重仓中的集中度
  信号: 前10大基金重仓股占总仓位>40% → 过度拥挤
    → 一旦赎回潮，这些股票跌最多 → 2022年白酒、2024年新能源就是典型
    新进入重仓但未拥挤 → 机构刚建仓(值得跟踪)
  检测方法: 公募基金季报(4次/年) 十大重仓股 / ftshare stock-holder-ten / mx-data 机构持仓

北向资金拥挤度（某股票北向持仓比例 + 变化速率）:
  高持仓(>10%) + 在卖出 → 外资减持信号
  高持仓(>10%) + 在买入 → 外资持续看好
  低持仓(<2%) + 快速买入 → 外资刚发现(最佳买入时机)
  低持仓 + 无变化 → 外资不关注
  数据源: 沪深股通每日持股数据

    第五层 订单流分析（order-flow-analysis.md）¶

    订单流分析(Order Flow Analysis)不是看K线，而是看每一笔交易的主动买卖方向。 传统K线图告诉你: "今天涨了3%"；订单流告诉你: "涨的3%是由买盘推动还是卖盘衰竭推动"。K线=结果，订单流=过程。

    Footprint Chart（足迹图） 

    Footprint = K线的"X光片"
标准K线: [O=100, H=105, L=98, C=103]
Footprint在同一根K线上显示每个价格水平的:
  ├─ 主动买入量(Bid) ；├─ 主动卖出量(Ask) ；└─ 净Delta = Bid - Ask

关键信号:
1. 吸收(Absorption): 在某个价位出现极大成交量但价格不动
   → 有机构在大量承接抛盘(底部信号) 或 机构在大量派发买盘(顶部信号)
2. 失衡(Imbalance): 某一侧交易量远大于另一侧
   ├─ Bid >> Ask → 主动买入压倒性优势 → 看涨
   └─ Ask >> Bid → 主动卖出压倒性优势 → 看跌
3. Delta背离: 价格创新低，但Footprint上的净Delta在减少 → 卖盘力量在衰竭 → 即将反转

A 股的挑战:
  ├─ A股缺少官方Order Flow数据(美股有直接Bid/Ask标记)
  └─ 替代方案:
    1. 逐笔成交(Tick Data): futuapi可获取 → 通过Tick的买卖标记(B/S Flag)近似计算Delta
    2. 同花顺/通达信L2: 分时成交明细 → 但A股的B/S标记可能不准确(被动成交)
    3. 大单统计: 东方财富资金流(超大单/大单/中单/小单) → 粗略但可用的替代
结论: A股的订单流分析精度不如美股/期货，但大单-小单对比仍可提供有价值的信号

    累积成交量Delta（CVD） 

    CVD = Cumulative Volume Delta = Σ(主动买入量 - 主动卖出量)
每个Tick: 成交在卖一价 → 主动买入(买方吃单)；成交在买一价 → 主动卖出(卖方吃单)；
  CVD累加所有Tick的差值
关键信号:
  CVD向上 + 价格向上 → 多头趋势健康
  CVD向上 + 价格横盘/下跌 → 隐藏买盘(Delta Divergence)
  CVD向下 + 价格向下 → 空头趋势健康
  CVD向下 + 价格横盘/上涨 → 隐藏卖盘(Delta Divergence)
Delta Divergence = 价格在新高/新低但CVD在反向运动
  → 最重要的订单流信号 → 预示趋势即将反转

    市场轮廓（Market Profile / TPO） 

    Market Profile = 价格+时间+成交量的三维视图
TPO(Time Price Opportunity): 每个字母代表一个30分钟时间段(A=开盘第一个30min, B=第二个...)；
  字母堆积最多的价格=价值区域(Value Area)
价值区域(Value Area): 覆盖总成交量70%的价格范围；
  VA高(VAL)和VA低(VAH)形成日内S/R；价格在VA内→区间交易；突破VA→趋势交易
关键信号:
  1. 单边TPO(只在一个方向大量交易) → 趋势日，不要逆势
  2. 双分布(两个分开的价值区域) → 多空分歧严重 → 可能有大行情
  3. P型分布(开盘后先跌后涨) → 空头先发起但被多头压制 → 收盘前大概率继续涨
  4. b型分布(开盘后先涨后跌) → 多头先发起但被空头压制 → 收盘前大概率继续跌

    第六层 OI集中度（maxpain-cta-gamma.md 后半）¶

    Max Pain 理论（最大痛点） 

    定义: Max Pain = 期权卖方利润最大的行权价 = 使最多期权合约归零的价格
计算: 对每个行权价，计算所有Call+Put在该价的损失；找到使这个损失最小的价格 = Max Pain
理论基础: 期权卖方(做市商)在市场到期时有动机把价格"钉"在Max Pain附近，以使自己的损失最小化
  → 这是"做市商定价权"的极端体现

应用:
信号1: 当前价格 vs Max Pain
  价格远高于Max Pain → 下跌至Max Pain的概率增大
  价格远低于Max Pain → 上涨至Max Pain的概率增大
  价格接近Max Pain → 符合做市商利益，无特殊信号
信号2: Max Pain的变化方向
  Max Pain上升 → 做市商预期价格上涨 ；Max Pain下降 → 做市商预期价格下跌
信号3: 到期日效应
  到期日前最后2-3天，Max Pain的"引力"最强
  → 尤其是每月第三个周五(美股) / 第四个周三(A股期权)

A 股50ETF/300ETF期权: 到期日=每月第四个星期三；Max Pain计算可通过东方财富期权频道获取OI数据后自行计算
简化方法:
  1. 找到Put Wall = Max OI的Put行权价 ；2. 找到Call Wall = Max OI的Call行权价
  3. 粗略Max Pain ≈ (Put Wall + Call Wall) / 2
实操: 到期日前2-3天 + 价格距Max Pain >2% → 存在"回归Max Pain"的交易机会

    OI 集中度分析 

    OI集中度 = 最大OI合约的OI / 全部OI
高集中度(>25%): 做市商对冲压力集中在窄幅价格区间；"Pin Risk"增大（价格被钉在某行权价的概率）；
  Gamma效应放大
低集中度(<15%): 做市商对冲分散；Gamma效应温和
跨行权价OI变化: OI向更高行权价移动 → 看涨预期；OI向更低行权价移动 → 看跌预期

    Put/Call OI 比例（逆向指标） 

    P/C OI = Put OI 总量 / Call OI 总量
> 1.5: 过度看跌 → 可能反转向上
1.0-1.5: 正常偏空
0.7-1.0: 中性
0.5-0.7: 正常偏多
< 0.5: 过度看涨 → 可能反转向下
注: 这是逆向指标（过度一致看跌=底，过度一致看涨=顶）

    三、核心方法¶

    3.1 分析工作流（SKILL.md 主流程：当用户问"这只股票有机构资金支撑吗?"）¶

    Step 1: 检查是否有对应ETF期权？
  ├─ 有(沪深300/50/500成分股) → 分析ETF的Put Wall/Call Wall/Gamma暴露
  └─ 无 → 跳过期权分析，直接做暗盘资金+北向分析
Step 2: 期权做市商分析
  → 获取期权链 OI数据 → 定位 Put Wall (最大OI Put行权价) → 定位 Call Wall (最大OI Call行权价)
  → 估算零Gamma水平 → 得出: 做市商对冲方向(流入/流出)
Step 3: 暗盘/机构资金流分析
  → 检查大宗交易(折溢价/接盘方) → 检查明盘vs暗盘资金差异 → 检查北向资金连续流向
Step 4: 波动率环境判断
  → 当前iVIX水平(历史分位数) → 隐含波动率期限结构(Contango vs Backwardation)
  → 得出: 环境是"支持Gamma squeeze"还是"Gamma压制"
Step 5: 综合判断
  → 做市商对冲方向 + 机构暗流方向 + 波动率环境
  → 给出: 机构资金是"流入、中性、流出"

    3.2 五层分析的整合工作流（institutional-flow-framework.md）¶

    当你想知道"机构资金是流入还是流出"时:
Layer 1: Gamma暴露分析 (5分钟) → 做市商当前是对冲买入还是卖出？
Layer 2: 波动率环境 (3分钟) → 当前环境是支持还是压制Gamma效应？
Layer 3: 暗盘/暗流分析 (5分钟) → 大资金在明面上做什么？暗地里做什么？
Layer 4: CTA/趋势资金 (3分钟) → 趋势跟踪资金的仓向？与Gamma是否正向共振？
Layer 5: 期权流分析 (5分钟) → Call/Put分布、PCR、Skew揭示的资金偏好
总耗时: 约21分钟/标的

    3.4 典型机构行为模式识别（四种模式）¶

    模式1: "隐身建仓" 

    信号组合:
  ├─ 明盘: 大单净流出
  ├─ 暗盘: 大单净流入(拆单隐藏)
  ├─ 期权: Put OI下降(保护性卖盘减少)
  ├─ 大宗: 小幅折价(机构间换手)
  └─ iVIX: 低位企稳(恐慌消退)
解读: 机构在"隐身建仓" — 打压价格制造恐慌，同时通过拆单在低位吸筹
  → 这是最值得跟随的做多信号
策略: 跟随建仓，设止损在最近的支撑位下方

    模式2: "隐身出货" 

    信号组合:
  ├─ 明盘: 小单净流入(散户在买)
  ├─ 暗盘: 大单净流出(拆单出货)
  ├─ 期权: Put OI上升(机构买保护)
  ├─ 大宗: 高折价大额交易(紧急出货)
  └─ iVIX: 上升(做市商压力增大)
解读: 机构在"隐身出货" — 维持价格让散户接盘，同时通过拆单在高位出货
  → 这是最危险的做空信号
策略: 立即离场或轻仓试空

    模式3: "Gamma Squeeze前置" 

    信号组合:
  ├─ Gamma: 价格接近Call Wall + Short Gamma体制
  ├─ Vol: iVIX在低位(<15分位)
  ├─ 期权: Call OI集中在一两个行权价
  ├─ 暗盘: 大额Call买入(机构在押注突破)
  └─ 北向: 连续净买入
解读: Gamma Squeeze正在酝酿 — Call Wall上方积累了大量Short Call
  → 一旦突破触发保证金追缴，做市商被迫买涨 → 低VIX意味着Gamma很大(期权便宜→OI多)
策略: 提前布局做多，在Call Wall上方1-2%设止盈；或用Call Spread降低成本

    模式4: "Put Wall防御" 

    信号组合:
  ├─ Gamma: 价格跌向Put Wall
  ├─ Vol: iVIX高位(>85分位)
  ├─ 期权: Put交易量暴增+OI集中
  ├─ 暗盘: 机构低价吃进
  └─ 北向: 开始转为净买入
解读: 价格触及机构"防御线" — Put Wall处有强大的结构性买盘
  → 机构平仓Put + 做市商空头回补 = 暴力反弹基础；93%概率不会有效跌破
策略: 在Put Wall附近做多；止损: Put Wall下方2-3%；止盈: 第一目标价反弹3-5%
