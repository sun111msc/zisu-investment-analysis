# 七条铁律

> 贴在显示器旁边，每天交易前看一遍。

```
 1% — 任何一笔不超过总资金 1%（绝对的绝对）
2:1 — 盈亏比至少 2:1（否则不交易）
 3 — 连续3亏减仓，5亏停（非情感，自动触发）
15% — 回撤 15% 警戒线（强制休息+完整复盘）
20% — 单只不超过 20%*（组合分散底线）
70% — 总仓位不超过 70%（留下子弹永远是正确的事）

*高确信标的（紫苏叶4-5级+治理A/B）单只上限可至25%，详见《紫苏叶等级仓位上限速查》
 ∞ — 不预测·只应答·错过不亏钱（最后一条最重要）
```

### 对应解释

| 铁律 | 来源 | 不可违反的原因 |
|---|---|---|
| 1% | risk-management Layer 1 | 亏50%要赚100%才能回本 |
| 2:1 | risk-management Layer 2 | 胜率低于50%时，必须靠赔率 |  
| 3笔 | risk-management Layer 4 | 连续亏损不是市场变了，是你状态不对 |
| 15% | risk-management Layer 5 | 15%以内三个月可回，25%+需要一年 |
| 20% | risk-management Layer 5 | 单只踩雷不至于伤筋动骨 |
| 70% | risk-management Layer 5 | 永远保留"抄底"和"救命"的子弹 |
| ∞ | 浑天哲学 Layer 0 | "错过"不亏损本金，"做错"才亏 |
