# 行业BOM拆解模板

> **Bill of Materials — 物理瓶颈狩猎的核心工具**
> 从终端产品的物料清单逐层逆向拆解，定位哪个环节最稀缺。
> 对应Layer 2 Serenity Phase 1-3。

---

## 一、BOM拆解模板（通用）

```
[终端产品名称]
├── 第1层: 核心系统/模组 (价值占比 XX%)
│   ├── 子系统A (价值占比 XX%)
│   │   ├── 零部件A1 (价值占比 XX%)
│   │   │   ├── 材料A1a (价值占比 XX%)
│   │   │   │   └── 上游原料A1a1 (XX家供应商·瓶颈评级:🍃)
│   │   │   └── 工艺A1b (XX家能做·瓶颈评级:🍃)
│   │   └── 零部件A2 (价值占比 XX%)
│   └── 子系统B (价值占比 XX%)
```

## 二、每个节点的采集项

| 项 | 填写示例 | 说明 |
|---|---------|------|
| 名称 | 高频高速覆铜板 | 具体物料名称 |
| 价值占比 | 15% | 占终端BOM成本的比重 |
| 全球供应商数 | 3家 | 有量产能力且通过客户认证的 |
| 集中度 | CR3=95% | 前3大供应商份额之和 |
| 认证周期 | 18-24个月 | 客户导入到量产的时间 |
| 技术代际差距 | 1.0代 | 龙头vs第二名的技术差距 |
| 国产化率 | 15% | 中国供应商占比 |
| 产能利用率 | 90% | 当前满载程度 |
| 毛利率 | 50-60% | 供应商的典型毛利率 |
| **瓶颈评级** | 🍃🍃🍃 | 1-5级紫苏叶等级 |

## 四、瓶颈定位四问

每个BOM节点都要问这四个问题：

| # | 问题 | 通过条件 |
|---|------|---------|
| 1 | 全球只有≤2家能做？ | 供应商数≤2 → 候选瓶颈 |
| 2 | 少了它产业链能替代吗？ | 认证周期>12个月 → 不可替代 |
| 3 | 产能已经被抢订了吗？ | 产能利用率>85% → 紧缺 |
| 4 | 市值是否被低估（PS<5x且增速>30%）？ | 符合 → 估值错配 |

**四个全通过 → 🍃🍃🍃🍃🍃 终极瓶颈，不可替代**
