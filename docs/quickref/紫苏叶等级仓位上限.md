## 三阶段建仓节奏

| 阶段 | 加到 | 触发条件 |
|---|---|---|
| 试错仓 | ≤ 10% | PA 入场信号 + 宏观 ≥ C |
| 确认仓 | +20%（总 30%） | 试错仓浮盈 ≥ 3% + PA 未破 + 催化剂在 60 天内 |
| 主升仓 | +20%（总 50%） | 确认仓浮盈 ≥ 5% + 催化剂兑现 + 机构持续加仓 |

## 降级触发条件（触发任一条 → 紫苏叶自动降一级）

- 出现可量产替代品/第二供应商放量
- 客户合同到期未续约
- 实控人减持 / 质押率 > 40%
- 行业 capex 同比 > 50%（扩产竞赛预警）
