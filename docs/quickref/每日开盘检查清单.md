# 每日开盘前15分钟检查清单

> **无论多忙，开盘前必须过一遍。**

---

## 第一步：宏观环境（1分钟）

```
□ 昨晚有没有重大政策/新闻？
□ 当前大盘环境评级（来源：MACRO-GATE）：A / B / C / D
  ← D 级 → 今天不开新仓，只处理持仓
□ 当前总仓位：___%（目标：≤70% / D级≤10%）
```

## 第二步：持仓检查（3分钟）

```
□ 现有持仓有没有触及止损线？
□ 有没有公告减持/解禁/质押问题？
□ 有没有重大负面舆情？
□ 需要减仓或止盈的标的？
```

## 第三步：待交易检查（3分钟）

```
□ 待买入的股票有没有暗雷？（查 ashare-insider 排雷清单）
□ 仓位够吗？（单只上限 ≤ 20%/行业 ≤ 40%）
□ 催化剂在60天内吗？（否则只给底仓）
□ 当前回撤：___%（目标 ≤ 15%）
```

## 第四步：心理状态（1分钟）

```
□ 今日情绪：平静 / 自信 / 不安 / 兴奋 / 恐惧
  ← 兴奋或恐惧 → 减仓50%
□ 连续亏损笔数：___笔（≥3笔 → 自动减仓50%；≥5笔 → 停止交易）
□ 是否FOMO？是否在报复性交易？
```

## 第五步：今天不可违反的规则

```
□ 单笔风险 < 1%
□ 盈亏比 ≥ 2:1
□ 不用市价单（除非黑天鹅）
□ 入场必须有预设止损
□ 尾盘建仓（早盘最多开半仓）
```

---

> **全部通过 ← 可以开始今天的交易**
> **任一项未通过 ← 暂停，重新评估计划**
