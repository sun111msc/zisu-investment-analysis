# 风控评分矩阵

> **每笔交易前执行，< 4 分不出手。**

| 维度 | 通过 (+1) | 有风险 (0) | 危险 (-1) | 你的分 |
|---|---|---|---|---|
| **仓位** | 单笔风险 < 1% | 1-2% | > 2% | |
| **止损** | 预设技术止损 | 有止损但位置不合理 | 无止损 | |
| **回撤** | 当前 DD < 5% | 5-15% | > 15% | |
| **心理** | 平静 | FOMO/不安 | 报复/膨胀 | |
| **执行** | 分批 + 限价 | 未分批 | 市价满仓 | |
| **组合** | 现金 > 15% | 5-15% | < 5% | |
| **总分** | | | | |

### 结论

| 总分 | 动作 |
|---|---|
| **≥ 4** | ✅ 可以入场 |
| **2-3** | ⚠️ 减仓 50%，严格止损 |
| **≤ 1** | 🛑 放弃，等状态恢复 |

### 六大维度的快速检查

1. **仓位**：用 1% 铁律算：`(总资金 × 1%) ÷ (入场价 - 止损价) = 最大股数`
2. **止损**：结构止损（OB 下方 1ATR）或波动率止损（1.5×ATR），取两者最保守
3. **回撤**：账户最大回撤 = 最高净值至今的跌幅
4. **心理**：如果收盘前你紧张到不想看账户 → 仓位太大
5. **执行**：单笔 > 100 万必须分批，> 500 万必须用 VWAP/冰山
6. **组合**：现金是期权——不持仓的时候你拥有选择的自由
