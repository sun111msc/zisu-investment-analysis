# 八种退出场景速查

> **入场时你就应该知道什么场景下会退出。**

| # | 场景 | 信号 | 动作 | 速度 |
|---|---|---|---|---|
| 1️⃣ | **止损触达** | 价格触及预设止损位 | 立即平仓 | ⚡ 立即 |
| 2️⃣ | **止盈触达** | 价格触及预设止盈位 | 减仓或平仓 | ⚡ 立即 |
| 3️⃣ | **结构改变** | HH/HL 被破坏（趋势反转） | 立即平仓 | ⚡ 立即 |
| 4️⃣ | **BOS/ChoCH** | 关键结构被突破 | 立即平仓 | ⚡ 立即 |
| 5️⃣ | **时间止损** | 持仓 3 天无浮盈 | 平仓退出 | 📦 分批 |
| 6️⃣ | **V 止盈** | 快速拉升后无跟随 | 平 1/2 | 📦 分批 |
| 7️⃣ | **新闻事件** | 出现重大利空（监管/制裁/丑闻） | 立即平仓 | ⚡ 立即 |
| 8️⃣ | **信号失效** | 入场逻辑不再成立（逻辑证伪） | 平仓退出 | ⚡ 立即 |

### 三种止损优先级

```
1️⃣ 结构止损（OB下方1ATR）——与技术逻辑一致，给价格呼吸空间
2️⃣ 波动率止损（1.5×ATR）——自适应市场波动
3️⃣ 分步止损（分批：1ATR→1/3，1.5ATR→1/3，2ATR→全部）
```

**实际止损点取三者最小值（最保守的那个）。**

### 四种止盈方法

| 方法 | 规则 | 适用 |
|---|---|---|
| 固定 R:R | 止损 1 → 止盈 2 (R:R ≥ 2:1) | 简单量化，进场前定好 |
| 结构目标 | 做多：下一关键阻力位 | 与技术逻辑一致 |
| ATR 追踪 | 入场价 + N×ATR | 自适应波动 |
| 分步止盈（推荐） | 1/3 @ 1.5R + 1/3 @ 3R + 1/3 追踪止损 | 平衡快速获利与长尾 |
