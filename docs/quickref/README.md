## 核心数字速记

```
【仓位】
单笔风险      ≤ 总资金 1%
单只标的      ≤ 20%（高确信 + 瓶颈≥4级 可至 25%）
单行业        ≤ 40%
总仓位        ≤ 70%
最低现金      ≥ 15%
环境 A/B/C/D  → 总仓上限 100% / 70% / 30% / 10%

【止损止盈】
盈亏比        ≥ 2:1
止损距离      结构止损与 1.5×ATR 取较近者
分步止盈      1/3 @ 1.5R + 1/3 @ 3R + 1/3 追踪
动态止盈      浮盈 ≥10% 启动，每涨 1×ATR 上移 1×ATR
时间止损      持仓 3 天无浮盈 → 重新评估

【风控协议】
连续 3 笔亏损  → 减仓 50%
连续 5 笔亏损  → 停止交易 3 个交易日
单月亏损 >10%  → 停止所有交易
回撤 >15%      → 检查系统是否存在根本性问题

【瓶颈分级】
5 级 全球独家 + 认证≥2年     → 25%
4 级 全球 2 家 + 认证≥2年     → 20%
3 级 全球 2-3 家              → 15%
2 级 全球 3-4 家              → 8%
1 级 全球 4+ 但有差异化       → 3%
```
