# 市场结构与定价机制

> 基本面回答「这家公司值多少」，本文回答「为什么它现在的价格不是那个值」。
>
> 这一层关注的是**价格形成机制本身** —— 谁在定价、供给有多薄、悲观者能不能表达意见。

---

## 一、为什么需要单独分析定价机制

基本面分析有一个隐含假设：价格由基本面决定，只是可能暂时偏离。

但这个假设在特定条件下不成立。当以下三个条件同时满足时，价格**系统性**地由最乐观的参与者决定：

1. 市场对该公司的分歧很大
2. 表达悲观意见的渠道受限（无法做空）
3. 供给（可交易的股份）很薄

此时价格不是「市场对基本面的共识」，而是「最乐观者的出价」。理解这一点，才能正确解读估值倍数。

**这不是市场失效，是结构特征。** 需要识别它，而不是否认它。

## 二、Miller 定价框架

### 2.1 核心逻辑

```
分歧越大 + 做空越受限 → 价格越由最乐观的边际买家单方面决定
```

**推演**：

```
在一个可以自由做空的市场：
  乐观者买、悲观者卖（做空）
  → 价格反映双方的加权观点

在一个做空受限的市场：
  乐观者可以买
  悲观者只能选择「不买」或「卖出已有持仓」
  → 悲观者的意见只能通过「不参与」表达
  → 价格由愿意出的最高价决定
```

**结论**：在做空受限的市场里，**当前价格 = 最乐观的人愿意付的价**，而不是均衡价。

### 2.2 三要素评估

| 要素 | 判据 | 数据来源 |
|---|---|---|
| **① 分歧度** | 卖方评级中卖出+持有占比高；一致预期方差大 | 研报覆盖统计、EPS 预测标准差 |
| **② 做空受限程度** | 融券余额占流通市值比例；是否有替代做空渠道 | 融券数据、H 股/期权 |
| **③ 最乐观者定价** | 当前价格是否显著高于任何基本面方法给出的值 | 估值交叉验证 |

### 2.3 做空通道评级

| 评级 | 判据 |
|---|---|
| 🟢 宽松 | 融券 > 流通市值 0.5% + 有替代做空渠道 |
| 🟡 受限 | 融券 0.1-0.5% + 无替代渠道 |
| 🔴 极度受限 | 融券 < 0.1% + 无 H 股 + 无卖出评级覆盖 |
| 💀 无做空 | 融券近乎为零 |

### 2.4 结构强度判定

| 分歧度 \ 做空通道 | 🟢 宽松 | 🟡 受限 | 🔴 极度受限 |
|---|---|---|---|
| 🟢 高分歧 | 正常定价 | 轻微乐观偏差 | **显著乐观偏差** |
| 🟡 中分歧 | 正常定价 | 正常定价 | 轻微乐观偏差 |
| 🔴 低分歧 | 正常定价 | 正常定价 | 正常定价 |

### 2.5 修正处理

| 判定 | 处理 |
|---|---|
| 显著乐观偏差 | 估值应下调 10-20% 作为「结构溢价折让」 |
| 轻微乐观偏差 | 安全边际要求额外增加 5-10% |
| 正常定价 | 不修正 |

### 2.6 第九问：魔鬼代言人的补充

标准魔鬼代言人有八问。这里追加第九问：

```
「如果做空完全自由，这只股票的真实价格会是多少？」

输出：「当前价格中约有 XX% 来自做空限制的结构性溢价，
       而非基本面支撑。」
```

**这个问题的价值**：它把「估值偏高」这个模糊判断，变成了一个可以量化归因的分解。

## 三、卖盘厚度分析

### 3.1 核心问题

```
当前价格下，还有多少股份可能被卖出？供给曲线有多陡？
```

如果可交易的股份很少，那么少量买盘就能推动大幅上涨 —— 这与基本面无关。

### 3.2 五层拆解

| 层级 | 构成 | 典型占比 | 卖出条件 | 可预测性 |
|---|---|---|---|---|
| 🏔️ **不卖层** | 实控人、一致行动人、国有股东、上市前高管 | 25-55% | 除控制权变更、质押爆仓 | ★★★★★ |
| 🔒 **锁定层** | 被动指数持仓、战略配售、定增锁定 | 5-20% | 赎回、再平衡、锁定期满 | ★★★★ |
| 🧊 **长持层** | 长期机构、外资 | 5-15% | 估值体系崩溃、行业逻辑变更 | ★★★ |
| 🌫️ **浮筹层** | 主动公募、游资、量化、散户短线 | 15-40% | 价格波动、情绪变化 | ★★ |
| 💀 **空头层** | 融券余额 | < 0.1% | 价格下跌 | ★ |

### 3.3 浮筹比例判读

```
浮筹比例 = 100% − 不卖层 − 锁定层
```

| 浮筹比例 | 判定 | 含义 |
|---|---|---|
| > 60% | 🟢 卖盘充足 | 价格发现正常 |
| 40-60% | 🟡 卖盘偏薄 | 价格可能被放大 |
| 20-40% | 🔴 卖盘极薄 | 小资金可撬动大涨幅 |
| < 20% | 💀 近乎空转 | 价格严重脱离供需基本面 |

### 3.4 与指数晋级路径的联动

```
指数权重上升 → 被动资金买入 → 锁定层扩大 → 卖盘更薄 → 下一次上涨更省力

指数权重触顶 → 再平衡强制卖出 → 短期卖盘增加 → 可能阶段见顶
```

**这条循环解释了为什么有些股票「越涨越轻松」**：上涨本身降低了可交易供给。

### 3.5 价格弹性估计

```
净买入 X 亿 可推动约 Y% 的涨幅

参考量级：某些极端案例中，
  扩张的市值 / 可见净流入 ≈ 数十倍
```

**注意**：这个弹性系数会随浮筹比例变化。浮筹越薄，弹性越大 —— 但反向也成立：一旦卖盘出现，跌幅同样会被放大。

## 四、指数晋级路径

### 4.1 晋级循环

```
股价上涨
  → 自由流通市值上升
  → 指数权重上升
  → 进入更大的指数
  → 跟踪资金扩大
  → 锁定浮筹增加
  → 卖盘更薄
  → 下一次上涨更省力
```

**这是一个自我强化的循环。** 理解它的位置，才能判断还有多少空间。

### 4.2 常见晋级阶梯

| Level | 指数 | 意义 |
|---|---|---|
| 0 | 不在主要指数 | 无被动资金覆盖 |
| 1 | 板块/主题指数 | 首批被动覆盖 |
| 2 | 主流宽基指数 | 大规模被动覆盖 |
| 3 | 大盘蓝筹指数 | 蓝筹身份确认 |
| 4 | 国际指数 | 国际资金覆盖 |
| 5 | 多数指数权重接近上限 | 再平衡卖方 |

### 4.3 阶段判定

| 阶段 | 特征 | 含义 |
|---|---|---|
| 🟢 上升期 | 正在进入更大指数，权重仍有大幅上升空间 | 被动买入持续 |
| 🟡 触顶前 | 已进入多个主要指数，权重未触上限 | 仍有空间但放缓 |
| 🔴 触顶期 | 权重接近或超过上限 | 被动盘转为强制卖方 |
| 💀 拐点 | 权重触发强制再平衡 | 浮筹开始增加 |

### 4.4 需要检查的事件

```
□ 定期调样的日期（通常每季度）
□ 是否触发强制再平衡（单一权重超上限）
□ 纳入 / 剔除公告
□ 这些事件的市场预期程度（已定价还是超预期）
```

**重要提醒**：被动的买与卖**都已被提前定价**。真正的收益来自预期之外的部分。

## 五、追认台阶模型

### 5.1 核心问题

```
当前市场对这只股票的定价，处于追认的哪一级台阶？
```

「追认」指的是机构从「不认识」到「重仓」的过程。这个过程通常分三步，每一步对应不同的定价者与不同的风险收益比。

### 5.2 三级台阶

| 台阶 | 特征 | 定价者 | 研究状态 | 处理 |
|---|---|---|---|---|
| 🥇 **台阶 1 · 试水期** | 已涨 2-3 倍，重仓基金数 < 50 | 极少数先知先觉者 + 产业资本 | 卖方覆盖 < 5 家 | ✅ 可入场（信息优势期） |
| 🥇 **台阶 2 · 追认期** | 已涨 5-10 倍，重仓基金数 200-500 | 多数主动基金开始建仓 | 覆盖 10-20 家，研报密集 | ⚠️ 仍有空间但降低速度 |
| 🥇 **台阶 3 · 拥挤期** | 已涨 20-50 倍，成为前十大重仓 | 被动 + 主动资金完成追认 | 覆盖 20+ 家，白空间消失 | ⛔ 不再新开仓位 |

### 5.3 判断方法

| 指标 | 台阶 1 | 台阶 2 | 台阶 3 |
|---|---|---|---|
| 公募重仓数 | < 50 | 50-500 | 500+ |
| 卖方覆盖 | < 5 | 5-20 | 20+ |
| 拥挤度 | 低 | 上升 | 高 |
| 机构态度 | 多数未参与 | 快速上升 | 已成为共识 |

**为什么这个模型有用**：它把「现在还能不能买」这个模糊问题，变成了「机构参与到了哪一步」。

**等「更好的价格」的风险**：如果你在台阶 2 等待回调，可能永远等不到 —— 因为台阶 3 的被动买入会持续推高价格。反过来，在台阶 3 买入，风险是流动性反转。

## 六、边际买家更替

### 6.1 核心问题

```
当前阶段，谁是这只股票的边际净买家？
上一段的主力还在增持吗？
```

一只长牛股票的上涨通常由**不同批次的买家接力**完成。前一阶段的主力往往在下一阶段离场。

### 6.2 五批买家画像

| 类型 | 特征 | 视野 | 何时出现 | 撤退信号 |
|---|---|---|---|---|
| 🅰 产业资本 / 原始股东 | 上市前入股，信息最充分 | 数年 | 上市后不久即减持 | 清仓式减持 |
| 🅱 先知机构 / 游资 | 主题行情早期，敢在信息稀疏期下注 | 数月 | 催化剂出现初期 | 前十大名单消失 |
| 🅲 配置型 / 被动资金 | 按规则买，不需要基本面确认 | 长期锁定 | 信息验证期 | 份额大幅赎回 |
| 🅳 牛散 / 大资金 | 有研究能力，灵活性高于机构 | 数月-1 年 | 趋势确立后 | 前十大名单消失 |
| 🅴 散户 / 融资盘 | 最后入场 | 数周-数月 | 涨幅巨大、情绪亢奋时 | 融资余额见顶回落 |

### 6.3 阶段对应关系

```
产业资本主导（减持期）  → 行情早期，挖坑中
先知机构 / 游资主导     → 早期发现阶段
配置型 / 被动资金主导   → 筹码锁定阶段
牛散主导                → 趋势验证后，弹性最大
散户 / 融资盘主导       → 后期，接近顶部
```

### 6.4 跟踪方法

```
Step 1  回溯过去 3 期的前十大流通股东名单
        → 提取每期新进 / 退出名单
        → 标注每期最大的净买入方类型

Step 2  判断当前接力阶段
        → 当前主力是哪一类？

Step 3  验证信号
        □ 融资余额：加速流入还是已过峰值？
        □ 股东户数：是否突然暴增（散户进场信号）？
        □ ETF 份额：被动资金流入还是流出？
        □ 牛散名单：老面孔退出、新面孔进入？
```

**关键风险提示**：当融资盘从增量转为存量时，定价权进入最不稳定的阶段 —— 因为融资盘有强制平仓机制。

## 七、叙事纯度分析

### 7.1 核心问题

```
这家公司最核心的想象空间，被多少不相关的业务摊薄了？
```

相同的技术壁垒，放在一家「纯粹」的公司里和放在一家「多元」的公司里，得到的估值可能相差一倍。

### 7.2 五维评分

| 维度 | 10 分 | 5 分 | 0 分 |
|---|---|---|---|
| 核心叙事营收占比 | > 90% | 50-90% | < 50% |
| 核心叙事毛利率 | > 50% | 30-50% | < 30% |
| 核心叙事增速 | > 50% | 20-50% | < 20% |
| 非核心业务拖累 | 几乎没有 | 部分拖累 | 严重拖累 |
| 市场独占性 | 唯一 / 唯二 | 有 2-3 家同类 | > 5 家同类 |

### 7.3 评级与估值影响

| 评级 | 纯度分 | 估值影响 |
|---|---|---|
| 🟢 纯 | 8-10 | 可享受纯叙事溢价（+20-50%） |
| 🟡 较纯 | 5-7 | 部分摊薄，核心叙事仍主导 |
| 🔴 摊薄 | 3-4 | 核心叙事被严重稀释 |
| 💀 伪纯 | 0-2 | 所谓「核心叙事」实际收入占比极小 |

### 7.4 拖累系数

```
叙事拖累系数 = (整体倍数 − 纯叙事部分倍数) / 整体倍数
```

系数越高，说明想象空间被摊薄得越严重。

**这一步的用途**：在做估值时，不能简单地对整体使用「纯叙事公司」的倍数。必须先拆分，再对各部分使用不同的倍数。

## 八、信息稀疏度评估

### 8.1 核心问题

```
这只股票当前处于信息周期的什么位置？
```

信息稀疏期是价值最高的窗口 —— 机构的研究体系还没启动，而信息已经可以通过另类渠道获取。

### 8.2 五维评分（0-10 分）

| 维度 | 极稀疏（10 分） | 中等（5 分） | 极密集（0 分） |
|---|---|---|---|
| 卖方覆盖数 | 0-2 家 | 3-8 家 | 15+ 家 |
| 距上次财报天数 | > 120 天 | 45-90 天 | < 30 天 |
| 距下次财报天数 | > 60 天 | 30-60 天 | < 15 天 |
| 近 3 月研报数 | 0-2 篇 | 3-10 篇 | 20+ 篇 |
| 讨论热度 | 冷清 | 中等 | 火爆 |

```
总稀疏度 = 各维度得分之和 / 5
```

### 8.3 稀疏度与策略

| 稀疏度 | 信息阶段 | 最优策略 | 主要风险 |
|---|---|---|---|
| 8-10 | 信息真空 | 优先采集提前信号，可建立试探仓 | 信息不对称大，方向可能全错 |
| 5-7 | 过渡期 | 混合策略，已有仓位持有 | 等待验证期，可能中途动摇 |
| 3-4 | 信息密集 | 追认期可加仓，但注意拥挤 | 接近拥挤台阶，延迟入场代价大 |
| 0-2 | 完全定价 | ⛔ 不新开仓位 | 机构完成追认，空间极小 |

### 8.4 提前信号采集

当稀疏度 ≥ 5 时，应主动采集五类提前信号：

| 信号类型 | 来源 | 领先时间 | 强度 |
|---|---|---|---|
| 🅰 供应链信号 | 客户产能扩张、设备招标公告 | 1-2 季度 | ★★★ |
| 🅱 招聘信号 | 岗位数量、类型、薪资变化 | 1-2 季度 | ★★ |
| 🅲 专利信号 | 核心专利公开、数量变化 | 1-3 年 | ★★ |
| 🅳 管理层信号 | 业绩会中的非常规表述 | 0-1 季度 | ★★★ |
| 🅴 客户信号 | 关键客户的动态、转单 | 0-1 季度 | ★★★★ |

**这几类信号的价值**：它们不在所有人的屏幕上。等一个信号出现在研报里，它已经被定价了。

**风险提示**：提前信号的误读成本是滞后 4-8 周才被发现。因此需要与后续的财务数据交叉验证。

## 九、拥挤度检测

### 9.1 三维检测

| 维度 | 判据 | 含义 |
|---|---|---|
| **持仓拥挤** | 公募重仓基金数、持仓占流通股比例 | 机构是否过度集中 |
| **交易拥挤** | 成交额占全市场比例、换手率 | 交易是否过热 |
| **估值拥挤** | 相对分位、绝对倍数 | 估值是否透支 |

### 9.2 判读

```
拥挤度 > 80%  → 不碰（反转风险高）
拥挤度 20-80% → 正常分析
拥挤度 < 20%  → 关注（可能是机会）
```

**注意「不碰」的含义**：拥挤度高不等于一定下跌，但它意味着风险收益比恶化。在拥挤度 80% 以上的位置买入，需要依赖「更乐观的人继续买入」这个假设。

## 十、本层方法的整合逻辑

这七种方法不是独立的，它们共同回答一个问题：**当前价格是怎么形成的？**

```
第一步 · 分歧与做空
  → Miller 框架：价格是否由最乐观者决定？

第二步 · 供给结构
  → 卖盘厚度：可交易的股份有多少？

第三步 · 被动资金
  → 指数晋级：被动买入还有多少空间？

第四步 · 机构进程
  → 追认台阶：机构参与到哪一步？

第五步 · 买家接力
  → 边际买家：谁在买？上一批还在吗？

第六步 · 叙事质量
  → 叙事纯度：想象空间是否完整？

第七步 · 信息位置
  → 稀疏度：现在是早期还是晚期？

综合输出：价格构成分解
  基本面支撑        X%
  指数化结构锁定    Y%
  做空受限的乐观溢价 Z%
  情绪与资金驱动    W%
```

**这个分解的意义**：它把「这只股票为什么涨」变成了一个可以归因的问题。如果涨幅中只有 30% 来自基本面，那么仓位管理和退出纪律就应该按 30% 的确定性来设计。

## 十一、常见错误

| 错误 | 后果 |
|---|---|
| 把「最乐观者定价」误认为市场共识 | 用错误的锚做估值 |
| 忽略卖盘厚度 | 低估上涨弹性，也低估下跌风险 |
| 把指数纳入当作利好 | 纳入的买卖都已被提前定价 |
