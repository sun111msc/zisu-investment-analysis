# 分析流程：八阶段正金字塔

> 本文说明一次完整的单标的分析按什么顺序展开、每个阶段要产出什么、
> 深度到什么程度算合格，以及在什么情况下应该停下来。

---

## 一、为什么是「正金字塔」

早期版本的流程把「市场认知偏差」放在最前面 —— 先问「市场在什么问题上犯了错误」，再去分析公司。

这个顺序有一个隐蔽的缺陷：**它会让后续所有分析被先入的判断锚定。**

一旦你在开头写下「市场低估了这家公司的技术壁垒」，接下来你会不自觉地：
- 在产业链分析中更关注支持这个判断的环节
- 在财务分析中把超预期数据当作验证、把低于预期数据当作噪音
- 在风险分析中把空头论点写得更弱

每一步看起来都很合理，但整篇分析变成了对一个预设结论的论证，而不是对事实的调查。

**改造后的顺序**：业务事实先行，市场认知后置。

```
P0 公司画像   →  这家公司靠什么赚钱       ← 事实
P1 行业定位   →  赛道多大、格局如何       ← 事实
P2 深度穿透   →  钱被产业链哪层赚走了     ← 事实
P3 财务预测   →  数字背后发生了什么       ← 事实
─────────────────────────────────────────
P4 市场认知   →  市场在哪可能错了         ← 判断（只提问）
P5 估值定价   →  隐含预期反解 + 多锚交叉  ← 判断
P6 执行方案   →  买多少、什么价、何时退   ← 决策
P7 最终裁决   →  一句话可证伪的结论       ← 结论
```

**关键约束**：P0–P3 只处理事实，禁止出现任何结论性表述。P4 只提出问题，禁止给出结论。这个约束把「事实收集」与「判断」在时间上分离，使两者互相独立。

## 二、P0 · 公司画像

**核心问题**：这家公司是做什么的？靠什么赚钱？

这是最高优先级的阶段。如果在这一步无法建立基本理解，后续所有分析都是在沙地上建楼。

### 2.1 必产出

#### ① 一句话公司定义

- 外行能听懂，不含行业术语
- **禁止使用**：赋能、生态化、全链路、一站式、闭环
- 检验方法：拿这句话给一个非金融从业者看，他能否复述

**为什么禁用那些词**：它们不是描述，是**掩盖**。当一个人说「我们提供一站式全链路赋能解决方案」时，通常意味着他自己也说不清具体在卖什么。这类词出现在分析报告里，是把「没理解」伪装成「理解了」。

#### ② 商业模式五维

| 维度 | 要回答的问题 |
|---|---|
| 客户 | 谁付钱？为什么付？ |
| 产品 | 卖的是什么？解决什么问题？ |
| 渠道 | 怎么触达客户？ |
| 收入模式 | 一次性？订阅？按量？ |
| 成本结构 | 固定成本还是变动成本？边际成本走势？ |

#### ③ 分业务拆解表

**必须一次性完整呈现，不允许分散到后续章节。**

| 业务线 | 收入 | 收入占比 | 毛利率 | YoY 增速 | 趋势方向 |
|---|---|---|---|---|---|
| 业务 A | | | | | |
| 业务 B | | | | | |
| **合计/整体** | | 100% | | | |

**加权验证**（强制）：

```
Σ(各业务线收入占比 × 各业务线毛利率) ≈ 公司整体毛利率
```

**容差 2 个百分点**。超出说明拆解口径不自洽 —— 可能是内部抵消未处理、口径不一致、或者拆解本身是估算的。

**为什么这一步不能简化**：后续所有判断都依赖这张表。行业定位要看哪块业务在哪个赛道；产业链分析要针对具体业务；估值要做分部估值。表做不对，后面全错。

#### ④ 分业务同业对标

至少 6 家可比公司，**按分业务线 PK 毛利率与增速**，而不是只比公司整体。

一家公司整体毛利率 45% 而同业 30%，可能是因为业务结构不同（比如做高端产品），而不是效率更高。只有分业务对比才能区分。

### 2.2 深度检查点

```
□ 一句话定义是否通过了「外行复述」测试？
□ 分业务收入合计是否等于整体营收（偏差 < 2%）？
□ 加权毛利率是否等于整体毛利率（偏差 < 2pp）？
□ 每条业务线是否有对应的可比公司？
□ 商业模式五维是否全部回答，且没有用「多元化」「综合服务」这类模糊词？
```

## 三、P0.9 · 公司全息理解

**核心问题**：如果我是这家公司的 CEO，我能回答以下所有问题吗？

这一步不解决估值问题，它解决的是**「我真的理解这家公司吗」**。

### 3.1 八维认知

| # | 维度 | 问题 |
|---|---|---|
| 1 | 产品与服务 | 它到底在卖什么？解决什么问题？ |
| 2 | 客户体验 | 做它的客户是什么感觉？ |
| 3 | 收入模型 | 钱是怎么从客户口袋流到公司账上的？ |
| 4 | 日常运营 | 这家公司的一天是怎样的？ |
| 5 | 组织与文化 | 在里面工作是什么感觉？ |
| 6 | 历史演化 | 这家公司是怎么走到今天的？ |
| 7 | 战略路线图 | 管理层想把公司带向哪里？ |
| 8 | 死亡清单 | 什么能杀死这家公司？ |

### 3.2 两条硬约束

**约束一：本阶段禁止使用任何分析框架。**

不允许引用五力模型、护城河评分、DCF —— 只用常识和调研回答。因为框架会把「没想清楚」包装成「分析过了」。

**约束二：每个维度至少引用 2 个独立数据来源。**

### 3.3 芒格死亡清单

从 CEO 视角（而非投资者视角）回答八种死亡路径：

| # | 死亡路径 | 可能性 | 影响幅度 |
|---|---|---|---|
| 1 | 技术被替代 | 高/中/低 | |
| 2 | 核心客户流失 | | |
| 3 | 供应链断裂 | | |
| 4 | 关键人才出走 | | |
| 5 | 监管政策变化 | | |
| 6 | 价格战 | | |
| 7 | 资产负债表恶化 | | |
| 8 | 道德风险事件 | | |

**为什么用 CEO 视角**：投资者视角关注「股价会不会跌」，CEO 视角关注「公司会不会死」。前者会漏掉那些缓慢但致命的问题。

## 四、P1 · 行业定位

**核心问题**：这个赛道多大、增速多快、竞争格局如何。

### 4.1 必产出

**① 空间测算（TAM / SAM / SOM）**

| 层级 | 定义 | 数值 |
|---|---|---|
| TAM | 理论总市场 | |
| SAM | 可服务市场（受地域/技术/资质限制） | |
| SOM | 可获得市场（受产能/渠道限制） | |

**层级不得倒挂**：TAM ≥ SAM ≥ SOM。倒挂说明口径混乱。

**② 渗透率与生命周期定位**

| 阶段 | 特征 | 增速 | 估值方法 |
|---|---|---|---|
| 导入期 | 技术验证，商业模式探索 | 波动大 | 收入倍数 + TAM |
| 成长期 | 标准化 + 渗透率提升 | 高 | 增长调整倍数 |
| 成熟期 | 增速放缓，格局稳定 | 中低 | 盈利倍数 + 分红 |
| 衰退期 | 需求下降，产能过剩 | 0 或负 | 资产价值 |

**③ 竞争格局**

CR3 / CR5 集中度、行业生命周期位置、主要玩家的份额变化趋势。

**④ 同业四维对标表**（≥6 家）

按 收入 / 毛利率 / 增速 / 估值 四个维度列出，包含中位数行与标的行。

### 4.2 深度检查点

```
□ TAM/SAM/SOM 是否层级正确、数据来源是否标注？
□ 渗透率定位是否与生命周期判断一致？
□ 同业对标是否分业务线，而非只比整体？
□ 是否识别出行业的关键价值驱动因子（KVD）？
```

## 五、P2 · 深度穿透

**核心问题**：这个产业到底怎么运转？钱被谁赚走了？

这是全篇最长、最深、最核心的一章。**工序级、排除性、量化**三项缺一不可。

详细方法见 [04-产业链瓶颈方法论](04-产业链瓶颈方法论.md)，此处只列深度标准。

### 5.1 必产出

| # | 产出 | 深度要求 |
|---|---|---|
| 1 | 产业链 BOM 拆解 | ≥7 层，每层描述**具体工序**而非行业名称，标注全球供应商数、认证周期、单件价值量 |
| 2 | 竞争者排除矩阵 | ≥5 家被排除的玩家，逐家说明排除原因 |
| 3 | 产能→收入量化桥梁 | 设备台数 × ASP × 交付率 × 验收率，五个字段齐全 |
| 4 | 瓶颈分级 | 基于客观判据（供应商数量、认证周期），可证伪 |
| 5 | 利润池分析 | 各层按「利润规模 × 利润率」排序，识别标的所处的位置 |
| 6 | 技术路线图 | 当前→下一代跃升点 + ≥3 条替代路径 |

### 5.2 深度检查点

```
□ 产业链是否拆到 ≥7 层？
□ 每层写的是工序还是行业？（含「行业」「领域」「板块」的层级名不合格）
□ 每层是否标注了单件价值量？
□ 排除矩阵是否 ≥5 家，且每家理由是否有实质内容（>10 字）？
□ 产能桥梁的五个字段是否齐全？
□ 瓶颈分级的判据是否客观可核查？
```

## 六、P3 · 财务预测与盈余质量

**核心问题**：利润数字背后真正发生了什么？

### 6.1 三表联动五年预测

**损益表 / 资产负债表 / 现金流量表**，且必须勾稽验证。

**推荐做法**：让权益由「资产 − 负债」倒算，使恒等式天然成立。

```
总资产 = 收入 / 资产周转率
总负债 = 总资产 × 杠杆率
总权益 = 总资产 − 总负债        ← 倒算，恒等式必然成立
```

这样做的价值：**任何不平衡都指向真实的建模错误，而不是舍入误差。** 如果反过来先预测权益再验证资产，报表永远差一点，而你无法判断差的那一点是错误还是精度问题。

### 6.2 法务会计四模型

| 模型 | 回答的问题 | 关键阈值 |
|---|---|---|
| Beneish M-Score | 盈余操纵概率是否异常偏高 | > -1.78 需进一步核查 |
| Piotroski F-Score | 基本面是否在改善 | ≥7 分改善信号强 |
| Altman Z-Score | 短期财务困境风险 | < 1.81 困境区 |
| Sloan 应计比率 | 利润中非现金成分占比 | > 10% 利润现金含量偏低 |

**四项都是筛查工具，命中不等于结论。** 每个模型都有已知误报来源，引用时必须同时给出局限。例如 Beneish 对高成长公司天然得分偏高（因为营收增长指数权重高）。

### 6.3 先导指标追踪

| 指标 | 为什么领先 |
|---|---|
| 合同负债（预收） | 客户已付钱，收入将在未来确认 |
| 发出商品 | 已发货未确认收入 |
| 存货中在产占比 | 生产节奏的前瞻信号 |

**关键判读**：如果合同负债与发出商品大增但利润没跟上 → 「订单爆发、利润滞后」的强证据。这比任何预测模型都直接。

### 6.4 深度检查点

```
□ 预测年数是否 ≥5？
□ 三表是否勾稽平衡（资产 = 负债 + 权益，容差 0.5%）？
□ 分业务收入加总是否等于整体营收（偏差 <2%）？
□ 法务会计结果是否附带了各自的局限说明？
□ 是否追踪了至少一个先导指标？
```

## 七、P4 · 市场认知与定价假设

**核心问题**：市场在什么问题上可能犯了错误？

### 7.1 本阶段的硬性约束

```
⛔ 只提出问题，不给结论。

禁止出现「我们认为」「我们的判断」「应该」「被低估」「市场错了」。
```

**原因**：业务认知刚刚建立。此时下判断，会让 P5-P7 变成对这个判断的论证。而只提问，可以让后面的估值与裁决真正独立。

**注意这个约束只适用于本阶段**。P5 之后可以给判断，因为那时判断已经建立在独立的事实基础上。

### 7.2 必产出

**① 市场定价假设识别**

不是「市场低估了」，而是：

```
当前 PE（X 倍）隐含了市场的什么假设？
  → 隐含 20XX 年净利 = Y 亿
  → 隐含增速 = Z%
  → 隐含毛利率 = W%
  这个数字对吗？
```

**② 反假设**

列出 2-3 个替代假设，每个标注「什么证据会支持这个替代假设」。

**③ 非共识发现（≥2 条）**

```
Step 1  列出市场最流行的 3 个看多理由 → 这些已被定价
Step 2  列出市场最流行的 3 个看空理由 → 每个藏着什么机会？
Step 3  提出 ≥2 个真正非共识的观点
         每条标注：为什么别人没想到？触发事件 + 概率 + 时间窗口
```

**④ 催化剂表**（≥4 个）

含时间、级别、状态、以及**它如何修正市场的定价假设**。

**⑤ 魔鬼代言人**

空头论证的高证据等级条数**不得少于多头**，且不少于 2 条。

检验标准：读完空头章节后，读者应该觉得「做空也有道理」。如果不会，说明空头写得太弱，是自我确认而非风险揭示。

**⑥ 反事实推理**

每条需含三要素：`if`（什么条件下）/ `then`（会怎样）/ `observable`（用什么指标观测）。

「如果需求下滑则收入下降」不合格 —— 缺少可观测指标。

**⑦ 周期 vs 成长判定**

见 [05-周期与成长判定](05-周期与成长判定.md)。判定结果直接决定 P5 使用哪个估值锚。

### 7.3 深度检查点

```
□ 本阶段是否出现了结论性表述？
□ 非共识论点是否 ≥2 条，且每条能被事实推翻？
□ 高证据等级空头论据是否 ≥ 多头？
□ 反事实推理是否含三要素？
□ 市场定价假设是否量化到了具体数字？
```

## 八、P5 · 估值与定价

**核心问题**：不是「值多少钱」，而是「要做到什么」。

### 8.1 反向优先

**必做项：反向 DCF** —— 把市值当作已知量，反解市场隐含的永续增速与折现率。

```
正向 DCF：我认为它值 41.2 元        → 观点，无法检验
反向 DCF：当前市值要求永续增速 3.5%  → 事实约束，可以检验
```

**反向 DCF 不产出目标价。** 这不是文档约定，是设计约束 —— 它的返回值里没有价格字段。

**不收敛也是结论**：如果市值高于任何合理参数下的价值，说明现金流假设无法解释当前市值。这本身是重要信号（可能是指数化锁定、做空受限下的乐观定价、或纯情绪），而不是「需要再调参数」。

### 8.2 多锚交叉

| 公司类型 | 主锚 | 副锚 | 交叉验证 |
|---|---|---|---|
| 真成长 | 增长调整倍数 | DCF | EV/EBITDA 底线 |
| 周期股 | 资产倍数分位 + 供需拐点 | EV/EBITDA | 分红率 |
| 成长转周期 | 毛利率趋势 | — | 立即清仓 |
| 混合型 | 分部估值 | 加权整体 | 分部之和 |

**硬约束**：至少 2 个锚；离散度 > 80% 判定结论不可靠。

### 8.3 增速可持续性检验

在使用任何以增速为核心的估值方法之前，必须回答三个问题：

```
□ 增速来源是渗透率（可持续）还是价格弹性（不可持续）？
□ 增速是否依赖一次性因素（补贴、抢装、涨价）？
□ 卖方一致预期增速的方差（分歧度）有多大？
```

**为什么必须做**：增长调整的估值方法（如 PEG）对增速的脆弱性极高。一个被叙事推高的增速假设，会让估值看起来非常便宜。

### 8.4 正向 DCF 的定位

正向 DCF 保留，但定位是**检验自身假设一致性**，不是定价输出。使用时必须披露：

```
终值占企业价值的比例 = ?
```

| 占比 | 判定 |
|---|---|
| < 50% | ✅ 结论稳健 |
| 50-70% | 🟡 中等依赖，需检查永续假设 |
| 70-85% | 🔴 高度依赖 |
| > 85% | 🛑 数值不可靠，应改用其他方法 |

## 九、P6 · 执行方案

**核心问题**：具体怎么做。

### 9.1 前置：尺度声明

```
本次分析的持有周期 = [短/中/长]
主导决策模块 = [价格行为 / 产业链盈利窗口 / 现金流与瓶颈等级]
```

**为什么必须显式声明**：绝大多数「信号矛盾」实际上是尺度矛盾。说清尺度，矛盾自动消失。

### 9.2 前置：制度排雷

任何信号（技术面、基本面、量化、新闻）进入执行前，先排除 A 股特有的隐藏风险。

| 类别 | 检查内容 |
|---|---|
| 资金链 | 质押比例、融资盘集中度、私募清盘线 |
| 制度 | 定增破发、解禁节奏、减持新规 |
| 信息 | 公告暗语、问询函、分析师反指 |
| 微观结构 | 集合竞价陷阱、盘口语言、价格笼子 |

**致命规则（任一触发即否决）**：

```
⛔ 质押比例 > 40%                    → 永远不做多
⛔ 北向单日大买但次日不持续            → 假信号
⛔ 交易所问询函                        → 存在监管层关注的问题
```

**原则：制度 > 技术。** 当制度规则与技术信号冲突时，制度优先。

### 9.3 仓位上限

仓位上限由三者的最小值决定：

```
仓位上限 = min(瓶颈等级对应上限, 治理评级对应折价, 环境评级对应天花板)
```

| 瓶颈等级 | 治理 A | 治理 B | 治理 C | 治理 D |
|---|---|---|---|---|
| 5 级（独家 + 长认证） | 25% | 20% | 15% | ❌ 不投 |
| 4 级（全球 2 家 + 长认证） | 20% | 15% | 10% | ❌ 不投 |
| 3 级（全球 2-3 家） | 15% | 10% | 8% | ❌ 不投 |
| 2 级（全球 3-4 家） | 8% | 5% | 3% | ❌ 不投 |
| 1 级（有差异化） | 3% | 2% | 1% | ❌ 不投 |

再与环境评级天花板取最小值（A ≤100% / B ≤70% / C ≤30% / D ≤10%）。

### 9.4 止损定义

```
止损价 < 入场价（否则不构成止损）
单笔风险 = (入场价 − 止损价) / 入场价 ≤ 20%
```

### 9.5 深度检查点

```
□ 是否声明了持有周期与主导模块？
□ 尺度冲突是否都已裁决？
□ 制度排雷是否完成，致命规则是否触发？
□ 仓位上限是否 ≤25%，环境是否允许开新仓？
□ 止损是否低于入场价，单笔风险是否在限？
```

## 十、P7 · 最终裁决

**核心问题**：这篇报告到底说了什么。

### 10.1 必产出

| # | 产出 | 要求 |
|---|---|---|
| 1 | 一句话核心论点 | **必须可证伪** |
| 2 | 情景概率加权 | 乐观/基准/悲观三情景 + 概率 |
| 3 | 关键假设追踪清单 | 5-7 条，每条附验证时点与可逆性 |
| 4 | 风险矩阵 | ≥10 类，标注逻辑破坏与黑天鹅 |

### 10.2 可证伪性标准

「行业景气度提升，公司有望受益」**不合格** —— 它无法被任何数据推翻。

合格的标准是：这句话能被写成一个可以被事实检验的命题。

| 不合格 | 合格 |
|---|---|
| 公司有望受益于行业增长 | 若 Q3 合同负债环比增长 >20%，则 20XX 年收入增速可达 X% |
| 估值具有吸引力 | 当前市值隐含永续增速 3.5%，若实际达成 5%，对应上行空间 X% |
| 技术领先 | 该工序全球仅 1 家可供应，若出现第二家认证通过，逻辑不成立 |

## 十一、终止规则

分析是一个逐步排除的过程。以下五个终止点用于及时止损分析资源。

### T0 · 全息认知终止点

```
触发条件：完成 P0.9 八维认知后，仍无法用一段话向外行解释这家公司
判定标准：
  → 八维认知画像存在 ≥3 个空白维度
  → 或：死亡清单 8 条中 ≥4 条无法回答
  → 或：无法用非专业语言描述公司核心产品

操作：立即停止分析
输出：
  □ 终止原因：「无法建立对公司业务的基本理解 · 不理解 = 不投资」
  □ 已完成摘要
  □ 进一步调研方向
  □ 重新分析触发条件：补全至少 6 个维度
```

### T1 · 估值脱节终止点

```
触发条件：周期判定 = 反身性溢价
判定标准：估值与基本面完全脱节，叙事驱动，无估值锚点
操作：立即停止分析

重新分析触发条件：
  → 股价回调 > 40%
  → 出现实质性业务突破（渗透率/产品/订单）
  → 连续 2 季度财报证明基本面可支撑估值
```

### T2 · 产业链深度终止点

```
触发条件：发现致命卡脖子环节，且标的无替代方案
判定标准：
  → 产业链中存在 ≥1 个环节被单一供应商垄断
  → 标的对该环节无自研能力且无替代供应商
  → 断供概率 > 30%
操作：停止后续章节分析

重新分析触发条件：
  → 标的公告自研突破 / 第二供应商认证通过
  → 地缘局势缓和
  → 替代技术路线出现
```

### T3 · 逻辑终止点

```
触发条件：反方论证压倒性优于正方
判定标准：
  → 魔鬼代言人八问中 ≥5 问无法有力反驳
  → 压力测试三情景中悲观情景概率 > 50%
操作：降级为「观望」，不进入 P5 估值

重新分析触发条件：
  → 反方核心论点被新数据证伪
  → 标的发布超预期业绩/订单/技术突破
  → 估值回调至安全边际充足区间
```

### T4 · 估值终止点

```
触发条件：安全边际 < 10%（基准情景）
判定标准：
  → 基准情景目标价 vs 当前股价，上行空间 < 10%
  → 或：成长股增长调整倍数 > 1.5 / 周期股资产倍数 > 历史 80 分位
操作：停止分析，不进入 P6 执行方案

重新分析触发条件：
  → 股价回调至安全边际 > 30%
  → 盈利上修使目标价提升 > 20%
  → 催化剂兑现使估值切换条件满足
```

### 终止报告格式

```
┌─────────────────────────────────────────┐
│  ⛔ 漏斗终止报告                          │
│  终止点: T[0/1/2/3/4] · [名称]            │
│  终止原因: [一句话]                        │
│  ───────────────────────────────────────  │
│  已完成分析摘要:                           │
│    [列出已完成阶段的核心发现]               │
│  ───────────────────────────────────────  │
│  重新分析触发条件:                         │
│    1. [条件1]                              │
│    2. [条件2]                              │
│    3. [条件3]                              │
│  ───────────────────────────────────────  │
│  建议: [回避 / 观望 / 等待回调]            │
└─────────────────────────────────────────┘
```

**终止 ≠ 否定**。终止意味着「不值得继续投入分析资源」，不代表公司不好。每个终止点都附重新分析触发条件 —— 条件满足时可以从终止点继续。
