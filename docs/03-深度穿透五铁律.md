# 深度穿透五铁律

> 「深度」是分析报告里最容易被滥用、也最难检验的词。本文把深度变成**可检查的条件**。
>
> 五条铁律的共同特征：**它们都是可以被违反的。** 一条无法被违反的要求不是纪律，是口号。

---

## 一、为什么需要把深度写成铁律

分析报告最常见的两种失败：

**失败一：深度不足，但看起来很深。**

一篇报告拆了产业链，写了六个层级：「上游材料层」「中游制造层」「下游应用层」「设备环节」「软件环节」「服务环节」。看起来结构清晰，实际上完全没有信息 —— 这六个名字任何人都能写出来，它们不包含任何关于「谁在做、有多难、值多少钱」的内容。

**失败二：深度足够，但不可验证。**

报告写了大量细节，读者无法判断这些细节是研究得出的还是编出来的。没有任何检查点能区分「做了功课」和「写了很多字」。

五条铁律的作用是：给「深度」设定**可检查的形态**。只要检查条件不满足，就是深度不足，不需要争论。

## 二、铁律零 · 业务事实必须最先建立

### 2.1 铁律内容

```
⛔ 公司画像（P0）必须在任何其他分析之前完成，且不可分散到后续章节。
```

具体包括：

| 必产出 | 检查条件 |
|---|---|
| 一句话定义 | 外行能听懂；不含「赋能/生态化/全链路/一站式/闭环」 |
| 商业模式五维 | 客户 × 产品 × 渠道 × 收入模式 × 成本结构，全部回答 |
| 分业务拆解表 | ≥2 条业务线；收入占比合计 = 1.0；加权毛利率 = 整体毛利率（容差 2pp） |
| 分业务同业对标 | ≥6 家可比公司，按业务线 PK |

### 2.2 为什么这是「零号」铁律

因为它约束的不是某个阶段的质量，而是**整个流程的起点**。

如果起点是错的 —— 比如把公司的主要收入来源理解错了 —— 后面每一章都会正确执行一个错误的前提。这类错误最难发现，因为所有局部检查都会通过。

### 2.3 常见违反形式

| 违反形式 | 表现 | 后果 |
|---|---|---|
| 拆解分散 | 业务 A 的收入在第三章讲，业务 B 的在第六章 | 无法做加权验证，口径容易串 |
| 只有一条业务线 | 「公司业务较为单一」一笔带过 | 掩盖了实际的多业务结构，或掩盖了没做功课 |
| 用模糊词替代 | 「公司主营业务为综合服务」 | 等于没写 |
| 对标只比整体 | 只比公司整体毛利率，不分业务 | 把业务结构差异误读为效率差异 |

## 三、铁律一 · 市场认知只提问，不给结论

### 3.1 铁律内容

```
⛔ 在市场认知阶段（P4），禁止出现任何结论性表述。

禁止词汇：
  「我们认为」「我们的判断」「应该」「被低估」「市场错了」
  「我们认为市场低估了……」
  「这家公司应该是……」

允许形式：
  「当前 PE 隐含了 XX 假设，这个假设对吗？」
  「市场主流观点是 A，存在的疑问是 B」
  「如果 X 发生，则 Y 假设不成立」
```

### 3.2 适用范围

**仅适用于 P4。** P5 之后可以给判断 —— 因为那时判断已经建立在独立的事实基础上。

### 3.3 为什么这条铁律只针对一个阶段

因为循环论证的风险集中在这一点上。

在业务事实建立之前讨论市场定价，会让后续所有分析被先入的判断锚定。一旦写下「市场低估了这家公司的技术壁垒」，接下来会不自觉地：

- 在产业链分析中更关注支持这个判断的环节
- 在财务分析中把超预期数据当作验证、低于预期数据当作噪音
- 在风险分析中把空头论点写得更弱

每一步看起来都合理，但整篇分析变成了对一个预设结论的论证。

### 3.4 检查方法

```
□ 搜索全文，是否出现「我们认为」「我们的判断」？
  → 出现在 P4 → 违规，重写
  → 出现在 P5 之后 → 允许
□ P4 的每个段落，是否可以改写成疑问句而不失原意？
  → 如果改不了（因为它本身是断言）→ 违规
```

## 四、铁律二 · 工序级 × 价值量级 × 排除性

### 4.1 铁律内容

产业链分析必须同时满足三个条件，缺一不可。

| 条件 | 要求 |
|---|---|
| **工序级** | 拆到具体制造步骤，含技术参数 |
| **价值量级** | 每层标注单件/单台价值与占资本开支比例 |
| **排除性** | 逐家说明为什么其他玩家做不到 |

### 4.2 工序级：合格与不合格的对比

| ❌ 行业口号层 | ✅ 工序级 |
|---|---|
| 「制冷剂层」 | 「R32 合成工序：二氟甲烷 + 氯气 → R32，催化剂 SbCl₅，温度 300°C」 |
| 「检测设备层」 | 「HBM 堆叠后通孔对准检测：3μm 分辨率、热应力补偿、10nm 对准精度」 |
| 「光学膜层」 | 「紫外固化硬化涂层合成：涂布厚度 3-5μm、固化能量 800mJ/cm²」 |

**判定规则**：层级名称中包含「行业」「领域」「板块」即不合格。

**为什么**：这些词是**分类**，不是**工序**。分类可以无限细分而不增加任何信息；工序则包含具体的技术约束，技术约束才决定「谁能做」。

### 4.3 价值量级：三个必须标注的数

| 数值 | 含义 | 为什么重要 |
|---|---|---|
| ASP | 单台/单件价值 | 决定了这个环节的市场规模上限 |
| 占资本开支比例 | 买这一台设备占整条产线预算的百分比 | 决定了客户的采购优先级 |
| 中国参与度 | 自给率 / 全球份额 / 技术代际差距（年） | 决定了国产替代的空间 |

**没有这三项，产业链分析就退化成了流程图。** 流程图告诉你顺序，不告诉你钱在哪里。

### 4.4 排除性：竞争者排除矩阵

只列出「竞争者有谁」是没有信息量的。有价值的是**为什么其他家做不到**。

| 公司 | 看起来能做 | 实际被排除的原因 | 排除类型 |
|---|---|---|---|
| 公司 A | 分辨率达标 | 无对准算法，至少 3 年研发 | 技术缺失 |
| 公司 B | 有算法、有产能 | 产能满负荷，2 年内无法新增客户 | 产能约束 |
| 公司 C | 技术成熟 | 出口管制限制对华销售 | 政策禁令 |
| 公司 D | 行业龙头 | 专攻其他细分赛道 | 赛道不同 |
| 公司 E | 全产品线 | 价格高 30%，客户寻求备份 | 竞争在位 |

**格式要求**：

```
≥5 家被排除的玩家
每家必须给出：[排除原因] + [量化差距指标]
排除理由长度 ≥10 字（「不行」「太贵」不合格）
```

**排除矩阵的真正价值**：它把「全球只有 2 家能做」这个断言从**主张**变成了**结论**。前者无法验证，后者可以逐条反驳 —— 如果有人能指出第 6 家其实也能做，整个判断就需要修正。

## 五、铁律三 · 产能到收入的量化桥梁

### 5.1 铁律内容

```
⛔ 禁止从「产能 XX 万吨」直接跳到「收入 XX 亿」。
   必须构建完整的量化桥梁。
```

### 5.2 桥梁公式

```
收入 = 设备台数 × ASP × 交付率 × 验收率

五个字段缺一不可：
  □ 设备台数（附计算过程：X 万片月产能需要 Y 台设备）
  □ ASP（单台价格）
  □ 交付率（实际交付 / 订单）
  □ 验收率（通过验收 / 已交付）
  □ 单位（明确量纲）
```

### 5.3 为什么不能跳跃

「产能 10 万吨 → 收入 50 亿」这个推断隐含了四个未验证的假设：产能真的能开满、产品真的能卖出、价格真的能维持、收入真的能确认。每一个假设都可能不成立，而跳过它们会让最终结论看起来非常确定。

**桥梁的作用是让每个假设可见**。当四个假设都写在表上时，读者可以自己判断哪个最脆弱。

### 5.4 配套：交付与验收节奏

| 环节 | 需要说明 |
|---|---|
| 交付节奏 | Q1 X% / Q2 Y% / Q3 Z% / Q4 W% |
| 验收周期 | 设备到厂后多久验收（通常 3-6 个月） |
| 收入确认 | 各季度确认的收入表 |
| 毛利率路径 | 初期毛利率 / 稳态毛利率及依据 |

**这几项的价值**：它们让「下个季度收入会是多少」变成可以独立推算的问题，而不必依赖卖方一致预期。

## 六、铁律四 · 强制发现非共识

### 6.1 铁律内容

```
⛔ 必须提出 ≥2 条真正的非共识观点。
   每条必须标注：为什么别人没想到？触发事件 + 概率 + 时间窗口。
```

### 6.2 三步法

```
Step 1  列出市场最流行的 3 个看多理由
        → 这些已经被定价，不构成 alpha

Step 2  列出市场最流行的 3 个看空理由
        → 每一个藏着什么被忽略的机会？

Step 3  提出 ≥2 个真正非共识的观点
        检验标准：与市场主流观点有明显分歧，且能被事实推翻
```

### 6.3 什么叫「真正的非共识」

| ❌ 伪非共识 | ✅ 真非共识 |
|---|---|
| 「市场没注意到这家公司的技术优势」 | 「市场认为第 3 家供应商会在 2027 年认证通过，但该公司 2025 年已停止相关产线投资」 |
| 「估值被低估了」 | 「市场用成熟期倍数定价，但该产品的渗透率仅 8%，处于 S 曲线加速段起点」 |
| 「行业前景好」 | 「行业产能出清已完成，但市场仍在用产能过剩期的资产倍数定价」 |

**判定方法**：这句话如果被市场主流看到，会不会引起争论？不会 → 伪非共识。

### 6.4 与信息增量审计的关系

非共识的质量最终由信息增量等级检验：

| 等级 | 定义 | 处理 |
|---|---|---|
| L1 | 全市场共识 | 零增量 |
| L2 | 部分先知先觉 | 已被部分定价 |
| L3 | 独立发现 | 高增量，需验证 |
| L4 | 非共识 | 高 alpha 潜力 |

**报告整体的 L3 + L4 占比应 ≥ 30%**。低于此值标记为「低增量报告」，降低仓位建议权重。

## 七、铁律五 · 估值必须分析切换触发条件

### 7.1 铁律内容

```
⛔ 估值必须回答：在什么条件下，应该从当前估值锚切换到另一个锚？
   以及切换之后的估值是多少？
```

### 7.2 为什么这条能防止循环论证

循环论证的典型形式：

```
问：为什么给 22 倍 PE？
答：因为可比公司是 22 倍。
问：为什么可比公司是 22 倍？
答：因为市场认可这个估值水平。
```

这个论证没有任何新信息 —— 它只是把「市场当前定价」重新表述了一遍。

**打破循环的方法**：分析**切换条件**。

```
当前 PE 22 倍 → 隐含假设：20XX 年净利 45 亿，增速 20%

触发条件 A：半年报净利 > X 亿
  → 20XXE 上调至 Y 亿
  → PE 压缩至 Z 倍（估值不变的情况下）

触发条件 B：连续 N 季度利润维持高位
  → 市场认可增速可持续
  → PE 扩张至 W 倍

如果两个条件都不出现：
  → 当前估值水平无法维持，向下修正
```

### 7.3 必产出

| # | 产出 | 要求 |
|---|---|---|
| 1 | PE 隐含假设分析 | 量化到具体数字 |
| 2 | 切换触发条件 | ≥2 个，每个含触发事件与切换后的估值 |
| 3 | 反向 DCF | 反解隐含增速与隐含折现率（不产出目标价） |
| 4 | 多锚交叉 | ≥2 个锚，离散度 ≤80% |
| 5 | 增速可持续性检验 | 三个问题全部回答 |
| 6 | 正向 DCF（附录） | 必须披露终值占比 |

## 八、五铁律的检查总表

| 铁律 | 检查条件 | 不通过的处理 |
|---|---|---|
| **零** 业务事实先行 | 分业务拆解完整 + 加权验证通过 | 禁止进入后续阶段 |
| **一** 市场只提问 | P4 无结论性表述 | 重写该阶段 |
| **二** 工序级×价值量级×排除性 | ≥7 层工序 + 价值量 + ≥5 家排除 | 补写，保留原内容 |
| **三** 产能收入桥梁 | 五个字段齐全 | 补写量化过程 |
| **四** 强制非共识 | ≥2 条可被推翻的非共识 | 重新提出 |
| **五** 估值切换条件 | 含隐含假设 + ≥2 个切换触发条件 | 重写估值章节 |

### 关于「不通过的处理」

**一律是补写，不是重写整篇。**

原因：报告的大部分内容是有效的，缺的是特定环节。全量重写会浪费已完成的工作，而且在时间压力下容易引入新错误。定位缺失章节、增量补写、重新校验 —— 这是标准流程。

## 九、铁律的工程化

五条铁律在本项目中都有对应的程序化实现（作为辅助材料）：

| 铁律 | 对应闸门 | 检查方式 |
|---|---|---|
| 零 | GATE-10 / GATE-11 | 定义长度与外行词汇检测；加权毛利率偏差 |
| 一 | GATE-15 / GATE-16 | 非共识条数；空头论据强度对比 |
| 二 | GATE-12 / GATE-13 | 层数与工序名检测；排除矩阵家数与理由长度 |
| 三 | GATE-14 | 五个字段完整性校验 |
| 四 | GATE-15 | 非共识条数与长度 |
| 五 | GATE-50 / GATE-51 | 反向 DCF 收敛；多锚数量与离散度 |

**注意**：闸门检查的是**形态**（是否齐全、是否达标），不检查**质量**（内容是否正确）。质量仍需人来判断 —— 这也是为什么这套体系是「人机协作」而非「全自动」。
