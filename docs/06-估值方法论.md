# 估值方法论

> 估值的核心问题不是「它值多少钱」，而是「当前价格要求它做到什么」。
> 本文按这个顺序展开：反向提问 → 多锚交叉 → 正向验证 → 分部分解 → 相对定位。

---

## 一、估值的第一原则：反向优先

### 1.1 正向 DCF 的结构性缺陷

正向 DCF 的输出是一个价格，但这个价格大部分来自假设：

```
企业价值 = 预测期现金流现值 + 终值现值

在典型参数下：
  终值占企业价值的比例 = 60% - 85%
```

这意味着那个精确到小数点后两位的「目标价」，绝大部分来自对永续增长率的一个假设。把假设包装成数字，会产生两个后果：

**后果一：伪精确。** 使用者以为得到的是客观结果，实际上是自己假设的回声。

**后果二：不可证伪。** 「目标价 41.2 元」这个判断，除了等股价走到那里，没有别的方式检验它对不对。

### 1.2 反向 DCF 的提问方式

反过来问：

```
正向：我认为它值 41.2 元
      → 观点，无法检验

反向：当前市值要求永续增速 3.5%、折现率 10%
      → 事实约束，可以检验
```

**第二个问题立刻产生可检验的子问题**：3.5% 的永续增速可信吗？

对照历史增速、同业水平、产能规划，这个问题有答案。而「值 41.2 元」没有。

### 1.3 三条硬性约束

**约束一：不产出目标价。**

反向 DCF 的输出是隐含增速与隐含折现率，**没有价格字段**。

**约束二：不收敛就是结论。**

如果市值高于任何合理参数下的价值，返回的不是「最接近的解」，而是：

```
市值高于最乐观假设下的价值
→ 现金流假设无法解释当前市值
→ 需考虑指数化锁定、做空受限下的乐观定价、或市场错误定价
```

**约束三：不返回伪解。**

二分法达到迭代上限即判定未收敛，不给出「近似值」。

### 1.4 数学结构

```
目标：找到 g 使得 EV(g) = 市值 + 净负债

EV(g) = Σ FCFFₜ/(1+WACC)ᵗ + [FCFFₙ(1+g)/(WACC−g)]/(1+WACC)ⁿ

EV 关于 g 单调递增 → 可直接二分
搜索区间：g ∈ [-10%, WACC − 1.5%]
```

上界取 `WACC − 1.5%` 是因为当 g 接近 WACC 时，永续模型数值不稳定（分母趋零）。

## 二、DCF 完整方法论

虽然在体系中 DCF 不作为主要定价工具，但方法论本身必须完整 —— 因为它同时是「检验自身假设一致性」的工具。

### 2.1 WACC 构建

```
WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1−t)
```

**股权成本 Ke（CAPM）**：

```
Ke = Rf + β × ERP + CRP
```

| 参数 | 说明 | A 股典型值 |
|---|---|---|
| Rf（无风险利率） | 10 年期国债收益率 | 2.5-3.0% |
| β（贝塔） | 相对大盘的波动敏感度 | 消费 0.8 / 科技 1.3 |
| ERP（股权风险溢价） | 股权投资相对债券的超额回报 | 5.5-6.5% |
| CRP（国家风险溢价） | 特定市场附加 | 0-0.5% |

**β 的三种取法**：

| 方法 | 做法 | 评价 |
|---|---|---|
| 历史 β | 回归过去 3-5 年月收益率 | 最常用，但有幸存者偏差 |
| 调整 β | 历史 β × 0.67 + 1.0 × 0.33 | 默认做法 |
| 行业 β | 用可比公司 β 去杠杆再重杠杆 | **最合理** |

**债务成本 Kd**：公司有效借贷利率，A 股通常 4.0-6.0%。

**WACC 典型范围**：

| 类型 | WACC |
|---|---|
| 大型蓝筹 | 7-9% |
| 中型成长 | 9-12% |
| 小型/高风险 | 12-15% |

**关键提醒**：WACC 每变化 1%，估值变化可达 15-25%。**永远做 WACC 敏感性分析。**

### 2.2 自由现金流（FCFF）

```
FCFF = EBIT × (1−t) + D&A − CapEx − Δ运营资本
```

**三条路径交叉验证**：

```
路径 1（从净利润出发）
  FCFF = 净利润 + 利息×(1−t) + D&A − CapEx − Δ运营资本

路径 2（从 EBIT 出发）
  FCFF = EBIT×(1−t) + D&A − CapEx − Δ运营资本

路径 3（从经营现金流出发）
  FCFF = 经营现金流 − 利息×(1−t) − CapEx
```

**三条路径的结果偏差通常 ±20%**，取均值作为基准。偏差过大说明某个科目的口径有问题。

### 2.3 终值（TV）—— 最敏感的参数

**必须用三种方法交叉验证**：

| 方法 | 公式 | 合理性 |
|---|---|---|
| **永续增长法** | `TV = FCFₙ × (1+g) / (WACC − g)` | g 用通胀率（2-3%）最合理 |
| **退出倍数法** | `TV = EBITDAₙ × 行业平均 EV/EBITDA` | 用当前行业平均或公司历史平均 |
| **零增长法** | `TV = NOPATₙ / WACC` | 最保守，可作为下限 |

**g 的合理性判据**：

```
g > GDP 增速      → ❌ 不合理（除非公司能永久扩张份额）
g = 通胀率（2-3%） → ✅ 最合理
g = 0%            → 保守，适用于周期行业
g < 0             → 适用于衰退行业
```

### 2.4 终值占比检查

```
终值占比 = 终值现值 / 企业价值
```

| 占比 | 判定 | 处理 |
|---|---|---|
| < 50% | ✅ 结论稳健 | 可正常参考 |
| 50-70% | 🟡 中等依赖 | 检查永续假设 |
| 70-85% | 🔴 高度依赖 | 需交叉验证 |
| > 85% | 🛑 数值不可靠 | 改用其他方法（如收入倍数） |

**占比 > 85% 时的处理**：说明这个公司不适合用 DCF —— 通常是高成长或尚未盈利的公司，应改用收入倍数 + 空间测算。

### 2.5 三段验证

**第一段：隐含假设反推**

```
当前股价 → 反解市场假设的增速/g

如果隐含增速 > 行业实际增速的 2 倍  → 高估
如果隐含增速 < 行业实际增速         → 可能低估
```

**第二段：情景分析**

| 情景 | 概率 | 假设来源 |
|---|---|---|
| 乐观 | 25% | 超预期执行 |
| 基准 | 55% | 管理层指引 |
| 悲观 | 20% | 行业下行 |

```
加权期望回报 = Σ(情景回报 × 概率)
```

**第三段：敏感性矩阵**

```
WACC 行 × 永续增速 g 列 → ≥9 格
交叉输出估值，标注最大敏感参数
```

### 2.6 适用范围

DCF 更适合**成熟稳定的现金流型公司**。对于增速高度非线性、或尚未盈利的公司，匀速增长假设与实际情况根本矛盾。

判定方法就是上面的终值占比检查：占比 > 85% 说明不适用。

## 三、分部分解估值（SOTP）

适用于多业务线、多行业交叉的复杂标的（控股公司、转型公司、孵化型公司）。

### 3.1 核心问题

```
整体估值 ≥ 各部分估值之和？
  是 → 集团存在协同溢价
  否 → 存在多元化折价
```

**多数多元化集团存在折价**：因为投资者可以自己买各部分，不需要通过集团，而集团还多了一层管理费用。

### 3.2 六步法

**Step 1 · 业务拆分**

拆成独立可估值的业务单元。每个单元必须有：

```
□ 独立营收 / 利润数据（至少可估算）
□ 独立可比公司群
□ 独立估值驱动因子
```

**Step 2 · 双路径验证营收**

| 路径 | 公式 | 示例 |
|---|---|---|
| TOP-DOWN | 空间 × 渗透率 × 市占率 | 总规模 × 渗透率 × 份额 |
| BOTTOM-UP | 用户数 × 单用户收入 | 活跃客户数 × 户均年收入 |

**收敛判定**：

| 偏差 | 置信度 | 处理 |
|---|---|---|
| < 10% | ✅ 高确信 | 取均值 |
| 10-30% | 🟡 中等 | 取偏保守方 |
| > 30% | 🔴 低确信 | 检查假设，取置信区间下限 |

**Step 3 · 各分部选估值方法**

| 业务类型 | 首选方法 | 备选 | 关键假设 |
|---|---|---|---|
| 成熟盈利 | 盈利倍数（可比公司） | DCF | 增速 / 利润率 / 资本结构 |
| 高增长亏损 | 收入倍数（可比公司） | EV/Sales | 增速 / 毛利率 / 烧钱率 |
| 金融类 | 资产倍数 + ROE | 盈利倍数 | 杠杆 / 不良率 / 息差 |
| 控股股权 | 净资产折价 | SOTP | 折价率（通常 20-40%） |
| 周期业务 | 正常化盈利倍数 | 资产倍数 | 周期位置 |
| 初创孵化 | 最新融资估值 | 收入倍数 + 空间 | 融资轮估值 |

**Step 4 · 各分部独立估值**

建立可比公司矩阵：**3-5 家可比公司 × 6 个维度**（营收 / 增速 / 毛利率 / 估值倍数 / ROE / EV/EBITDA），含中位数行与标的行。

**Step 5 · 汇总与调整**

```
分部估值汇总：
  分部 A（成熟）  ：¥XXX 亿  （盈利倍数 × 净利润）
  分部 B（成长）  ：¥XX 亿   （收入倍数 × 营收）
  分部 C（投资）  ：¥XX 亿   （净资产 × 折价率）
  + 净现金        ：¥XX 亿
  = 加总估值       ¥XXX 亿

调整项：
  - 集团管理费折价  -10%
  - 流动性折价      -5%
  - 控股溢价（如有） +10%
  = 调整后公平估值   ¥XXX 亿
```

**Step 6 · 敏感性分析**

对每个分部最重要的假设做 ±10% / ±20% 测试，输出保守 / 基准 / 乐观三列。

### 3.3 最致命的错误

```
假设各分部可独立估值，而忽略集团内部协同
```

每个分部估值时必须追问：**这项业务独立出来是不是更值钱？**

如果答案是「是」，那整体估值应该打折 —— 因为市场会给它打折。

### 3.4 非上市股权的估值顺序

数据可靠性从高到低：

```
① 最近一轮融资估值（有机构背书）
② 可比上市公司倍数 × 折价（30-50%）
③ 净资产账面价值（最低可信度）
```

## 四、相对价值定位

绝对估值回答「值不值」，相对估值回答「现在贵不贵」。

### 4.1 三层可比矩阵

| 层次 | 范围 | 筛选标准 | 用途 |
|---|---|---|---|
| 同市场同行 | 同行业同市场上市公司 | 行业分类 + 收入规模 | 确定本地合理区间 |
| 跨市场同业 | 同行业其他市场 | 行业 + 市值门槛 | 溢价/折价分析 |
| 全球对标 | 全球同行业龙头 | 各主要市场 | 终极估值天花板 |

每层提取 5-7 家可比公司，**剔除极端值**（亏损、倍数超千倍）。

### 4.2 分位偏离度

```
z-score = (当前倍数 − 历史均值) / 标准差
```

| z-score | 判定 |
|---|---|
| < −2.0 | 极度低估（历史罕见） |
| −2.0 ~ −1.5 | 明显低估 |
| −1.5 ~ −0.5 | 略被低估 |
| −0.5 ~ +0.5 | 合理区间 |
| +0.5 ~ +1.5 | 略被高估 |
| +1.5 ~ +2.0 | 明显高估 |
| > +2.0 | 极度高估（泡沫区） |

### 4.3 增长调整的决策规则

单纯的倍数比较会误导 —— 高倍数可能是因为高增长。必须做增长调整：

```
相对倍数 = 标的倍数 / 同业中位数倍数

相对倍数 > 1.2 且 标的增速 > 同业中位数  → 高倍数被高增长消化，可持有
相对倍数 > 1.2 且 标的增速 < 同业中位数  → 高倍数 + 低增长 = 估值泡沫
相对倍数 < 0.8 且 标的增速 > 同业中位数  → 低倍数 + 高增长 = 明显低估
```

### 4.4 跨市场溢价/折价

A 股相对全球同业的平均溢价来源：

| 因素 | 平均溢价 |
|---|---|
| 流动性溢价 | +10-15% |
| 成长性溢价 | +10-20% |
| 政策风险折价 | −10-20% |
| 外资参与限制折价 | −5-10% |
| **综合** | **+5-15%** |

用于把全球对标估值换算为本地可接受区间。

### 4.5 输出形式

**输出分位区间，不输出单点倍数。**

「给 30 倍估值」是一种观点；「当前处于同业第 85 分位」是一个事实。

| 分位 | 判定 |
|---|---|
| ≥ 80% | 估值偏高，需更高增速或更强护城河支撑 |
| 20-80% | 位于中位区间 |
| ≤ 20% | 估值偏低，需排查是否基本面劣化所致 |

**注意最后一条**：低估值不一定是机会。处于同业低分位可能是因为市场已经预期到基本面会恶化。

## 五、多锚交叉验证

### 5.1 锚的选择

| 公司类型 | 主锚 | 副锚 | 交叉验证 |
|---|---|---|---|
| 真成长 | 增长调整倍数 | DCF | EV/EBITDA 底线 |
| 周期股 | 资产倍数分位 + 供需拐点 | EV/EBITDA | 分红率 |
| 成长转周期 | 毛利率趋势 | — | 立即清仓 |
| 混合型 | 分部估值 | 加权整体 | 分部之和 |

### 5.2 硬约束

```
□ 至少 2 个锚
□ 各锚离散度 ≤ 80%
□ 每个锚必须注明方法
```

**离散度计算**：

```
离散度 = (最大值 − 最小值) / 均值
```

离散度 > 80% 说明不同方法给出的结论相互矛盾，此时不应选一个「看起来合理」的，而应判定结论不可靠。

### 5.3 为什么单一锚不行

| 情形 | 单一锚的问题 |
|---|---|
| 只有增长调整倍数 | 增速假设被叙事推高时，估值显得异常便宜 |
| 只有 DCF | 终值假设主导结果，且不可证伪 |
| 只有相对倍数 | 同业本身可能整体高估或低估 |
| 只有分部估值 | 各分部的估值假设可能相互矛盾 |

不同方法的假设相互独立，交叉验证才能暴露矛盾。

## 七、常见错误

| 错误 | 后果 |
|---|---|
| 把正向 DCF 的目标价当结论 | 输出自己假设的回声 |
| 反向 DCF 不收敛时强行调参 | 得到一个无意义的数 |
| 不检查终值占比 | 用不可靠的数值下结论 |
| 单一估值锚 | 无法发现方法间的矛盾 |
| 只比倍数不做增长调整 | 把高成长公司误判为高估 |
| 只看绝对分位不看基本面 | 把基本面恶化导致的低估当机会 |
| 分部估值忽略集团折价 | 高估多元化集团 |
| 敏感性只做单变量 | 忽略参数间的交互 |
