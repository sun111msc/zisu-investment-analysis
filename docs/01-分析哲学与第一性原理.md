# 分析哲学与第一性原理

> 所有具体方法都从本文推导。如果某条操作规则与本文的原理冲突，
> 改规则，不改原理。

---

## 一、为什么要先说哲学

分析体系最容易失败的方式不是「某个指标算错了」，而是「整套方法自我欺骗」。

典型的自我欺骗有三种：

**第一种：用深度掩盖方向错误。** 产业链拆到第七层、财务模型做到三表联动、估值用了四种方法 —— 但前提假设（这家公司真的不可替代吗）从未被检验。精致的过程掩盖了错误的起点。

**第二种：用框架代替判断。** 把所有能套的框架都套一遍（五力、护城河、DCF、PEG），输出一份看起来很专业的报告，但没有任何一个结论是框架之外独立得出的。框架变成了装饰。

**第三种：用数据代替推理。** 列了 200 个数据点，但没有任何一个数据点被用来推翻自己的判断。数据只被用来确认。

本文列出的原理，作用是在这三条路径上设置检查点。

## 二、第一性原理：利润即真理

### 2.1 原理表述

**股价的长期锚是企业创造现金的能力。**

叙事、题材、概念、政策预期，最终必须落到利润和现金流上。如果一家公司的股价上涨无法被任何未来的现金流假设解释，那它涨的是别的东西 —— 可能是指数纳入带来的被动买入，可能是做空受限下的乐观者定价，可能是纯粹的情绪。这些都可以推动价格，但它们不是**可持续**的。

**推论**：任何投资逻辑，必须能回答「这家公司未来靠什么赚钱、赚多少、什么时候赚到」。回答不了，逻辑不成立。

### 2.2 护城河验证公式

```
护城河真伪 = 毛利率稳定性 × 现金流转化率 × 客户不可替代性
```

三个因子是**乘法关系**，不是加权平均。这意味着任何一项接近于零，整体就接近于零。

| 通过项数 | 判定 | 处理 |
|---|---|---|
| 三项全通过 | 真护城河 | 可以重仓 |
| 任意两项 | 候选 | 需要深度验证缺失的那一项 |
| 任意一项不通过 | 画饼 | 严禁推荐 |

### 2.3 三项因子的具体判据

#### 因子一：毛利率稳定性

```
毛利率稳定性 = 近 5 年毛利率标准差 / 近 5 年毛利率均值
```

| 值 | 判定 | 含义 |
|---|---|---|
| < 8% | 🟢 强 | 定价权稳定存在 |
| 8-15% | 🟡 中 | 有一定波动，需查原因 |
| > 15% | 🔴 弱 | 定价权可能来自短期供需错配，非结构性 |

**为什么用稳定性而不是水平**：一家毛利率 20% 但十年稳定的公司，其护城河往往强于一家毛利率 50% 但三年内从 60% 跌到 35% 的公司。前者说明它在这个价位上掌握了定价权，后者说明它曾经掌握过。

**必须追问**：如果毛利率在下降，是价格下降还是成本上升？价格下降 → 竞争加剧；成本上升 → 可能是原材料，需要看能否转嫁。

#### 因子二：现金流转化率

```
现金流转化率 = 经营活动现金流 / 净利润
```

| 值 | 判定 |
|---|---|
| 持续 > 1.0 | 🟢 利润现金含量高 |
| 0.8 – 1.0 | 🟢 正常 |
| 0.5 – 0.8 | 🟡 需关注，检查应收账款与存货 |
| 持续 < 0.5 | 🔴 红旗，利润可能未收到现金 |

**为什么这一项最容易被忽略**：利润表是按权责发生制编制的，签了合同、发了货就能确认收入。但现金流不会骗人 —— 钱没到账就是没到账。一家连续三年净利润增长但经营现金流持续为负的公司，要么在高速扩张（可以解释，但需要看资本开支），要么在虚增收入（无法解释）。

#### 因子三：客户不可替代性

| 指标 | 绿灯 | 黄灯 | 红灯 |
|---|---|---|---|
| 前五大客户占比 | < 40% | 40-60% | > 60% |
| 单一最大客户占比 | < 15% | 15-30% | > 30% |
| 客户切换成本 | 认证周期 > 2 年 | 6 个月 – 2 年 | < 6 个月 |

**注意这里的方向**：客户集中度高通常被视为风险（依赖大客户），但它同时也是一个信号 —— 如果大客户离不开你，那集中度高反而是壁垒。关键在于区分「客户大且随时能换掉你」与「客户大但换不掉你」。

判断方法：看这家公司的产品在客户处是否通过了长期认证、是否被列入客户的合格供应商名录、客户历史上是否更换过供应商。

### 2.4 快速筛查

三个因子都不需要复杂模型，可以在 30 分钟内完成初筛：

```
□ 打开近 5 年年报，取毛利率序列 → 算标准差/均值 → < 15%?
□ 取近 5 年经营现金流与净利润 → 算比值 → 是否持续 > 0.8?
□ 取最新年报前五大客户占比 → < 60%? 查是否有长期认证?
```

三项全部通过 → 进入深度分析；任意一项不通过 → 需要解释，解释不通 → 终止。

## 三、第一性原理：覆巢之下无完卵

### 3.1 原理表述

**仓位上限不由个股质量决定，由市场环境决定。**

再好的标的，在市场系统性下行中也会被拖下去。区别只是跌多跌少。因此，在决定「买什么」之前，必须先决定「今天能不能买、最多买多少」。

### 3.2 环境四级评级

| 环境 | 特征 | 总仓位上限 | 开新仓 |
|---|---|---|---|
| **A 进攻** | 指数在均线上方、涨停家数多、赚钱效应强、资金持续流入 | ≤100% | ✅ 正常 |
| **B 中性** | 结构性行情、分歧期、主线清晰但资金分化 | ≤70% | ✅ 正常 |
| **C 谨慎** | 退潮前兆、赚钱效应转弱、成交量萎缩 | ≤30% | ⚠️ 瓶颈等级不足则跳过 |
| **D 防守** | 恐慌、冰点、系统性下跌、跌停家数激增 | ≤10% | 🛑 禁止开新仓 |

### 3.3 为什么这是投入产出比最高的一步

环境判断只需要几个数据：**成交量、涨跌家数比、涨停与跌停家数、赚钱效应（上涨家数占比）、主要指数位置。**

这些数据 1 分钟内可以取到。但它决定了后面所有分析结果的可用范围：

- A 级环境下，一个 3 级瓶颈的标的可以建到 15% 仓位
- D 级环境下，同样的标的只能观察，不能建仓

**这不是保守，这是数学**：在系统性下跌中，所有个股的相关性会趋近于 1。分散化在这个时刻失效，唯一的保护是低仓位。

### 3.4 环境评级的执行纪律

```
⛔ D 级环境下，无论标的多好，禁止开新仓。
   不是「谨慎开仓」，是「禁止」。
   唯一允许的动作是持有已建仓位与减仓。
```

这条纪律的价值在于：它把「要不要买」这个容易被情绪影响的问题，变成了「环境等级是多少」这个可以客观回答的问题。

## 四、第一性原理：没有催化剂的好股是死水

### 4.1 原理表述

**基本面优秀但缺少触发事件的标的，可能长期不涨。**

资金需要理由才能进入。一个「便宜且优质」的标的，如果没有催化剂，可能一直很便宜 —— 因为没有人有理由现在买入。

### 4.2 催化剂的三段式处理

催化剂不是「有没有」的问题，是「多大概率、多大影响、失败了怎么办」的问题。

**段一 · 概率评估**

| 字段 | 说明 |
|---|---|
| 事件 | 具体是什么（财报发布、客户认证、产能投产、政策落地） |
| 发生概率 | 高（>70%）/ 中（30-70%）/ 低（<30%） |
| 依据 | 客观事实：公司已预告、历史惯例、管理层指引 |

**段二 · 影响量化**

| 情景 | 估值影响 | 股价影响 | 概率加权 |
|---|---|---|---|
| 超预期 | +X% | +Y 元 | P1 × X% |
| 符合预期 | 0% | 0 元 | P2 × 0% |
| 低于预期 | -X% | -Y 元 | P3 × (-X%) |
| **概率加权期望** | | | **±Z 元（100%）** |

**段三 · 对冲策略**

| 情景 | 动作 |
|---|---|
| 兑现且超预期 | 持有或加仓 |
| 兑现但符合预期 | 持有，检查是否有下一个催化剂 |
| 兑现但低于预期 | 减仓 50%，3 日内重新评估 |
| 未兑现（延迟） | 查延迟原因，设定新截止日（30 天） |
| 逻辑证伪（永久失效） | 清仓 |

### 4.3 退出优先级

催化剂的状态直接决定退出优先级：

```
优先级 1️⃣  催化剂逻辑证伪            → 无条件清仓
优先级 2️⃣  主要催化剂已全部兑现
            且无新催化剂              → 减仓 50%
优先级 3️⃣  催化剂延迟超过原始窗口 2x  → 减仓 30%
```

### 4.4 硬规则

| 情形 | 处理 |
|---|---|
| 未来 60 天内无可识别催化剂 | 自动降权一档 |
| 催化剂已全部兑现且无新催化剂 | 标注「真空期」，建议减仓 |

**为什么是 60 天**：这是「等待」与「资金占用」之间的平衡点。超过 60 天没有催化剂的持仓，其机会成本会显著超过等待收益。

## 五、认知偏差自省：体系如何检查自己

任何分析体系都必须内置对自身的怀疑。以下是三个固定的自省机制。

### 5.1 幸存者偏差自省

**核心问题**：我现在分析这只股票，是因为筛选系统真的发现了什么，还是因为它涨了很多、吸引了我的注意力？

**三问**：

| 自省 | 问题 | 判断方式 |
|---|---|---|
| ① 赛道问 | 这个赛道的其他股票涨了吗？ | 对比至少 3 家同赛道标的涨幅 |
| ② 规则问 | 如果没有被纳入主要指数，它的价格会不同吗？ | 看指数纳入带来的被动买入量 |
| ③ 反面问 | 同一路径上那些没涨的公司，为什么没涨？ | 列 3-5 家同路径未涨标的，分析差异 |

**结论要求**：把涨幅分解为三个来源，并标注各自占比：

```
涨幅分解：
  行业贝塔贡献           ~X%
  指数晋级循环结构性锁定  ~Y%
  叙事与定价机制偏差      ~Z%
  基本面改善贡献          ~W%
  → 你的分析真正解释的可能只有 W%
```

**为什么这条重要**：规则从不挑选赢家，它只放大已经被选中的。如果分不清「规则放大的效果」和「被规则选中的原因」，就会把运气误认为能力。

### 5.2 信息增量审计

**核心问题**：这篇报告里有没有任何一句核心结论，是市场共识已经说过的？

对每章核心结论标注信息增量等级：

| 等级 | 定义 |
|---|---|
| **L1** | 全市场共识（几乎零增量） |
| **L2** | 部分先知先觉（有增量但已被部分定价） |
| **L3** | 独立发现（高增量，需验证） |
| **L4** | 非共识（与市场主流相反，高 alpha 潜力） |

**判定**：

| L3 + L4 占比 | 处理 |
|---|---|
| ≥ 30% | ✅ 正常输出 |
| < 30% | 🔴 标记为「低增量报告」，降低仓位建议权重（如凯利系数 × 0.5），**但不禁止输出** |

**为什么保留低增量报告**：它仍有存档和参考价值，只是不应被当作新的投资依据。禁止输出会浪费已完成的核对工作。

### 5.3 时间尺度冲突裁决

**核心问题**：不同时间尺度给出的信号互相矛盾时，听谁的？

**裁决规则**：先声明本次分析的持有周期，然后按周期确定主导模块。

| 持有周期 | 主导模块 | 其他模块的角色 |
|---|---|---|
| ≤ 3 个月 | 价格行为 | 基本面作为背景 |
| 3 – 12 个月 | 产业链瓶颈与盈利窗口 | 价格行为用于优化出入场 |
| ≥ 1 年 | 现金流与瓶颈等级 | 价格行为仅用于降低建仓成本 |

**冲突处理**：

| 情形 | 裁决 |
|---|---|
| 短线看空 + 长线看多 | 不冲突（尺度不同）→ 长线持有，短线用 30% 以内底仓做波段降成本 |
| 短线看空 + 长线看空 | 共振看空 → 立即减仓 |
| 短线看多 + 长线看空 | 反弹诱多 → 不参与 |

**为什么要显式声明尺度**：绝大多数「分析矛盾」实际上是尺度矛盾。把尺度说清楚，矛盾自动消失。

## 六、哲学层面的三条禁令

以下三件事在本体系中是禁止的，因为它们会系统性地破坏判断。

### 禁令一：在业务认知建立之前讨论市场定价

如果在还不清楚「这家公司靠什么赚钱」的时候就开始讨论「市场是不是低估了它」，后续所有分析都会被这个判断锚定。

**执行**：市场认知（P4）必须在业务事实（P0-P3）之后。在此之前，禁止出现「我们认为」「我们的判断」「应该」这类结论性表述。

### 禁令二：用单一估值锚下结论

不同估值方法可能给出相差两倍的结果。只报告其中一个，等于选择性地呈现。

**执行**：估值必须至少两个锚交叉验证，且离散度超过 80% 时判定结论不可靠。反向 DCF 不产出目标价 —— 它只反解市场的隐含假设。

### 禁令三：让空头论证弱于多头

如果空头章节只是列几条通用风险（「估值偏高」「竞争加剧」），而多头章节有五条带证据的论据，那不是风险揭示，是自我确认。

**执行**：高证据等级的空头论据条数不得少于多头，且不得少于 2 条。检验标准是：读完空头章节后，读者应该觉得「做空也有道理」。
