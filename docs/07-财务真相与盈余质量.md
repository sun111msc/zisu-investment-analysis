# 财务真相与盈余质量

> 利润表是按权责发生制编制的 —— 签了合同、发了货就能确认收入。
> 本文的任务是回答：这些利润里，有多少是真的。

---

## 一、财务分析的两个层次

| 层次 | 问题 | 方法 |
|---|---|---|
| **预测层** | 未来会赚多少钱？ | 三表联动预测 |
| **验证层** | 过去的利润是真的吗？ | 法务会计 + 盈余质量 |

**顺序不能颠倒。** 如果历史利润本身有问题，基于它做的预测毫无意义。

---

## 二、三表联动五年预测

### 2.1 为什么必须三表联动

单做损益表预测会漏掉两个关键约束：

- **资产负债表的约束**：收入增长需要营运资本和固定资产支撑，钱从哪来？
- **现金流量表的约束**：利润有没有变成现金？

只预测损益表的报告，本质上是在假设「增长不需要投入」—— 这个假设通常不成立。

### 2.2 推荐建模顺序

```
① 预测收入（分业务线加总）
② 预测利润率 → 得到净利润
③ 由收入 / 资产周转率 → 得总资产
④ 由总资产 × 杠杆率 → 得总负债
⑤ 总权益 = 总资产 − 总负债        ← 倒算
⑥ 由净利润 × 现金转化率 → 经营现金流
⑦ 由收入 × 资本开支率 → CapEx
⑧ FCFF = NOPAT + D&A − CapEx − Δ运营资本
```

**第 ⑤ 步是关键**：让权益倒算，勾稽恒等式天然成立。

```
资产 = 负债 + 权益
```

这样做的价值：**任何不平衡都指向真实的建模错误，而不是舍入误差。**

如果反过来先预测权益再验证资产，报表永远差一点，而你无法判断差的那一点是错误还是精度问题。

### 2.3 勾稽验证规则

```
□ 预测年数 ≥ 5
□ 每一年：资产 − (负债 + 权益) 的偏差 < 0.5%
□ 分业务收入加总 = 整体营收（偏差 < 2%）
□ 分业务利润加总 = 整体利润（偏差 < 2%）
□ 现金流表的期末现金 = 资产负债表的货币资金
```

## 三、法务会计四模型

这四个模型是**筛查工具**。命中不等于造假，未命中不等于安全。每个都有已知的误报来源。

### 3.1 Beneish M-Score —— 盈余操纵筛查

**公式**：

```
M = −4.84
    + 0.920 × DSRI
    + 0.528 × GMI
    + 0.404 × AQI
    + 0.892 × SGI
    + 0.115 × DEPI
    − 0.172 × SGAI
    + 4.679 × TATA
    − 0.327 × LVGI
```

**八个变量**：

| 变量 | 全称 | 计算 | 异常含义 |
|---|---|---|---|
| DSRI | 应收账款指数 | (应收/营收)ₜ ÷ (应收/营收)ₜ₋₁ | 应收增速快于营收 → 放宽信用卖货 |
| GMI | 毛利率指数 | 毛利率ₜ₋₁ ÷ 毛利率ₜ | > 1 表示毛利率恶化 |
| AQI | 资产质量指数 | (1−(流动资产+固定资产)/总资产)ₜ ÷ 同式ₜ₋₁ | 其他资产异常增加 |
| SGI | 营收增长指数 | 营收ₜ ÷ 营收ₜ₋₁ | 高增长本身是操纵诱因 |
| DEPI | 折旧指数 | 折旧率ₜ₋₁ ÷ 折旧率ₜ | > 1 表示折旧率下降（延长资产寿命） |
| SGAI | 费用率指数 | (销售管理费/营收)ₜ ÷ 同式ₜ₋₁ | 费用率上升 |
| TATA | 总应计 | (净利润 − 经营现金流) / 总资产 | **权重最高（4.679）**，应计占比过高 |
| LVGI | 杠杆指数 | 资产负债率ₜ ÷ 资产负债率ₜ₋₁ | > 1 表示负债率上升 |

**判读**：

| M-Score | 判定 |
|---|---|
| < −2.22 | 🟢 无操纵迹象 |
| −2.22 ~ −1.78 | 🟡 灰色地带 |
| > −1.78 | 🔴 存在操纵嫌疑，需进一步核查 |

**已知误报来源（必须披露）**：

```
高成长公司的 SGI 天然偏高（系数 0.892），会推高 M-Score
→ 对营收增速 > 30% 的公司，需结合成长性单独判断
```

### 3.2 Piotroski F-Score —— 基本面改善度

**九个信号，每项 1 分，总分 0-9**：

| # | 类别 | 信号 | 判据 |
|---|---|---|---|
| 1 | 盈利 | ROA 为正 | ROA > 0 |
| 2 | 盈利 | 经营现金流为正 | CFO > 0 |
| 3 | 盈利 | ROA 改善 | ROAₜ > ROAₜ₋₁ |
| 4 | 盈利 | 现金流优于利润 | CFO/总资产 > ROA |
| 5 | 杠杆 | 长期负债率下降 | (长期负债/总资产)ₜ < ₜ₋₁ |
| 6 | 流动性 | 流动比率改善 | 流动比率ₜ > ₜ₋₁ |
| 7 | 稀释 | 未增发 | 股本ₜ ≤ 股本ₜ₋₁ |
| 8 | 效率 | 毛利率改善 | 毛利率ₜ > ₜ₋₁ |
| 9 | 效率 | 资产周转率改善 | 周转率ₜ > ₜ₋₁ |

**判读**：

| 分数 | 判定 |
|---|---|
| ≥ 7 | 基本面改善信号强 |
| 4-6 | 中性 |
| ≤ 3 | 存在恶化信号 |

**注意第 7 项**：缺少股本数据时应标注未计入，并按比例折算满分，不能用 0 分代替。

### 3.3 Altman Z-Score —— 财务困境风险

**上市公司版**：

```
Z = 1.2×X₁ + 1.4×X₂ + 3.3×X₃ + 0.6×X₄ + 1.0×X₅

X₁ = 营运资本 / 总资产        （营运资本 = 流动资产 − 流动负债）
X₂ = 留存收益 / 总资产
X₃ = EBIT / 总资产
X₄ = 市值 / 总负债
X₅ = 营业收入 / 总资产
```

| Z 值 | 分区 |
|---|---|
| > 2.99 | 安全区 |
| 1.81 – 2.99 | 灰色区 |
| < 1.81 | 困境区 |

**非上市版（Z''）**：市值缺失时使用，将 X₄ 换为账面权益/总负债，系数改为 6.56 / 3.26 / 6.72 / 0 / 1.05，分区阈值为 2.6 和 1.1。

**已知局限**：该模型基于制造业样本校准，对轻资产、高研发或高预收模式的公司区分度下降，仅作筛查。

### 3.4 Sloan 应计比率 —— 利润现金含量

```
应计比率 = (净利润 − 经营现金流) / 总资产
```

| 值 | 判定 |
|---|---|
| < −5% | 🟢 现金流优于利润，质量高 |
| −5% ~ +5% | 正常 |
| +5% ~ +10% | 🟡 利润可能虚高 |
| > +10% | 🔴 严重预警 |

**核心逻辑**：应计利润驱动的高增长早晚会反转，现金流驱动的高增长才是真的。

**已知局限**：重资产扩张期的公司应计比率会自然偏高，需结合资本开支节奏解读。

## 四、盈利质量六维诊断

Beneish 只覆盖了盈余操纵的一个角度。完整的盈余质量检查需要六个维度。

### 4.1 六维与权重

| 维度 | 权重 | 检查内容 |
|---|---|---|
| M-Score | 25% | 盈余操纵信号 |
| 应计利润 | 20% | 利润现金含量 |
| 营收确认质量 | 20% | 收入是否真实 |
| 费用资本化 | 15% | 利润是否被美化 |
| 非经常性项目 | 10% | 核心利润占比 |
| 表外风险 | 10% | 隐藏负债 |

### 4.2 营收确认质量（四项红灯）

| 信号 | 含义 |
|---|---|
| 应收账款增速 > 营收增速 2 倍 | 可能通过放宽账期冲收入 |
| 营收增速 > 行业 2 倍且无合理解释 | 天然造假嫌疑 |
| 预收账款 / 合同负债大幅下降 | 未来收入可能失速 |
| 其他应收款暴增 | 资金可能被占用或转移 |

### 4.3 费用资本化检测（四项危险信号）

| 信号 | 含义 |
|---|---|
| 研发费用突然大幅下降 | 转为资本化，美化当期利润 |
| 销售费用资本化 | 将广告 / 促销费用推迟确认 |
| 折旧年限突然延长 | 减少当期折旧费用 |
| 利息费用资本化比例异常提高 | 美化当期利润 |

**核心逻辑**：把费用变成资产，当期利润就变好看了 —— 但代价是未来的摊销压力。这是一种时间上的利润转移，不是真的创造了利润。

### 4.4 非经常性项目排除

```
调整后净利润 = 净利润 − 非经常性收益 + 非经常性损失
```

| 项目 | 处理 |
|---|---|
| 资产出售收益 | 排除 |
| 政府补贴 | 标注依赖性；若占利润 > 20% 则危险 |
| 公允价值变动 | 排除（纸面利润，非现金） |
| 资产减值转回 | 排除（会计操控空间大） |

### 4.5 表外风险（四项陷阱）

| 陷阱 | 说明 |
|---|---|
| 养老金假设过于乐观 | 折现率 / 回报率假设激进 → 未来需补缴 |
| 经营租赁表外化 | 隐藏负债（新准则已部分解决） |
| 大洗澡（Big Bath） | 新任 CEO 巨额减值 → 下年轻松「反转」 |
| 商誉 / 总资产 > 30% | 收购后遗症，随时减值 |

### 4.6 综合评级

| 综合得分 | 评级 | 含义 |
|---|---|---|
| 4.5 – 5.0 | A | 利润质量极高 |
| 3.5 – 4.4 | B | 正常，少数可接受瑕疵 |
| 2.5 – 3.4 | C | 需保持警惕，存在明显风险 |
| 1.0 – 2.4 | D | 🛑 利润质量极差，可能正在造假 |

## 五、先导指标追踪

有些指标比收入和利润更早反映趋势。

### 5.1 三个核心先导指标

| 指标 | 领先性来源 | 判读 |
|---|---|---|
| **合同负债（预收）** | 客户已付钱，收入将在未来确认 | 环比大增 → 订单在增长 |
| **发出商品** | 已发货未确认收入 | 环比大增 → 即将确认 |
| **存货中在产占比** | 生产节奏 | 占比上升 → 备货中 |

### 5.2 关键判读模式

```
合同负债 + 发出商品 环比大增，但利润没跟上
  → 「订单爆发、利润滞后」的强证据
  → 这比任何预测模型都直接
```

**为什么这一项价值高**：它把「公司说订单很好」这个不可验证的说法，变成了两个可验证的会计科目。而且这两个科目造假成本高（需要真实的客户付款或发货记录）。

### 5.3 与提前信号的关系

先导指标（会计科目）与提前信号（供应链、招聘、专利）是两个独立的验证通道：

```
提前信号（外部可观测）  → 形成预判
先导指标（会计科目）    → 事后验证
两者交叉 → 提高置信度
```

## 六、现金流解剖

利润表可以被修饰，现金流表难度大得多。

### 6.1 四个核心检查

| 检查 | 公式 | 健康标准 |
|---|---|---|
| 现金转化 | 经营现金流 / 净利润 | 持续 > 0.8 |
| 自由现金流 | 经营现金流 − 资本开支 | 为正或可解释 |
| 资本开支效率 | 增量收入 / 增量资本开支 | > 1 |
| 现金循环周期 | 存货天数 + 应收天数 − 应付天数 | 稳定或下降 |

### 6.2 ROIC 树

```
ROIC = NOPAT / 投入资本

NOPAT = EBIT × (1 − t)
         ↗ EBIT = 营收 × 营业利润率
         |      ↗ 营收 = 量 × 价
         |      └ 营业利润率 = 毛利率 − 费用率
         └ (1−t) 有效税率

投入资本 = 运营资本 + 固定资产 + 无形资产
           ↗ 运营资本 = 应收 + 存货 − 应付
           ├ 固定资产
           └ 无形资产（含商誉、资本化研发）
```

**重要修正**：不资本化研发和租赁会严重高估 ROIC，尤其对科技和零售公司。

```
调整后 NOPAT = NOPAT + 研发资本化摊销 + 经营租赁利息
调整后投入资本 = 投入资本 + 资本化研发 + 经营租赁资产
```

### 6.3 杜邦分解与质量判定

```
ROE = 净利润率 × 资产周转率 × 权益乘数
      （盈利能力）（运营效率）（杠杆水平）
```

**判定规则**：

| ROE 来源 | 质量 | 说明 |
|---|---|---|
| > 50% 来自高利润率 | 🟢 最高 | 定价权驱动 |
| > 50% 来自高周转 | 🟡 中等 | 效率驱动 |
| > 50% 来自高杠杆 | 🔴 最弱 | 风险驱动 |

**为什么这个判定重要**：三个 ROE 相同的公司，质量可能完全不同。高利润率驱动的 ROE 最可持续；高杠杆驱动的 ROE 在下行周期会被放大成亏损。

## 七、财务叙事整合

财务分析的最后一步不是输出数字，而是回答：

```
数据验证了投资命题的哪些部分？
数据挑战了投资命题的哪些部分？
```

**格式**：

| 投资命题 | 财务证据 | 结论 |
|---|---|---|
| 公司具备定价权 | 毛利率稳定性 X%，现金流转化 Y | ✅ 验证 |
| 需求在加速 | 合同负债环比 +X% | ✅ 验证 |
| 成本可控 | 费用率上升 X pp | ❌ 挑战 |

**这一步的意义**：它把财务分析从「报表解读」变成「命题检验」。前者是描述，后者是判断。

## 八、检查清单

```
【三表联动】
□ 预测年数 ≥5？
□ 每年勾稽平衡（偏差 <0.5%）？
□ 分业务加总一致（偏差 <2%）？

【法务会计】
□ Beneish 八个变量是否齐全？
□ 是否披露了高成长公司的误报风险？
□ Piotroski 是否因缺股本数据而未计入第 7 项？
□ Altman 是否在市值缺失时切换为 Z'' 版本？
□ Sloan 是否结合资本开支节奏解读？

【盈余质量六维】
□ 应收账款增速是否异常快于营收？
□ 是否有费用资本化的迹象？
□ 非经常性项目占比多少？
□ 商誉占总资产比例？
□ 政府补贴占利润比例？

【先导指标】
□ 是否追踪了合同负债与发出商品？
□ 两者与利润的变化是否一致？

【现金流】
□ 现金转化率是否持续 >0.8？
□ ROIC 是否做了研发与租赁调整？
□ ROE 的主要来源是什么（利润率/周转/杠杆）？
```

## 九、常见错误

| 错误 | 后果 |
|---|---|
| 只做损益表预测 | 忽略资本需求与现金流约束 |
| 用零值填充缺失科目 | 制造假精确 |
| 把法务会计命中当结论 | 误报率高，需人工判断 |
| 只看净利润不看现金流 | 漏掉利润质量问题 |
| 忽略先导指标 | 失去最早的信号 |
| ROE 不拆解来源 | 把高杠杆公司误判为高质量 |
| 财务分析与投资命题脱节 | 分析变成报表复述 |
