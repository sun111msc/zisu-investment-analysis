# 闸门目录

> **本文件与代码同源。** CI 会校验 `docs/engineering/gate-catalog.md` 中的编号与
> `src/zisu/gates/rules.py` 的 `ALL_RULES` 是否一致；新增闸门不更新本文件会导致构建失败。

> 当前实现：**25 道**，分五个阶段执行。

## 三态判定规则

| 情形 | 最终状态 | 能否输出结论 |
|---|---|---|
| 全部通过 | `PASS` | ✅ 可以作为正式结论 |
| 仅非阻断项失败 | `DRAFT_REVIEW` | ⚠️ 可输出，但必须带状态声明，需人工复核 |
| 任一阻断项失败 | `BLOCKED` | ⛔ **不输出结论**，只输出阻断原因清单 |

## 规则的实现约定

1. **规则是纯函数**：`GateContext -> GateResult`，只读不写。
2. **规则抛异常等于失败**：引擎会把规则内部错误按阻断处理（有单测覆盖），绝不静默放行。
3. **前置不足返回 SKIP**：不计入通过率分母，避免「因为没跑到所以 100%」。
4. **阻断性是可配置的**：`ALL_RULES` 第五个字段 `blocking` 决定。
