# 行业结构与护城河

> 再好的个股也逃不过所处行业的宿命。
> 本文的顺序是：先判断行业结构，再判断公司位置，最后才讨论公司本身。

---

## 一、为什么行业优先于公司

一家公司能取得超越行业的回报，只有两种可能：

1. **行业本身好**，公司在其中占据了有利位置
2. **公司确实有独特优势**，能在坏行业里做好

第二种情况存在，但**概率远低于第一种**。多数「公司优秀」的叙事，实际是「行业顺风」的误读。

**判定方法**：把公司业绩与行业平均对比。

| 对比结果 | 结论 |
|---|---|
| 公司增速 ≈ 行业增速 | 增长来自行业（贝塔），非公司能力 |
| 公司增速 > 行业增速，且毛利率同步提升 | 可能有真实竞争优势 |
| 公司增速 > 行业增速，但毛利率下降 | 用价格换份额，优势不牢 |

**第三种情形最容易被误读**：收入增长快、份额提升，看起来是竞争优势，实际上是靠降价换来的。毛利率的同步下降是识别的关键。

## 二、行业结构分析：五力模型

### 2.1 五个维度

每维 10 分，总分 50 分。

| 维度 | 问题 | 强（高分）信号 | 弱（低分）信号 |
|---|---|---|---|
| **现有竞争** | 行业内竞争有多激烈？ | CR3 > 70%，格局稳定 | 价格战，CR3 < 30% |
| **新进入者** | 新玩家容易进来吗？ | 牌照 / 规模 / 品牌壁垒高 | 轻资产，无技术门槛 |
| **替代品** | 有没有替代方案？ | 无直接替代，切换成本高 | 替代品多，价格可互换 |
| **客户议价力** | 客户能压价吗？ | 客户分散，单品重要性高 | 客户集中 > 50% |
| **供应商议价力** | 供应商能涨价吗？ | 供应商分散，切换容易 | 核心材料独家供应 |

### 2.2 总分判读

| 总分 | 判定 |
|---|---|
| > 40 | 🟢 行业结构好 |
| 30-40 | 🟡 一般 |
| < 30 | 🔴 行业结构差 |

**行业结构差的公司，即使管理层优秀，也很难持续创造超额回报。** 因为在坏结构里，任何利润都会被竞争或上下游挤压掉。

### 2.3 一个容易误判的维度

**供应商议价力强，可能对标的公司是坏事，也可能是好事 —— 取决于标的站在哪一边。**

如果标的本身就是那个「核心材料独家供应商」，那么供应商议价力强对它有利。

**所以五力分析必须明确「站在谁的角度」。**

## 三、护城河量化

### 3.1 五源护城河评分

每维 10 分（强 10 / 无 1），总分 50 分。

| 维度 | 定义 | 强（10 分） | 无（1 分） |
|---|---|---|---|
| **无形资产** | 品牌 / 专利 / 牌照 | 品牌溢价 > 20% 或专利壁垒 | 无品牌认知或无专利 |
| **转换成本** | 客户换供应商的成本 | 换供应商需 > 2 年认证 | 一键切换，零成本 |
| **网络效应** | 用户越多越有价值 | 双边网络 + 粘性 | 单用户无网络价值 |
| **成本优势** | 能比别人更便宜 | 单位成本比对手低 30%+ | 成本结构相同 |
| **规模效应** | 高效规模 | 单一市场仅容 2-3 家 | 无规模经济 |

### 3.2 护城河宽度

| 总分 | 判定 |
|---|---|
| 40-50 | 宽护城河 |
| 25-39 | 窄护城河 |
| < 25 | 无护城河 |

### 3.3 与瓶颈方法论的关系

护城河评分与 [04-产业链瓶颈方法论](04-产业链瓶颈方法论.md) 的瓶颈分级是**两个不同的判断**：

| | 护城河 | 瓶颈 |
|---|---|---|
| 视角 | 公司与竞争对手之间 | 产业链环节之间 |
| 问题 | 为什么它比对手强？ | 为什么这个环节不可替代？ |
| 可变性 | 会随竞争格局变化 | 结构性，变化慢 |

**两者需要互相验证**：

```
有瓶颈但无护城河 → 公司占据了不可替代的位置，但份额被同行瓜分
                    （可能是一家小公司在一个好环节里）
有护城河但无瓶颈 → 公司很强，但这个环节可以被绕过
                    （竞争地位好但行业地位一般）
两者都有         → 理想情形
```

## 四、行业生命周期定位

### 4.1 四阶段特征

| 阶段 | 特征 | 增速 | 毛利率趋势 | 竞争格局 | 估值方法 |
|---|---|---|---|---|---|
| **导入期** | 技术验证，商业模式探索 | 波动大 | 低或负 | 大量竞争者涌入 | 收入倍数 + 空间 |
| **成长期** | 标准化 + 渗透率提升 | 高 | 稳定或提升 | 龙头开始出现 | 增长调整倍数 |
| **成熟期** | 增速放缓，格局稳定 | 中低 | 稳定或微降 | 前 3 市占率 > 60% | 盈利倍数 + 分红 |
| **衰退期** | 需求下降，产能过剩 | 0 或负 | 下降 | 整合 / 退出 | 资产倍数 |

### 4.2 定位方法

定位的依据是**渗透率**（见 [05-周期与成长判定](05-周期与成长判定.md)）：

```
渗透率 0-5%    → 导入期
渗透率 5-30%   → 成长期（黄金区间）
渗透率 30-50%  → 成长后期
渗透率 50-70%  → 成熟期
渗透率 > 70%   → 存量期
```

### 4.3 为什么这个定位决定估值方法

因为不同阶段的**价值驱动因子完全不同**：

| 阶段 | 估值最敏感的参数 |
|---|---|
| 导入期 | 技术路线是否成立 |
| 成长期 | 渗透率提升速度 |
| 成熟期 | 利润率与现金流稳定性 |
| 衰退期 | 资产清算价值 |

**用错参数，估值就失去了意义。** 对成长期公司用现金流折现，会低估；对成熟期公司用收入倍数，会高估。

## 五、关键价值驱动因子（KVD）

### 5.1 通用驱动树

```
企业价值 =
  ↗ 收入端：TAM × 渗透率 × 市占率
  ↗ 利润端：利润率（毛利率 − 费用率）× 效率（周转率）
  ↗ 增长端：资本回报（ROIC − WACC）× 再投资率
```

### 5.2 行业专属 KPI

不同行业的价值驱动因子差异巨大。以下是几个典型行业的核心 KPI：

#### 半导体 / 芯片

```
收入 = 晶圆出货量（片）× 平均售价（ASP）
利润 = 产能利用率 × 良率 × 毛利率
竞争力 = 制程节点（nm）× 设计赢单率
周期位置 = 库存周转天数 × 资本开支 / 营收比
```

#### AI 基础设施

```
收入 = 算力服务收入 + 模型授权 + API 调用量
竞争力 = 模型评测排名 × 训练效率（Tokens/美元）
护城河 = 数据飞轮效应 × 开发者生态规模
```

#### 新能源 / 光伏

```
收入 = 出货量（GW）× 组件价格（元/W）
利润 = 产能利用率 × 非硅成本下降率
竞争 = 市占率 × 海外收入占比
风险 = 行业产能 / 需求（过剩率）
```

#### 消费品牌

```
收入 = 门店数 × 同店增速 × 线上渗透率
利润 = 毛利率（品牌溢价力）× 库存周转率
健康度 = 复购率 × 净推荐值 × 品牌搜索指数
```

#### 金融 / 银行

```
收入 = 净息差 × 生息资产规模 + 手续费收入
质量 = 不良率 × 拨备覆盖率
回报 = ROE = 净利率 × 资产周转率 × 权益乘数
风险 = 核心一级资本充足率
```

### 5.3 怎么用 KVD 树

```
Step 1  确定公司所处行业
Step 2  取出该行业的 KPI 树
Step 3  逐项填入公司的实际数据
Step 4  识别哪一项是当前最关键的（决定估值的那个）
Step 5  在后续分析中重点跟踪这一项
```

**这一步的价值**：它把「研究这家公司」变成了「跟踪这几个数」。研究是发散的，跟踪是收敛的。

## 七、常见错误

| 错误 | 后果 |
|---|---|
| 跳过行业直接分析公司 | 把行业顺风误认为公司能力 |
| 五力分析不明确立场 | 「供应商议价力强」到底是好是坏说不清 |
| 护城河与瓶颈混为一谈 | 两个判断相互独立，需分别验证 |
| 生命周期定位不看渗透率 | 用主观感受替代客观数据 |
| 用通用 KPI 分析所有行业 | 抓不到关键驱动因子 |
| 只看公司增速不看毛利率变化 | 把以价换量误读为竞争优势 |
