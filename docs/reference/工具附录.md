### A. MACRO-GATE 语义区分（FIX-29）

MACRO-GATE 在两处出现，职责不同：
- **Layer 0 MACRO-GATE**: 开盘前一次性判定（当日有效），基于昨日收盘数据
- **Layer 4 MACRO-GATE**: 盘中环境突变时的二次复核，基于实时数据（如盘中跌停激增）
  → 仅在 Layer 0 判定为 B/C 级且盘中环境恶化时触发
  → 如果 Layer 0 已判定为 D 级，Layer 4 不再重复检查（已在 Layer 0 阻断）

### F. §1 非共识验证必须项（FIX-46）

每条非共识发现必须包含以下三项：
1. **市场共识来源**: 引用来源（卖方研报标题+日期 / 雪球热帖链接 / 媒体报道）
2. **具体矛盾点**: 为什么市场共识可能是错的（量化证据 + 逻辑链条）
3. **可验证预测**: 在什么时间窗口内、观察什么事件/数据可以验证或证伪这个判断

> 禁止笼统表述如"管理层能力被低估"、"市场反应过度"——这类判断无法证伪。

### L. 法务会计四大模型速查（FIX-47·Python实现见scripts/forensic/）

| 模型 | 用途 | 关键输入 | 红旗阈值 |
|------|------|---------|---------|
| **Beneish M-Score** | 盈余操纵检测 | DSR/GMI/AQI/SGI/DEPI/SGAI/TATA/LVGI | M > -2.22 = 操纵嫌疑 |
| **Piotroski F-Score** | 财务基本面强度 | ROA/CFO/ΔROA/Accrual/ΔLeverage/ΔLiquid/EQ_Offer/ΔMargin/ΔTurnover | ≤3 = 弱基本面 |
| **Altman Z-Score** | 破产风险预测 | WC/TA + RE/TA + EBIT/TA + MV/BV + Sales/TA | <1.81 = 破产风险 |
| **Sloan Accruals** | 应计质量 | (ΔCA-ΔCash) - (ΔCL-ΔSTD-ΔTP) - D&A | 高应计 = 盈利质量差 |

> 实现脚本: `scripts/forensic/beneish.py` `scripts/forensic/piotroski.py` `scripts/forensic/altman_z.py` `scripts/forensic/sloan_accruals.py`
