# 宏观-行业-个股中层传导模块（Macro-Sector-Stock Transmission）

> **对应《研究方法审查与升级方案》缺失环节3 + 问题D1**：§L-1 流动性覆盖"全市场"，news-radar 覆盖"行业"，但中间缺"宏观流动性 → 行业风格 → 个股估值"的定量传导。
> 本模块建立中层传导框架，把 §L-1 的定性传导量化。

---

## 一、核心传导链（三层）

```
宏观变量（利率/汇率/流动性）
    ↓ 弹性系数传导
行业风格（成长 vs 价值 / 拥挤度）
    ↓ 估值中枢传导
个股估值（折现率 / PE 中枢 / 目标价）
```

---

## 二、传导公式（简化的弹性系数法）

### 2.1 美债利率 → 成长股折现率 → PE 中枢

```
ΔPE中枢 ≈ -Δ(10Y美债利率) × 久期系数 D
其中: 成长股 D ≈ 15-20（长久期资产对利率敏感）
      价值股 D ≈ 5-8（短久期资产不敏感）
```

**用法**：10Y 美债利率每上行 100bp，成长股合理 PE 中枢下修约 15-20%；价值股仅下修 5-8%。

### 2.2 人民币汇率 → 外资风险偏好 → 北向资金

```
Δ北向流入 ≈ -Δ(USD/CNY) × 风险敏感系数
人民币贬值 → 外资撤离高 Beta 科技 → 科技板块 PE 承压
```

### 2.3 全市场成交量结构 → 行业拥挤度 → 个股波动率

```
Top5% 个股成交占比 > 40% → 资金极度集中 → 非主线个股流动性枯竭
→ 非主线个股波动率放大 → 目标价需加流动性折价
```

---

## 三、传导检查清单（分析时强制输出）

| 传导链 | 检查项 | 输出 |
|---|---|---|
| 利率 → 成长股 | 10Y 美债利率当前水平 + 变动方向 | 成长股 PE 中枢方向 |
| 汇率 → 外资 | USD/CNY 当前 + 趋势 | 北向资金方向 |
| 流动性 → 拥挤度 | Top5% 成交占比 + HHI | 是否极端集中 |
| 风格 → 个股 | 成长 vs 价值相对强度 | 持仓 Beta 调整 |

---

## 四、与 §L-1 的衔接

§L-1 十二维流动性评分输出"仓位上限"（拍脑袋映射），本模块为其提供**定量传导依据**：

```
§L-1 十二维评分 < 20 → 仓位 D 级（5% 观察仓）
  ↑ 背后传导逻辑:
  美债利率上行 + 北向流出 + 成交量极端集中 → 成长股 PE 中枢下修 15-20%
  → 成长股目标价系统性下修 → 仓位必须降
```

**v8.1 状态**：本模块为框架文档（P2 项），弹性系数（D=15-20 等）为经验值，需接入历史数据做回归校准（P3 项）后转为硬约束。
