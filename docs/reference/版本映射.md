3. **新增模块** → 只加在 `zisu-deep-analysis/modules/` 下
4. **估值规则** → 唯一参考 `modules/10-valuation-rules.md` v3.0
5. **方法论文档** → 唯一位于 `zisu-deep-analysis/references/kb/01-方法论总纲/`
6. **新增skill** → 创建在 `skills/` 顶层
