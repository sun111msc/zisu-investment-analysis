## 使用说明

这些文件是**支撑材料**，不是方法论主体。阅读顺序建议：

```
先读方法论（docs/00-14）
  → 需要具体模板时来查这里
  → 需要数据源能力边界时查注册表
```

**注意**：`数据源注册表.json` 与工程层 `src/zisu/datasources/registry.py` 的描述对象一致 ——
前者是文档形态，后者是代码形态。修改其一时应同步另一处。
