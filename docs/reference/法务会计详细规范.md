## 一、Beneish M-Score（利润操纵检测·8变量完整版）

### 1.1 模型公式

```
M-Score = -4.84 + 0.920×DSRI + 0.528×GMI + 0.404×AQI + 0.892×SGI
          + 0.115×DEPI - 0.172×SGAI + 4.679×TATA - 0.327×LVGI
```

### 1.2 八变量定义与计算

| 变量 | 名称 | 公式 | 输入数据 | 红旗阈值 |
|------|------|------|---------|:---:|
| **DSRI** | 应收账款指数 | (AR_t/Sales_t) / (AR_t-1/Sales_t-1) | 应收+营收 | > 1.031 |
| **GMI** | 毛利率指数 | GM_t-1 / GM_t | 毛利率 | > 1.014 |
| **AQI** | 资产质量指数 | (1-(CA_t+PPE_t)/TA_t) / (1-(CA_t-1+PPE_t-1)/TA_t-1) | 流动资产+固资+总资产 | > 1.039 |
| **SGI** | 销售增长指数 | Sales_t / Sales_t-1 | 营收 | > 1.134 |
| **DEPI** | 折旧指数 | (Dep_t-1/(Dep_t-1+PPE_t-1)) / (Dep_t/(Dep_t+PPE_t)) | 折旧+固资 | > 1.001 |
| **SGAI** | 销售管理费用指数 | (SGA_t/Sales_t) / (SGA_t-1/Sales_t-1) | 销售管理费用+营收 | > 1.05 |
| **TATA** | 总应计/总资产 | (NI_t - CFO_t) / TA_t | 净利+经营现金流+总资产 | > 0.018 |
| **LVGI** | 杠杆指数 | (LTD_t+CL_t)/TA_t / (LTD_t-1+CL_t-1)/TA_t-1 | 长期负债+流动负债+总资产 | > 1.037 |

### 1.3 判定矩阵

```
M-Score < -2.22:  🟢 低操纵风险（正常公司）
M-Score -2.22 ~ -1.78:  🟡 灰色区域（关注）
M-Score > -1.78:  🔴 高操纵风险（可能利润操纵）

单独变量检查:
  任何单一变量超过其红旗阈值 → 该维度标记为⚠️
  5+个变量触发红旗 → 视为M-Score≥-1.78对待（无论总分）
```

### 1.4 A股修正参数

Beneish原始模型基于美国数据，用于A股时需注意：

| 变量 | A股修正 | 原因 |
|------|---------|------|
| DSRI | 阈值提高至1.1 | A股应收账款管理普遍较松 |
| GMI | 阈值提高至1.05 | A股毛利率波动更大 |
| TATA | 阈值提高至0.025 | A股应计利润水平整体偏高 |
| LVGI | 关注分类（短期/长期） | A股企业常通过再融资调整负债结构 |

### 1.5 输出格式

```
【Beneish M-Score检测】
```

## 二、Piotroski F-Score（基本面质量·9项·A股改造版）

### 2.1 九项指标

| # | 指标 | 原始公式 | 得分条件 | A股修正 |
|:---:|------|---------|------|------|
| 1 | ROA | NI / TA | ROA > 0 → 1分 | 不变 |
| 2 | CFO/TA | CFO / TA | > 0 → 1分 | 不变 |
| 3 | ΔROA | ROA_t - ROA_t-1 | > 0 → 1分 | 不变 |
| 4 | 应计利润 | CFO/TA - ROA | > 0 → 1分（现金流质量） | 不变 |
| 5 | Δ杠杆 | (LTD+CL)/TA | 下降 → 1分 | 不变 |
| 6 | Δ流动比率 | CR_t - CR_t-1 | > 0 → 1分 | 不变 |
| 7 | 股票发行 | 是否增发新股 | 无增发 → 1分 | A股: 送转股不扣分·仅配股/增发扣分 |
| 8 | Δ毛利率 | GM_t - GM_t-1 | > 0 → 1分 | 不变 |
| 9 | Δ资产周转率 | Sales/TA_t - Sales/TA_t-1 | > 0 → 1分 | 不变 |

### 2.2 判定矩阵

```
F-Score 8-9:  🟢🟢 极高质量（最佳价值投资候选）
F-Score 6-7:  🟢 高质量
F-Score 4-5:  🟡 中等（中性）
F-Score 2-3:  🟠 低质量
F-Score 0-1:  🔴 极低质量（大概率价值陷阱）
```

### 2.3 与紫苏叶体系的联动

```
F-Score ≥ 7 + 紫苏叶 ≥ 4级 = 最强组合·可重仓
F-Score 4-6 + 紫苏叶 ≥ 3级 = 标准候选·验证后建仓
F-Score ≤ 3 + 任何紫苏叶 = 红色预警·基本面质量不支持卡位逻辑
                                       → T1/T2可能不通过·画饼风险高
```

## 三、Altman Z-Score（破产风险·A股改造版）

### 3.1 原始模型（制造业）

```
Z = 1.2×X1 + 1.4×X2 + 3.3×X3 + 0.6×X4 + 1.0×X5

X1 = 营运资本 / 总资产
X2 = 留存收益 / 总资产
X3 = EBIT / 总资产
X4 = 市值 / 总负债
X5 = 营收 / 总资产
```

### 3.2 A股改造版（Zhang et al. 2010·中国上市公司）

```
Z_CN = 0.517 - 0.460×X1 + 9.320×X2 + 0.388×X3 + 1.158×X4 + 0.296×X5

其中X2（负债/资产）权重最高·反映A股高杠杆风险
```

### 3.3 判定

```
Z_CN < 0.5:  🔴 破产风险高
Z_CN 0.5-1.0: 🟡 灰色区域
Z_CN > 1.0:  🟢 财务安全
```

## 四、Sloan应计利润异常检测

### 4.1 核心公式

```
应计利润 = (Δ流动资产 - Δ现金) - (Δ流动负债 - Δ短期负债 - Δ应付税款) - 折旧

简化版:
Total Accruals = (NI - CFO) / Average Total Assets
```

### 4.2 判定

```
|Accruals/TA| < 0.05:  🟢 正常
|Accruals/TA| 0.05-0.10: 🟡 关注
|Accruals/TA| > 0.10: 🔴 应计利润异常高·利润质量差

连续2年 > 0.10 → 强烈信号：利润可能被操纵
```

### 4.3 Sloan效应

Sloan(1996)发现：应计利润高的公司，未来股价表现系统性差于应计利润低的公司。因为市场不能完全"看穿"应计利润的低持续性。

```
操作含义:
  应计/总资产 > 0.10 + 高PE → 双重谨慎（利润虚高+市场高预期）
  应计/总资产 < 0 + 低PE → 双重机会（利润被低估+市场低预期）
```

## 五、法务会计红旗信号速查（Schilit 7大手法·A股适配）

| 手法 | 英文 | 检测方法 | A股特征 |
|------|------|---------|------|
| 1. 过早确认收入 | Recording Revenue Too Soon | 应收增速>营收增速1.5x + DSO飙升 | 关联交易虚增收入最常见 |
| 2. 虚构收入 | Recording Bogus Revenue | 客户集中度突然变化 + 大客户为关联方 | 空壳公司循环交易 |
| 3. 一次性收益充持续性 | Boosting Income with One-Time Gains | 非经常性损益/净利润 > 20% | 卖资产/政府补贴美化利润 |
| 4. 费用不当资本化 | Shifting Expenses to Later Periods | 无形资产/总资产突增 | 研发费用资本化激进 |
| 5. 隐藏费用/负债 | Failing to Record Liabilities | 表外负债·担保·或有负债 | 对外担保黑洞 |
| 6. 减少当期费用 | Reducing Expenses Improperly | 折旧率突降·坏账准备不足 | 会计估计变更 |
| 7. 现金流造假 | Shifting Financing Cash to Operating | OCF异常好转但应收同步增加 | 票据贴现充经营现金流 |
