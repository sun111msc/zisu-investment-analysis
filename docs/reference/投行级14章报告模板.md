## 二、三段式逻辑框架（强制 · 核心改造）

### 2.1 三段式定义

**每个核心观点强制走"核心假设 → 论据支撑 → 结论推导"三段式，并附可证伪条件。**

```
❌ 旧写法（清单式·观点罗列）：
   "公司毛利率持续提升，反映 2.5D 高毛利业务占比提升"

✅ 新写法（三段式·逻辑推导）：
   核心假设：2.5D 业务毛利率显著高于传统封装，占比提升将抬升整体毛利率
   论据支撑：分业务毛利率 2.5D≈40% vs 传统≈20%（数据）；2.5D 占比 51% 且提升
   结论推导：整体毛利率 23.53% → 30.99%（+7.46pp），验证假设成立
   可证伪：若 2.5D 毛利率因竞争降至 30% 以下，则毛利率提升逻辑失效
```

### 2.2 三段式适用范围

| 章节 | 是否强制三段式 | 说明 |
|---|---|---|
| ② 投资摘要核心逻辑 3 条 | ✅ 强制 | 每条逻辑必须可被第三方复现 |
| ④⑤ 行业/公司分析结论 | ✅ 强制 | 竞争格局、护城河判断需推导 |
| ⑥⑦ 财务模型/盈利预测 | ✅ 强制 | 预测必须有驱动因子分解 |
| ⑨ 市场认知（预期差） | ✅ 强制 | 预期差必须量化 |
| ⑪ 估值 | ✅ 强制 | 目标价必须 Step-by-step 推导 |

### 2.3 三段式闸门（程序化校验）

报告生成后，gate_checker 校验：
- 每个核心观点是否含"核心假设/论据支撑/结论推导"关键词
- 是否含"可证伪"条件

### 3.0 无图表版原则（v8.2 落地·不依赖图表工具）

> **用户约定**：不用图片图表，但必须"说明数据和逻辑"。即每个"图"用 **Markdown 表格承载数据 + 文字承载逻辑解读** 替代。
> 铁律：一个"图"如果只有数据没有逻辑解读，或只有结论没有数据，都不合格——**数据 + 逻辑必须成对出现**。

### 3.2 核心数据表 + 逻辑解读（Key Charts 无图表版 · 对标高盛）

3 张核心数据表前置，每张表后必须附一段"这张表说明了什么"：

**表1 · 盈利预测表（数据）**
| 年份 | 营收(亿) | 同比 | 净利(亿) | 同比 | 毛利率 | EPS |
|---|---|---|---|---|---|---|
| 2025A | 65.21 | +38.6% | 9.21 | +331% | 30.99% | 0.57 |
| 2026E | 89.20 | +36.8% | 11.53 | +25% | 31.5% | 0.62 |
| 2027E | 125.05 | +40.2% | 18.56 | +61% | 32.5% | 1.00 |

**逻辑解读**：营收 3 年 CAGR 40%，净利增速先降后升（2026 年 +25% 是毛利率提升的高基数消化，2027 年 +61% 是 2.5D 产能释放）。核心变量是 2026 年营收增速能否兑现 36.8%（Q1 仅 +13.13%）。

**表2 · 估值表（数据）**
| 估值锚 | 合理市值(亿) | 当前市值(亿) | 偏离度 |
|---|---|---|---|
| PEG | 461 | 2623 | +469% |
| 可比 | 692 | 2623 | +279% |
| DCF | 800 | 2623 | +228% |

**逻辑解读**：三种方法合理市值中枢 650 亿，当前 2623 亿偏离 +300%，无论用哪种锚，结论都是"显著高估"——这比单看 PE 数字更有说服力。

**表3 · K 线数据表（数据 · 浑天紫苏优势）**
| 日期 | 收盘 | 涨跌 | 换手率 | 主力净流入 |
|---|---|---|---|---|
| 8/03 | 116.42 | -5.27% | 6.32% | -1.14亿 |
| 8/07 | 140.84 | +3.36% | 10.51% | +0.40亿 |
| 8/13 | 139.04 | +0.75% | 5.67% | +0.90亿 |

**逻辑解读**：8/03 见底 115.91 后反弹 20%，但近 20 日主力净流出 33.18 亿，属"高位震荡出货中的间歇性回流"——反弹是资金面背离，不改变中期偏弱判断。

### 3.3 风险回报表（Risk-Reward 无图表版 · 对标大摩）

```
【风险回报表】（数据 + 逻辑）：
  当前价：139.04 元
  上行空间（Bull）：目标价 180 元 → +29.5%
  下行空间（Bear）：止损价 115 元 → -17.3%
  风险回报比 = 29.5 / 17.3 = 1.7
  逻辑解读：X/Y=1.7，介于"不建仓(<1)"与"可建仓(≥2)"之间，
            但这是"赌中报超预期"的赔率；若按基本面合理价 43 元计，
            下行空间是 -69%，风险回报比骤降至 0.4，明确不建仓。
```

```
【催化剂日历】（表格即数据，解读即逻辑）：
| 日期 | 催化剂 | 方向 | 影响级别 | 验证指标 |
|---|---|---|---|---|
| 2026-08-20 | 半年报 | 多/空 | ★★★ | 营收增速 vs 36.8% 预期 |

### 3.5 估值敏感性矩阵（无图表版 · 对标大摩/中信）

```
【敏感性矩阵】（≥9 格，表格承载数据）：
              盈利预测
             下修-20%   基准    上修+20%
WACC 7%       58元      73元    91元
WACC 9%       49元      62元    77元
WACC 11%      42元      53元    66元

### 3.6 反向 DCF —— 市场隐含预期解码（v8.3 新增 · 铁律 28 强制）

```
【定位】不产生目标价，只回答"当前股价隐含了什么假设"。
       这是**市场预期读数**，不违反"A股 PEG 为唯一锚、DCF 仅作附录"铁律。

【工具】cd skills/zisu-deep-analysis/scripts
       python reverse_dcf.py --input case.json                # 反解隐含 g
       python reverse_dcf.py --input case.json --solve wacc   # 反解隐含 WACC
       （模板：reverse_dcf_example.json｜单位：金额亿元 / 股本亿股 / 股价元）

【输出结构】
  当前价                = XX.XX 元
  市场隐含永续增长率 g   = X.XX%（模型假设 X.XX%｜偏离 X.XX pct）
  市场隐含 WACC         = X.XX%（模型假设 X.XX%｜偏离 X.XX pct）
  终值占企业价值         = XX.X%
  状态                  = 🟢PASS / 🟡DRAFT_REVIEW / 🔴BLOCKED

【三段式解读】（强制 · 铁律 24）
  核心假设：市场按隐含永续增长率 g = X.XX% 给公司定价
  论据支撑：由当前价 + 明确期 FCFF 路径 + 股权桥反解（工具可独立复算）
  结论推导：隐含 g 高于名义 GDP 长期增速 → 定价隐含长期高增长，安全边际薄
  可证伪：若第 N 年 FCFF 低于 X 亿，隐含 g 将升至 Y%，定价失去支撑

【判定阈值】
  隐含 g > 5%             → 超名义 GDP，定价隐含长期高增长
  隐含 g 与模型偏离 > 2pct → 必须解释市场与你的分歧来源（不能沉默）
  终值占比 > 85%           → 估值过度依赖永续假设
  隐含 WACC > 25%          → 市场风险补偿要求异常

【常见误用·禁止】
  ⛔ 把反向 DCF 结果当作目标价 → 违规（它是读数，不是估值）
  ⛔ 只报隐含 g 不给解读 → 违规（必须回答"偏高/偏低/合理"）
  ⛔ 缺失数据用 0 或行业均值填充 → 违规（应返回 BLOCKED）
```

### 3.7 目标价推导 Step-by-step（无图表版 · 对标小摩）

```
【目标价推导链】（文字承载逻辑，每一步带数据）：
  当前价 139.04 元
  → 核心假设：2.5D 国产替代 <20% 渗透率，盛合市占 85%，2026-28 净利 CAGR 40%
  → 盈利预测：2026E 净利 11.53 亿 / 2027E 18.56 亿 / 2028E 25.49 亿（一致预期）
  → 合理估值：40-60 倍 PE × 2026E 净利 = 461-692 亿（PEG 1.0-1.5）
  → 目标价：35-43 元（合理市值中枢 650 亿 ÷ 18.63 亿股本）
  逻辑解读：当前价是目标价中枢的 3.5 倍，推导链每一步数据可复现，
            "高估"不是主观判断，而是每一步算术的结果。
```
