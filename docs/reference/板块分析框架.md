# HARD-GATE-SECTOR-RADAR · 板块趋势雷达方法论

> **层级**: Layer 0.15（宏观门禁之后·信息流雷达之前）
> **定位**: 弥合"宏观→行业→个股"链条中最关键的"行业/板块趋势"空白

---

## 一、为什么需要板块雷达

浑天紫苏 v5.3 的框架存在一个结构性缺口：

```
Layer 0: 宏观门禁 ✅  →  直接跳到
Layer 0.25: 信息流雷达 ✅  →  直接跳到
Layer 0.5: 题材门禁 ✅
```

**缺失环节**: 公司所属的概念板块/行业板块的**实时走势**——"这个赛道本身是在涨还是在跌？资金在流入还是流出？它在板块里排第几？"

### 核心命题

> "再好的个股，如果所属板块在系统性下跌，独立走强的概率大幅降低。
> 再差的个股，如果所属板块在集体暴涨，也会被板块Beta带起来。"

## 二、板块雷达五维分析

### 维度1: 板块涨跌情绪（涨跌比 + 平均涨幅）

| 数据 | 来源 | 含义 |
|------|------|------|
| 板块成分股数量 | 新浪财经板块数据 | 板块规模 |
| 上涨家数/下跌家数 | 同上 | 涨跌比>3:1=强势, 1:3=弱势 |
| 板块平均涨幅 | 加权计算 | vs大盘涨幅=相对强弱 |

### 维度2: 个股在板块中的位置

| 数据 | 来源 | 含义 |
|------|------|------|
| 今日涨幅排名 | 板块内排序 | 前20%=龙头气质, 后20%=跟风 |
| 成交额排名 | 同上 | 高成交额排名=资金关注度高 |
| 5日/20日累计涨幅排名 | 需额外计算 | 中期动量排名 |

### 维度3: 板块资金流向

| 数据 | 来源 | 含义 |
|------|------|------|
| 板块主力净流入 | 新浪资金流页面 | >0=资金流入, <0=流出 |
| 板块成交额变化 | 同上 | 放量上涨=有效, 缩量上涨=弱 |
| 融资余额变化 | 交易所数据 | 杠杆资金态度 |

### 维度4: 板块 vs 大盘强弱对比

| 数据 | 来源 | 含义 |
|------|------|------|
| 相对强度(RS) | 板块涨幅 - 大盘涨幅 | RS>0=强于大盘, RS<0=弱于大盘 |
| 5日相对强度 | 同上 | 趋势性跑赢 |
| 20日相对强度 | 同上 | 中期风格确认 |

### 维度5: 板块轮动位置

| 数据 | 来源 | 含义 |
|------|------|------|
| 板块年内涨幅分位 | 历史数据 | >90%=过热, <10%=超跌 |
| 板块换手率变化 | 成交量数据 | 明显放大=资金涌入 |
| 关联板块共振 | 上下游板块对比 | 产业链上下游是否同涨 |

## 四、集成到浑天紫苏框架

板块雷达产出插入到 Layer 0 和 Layer 0.25 之间：

```
Layer 0: 宏观门禁（macro-research + macro-to-stock）
  ↓
🆕 Layer 0.15: 板块趋势雷达（HARD-GATE-SECTOR-RADAR）
  ├── 执行: python scripts/sina_sector_fetcher.py benchmark <code>
  ├── 执行: python scripts/sina_sector_fetcher.py sector <板块名>
  ├── 5维分析 → 板块情感评级（强/中/弱）
  └── 输出: 板块分析段落到报告 Layer 0.15 章节
  ↓
Layer 0.25: 信息流雷达（news-radar + tdx news）
  ↓
Layer 0.5: 题材门禁
```

## 五、板块情感评级

| 评级 | 条件 | 仓位调整 |
|------|------|----------|
| **A (强势)** | 涨跌比>4:1 + RS>2% + 板块放量 | 仓位上限+3% |
| **B (偏强)** | 涨跌比>2:1 + RS>0 + 板块正常 | 仓位不变 |
| **C (中性)** | 涨跌比1:1 + RS≈0 | 仓位上限-2% |
| **D (偏弱)** | 涨跌比<1:2 + RS<-1% | 仓位上限-5% |
| **E (弱势)** | 涨跌比<1:4 + RS<-2% + 板块缩量 | 不开新仓·已持仓减仓30% |
