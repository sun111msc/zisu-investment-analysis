### 6.2 校准后的核心可借鉴点（最终版）

1. **高盛标题三要素**：标题必须同时含「公司 + 核心观点 + 目标价动作(上调/维持/下调) + 评级」，标题即可独立传达投资结论
2. **高盛 GSe 盈利预测**：建立自己的盈利预测体系（对标浑天紫苏财务模型），不直接引用一致预期
3. **大摩风险回报更新**：单标的报告的核心是"风险回报"——上行空间 vs 下行空间，而非单纯罗列观点
4. **大摩关键预测**：定期发布关键预测（宏观/行业/个股），形成可追踪的预测体系（对标浑天紫苏"预先错误登记+事后验证"）
5. **内资首次覆盖标题**：标题=公司+行业定位+成长逻辑（"XX龙头，YY打开成长增量"）
