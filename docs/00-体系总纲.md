# 体系总纲

> 本文是整个分析体系的总装配图。它不展开细节，只回答一个问题：
> **一套完整的股票分析，应该由哪些部分构成、以什么顺序运转、在什么情况下停下来。**

---

## 一、命名与隐喻

体系名「浑天紫苏」，由两个意象组成，分别对应两条设计主线。

**浑仪 —— 多维并行。** 浑仪是中国古代的多层嵌套测角环，可以同时追踪日月星辰各自的轨道。体系以此隐喻：单点结论不可靠，必须同时从产业链、财务、资金、情绪、制度等多个维度观测同一标的，让不同维度的结论互相校验。

**紫苏叶 —— 单一锚点。** 紫苏在料理中是「一片定味」的存在，放进去整道菜的味道就定了。体系以此隐喻：在多维观测之上，最终必须收敛到一个不可替代的判断锚点 —— **产业链上的物理瓶颈**。

这两条主线看似矛盾（多维 vs 单一），实际是分工：

| | 浑仪（多） | 紫苏叶（单） |
|---|---|---|
| 作用 | 收集证据、交叉验证 | 收敛结论、定仓位 |
| 层级 | 过程 | 终点 |
| 失败方式 | 信息过载、无结论 | 锚点选错、全盘皆错 |
| 对治 | 用紫苏叶收敛 | 用浑仪验证 |

**体系的核心主张**：多数分析失败不是因为看得太少，而是因为看得太多却没有锚点。浑仪负责不要看漏，紫苏叶负责不要看散。

## 二、三条第一性原理

所有下游方法都从这里推导。如果某条具体规则与原理冲突，改规则不改原理。

### 第一性：利润即真理

**原理**：股价的长期锚是企业创造现金的能力。所有叙事、题材、概念，最终必须落到利润和现金流上。

**护城河验证公式**：

```
护城河真伪 = 毛利率稳定性 × 现金流转化率 × 客户不可替代性
```

三连击判定：

| 通过项数 | 判定 | 处理 |
|---|---|---|
| 三项全通过 | 真护城河 | 可重仓 |
| 任意两项 | 候选 | 需深度验证 |
| 任意一项不通过 | 画饼 | 严禁推荐 |

三项的具体判据：

| 维度 | 判据 | 红旗线 |
|---|---|---|
| 毛利率稳定性 | 近 5 年毛利率标准差 / 均值 | > 15% |
| 现金流转化率 | 经营现金流 / 净利润 | 持续 < 0.5x |
| 客户不可替代性 | 前五大客户占比 / 单一客户占比 | 单一客户 > 30% |

**为什么是这三项**：毛利率稳定性检验定价权是否真实存在；现金流转化率检验利润是否收到现金；客户不可替代性检验这份生意是否掌握在自己手里。三者互相独立 —— 一家公司可以毛利率很高但没有定价权（一次性涨价），可以利润很好但全是应收账款，可以客户稳定但客户随时能换掉它。

### 第二性：覆巢之下无完卵

**原理**：仓位上限不由个股质量决定，由市场环境决定。再好的标的，在市场系统性下行中也会被拖下去。

**执行方式**：市场环境四级评级，直接约束总仓位天花板。

| 环境 | 特征 | 总仓位上限 | 是否开新仓 |
|---|---|---|---|
| A 进攻 | 情绪高位、资金持续流入、主线清晰 | ≤100% | ✅ 正常 |
| B 中性 | 结构性行情、分歧期 | ≤70% | ✅ 正常 |
| C 谨慎 | 退潮前兆、赚钱效应转弱 | ≤30% | ⚠️ 瓶颈等级不足则跳过 |
| D 防守 | 冰点、恐慌、系统性下跌 | ≤10% | 🛑 禁止开新仓 |

**这条原理的实操含义**：环境判断是整个流程中投入产出比最高的一步。一分钟的环境评级，决定了后面所有分析结果的可用范围。

### 第三性：没有催化剂的好股是死水

**原理**：基本面优秀但缺少触发事件的标的，可能长期不涨。资金需要理由才能进入。

**硬规则**：

| 情形 | 处理 |
|---|---|
| 未来 60 天内无可识别催化剂 | 自动降权一档 |
| 催化剂已全部兑现且无新催化剂 | 标注「真空期」，建议减仓 |
| 催化剂逻辑被证伪 | 无条件清仓（退出优先级 1️⃣） |

**为什么这条被放在第一性原理层**：因为它约束的是「什么时候可以买」，而不是「买什么」。一个正确的标的在错误的时间买入，等同于一个错误的决策。

## 三、六层漏斗：从五千只到三只

体系处理的是全市场 5000+ 标的，最终落到 2-3 只持仓。这个过程被组织为六层漏斗，每层的职责是**降低犯错概率**，而不是「找出好股票」。

```
Layer 0 · 天气站      宏观情绪门禁      → 决定「今天能不能做」
Layer 1 · 雷达网      多维数据采集      → 决定「锁定哪些目标」
Layer 2 · 声呐阵      产业链深潜        → 决定「谁是真正的鱼」
Layer 3 · 弹道计算    多维印证          → 决定「现在打不打」
Layer 4 · 火控系统    冲突仲裁          → 决定「分歧时听谁的」
Layer 5 · 弹药分配    执行闭环          → 决定「打多少，错了怎么办」
```

| 层级 | 核心问题 | 输出 | 淘汰率 |
|---|---|---|---|
| Layer 0 | 今天出海安全吗？ | 环境评级 A/B/C/D | — |
| Layer 1 | 哪些标的有异常信号？ | 候选项清单 | 5000+ → ~200 |
| Layer 2 | 谁的产业链位置不可替代？ | 瓶颈分级 | ~200 → ~20 |
| Layer 3 | 基本面结论能否被资金印证？ | 印证结论 | ~20 → ~5 |
| Layer 4 | 多维信号冲突时听谁的？ | 仲裁裁决 | ~5 → ~3 |
| Layer 5 | 具体怎么建仓、怎么退？ | 执行方案 | ~3 → 持仓 |

**关键设计**：漏斗是**串联**的，但每一层的否决是**独立**的。任何一层判定不合格，标的就出局，不需要等后面的层。

## 四、回到八阶段：分析本身的结构

六层漏斗描述的是「从全市场到持仓」的筛选路径。当聚焦到单只标的时，分析本身按八个阶段展开。

这八个阶段构成的是**正金字塔**：业务事实在底部，市场认知在顶部。

```
        ┌──────────────┐
        │ P7 最终裁决   │  ← 可证伪的一句话结论
        ├──────────────┤
        │ P6 执行方案   │  ← 买多少、什么价、何时退
        ├──────────────┤
        │ P5 估值定价   │  ← 隐含预期反解 + 多锚交叉
        ├──────────────┤
        │ P4 市场认知   │  ← 市场在哪可能错了（只提问）
        ├──────────────┤
        │ P3 财务预测   │  ← 三表联动 + 盈余质量
        ├──────────────┤
        │ P2 深度穿透   │  ← 钱被产业链哪层赚走了
        ├──────────────┤
        │ P1 行业定位   │  ← 赛道多大、格局如何
        ├──────────────┤
        │ P0 公司画像   │  ← 这家公司靠什么赚钱
        └──────────────┘
             业务事实底座
```

**为什么是正金字塔而不是倒金字塔**：早期版本把「市场认知偏差」放在最前面，结果后续所有分析都被先入的市场判断锚定 —— 你会不自觉地寻找支持既有结论的证据，形成循环论证。改为业务事实先行后，P4 的「市场是不是错了」成为与前序分析**相互独立**的判断。

详见 [02-分析流程](02-分析流程-八阶段正金字塔.md)。

## 五、十一个功能模块

八阶段是**时间轴**，十一个模块是**能力域**。它们不是一一对应关系 —— 一个阶段可能调用多个模块，一个模块也可能被多个阶段使用。

| # | 模块 | 职责 | 主要服务阶段 |
|---|---|---|---|
| 1 | 天象 | 宏观情绪门禁，输出环境评级 | P0 前置 |
| 2 | 经纬 | 多维数据采集与完整性校验 | 全程 |
| 3 | 司书 | 研报解码与机构行为分析 | P4 |
| 4 | 紫苏 | 产业链瓶颈深挖与分级 | P2 |
| 5 | 朝议 | 多派系对抗式评审 | P4/P5 |
| 6 | 测影 | 价格行为与结构分析 | P6 |
| 7 | 观流 | 机构资金行为透视 | P4 |
| 8 | 潜渊 | A 股制度与隐藏规则 | P6 前置 |
| 9 | 推演 | 量化策略验证与回测 | P3/P4 |
| 10 | 司南 | 冲突仲裁与一票否决 | P6 前置 |
| 11 | 弓矢 | 风控、仓位与执行 | P6 |

模块之间的数据流是单向的：

```
原始数据 → 分析产物 → 仲裁裁决 → 执行方案
（经纬）   （司书/紫苏/测影/观流）  （司南）    （弓矢）
```

其中**司南（仲裁）**是唯一的汇聚点：所有维度的结论必须在这里被裁决，不允许绕过。

## 六、终止机制：分析是排除的过程

不是所有标的都值得完整分析。体系内置五个终止点，用于在发现致命问题时及时止损分析资源。

| 终止点 | 触发条件 | 含义 |
|---|---|---|
| **T0** | 完成公司全息理解后，仍无法用一段话向外行解释这家公司 | 不理解 = 不投资 |
| **T1** | 周期判定为「反身性溢价」 | 估值与基本面脱节，无锚点可用 |
| **T2** | 产业链存在致命卡脖子环节且标的无替代方案 | 系统性风险不可控 |
| **T3** | 魔鬼代言人中 ≥5 问无法有力反驳 | 反方论证压倒性 |
| **T4** | 安全边际 < 10% | 当前不具备风险补偿 |

**终止 ≠ 否定**。终止意味着「不值得继续投入分析资源」，不代表公司不好。每个终止点都附带**重新分析触发条件** —— 当条件满足时，可以从终止点继续，而不必重来。

详见 [02-分析流程](02-分析流程-八阶段正金字塔.md) 的终止规则部分。

## 七、体系的适用边界

明确的边界比模糊的普适更有价值。

**适用**：

| 维度 | 范围 |
|---|---|
| 市场 | A 股为主，港股、美股可参照 |
| 行业 | 科技制造类：半导体、光通信、新能源、机器人、稀土材料、精密制造 |
| 持仓周期 | 1 个月 – 2 年 |
| 核心前提 | 标的存在可识别的产业链瓶颈 |

**不适用**：

| 类型 | 原因 |
|---|---|
| 短产业链行业（消费品牌、金融服务、内容平台、互联网平台） | 瓶颈概念不成立，用传统估值即可 |
| 期货 / 外汇 / 数字货币 | 无企业基本面 |
| 高频策略 | 与本体系的时间尺度不符 |
| 日均成交额 < 500 万的标的 | 流动性不足，任何框架都不适用 |

**最后一条特别重要**：分析前必须先检查流动性门槛。一个日均成交额 300 万的标的，即使基本面再好，也无法建立和退出一笔有意义的仓位。这类标的应该被直接跳过，不需要进入任何分析流程。
