## 这个项目解决什么问题

股票分析最难的从来不是「找到好公司」，而是**在三件事上不自欺**：

### 一、把行业顺风误认为公司能力

一家公司收入增长 40%，看起来很强 —— 但如果整个行业都增长 45%，它其实是跑输的。

**对治**：先判断行业结构与生命周期，再判断公司位置。用「公司增速 vs 行业增速」拆解增长的来源，并检查毛利率是否同步变化（增速快但毛利率降 = 以价换量）。

### 二、把叙事当成事实

「行业空间万亿」「技术全球领先」这类判断无法被证伪，因此它们不构成观点，只是姿态。

**对治**：每个核心结论都必须能写成一个可以被事实推翻的句子。「公司有望受益于行业增长」不合格；「若 Q3 合同负债环比增长 >20%，则当年收入增速可达 X%」合格。

### 三、把假设包装成结论

一个精确到小数点后两位的目标价，其中 60-85% 来自对永续增长率的假设 —— 这是把自己的假设穿上了客观的外衣。

**对治**：**反向 DCF**。不问「它值多少钱」，而问「当前市值要求它做到什么」。后者产生的是可检验的约束，而不是无法验证的观点。

## 方法概览

### 核心锚点

整套方法多维度收集证据，最终收敛到一个判断：

> **这家公司是否占据了产业链上一个不可替代的物理环节？**

瓶颈的三个特征必须同时成立：**不可替代**（找不到等效替代）、**供应集中**（全球可供应商极少）、**认证壁垒**（客户切换成本极高）。

按全球可供应商数量与认证周期分为五级，直接映射到仓位上限：

| 等级 | 判据 | 仓位上限 |
|---|---|---|
| 🍃🍃🍃🍃🍃 | 全球独家 + 认证 ≥2 年 | 25% |
| 🍃🍃🍃🍃 | 全球 2 家 + 认证 ≥2 年 | 20% |
| 🍃🍃🍃 | 全球 2-3 家 + 工艺/材料独家 | 15% |
| 🍃🍃 | 全球 3-4 家 + 单一产品领先 | 8% |
| 🍃 | 全球 4 家以上但有差异化 | 3% |

### 三条第一性原理

| 原理 | 含义 | 落地 |
|---|---|---|
| **利润即真理** | 股价的长期锚是创造现金的能力 | 护城河三维乘法验证 |
| **覆巢之下无完卵** | 仓位上限由市场环境决定，不由个股质量决定 | 环境 A/B/C/D 四级 → 总仓位天花板 |
| **没有催化剂的好股是死水** | 资金需要理由才能进入 | 60 天无催化剂自动降权 |

### 八阶段流程

```
P0 公司画像 → P1 行业定位 → P2 深度穿透 → P3 财务预测
→ P4 市场认知（只提问） → P5 估值定价 → P6 执行方案 → P7 最终裁决
```

**业务事实先行，市场认知后置。** 先建立独立的业务理解，再问「市场是不是错了」—— 这样两个判断才互相独立，不会形成循环论证。

## 方法与代码的分工

本项目把「模型该怎么做」和「代码该怎么算」分成两层，边界很硬：

| 层 | 负责 | 位置 |
|---|---|---|
| **Skills** | 表达 —— 如何描述、如何论证、如何组织语言 | `skills/` |
| **Methodology** | 判断 —— 用什么标准、什么阈值、什么顺序 | `docs/` |
| **Code** | 纪律与计算 —— 什么数据可用、什么结论可发、数字怎么算 | `src/zisu/` |

**代码不替模型写论证，只校验论证的结构是否完整**（有没有 ≥2 条非共识、空头强度是否足够、有没有反事实推理）。

### 为什么需要代码层

方法中最容易被违反的部分 —— 不是「想不到」，而是「想得到但做不到」—— 被实现为可执行的检查。

例如这一条：

> 曾经我用通用网页检索去估一个滚动市盈率，得到的口径与结构化数据库相差 **+76% ~ +265%**。事后复盘发现，提示词里其实明确写着「估值数据必须从数据库获取」—— 约束是清晰的，但它是**提醒**，不是**门禁**。

改造后，数据源约束变成编译期登记：未登记的数据源直接拒绝进入分析计划。

```
✅ unauthorized_source   非结构化源被授权提供估值数据  → GATE-01 越权拦截
✅ zero_fill             缺失数据填成 0               → GATE-41 零填充拦截
✅ single_line           跳过业务拆解直接给结论        → GATE-11 拆解不足拦截
✅ weak_bear             空头论据敷衍了事             → GATE-16 自我确认拦截
✅ no_market_cap         缺市值仍给估值结论           → GATE-50 反解不收敛拦截
✅ shallow_chain         产业链退化为行业口号         → GATE-12 深度不足拦截

拦截结果：8/8 全部挡下
```

## 适用边界

**明确的边界比模糊的普适更有价值。**

| 维度 | 适用 |
|---|---|
| 市场 | A 股为主，港股 / 美股可参照 |
| 行业 | 科技制造类：半导体、光通信、新能源、机器人、稀土材料、精密制造 |
| 持仓周期 | 1 个月 – 2 年 |
| 核心前提 | 标的存在可识别的产业链瓶颈 |

**不适用**：短产业链行业（消费品牌、金融、内容平台）、期货/外汇/数字货币、高频策略、日均成交额 < 500 万的标的。

**最后一条特别重要**：一个日均成交额 300 万的标的，即使基本面再好，也无法建立和退出一笔有意义的仓位。这类标的应该在分析之前就被跳过。
