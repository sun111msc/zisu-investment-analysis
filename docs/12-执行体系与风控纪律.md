# 执行体系与风控纪律

> 前十一篇文档解决的是「买什么」。本文解决的是「买多少、什么时候卖、错了怎么办」。
>
> 判断正确但仓位管理错误，结果可能和判断错误一样糟。

---

## 一、七条铁律

贴在显示器旁边，每次开仓前读一遍。

```
 1%  — 任何一笔的风险不超过总资金的 1%
2:1  — 盈亏比至少 2:1，否则不交易
 3   — 连续 3 笔亏损减仓，5 笔停止交易
15%  — 回撤 15% 警戒线（强制休息 + 完整复盘）
20%  — 单只标的仓位不超过 20%
70%  — 总仓位不超过 70%
 ∞   — 不预测 · 只应答 · 错过不亏钱
```

### 1.1 为什么是这些数字

| 铁律 | 数学依据 |
|---|---|
| **1%** | 亏 50% 需要赚 100% 才能回本。单笔 1% 意味着连续 10 笔全错也只亏 10%，仍在可恢复范围 |
| **2:1** | 胜率低于 50% 时，必须靠赔率。胜率 40% + 盈亏比 2:1 = 期望为正 |
| **3 笔** | 连续亏损通常不是市场变了，而是状态不对。需要强制中断 |
| **15%** | 15% 以内的回撤三个月可恢复；超过 25% 需要一年以上 |
| **20%** | 单只踩雷不至于伤筋动骨 |
| **70%** | 永远保留子弹 —— 用于抄底，也用于应对意外 |
| **∞** | 这是最重要的一条。错过不亏钱，做错才亏钱 |

### 1.2 关于最后一条

「不预测、只应答」的意思是：

```
不做「我判断它明天会涨」这类预测
只做「如果出现 A 条件，我做 B 动作」这类应答
```

**为什么**：预测是单向的（要么对要么错），应答是双向的（条件满足就行动，不满足就等待）。后者不需要预测能力，只需要纪律。

## 二、六层风控体系

### 2.1 层次结构

```
Layer 1  仓位数学       → 单笔应该下注多少
Layer 2  止损止盈       → 什么时候退出
Layer 3  交易执行       → 具体怎么下单
Layer 4  心理监控       → 状态是否适合交易
Layer 5  组合风控       → 整体暴露管理
Layer 6  每日检查       → 例行核对
```

### 2.2 Layer 1 · 仓位数学

#### 凯利公式与变体

```
Kelly = (胜率 × 盈亏比 − 败率) / 盈亏比

示例：胜率 60%、盈亏比 2:1
  Kelly = (0.6 × 2 − 0.4) / 2 = 40%
```

**40% 的仓位是危险的** —— 如果连续亏损 5 次，本金会损失 92%。

因此体系**不使用全凯利**：

| 变体 | 系数 | 适用 |
|---|---|---|
| 半凯利 | × 0.5 | 成熟系统 |
| **四分之一凯利** | **× 0.25** | **默认** |
| 回撤缩放 | 按回撤动态调整 | 回撤期 |

**升级条件**：四分之一凯利跑通 100 笔后可考虑升至半凯利。**永不用全凯利。**

#### 多层约束取最小值

```
最终仓位 = min(
    凯利仓位 × 0.25,
    波动率调整后仓位,
    回撤缩放后仓位,
    1% 风险限额对应仓位,
    单只上限 20%,
    环境评级上限
)
```

**取最小值而非平均值** —— 任何一个约束触顶都应该限制仓位，而不是被其他宽松的约束「平均」掉。

#### 1% 风险限额

```
仓位 = 账户总资金 × 1% / (入场价 − 止损价) × 入场价
```

示例：账户 100 万，入场价 10 元，止损价 9 元

```
风险金额 = 100 万 × 1% = 1 万
每股风险 = 10 − 9 = 1 元
可买股数 = 1 万 / 1 = 1 万股
仓位金额 = 10 万元 = 10%
```

**注意**：这个约束的含义是「如果止损被触发，亏损恰好是总资金的 1%」。止损越近，可以买的越多；止损越远，必须买的越少。

#### 波动率调整

```
调整后仓位 = 基准仓位 × (目标波动率 / 当前波动率)
```

**直觉**：波动大的标的，同样的仓位金额承担的风险更大，因此需要降低仓位。

#### 回撤缩放

| 当前回撤 | 仓位系数 |
|---|---|
| 0-5% | 100% |
| 5-10% | 67% |
| 10-15% | 33% |
| > 15% | 0%（停止交易） |

#### 三阶段建仓节奏

| 阶段 | 加到 | 触发条件 |
|---|---|---|
| 试错仓 | ≤10% | 入场信号出现 + 环境 ≥ C |
| 确认仓 | +20%（总 30%） | 试错仓浮盈 ≥3% + 结构未破 + 催化剂在 60 天内 |
| 主升仓 | +20%（总 50%） | 确认仓浮盈 ≥5% + 催化剂兑现 + 机构持续加仓 |

### 2.3 Layer 2 · 止损与止盈

#### 三重止损

| 类型 | 判据 |
|---|---|
| 结构止损 | 关键结构位下方 1×ATR |
| 波动率止损 | 1.5×ATR |
| 分步止损 | 反向 1×ATR 平 1/3；1.5×ATR 平 1/3；2×ATR 全平 |

**取值方法**：取结构止损与波动率止损中较近的那个（先触发先执行）。

#### A 股止损修正

```
□ 计算距离 × 0.7（考虑涨跌停导致的滑点）
□ 止损位 −7% 提前至 −5%（预留跌停空间）
□ 早盘波动大时，止损量减半执行
```

#### 四大止盈

| 类型 | 做法 |
|---|---|
| 固定盈亏比 | 到 2R 平仓 |
| 结构目标 | 到前高/关键位平仓 |
| ATR 追踪 | 每涨 1×ATR 上移止损 1×ATR |
| **分步止盈** | **1/3 @ 1.5R + 1/3 @ 3R + 1/3 追踪** |

#### 动态止盈

```
浮盈 ≥ 10% → 启动
之后每涨 1×ATR → 止损上移 1×ATR
```

#### 时间止损

```
持仓 3 天仍无浮盈 → 重新评估或退出
```

**为什么需要时间止损**：资金有成本。一只买入后长期不动的股票，占用了本可以用于其他机会的资金。

#### 八种退出场景

| # | 场景 | 动作 |
|---|---|---|
| 1 | 触发止损 | 全部退出 |
| 2 | 到达止盈目标 | 按分步计划退出 |
| 3 | 结构破坏 | 减仓 ≥60% |
| 4 | 趋势反转确认 | 清仓 |
| 5 | 时间止损到期 | 重新评估 |
| 6 | 催化剂兑现且无新催化剂 | 减仓 50% |
| 7 | 重大负面新闻 | 立即评估，倾向退出 |
| 8 | 投资逻辑被证伪 | **无条件清仓** |

**退出优先级**：逻辑证伪 > 结构破坏 > 止损触发 > 止盈。

### 2.4 Layer 3 · 交易执行

#### T+1 执行时序

| 时段 | 动作 |
|---|---|
| 早盘 9:30-10:00 | 只开半仓（观察方向） |
| 10:00-10:30 | 确认后可补足 |
| 14:30-15:00 | 主力建仓时段（趋势最明确） |
| 9:30-9:45 | **最差买入时段**（波动最大，方向最不确定） |

#### 拆单规模

| 规模 | 方式 |
|---|---|
| < 100 万 | 尾盘一次性 |
| 100-500 万 | 拆 3 批 |
| > 500 万 | VWAP + 冰山单 + 分 2-3 天 |

#### 挂单纪律

```
✅ 限价单优先
✅ 条件单预设
✅ 分批执行（3-5 批，间隔 30 分钟）
❌ 市价单
❌ 盘中追涨
```

### 2.5 Layer 4 · 心理监控

#### 入场前五问

```
□ 我是不是因为 FOMO 才想买？
□ 我是不是在报复上一笔亏损？
□ 这笔交易是否符合计划？
□ 我是不是因为它热门才关注？
□ 我现在的情绪状态适合交易吗？
```

**任一项不通过 → 减仓或放弃。**

#### 连续亏损协议（自动执行，非情绪决定）

| 状态 | 动作 |
|---|---|
| 连续亏损 3 笔 | 自动减仓 50% |
| 连续亏损 5 笔 | 停止交易，强制休息 3 个交易日 |
| 单月亏损 > 10% | 停止所有交易，完成月度复盘后重启 |
| 最大回撤 > 15% | 检查系统是否存在根本性问题 |

**关键**：这是**自动触发**的，不依赖当天的情绪判断。因为连亏状态下的人通常不认为自己需要休息。

### 2.6 Layer 5 · 组合风控

#### 回撤管理

| 回撤区间 | 仓位 | 附加动作 |
|---|---|---|
| 0-5% | 正常 | — |
| 5-8% | 75% | — |
| 8-12% | 50% | 提取 20% 盈利 |
| 12-15% | 25% | 提取 40% 盈利 |
| > 15% | 停止交易 | 完整复盘 |

#### 组合硬约束

```
总仓位 ≤ 70%
单只标的 ≤ 20%（高确信标的可至 25%，且瓶颈等级需 ≥4 级）
单行业 ≤ 40%
最低现金 ≥ 15%
杠杆 = 无
```

#### 绝对亏损限制

```
单日 ≤ 2%
单周 ≤ 5%
单月 ≤ 10%
```

### 2.7 Layer 6 · 每日检查

开盘前 15 分钟：

```
□ 昨日至今是否有重大政策/新闻？
□ 当前市场环境评级是几级？（决定仓位上限）
□ 检查持仓：有质押问题？有减持/解禁公告？是否触及止损？
□ 检查待交易标的：是否有隐藏风险？仓位是否够？
□ 今天不可违反的规则：单笔风险 <1%；连亏 3 笔则不开新仓；不用市价单
```

#### 风控评分矩阵

| 维度 | +1（通过） | 0（有风险） | −1（危险） |
|---|---|---|---|
| 仓位 | 单笔风险 < 1% | 1-2% | > 2% |
| 止损 | 预设技术止损 | 位置不合理 | 无止损 |
| 回撤 | < 5% | 5-15% | > 15% |
| 心理 | 平静 | FOMO / 不安 | 报复 / 膨胀 |
| 执行 | 分批 + 限价 | 未分批 | 市价满仓 |
| 组合 | 现金 > 15% | 5-15% | < 5% |

```
≥ 4 分  → 可以入场
2-3 分  → 减仓 50%
≤ 1 分  → 放弃，等状态恢复
```

## 三、复盘体系

没有日志的交易 = 闭着眼睛开车；没有复盘的系统 = 开了一万次还在犯同样的错。

### 3.1 四级复盘频率

| 频率 | 时长 | 内容 |
|---|---|---|
| 每日 | 15 分钟 | 开盘检查清单 + 心理状态检查 |
| 每周 | 30 分钟 | 周度复盘（不可跳过） |
| 每月 | 1-2 小时 | 月度深度复盘 |
| 每季 | 2-4 小时 | 战略复盘 + 体系升级 |

**硬规则**：跳过任意一次正式复盘 → 下周仓位自动降至原仓位的 70%，补上后恢复。

### 3.2 入场记录（入场后 24 小时内）

```
□ 标的、日期、入场价、仓位
□ 入场理由（瓶颈 / 技术结构 / 催化剂，三选一或组合）
□ 三类情景锚定：目标价 + 核心条件 + 失效条件
□ 止损位与止盈档位
□ 心理状态检查
□ 风控评分（≥4 分才允许入场）
```

### 3.3 出场记录（出场后 30 分钟内）

```
□ 出场方式（止损 / 止盈 / 结构破坏 / 时间 / 逻辑证伪 / 新闻）
□ 出场价、持仓天数、盈亏
□ 归因分析：
    □ 遵守了计划
    □ 提前出场（过于恐惧）
    □ 延迟出场（过于贪婪）
    □ 未设止损（纪律问题）
    □ 止损被扫后反弹
□ 三项打分：入场纪律 / 持仓执行 / 出场纪律（各 5 分，总分 15）
□ 学到的教训（一句话）
```

### 3.4 周度复盘六段

```
① 环境更新：市场评级、风格指向、本周主线
② 持仓检查：标的、持仓天数、浮盈亏、风控评分
③ 本周交易记录：入场表 + 出场表
④ 纪律执行率（五项）：
     单笔风险 <1%
     盈亏比 ≥2:1
     入场前设止损
     尾盘建仓
     入场前填日志
   → 每项统计执行率 %
⑤ 知行合一检查
⑥ 下周计划
```

**第 ④ 项是复盘的核心**：它不评价盈亏，只评价**是否遵守了自己定的规则**。盈亏可能来自运气，纪律不会。

### 3.5 月度深度复盘

```
① 绩效总览：月初/月末资金、月收益率、大盘同期、超额收益
② 交易统计：笔数、胜率、平均盈亏比、最大连盈/连亏、最大回撤
③ 盈亏归因：盈利 TOP3 / 亏损 TOP3，各标注原因
④ 纪律评估：五项核心纪律执行率 + 综合评分
   连续 3 个月纪律评分 < 3 分 → 强制停止交易 2 周
⑤ 体系进化建议：哪个模块需要改进
⑥ 下月重点
```

### 3.6 季度战略复盘

```
□ 凯利参数校准（胜率假设是否需要调整）
□ 标的池更新（新增 / 淘汰）
□ 方法论迭代记录
□ 体系版本升级（记录变更日志）
□ 对历史决策做批量回溯检验
```

## 四、执行体系的整体逻辑

```
                    ┌──────────────────┐
                    │  环境评级 A/B/C/D  │  ← 决定总仓位天花板
                    └────────┬─────────┘
                             ↓
                    ┌──────────────────┐
                    │  瓶颈等级 × 治理   │  ← 决定单只上限
                    └────────┬─────────┘
                             ↓
                    ┌──────────────────┐
                    │  凯利 × 多层约束   │  ← 计算具体仓位
                    │  （取最小值）       │
                    └────────┬─────────┘
                             ↓
         ┌───────────────────┼───────────────────┐
         ↓                   ↓                   ↓
   ┌──────────┐      ┌──────────┐      ┌──────────┐
   │ 三阶段建仓 │      │ 三重止损  │      │ 分步止盈  │
   └──────────┘      └──────────┘      └──────────┘
                             ↓
                    ┌──────────────────┐
                    │  执行（T+1 时序）  │
                    └────────┬─────────┘
                             ↓
                    ┌──────────────────┐
                    │  记录 + 复盘      │  ← 反馈到参数校准
                    └──────────────────┘
```

**三层约束的关系是「取最小值」，不是「加权平均」。** 任何一个约束触顶都应该限制仓位。

## 五、常见错误

| 错误 | 后果 |
|---|---|
| 用全凯利 | 连续亏损时本金迅速缩水 |
| 先定仓位再定止损 | 风险金额失控 |
| 止损设在整数关口 | 容易被精准扫掉 |
| 忽略 T+1 的滑点 | 实际亏损大于预期 |
| 连亏后继续交易 | 状态问题被放大 |
| 不复盘或复盘只看盈亏 | 无法发现模式性问题 |
| 用加仓摊薄成本 | 违反「错了就减」的原则 |
| 在 D 级环境重仓 | 分散化失效 |
| 用市价单 | 滑点不可控 |
| 总仓位打满不留现金 | 失去应对意外的能力 |
