# 端到端决策流程

> 前面十三篇文档是分模块的方法。本文把它们串成一条线：
> **从全市场筛选，到持仓管理，完整走一遍。**

---

## 一、总流程

```
┌──────────────────────────────────────────────────────────────┐
│  Step 0 · 环境评估                                            │
│  十二维流动性 → 环境评级 A/B/C/D → 总仓位天花板                │
│  ⛔ D 级 → 停止，不进行任何个股分析                            │
└───────────────────────────┬──────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────────┐
│  Step 1 · 流动性门槛筛查                                       │
│  日均成交额 < 500 万 → 直接跳过，不进入任何分析流程             │
└───────────────────────────┬──────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────────┐
│  Step 2 · 标的池构建                                           │
│  主线条识别 → 板块筛选 → 产业链映射 → 候选池                    │
└───────────────────────────┬──────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────────┐
│  Step 3 · 瓶颈初筛（漏斗第 2 层）                              │
│  产业链 BOM 拆解 → 识别瓶颈环节 → 紫苏叶分级                    │
│  ⛔ 瓶颈 < 2 级 → 出局                                        │
└───────────────────────────┬──────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────────┐
│  Step 4 · 八阶段深度分析                                       │
│  P0 画像 → P1 行业 → P2 穿透 → P3 财务                        │
│  → P4 市场 → P5 估值                                          │
│  ⛔ 触发 T0/T1/T2/T3/T4 → 终止，输出终止报告                   │

│  Step 6 · 执行方案                                             │

```

## 二、各步骤的输入、输出与判定

### Step 0 · 环境评估

| 项 | 内容 |
|---|---|
| **输入** | 成交额、涨跌家数、涨停/跌停家数、赚钱效应、主要指数位置、融资余额、北向资金 |
| **方法** | 十二维流动性评分（见 [11-A股生态](11-A股市场生态洞察.md)） |
| **输出** | 环境评级 A/B/C/D + 总仓位上限 |
| **判定** | D 级 → 停止流程，仅管理已有持仓 |
| **耗时** | 5 分钟 |

**为什么这是第一步**：它决定后面所有工作是否有意义。在 D 级环境下花十小时分析个股，结论是不可用的。

### Step 1 · 流动性门槛

| 项 | 内容 |
|---|---|
| **判定** | 日均成交额 < 500 万 → 直接跳过 |
| **理由** | 无法建立或退出一笔有意义的仓位，任何分析框架都不适用 |
| **耗时** | 1 分钟 |

**这一步常被跳过，但代价很高**：分析了一只没有流动性的股票，结论再正确也无法执行。

### Step 2 · 标的池构建

| 项 | 内容 |
|---|---|
| **输入** | 市场主线、板块强度、产业链映射 |
| **方法** | 主线识别 → 沿产业链上下游展开 |
| **输出** | 候选池（20-50 只） |
| **耗时** | 1-2 小时 |

**顺序很重要**：先定主线，再沿产业链找标的。反过来（先有标的再找逻辑）容易产生牵强的叙事。

### Step 3 · 瓶颈初筛

| 项 | 内容 |
|---|---|
| **输入** | 候选池 |
| **方法** | 产业链 BOM 拆解 + 竞争者排除矩阵 + 紫苏叶分级 |
| **输出** | 通过初筛的标的（5-15 只） |
| **判定** | 瓶颈等级 < 2 级 → 出局 |
| **耗时** | 每只 1-2 小时 |

**这是淘汰率最高的一步**。多数候选标的在这一步被排除，因为它们只是「行业里的公司」，而不是「不可替代的环节」。

### Step 4 · 八阶段深度分析

| 项 | 内容 |
|---|---|
| **输入** | 通过初筛的标的 |
| **方法** | 见 [02-分析流程](02-分析流程-八阶段正金字塔.md) |
| **输出** | 完整分析报告 + 三态结论 |
| **判定** | 五个终止点任一触发 → 终止 |
| **耗时** | 每只 4-10 小时 |

**终止点的价值**：不是所有标的都值得走完全程。T0（理解不了）、T1（估值脱节）、T2（卡脖子无解）、T3（空头压倒）、T4（无安全边际）—— 每一个都在节省资源。

### Step 5 · 多维印证与仲裁

| 项 | 内容 |
|---|---|
| **输入** | 八阶段结论 + 价格行为 + 机构资金 + 制度排雷 |
| **方法** | 三向裁决矩阵 |
| **输出** | 最终裁决 + 仓位建议 |
| **耗时** | 1-2 小时 |

#### 三向裁决矩阵

| 瓶颈 | 价格行为 | 制度排雷 | 裁决 | 仓位 |
|---|---|---|---|---|
| 4-5 级看好 | 看多 | 无雷 | 全力做多 | 按上限 |
| 4-5 级看好 | 看空 | 无雷 | 等待买点 | 30% 底仓 + 70% 等信号 |
| 4-5 级看好 | 看多 | 有政策/减持风险 | 降级处理 | 降至 30% |
| 3 级 | 看空 | 无雷 | 仅观察 | 不建仓 |
| 任意 | 任意 | **致命雷** | **禁止交易** | 零 |
| 任意 | **趋势破坏** | 任意 | 减仓/清仓 | ≥60% 减仓 |

#### 长短线权重差异化

| 风格 | 瓶颈 | 价格行为 | 制度 |
|---|---|---|---|
| 长线价投 | 60% | 25% | 15% |
| 中线波段 | 40% | 40% | 20% |
| 短线博弈 | 10% | 50% | 40% |

**注意权重的含义**：短线博弈时，制度权重（40%）高于瓶颈（10%）—— 因为短线交易中，制度性风险（质押、解禁、监管）的影响远大于基本面。

#### 一票否决条件

```
⛔ 宏观 D 级          → 严禁开新仓
⛔ 致命排雷触发        → 立即清仓
⛔ 趋势破坏（跌破核心结构 + 关键均线 + 放量）→ 减仓 ≥60%
```

### Step 6 · 执行方案

| 项 | 内容 |
|---|---|
| **输入** | 最终裁决 + 环境评级 |
| **方法** | 尺度声明 → 仓位计算 → 止损止盈 |
| **输出** | 可执行的交易计划 |
| **耗时** | 30 分钟 |

#### 输出清单

```
□ 持有周期声明（短/中/长）+ 主导决策模块
□ 仓位上限（三层约束取最小值）
□ 建仓节奏（试错 / 确认 / 主升）
□ 入场价位区间
□ 止损价（结构 + 波动率取近者，A股修正）
□ 止盈档位（1/3 @ 1.5R + 1/3 @ 3R + 1/3 追踪）
□ 退出场景清单（八种场景对应动作）
```

### Step 7 · 持仓管理与退出

| 项 | 内容 |
|---|---|
| **每日** | 开盘前检查清单 + 风控评分 |
| **每周** | 周度复盘（含纪律执行率） |
| **每月** | 月度深度复盘 |
| **每季** | 战略复盘 + 参数校准 |

#### 退出判定优先级

```
1️⃣  逻辑证伪          → 无条件清仓
2️⃣  结构破坏          → 减仓 ≥60%
3️⃣  止损触发          → 全部退出
4️⃣  止盈目标到达       → 按分步计划退出
5️⃣  时间止损到期       → 重新评估
6️⃣  催化剂真空         → 减仓 50%
```

## 三、决策点汇总

整条流程中有七个关键决策点，每一个都是「通过 / 不通过」的二值判断，不需要主观权衡。

| # | 决策点 | 判据 | 不通过的处理 |
|---|---|---|---|
| 1 | 环境是否允许 | 评级 ≥ C | 停止流程 |
| 2 | 流动性是否足够 | 日均成交额 ≥ 500 万 | 跳过标的 |
| 3 | 是否构成瓶颈 | 等级 ≥ 2 级 | 出局 |
| 4 | 是否触发终止点 | T0-T4 任一 | 输出终止报告 |
| 5 | 是否触发一票否决 | 三条否决条件 | 放弃 |
| 6 | 是否有安全边际 | 基准情景上行 ≥ 10% | 等待回调 |
| 7 | 是否触发退出 | 六种退出场景 | 按对应动作执行 |

**为什么把决策做成二值判断**：主观权衡容易被当天的情绪影响。而二值判断可以被外部核对 —— 如果判断错了，能定位是哪个判据出了问题。

## 四、时间预算

| 阶段 | 耗时 | 说明 |
|---|---|---|
| 环境评估 | 5 分钟 | 每日必做 |
| 流动性筛查 | 1 分钟 / 只 | 批量执行 |
| 标的池构建 | 1-2 小时 | 每周一次 |
| 瓶颈初筛 | 1-2 小时 / 只 | 淘汰率最高 |
| 八阶段深度分析 | 4-10 小时 / 只 | 完整流程 |
| 多维印证与仲裁 | 1-2 小时 | — |
| 执行方案 | 30 分钟 | — |
| 每日持仓检查 | 15 分钟 | 每交易日 |
| 周度复盘 | 30 分钟 | 每周 |
| 月度复盘 | 1-2 小时 | 每月 |

**关键的比例关系**：

```
环境评估（5 分钟）决定了 80% 的结果可用性
瓶颈初筛（1-2 小时）淘汰了 80% 的候选
深度分析（4-10 小时）只对剩下的少数标的进行
```

**这个比例不是偶然的**：前期快速筛选，后期深度投入。反过来做（对所有候选都做深度分析）会浪费大量时间在最终会被淘汰的标的上。

## 五、流程的自我校验

流程本身也需要被检验。三个固定的自省机制：

| 机制 | 位置 | 作用 |
|---|---|---|
| 幸存者偏差自省 | P0.9 之后 | 检查是否因为涨幅而关注 |
| 信息增量终审 | 报告完成后 | 检查是否有真正的新发现 |
| 纪律执行率统计 | 周度复盘 | 检查是否遵守了自己定的规则 |

**第三个最重要**：它不评价盈亏，只评价是否守纪律。因为盈亏可能来自运气，纪律不会。

## 六、流程的第一个原则

整条流程建立在一个前提上：

```
宁可错过，不可做错。
```

这意味着：

- 环境 D 级 → 停下，不分析
- 流动性不足 → 跳过，不例外
- 瓶颈不到 2 级 → 出局，不勉强
- 触发终止点 → 终止，不硬做
- 一票否决 → 放弃，不赌

**每一次「这次不一样」的例外，都是流程失效的开始。**

流程的价值不在于它总能给出答案，而在于它在不该有答案的时候**能说出「没有答案」**。
