# 溯源 · 困境反转与周期波动

> **模块定位**：本模块处理一类**估值逻辑与常识相反**的标的 —— 周期股。
> 在这里，高 PE 可能是买点，低 PE 可能是卖点。

---

## 一、核心命题：周期股的 PE 是反向指标

```
PE = 市值 / 净利润

利润低谷期：净利润极小 → PE 极高（甚至为负）
利润高峰期：净利润极大 → PE 极低
```

**因此在周期股上**：

```
PE 最高时买入（利润低谷，但周期将反转）
PE 最低时卖出（利润高峰，但周期将下行）
```

这与成长股逻辑完全相反。**用成长股的逻辑（低 PE 买入）会在周期顶部买入。**

---

## 二、四象限周期定位

| 象限 | 行业状态 | 动作 |
|---|---|---|
| **I 期** | 全行业亏损 | **买入**（产能出清、价格见底） |
| **II 期** | 利润恢复 | 持有 |
| **III 期** | 利润爆发 | 逐步减仓 |
| **IV 期** | 利润崩塌 | **清仓** |

### 判定指标

| 象限 | 行业 PE 中位数 | PB 分位 | 行业资本开支 |
|---|---|---|---|
| I 期 | > 50（或为负） | < 0.5 | 同比 < −20% |
| II 期 | 20-50 | 0.5-1.0 | 同比 0-20% |
| III 期 | < 15 | 1.0-1.5 | 同比 > 20% |
| IV 期 | < 10 | > 1.5 | 同比转负 |

---

## 三、周期反转的四个验证条件

**必须全部满足才算确认反转。**

```
□ 产能出清信号
   行业开工率下降、中小企业退出、行业 capex 同比大幅为负

□ 库存见底
   产业链库存周转天数降至历史低位、存货周转率开始上升

□ 产品价格见底
   连续 N 周不再下跌，或出现连续提价

□ 龙头率先盈利
   行业最优质的公司先转正（成本最低者先盈利）
```

**只有价格反弹而没有产能出清 → 通常是假反转。**

因为价格反弹会立刻刺激停产产能复产，供给重新过剩。

---

## 四、与「从 0 到 1」的区分

两者都可能表现为高 PE，但驱动因素完全不同。

| 维度 | 周期反转 | 从 0 到 1 |
|---|---|---|
| 营收增速 | 低增长 | 高增长 |
| 毛利率 | 低（价格反弹初期） | 高 |
| 驱动因素 | 价格反弹 + 供给收缩 | 政策 / 技术突破 |
| 估值锚 | PB 分位 + 周期位置 | PS + TAM |
| 持续时间 | 1-3 年（一个周期） | 可能更长 |
| 核心风险 | 产能复产 | 技术路线被替代 |

**判定方法**：
```
若营收增速 < 20% 且 毛利率处于低位但开始回升 → 周期反转
若营收增速 > 50% 且 毛利率高 → 从 0 到 1
```

## 五、周期股的操作纪律

| 项 | 规则 |
|---|---|
| 持有周期 | 1-2 年（覆盖一个完整周期） |
| 仓位上限 | 10-20%（周期股波动大于成长股） |
| 买入时机 | I 期末，四项验证条件满足至少 3 项 |
| 卖出时机 | III 期，利润创新高但股价不再创新高 |
| 止损 | 四项验证条件中被证伪 |

### 必须监控的信号

```
□ 行业资本开支同比（扩产竞赛 = 周期见顶前兆）
□ 行业开工率变化
□ 产品价格趋势（周度）
□ 库存周转天数
□ 龙头企业毛利率修复程度
```

## 六、与 peg-scanner 的关系

全市场扫描时，周期股必须走**独立赛道**，不能与成长股用同一套过滤条件。

| 赛道 | 入口条件 | 评分维度 |
|---|---|---|
| 周期 | 近 5 年净利润标准差/均值 > 100% 且 D&A/营收 > 15% | PB 分位 <0.5 (+3)、行业 PE 中位数 >50 (+3)、行业 capex 同比 <−20% (+2)、存货周转上升 (+1)、未破净 (+1) |

**周期行业名单**（用于自动分类）：
```
有色金属、钢铁、煤炭、化工、航运、面板、存储、猪产业、养殖
```

```
□ 是否判定标的属于周期股（净利润波动率 + 行业属性）？

□ 是否与「从 0 到 1」做了明确区分？

```
