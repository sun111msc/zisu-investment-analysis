# 推演 · 量化策略验证

> **模块定位**：本模块回答一个问题：**主观判断是否与量化证据一致？不一致在哪里？**
>
> 它不产生结论，只产生**对结论的质疑**。

---

## 一、为什么主观分析需要量化验证

主观分析的结构性弱点：

| 弱点 | 表现 |
|---|---|
| 叙事驱动 | 逻辑自洽但缺乏统计支撑 |
| 样本偏差 | 记住成功案例，忘记失败案例 |
| 因子暴露未知 | 以为是选股能力，实际是风格暴露 |
| 历史检验缺失 | 「这次不一样」成为常态理由 |

**量化验证的作用不是替代判断，而是把判断放到统计框架下检查。**

---

## 二、四类验证工具

### 工具一 · 因子暴露分析

回答：这只股票的收益来源是什么？

| 因子 | 说明 | 检查 |
|---|---|---|
| 市值 | 大盘 / 小盘 | 是否为小盘风格暴露 |
| 价值 | 低估值 | 是否因低 PB/PE 而涨 |
| 成长 | 高增长 | 是否因增速而涨 |
| 动量 | 趋势延续 | 是否只是追涨 |
| 质量 | 高 ROE/低杠杆 | 是否因质地而涨 |
| 波动率 | 低波 / 高波 | 是否因低波而被配置 |

**关键判据**：如果一只股票的涨幅可以被单一因子解释，那它可能不是「独特的机会」，
而是「某个风格的beta」。

### 工具二 · 相关性矩阵

回答：这个标的与什么一起涨跌？

```
□ 与主要指数的相关性
□ 与同行业标的的相关性
□ 与相关资产（上游/下游/替代品）的相关性
□ 与海外对标标的的相关性
```

**用途**：判断这是**个股alpha**还是**行业beta**。

**判定方法**：对比同赛道至少 3 家标的的涨幅 ——
如果整个赛道都涨，那是个股分析只是解释了已被选中，不是选中了它。

### 工具三 · 回测验证

回答：这个策略在历史上有效吗？

| 检查项 | 要求 |
|---|---|
| 样本区间 | 至少覆盖一轮完整周期 |
| 样本量 | 信号数量足够（通常 ≥30 次） |
| 前视偏差 | 是否使用了当时不可得的信息 |
| 幸存者偏差 | 是否剔除了退市/ST 标的 |
| 交易成本 | 是否计入手续费与冲击成本 |
| 参数稳健性 | 参数微调后结论是否还成立 |

**必须警惕的三种回测陷阱**：

```
① 过拟合：参数调到最优，样本外失效
② 数据窥探：反复测试直到找到「有效」的规则
③ 忽略成本：理论收益被交易成本吃掉
```

### 工具四 · 筹码结构分析

回答：筹码在谁手里、什么价进的、现在什么心理。

**核心理念**：筹码分布 = 市场参与者持仓成本的**概率密度函数**。
每个峰代表一群人「站在同一个成本位置」。

**五个核心指标**：

| 指标 | 判据 |
|---|---|
| 90% 成本集中度 | < 8% 极度集中；8-15% 较集中；> 30% 极度分散 |
| 获利比例 | 40-70% 为健康；< 30% 高位套牢；> 90% 获利了结压力 |
| 筹码穿透率 | 当日成交 / 当前峰厚度 |
| 活动筹码比率 | 判断筹码活性 |
| 平均成本 | 与现价的关系 |

**关键形态**：

| 形态 | 判定条件 | 含义 |
|---|---|---|
| 低位单峰密集 | 集中度 < 15% + 获利 40-70% + 上方无套牢峰 + 横盘 > 30 天 | 吸筹完成 |
| 高位单峰密集 | 下峰消失 + 获利 < 30% + 缩量 | 出货完成 |
| 锁仓峰 | 拉升中下峰不动 + 缩量 | 主力未走 |
| 对倒峰 | 峰变高但换手率不匹配 | 警惕诱多 |
| 筹码真空区 | 两峰之间稀疏 | 无阻力快速移动 |

**两条核心铁律**：

```
下峰不灭，趋势不死   ← 主力底仓还在，行情没完
上峰不消，上涨没戏   ← 套牢峰高耸，每次拉升都是出货机会
```

**五大陷阱检查**：

```
□ 假底：集中度 >25% + 横盘 <15 天 → 下跌中继
□ 假突破：放量突破后 3 天内回落 → 对倒诱多
□ 假锁仓：拉升放量 + 下峰不动 → 对倒
□ 小盘股信号打折：市值 <50 亿 → 信号打五折
□ 老峰衰减：>3 个月 → 支撑/压力衰减 50%
```

**使用边界**：
```
⛔ 禁止用筹码峰替代基本面分析
⛔ 筹码峰不独立决策，必须配合成交量、价格行为、大盘环境
✅ 多周期必查：日线判短期，周线判中期
```

## 三、验证结果的处理

| 验证结果 | 处理 |
|---|---|
| 主观判断与量化证据一致 | 置信度提高 |
| 不一致 | **必须解释不一致的原因**，不能忽略 |
| 发现因子暴露 | 重新评估这是不是「独特机会」 |
| 发现行业 beta | 按 beta 的确定性调整仓位 |

**不一致的三种可能原因**：

```
① 主观判断错了 → 修正结论
② 量化模型不适用于这个场景 → 说明理由
③ 存在量化未捕捉的信息 → 这是 alpha 的来源，需要重点验证
```

## 四、与 peg-scanner 的关系

全市场扫描属于本模块的「初筛」职能。

**四赛道并行**（避免用一套标准误杀）：

| 赛道 | 入口条件 | 估值锚 |
|---|---|---|
| 0→1 | 净利率 <5% 或 PE <0，且营收增速 >30%，且题材 ≥B 级 | PS + TAM |
| 1→10 | PE >0，营收增速 ≥15% | 多阶段 Forward PEG |
| 10→100 | 营收增速 <20% 且 0 <PE <50 | PE + 分红 |
| 周期 | 净利润波动率 >100% 且 D&A/营收 >15% | PB 分位 + PE 反向 |

**防误杀检查表**（每次扫描前必读）：

| 场景 | 为什么正确 |
|---|---|
| PE=200, PEG=5, 营收+150% | 0→1 赛道，不进 PEG 管道 |
| PE 为负，营收+90% | 亏损正常，用 PS 判断 |
| PE=80, PEG=0.30 | Forward EPS 已消化，多阶段 PEG 正常 |
| PE=300, A 级题材 | A 级题材 PEG 容忍度无上限 |
| PE=5, 行业全亏损 | 周期底部正常信号 |

**这一节的核心意义**：**单一筛选标准会系统性误杀整类标的。**
必须按阶段分赛道，各用各的锚。

## 六、检查清单

```
□ 是否做了因子暴露分析？（涨幅能否被单一因子解释）
□ 是否计算了与同赛道标的的相关性？（个股 alpha 还是行业 beta）
□ 回测是否检查了六项（样本区间/量/前视/幸存者/成本/稳健性）？
□ 筹码分析是否检查了五大陷阱？
□ 主观判断与量化证据不一致时，是否解释了原因？
□ 扫描是否按四赛道分轨（而非单一标准）？
□ 筹码结论是否与其他维度交叉验证（未独立决策）？
```
