# 望远镜 · 题材级别与产业阶段判定

> **模块定位**：本模块决定**用哪个估值锚**。同一家公司，判定为「0→1 阶段」还是
> 「10→100 阶段」，会导出完全不同的估值方法，结果可能相差两倍以上。

---

## 一、题材三问

### 第一问 · 题材级别（决定了估值的容忍度）

| 级别 | 定义 | 估值容忍度 |
|---|---|---|
| **A 级** | 国家级战略（写入规划、有专项政策） | PEG 容忍度无上限，用 PS + TAM |
| **B 级** | 行业级政策（部委层面推动） | PEG 可放宽至 2.0 |
| **C 级** | 公司级事件（订单、并购、产品） | 严格按行业常规估值 |
| **D 级** | 无题材 | 用 PEG，无放宽 |

**为什么 A 级可以放宽**：国家级战略意味着资金与政策的持续投入，
这类标的的估值不能用常规盈利框架衡量 —— 但也意味着**波动极大**。

### 第二问 · 产业阶段（决定了用哪个锚）

| 阶段 | 特征 | 估值锚 | 禁用 |
|---|---|---|---|
| **0 → 1** | 技术验证、商业模式探索、可能亏损 | PS + TAM | ⛔ 禁用 PEG |
| **1 → 10** | 渗透率提升、利润验证中 | 多阶段 Forward PEG | — |
| **10 → 100** | 增速放缓、格局固化 | PE + 分红率 | — |
| **周期 / 困境反转** | 全行业亏损或暴利 | PB 分位 + 周期位置 | ⛔ PE 是反向指标 |

**关键**：0→1 阶段禁用 PEG，因为亏损公司没有正的 E，PEG 无意义。

### 第三问 · 筹码结构（决定了拥挤度）

| 拥挤度 | 判定 | 处理 |
|---|---|---|
| > 80% | 极度拥挤 | ⛔ 不碰 |
| 20-80% | 中性 | 正常分析 |
| < 20% | 筹码干净 | 关注（可能是机会） |

## 二、阶段判定规则

```
if (净利率 < 5% 或 PE < 0) 且 营收增速 > 30% 且 题材级别 ≥ B 级:
    → 0→1 阶段（用 PS + TAM）

elif 近 5 年净利润标准差/均值 > 100% 且 D&A/营收 > 15% 且 属于周期行业:
    → 周期阶段（用 PB 分位 + PE 反向）

elif 营收增速 < 20% 且 0 < PE < 50:
    → 10→100 阶段（用 PE + 分红）

else:
    → 1→10 阶段（用多阶段 Forward PEG）
```

**周期行业名单**：有色金属、钢铁、煤炭、化工、航运、面板、存储、猪产业、养殖

## 三、估值锚切换矩阵

| 阶段 | 主锚 | 副锚 | 交叉验证 |
|---|---|---|---|
| 0 → 1 | PS（可比公司） | TAM 测算 | 研发投入占比 |
| 1 → 10 | 多阶段 Forward PEG | DCF | 现金流转化率 |
| 10 → 100 | PE + 分红率 | EV/EBITDA | 股息率 |
| 周期 | PB 分位 | 行业 PE 反向 | 产能出清信号 |

### 多阶段 Forward PEG

```
PEG_multi = PE / (g1 × 40% + g2 × 35% + g3 × 25%)

g1 / g2 / g3 = 未来 1 / 2 / 3 年的预期增速
权重递减，因为远期预测的不确定性更高
```

| PEG_multi | 判定 |
|---|---|
| < 0.5 | ⭐⭐⭐ 深度低估 |
| < 0.8 | ⭐⭐ 低估 |
| < 1.0 | ⭐ 边缘低估 |
| 1.0-2.0 | 合理区间（不输出） |
| > 2.0 且非 A/B 级题材 | 🟠 高估预警 |

## 四、题材生命周期七阶段

| 阶段 | 特征 | 对应动作 |
|---|---|---|
| 1 概念萌芽 | 少数人知道 | 研究储备 |
| 2 政策催化 | 政策落地 | 关注布局 |
| 3 资金进入 | 成交放大 | 可参与 |
| 4 主流确认 | 机构开始配置 | 主升段 |
| 5 全面扩散 | 人人皆知 | 逐步减仓 |
| 6 分化退潮 | 龙头与跟风分化 | 只留龙头 |
| 7 沉寂 | 无人讨论 | 观察下一轮 |

**目标：在阶段 2-3 介入，阶段 5 减仓。**

## 六、检查清单

```
□ 题材级别是否判定（A/B/C/D）？
□ 产业阶段是否判定（0→1 / 1→10 / 10→100 / 周期）？
□ 筹码拥挤度是否评估？
□ 估值锚是否按阶段选定？
□ 0→1 阶段是否已禁用 PEG？
□ 周期阶段是否已切换为 PB 分位 + PE 反向？
```
