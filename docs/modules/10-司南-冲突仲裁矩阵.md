# 司南 · 冲突仲裁矩阵

> **模块定位**：本模块是**唯一的汇聚点**。所有维度的结论必须在这里被裁决，
> 不允许绕过。它回答一个问题：**多维度信号互相矛盾时，听谁的？**

---

## 一、为什么需要仲裁

不同模块关注不同时间尺度、不同侧面，结论必然冲突：

| 冲突类型 | 典型表现 |
|---|---|
| 尺度冲突 | 短线技术看空，长线基本面看多 |
| 维度冲突 | 产业链位置极佳，但财务质量差 |
| 制度冲突 | 技术形态完美，但质押率 45% |
| 时间冲突 | 催化剂在 6 个月后，但资金面已经恶化 |

**没有仲裁机制的系统，会退化为「挑一个自己喜欢的结论」。**

---

## 二、一票否决权（最高优先级）

以下条件触发任一，**无条件放弃或减仓**，不需要讨论。

| # | 条件 | 动作 |
|---|---|---|
| 1 | 宏观环境 D 级 | 严禁开新仓 |
| 2 | 致命排雷（实控人清仓式减持 / 审计非标 / 质押 >40% 且有平仓线） | 立即清仓 |
| 3 | 趋势破坏（跌破核心结构 + 跌破关键均线 + 放量） | 减仓 ≥60% |

**一票否决的本质**：这三类是**确定性风险**，不是可能性风险。
技术形态是可能性，质押爆仓是确定性。

---

## 三、三向裁决矩阵

三个维度：**紫苏（产业链瓶颈）× 测影（价格行为）× 潜渊（制度排雷）**

| 紫苏 | 测影 | 潜渊 | 裁决 | 仓位 |
|---|---|---|---|---|
| 🍃4-5 看好 | 看多 | 无排雷 | **全力做多** | 按上限 |
| 🍃4-5 看好 | 看空 | 无排雷 | **等待买点** | 30% 底仓 + 70% 等信号 |
| 🍃4-5 看好 | 看多 | 有政策/减持风险 | **降级处理** | 降至 30% |
| 🍃3 强瓶颈 | 看空 | 无排雷 | **仅观察** | 不建仓 |
| 任意 | 任意 | **致命排雷** | **禁止交易** | 零 |
| 任意 | **趋势破坏** | 任意 | **减仓/清仓** | 减仓 ≥60% |

### 三种典型情形的处理逻辑

**情形一：基本面极佳 + 技术面看空**
```
不是矛盾，是时间差。
基本面回答「值不值」，技术面回答「现在买贵不贵」。
处理：建立底仓（30%），其余等待技术信号
```

**情形二：基本面极佳 + 制度有雷**
```
制度 > 技术 > 基本面。
质押爆仓是确定性事件，基本面再好也挡不住强制平仓。
处理：降级或放弃
```

**情形三：基本面一般 + 技术面极强**
```
这是纯博弈，不是投资。
处理：仅观察，或用极小仓位参与并在逻辑证伪时立即离场
```

## 四、长短线权重差异化

同一套模块，不同持有周期下的权重完全不同。

| 风格 | 紫苏（基本面） | 测影（技术面） | 潜渊（制度） |
|---|---|---|---|
| **长线价投** | 60% | 25% | 15% |
| **中线波段** | 40% | 40% | 20% |
| **短线博弈** | 10% | 50% | 40% |

**注意短线博弈的权重**：制度权重（40%）高于基本面（10%）——
因为短线交易中，质押、解禁、监管这类制度性风险的影响远大于基本面。

**这张表必须在分析开始前声明使用哪一行。** 否则仲裁无法执行。

---

## 五、时间尺度冲突的裁决

当不同模块给出方向相反的信号时，先判断是**尺度冲突**还是**真实冲突**。

| 情形 | 判定 | 处理 |
|---|---|---|
| 短线看空 + 长线看多 | 尺度不同，**不冲突** | 长线持有；短线用 ≤30% 底仓做波段降成本 |
| 短线看空 + 长线看空 | **共振看空** | 立即减仓 |
| 短线看多 + 长线看空 | **反弹诱多** | 不参与 |

## 六、仲裁的输出

```
## 司南 · 冲突仲裁

### 一票否决检查
| 条件 | 是否触发 |
|---|---|
| 宏观 D 级 | ❌ |
| 致命排雷 | ❌ |
| 趋势破坏 | ❌ |

### 三向裁决
| 维度 | 结论 | 依据 |
|---|---|---|
| 紫苏（瓶颈） | 🍃🍃🍃🍃 看好 | [分级依据] |
| 测影（技术） | 看多 | [结构判断] |
| 潜渊（制度） | 无排雷 | [排雷结果] |

**裁决**：全力做多
**仓位上限**：20%（受瓶颈等级与环境评级约束）

### 尺度声明
本次分析按 [中线] 尺度执行，权重分配 40:40:20

### 反面情形（若条件变化）
| 若发生 | 则裁决变为 | 动作 |
|---|---|---|
| 技术结构破坏 | 减仓 | ≥60% |
| 出现质押风险 | 降级 | 降至 30% |
| 瓶颈降级至 2 级 | 仅观察 | 不建仓 |
```

## 八、检查清单

```
□ 一票否决的三项是否逐条检查？
□ 三向裁决矩阵是否填完整（紫苏/测影/潜渊）？
□ 是否声明了本次分析的时间尺度与权重分配？
□ 是否处理了「基本面与时间面矛盾」的情形？
□ 是否给出了「若条件变化则裁决如何变」的反面情形？
□ 是否存在被绕过的裁决（只看某一个维度就下结论）？
```
