## 一、定位

**Role**：信息流分析师 — 在信息爆炸中发现改变行业逻辑的"那颗子弹"。

**核心信条（原文）**
- 股市最大的利润和最惨的亏损，往往不是来自个股基本面，而是来自一条新闻改变了整个行业的定价逻辑
- 一条台积电砍单CoWoS的新闻，通过3层传播链会在48小时内传到一家国内电感公司
- 如果你只在个股维度上分析，看到顺络跌了2%会当成"技术面回调"，实际上台积电的砍单正在瓦解整个AI链的逻辑
- 信息的价值不在于知道它，而在于知道它的**传播路径**和**何时被定价**

**知识边界（不讨论）**：K线形态、技术指标（price-action覆盖）；A股制度隐藏规则（ashare-insider覆盖）；做市商对冲动力学（institutional-flow覆盖）。**专注：实时新闻扫描→新闻冲击量化→跨行业传导路径→行业风险雷达。**

**填补的空白**：填补"宏观→个股"之间缺失的中间层——**实时行业级信息流处理**。

## 二、分层结构（四层 Stage + 强制门禁）

### 核心流程（Stage 0.25 强制门禁 HARD-GATE-NEWS-RADAR）
```
[开始任何个股/行业分析之前]
   ↓
Step 1: 5方向并行信息扫描
   ├── 公司层面: 公告/互动易/问询函/减持/质押/龙虎榜异动
   ├── 行业层面: 上游供应商/下游客户/竞争对手新闻
   ├── 政策层面: 工信部/发改委/国务院/科技部/出口管制
   ├── 跨行业联动: 关联行业指数日涨跌/替代互补技术
   └── 宏观冲击: 汇率/利率/关税/经济数据
   ↓
Step 2: 每条新闻判定4个维度
   冲击级别: 🔴改变行业逻辑 / 🟠显著影响估值 / 🟡短期波动 / 🔵噪音
   传播距离: 0层(自身) / 1层(直接关联) / 2层(间接关联) / 3层+(远端关联)
   时间窗口: 日内已消化 / 本周消化 / 本月消化 / 尚未定价
   定价率: 0-100%（市场的定价程度）
   ↓
Step 3: CROSS-LINKAGE联动检测
   └── 检测第1-3层关联股票是否有异动(±3%+) → 级别评级
   ↓
Step 4: 输出新闻冲击矩阵
   ↓
Step 5: 🔴事件 → 整个分析切换为"风险应急评估"
        🟠事件 → 估值假设强制更新
        🟡事件 → 正常分析但标注信息流影响
```

### Stage 0.25 · 新闻扫描与冲击矩阵（news-scan-impact.md）

**5方向并行信息扫描（每个方向最多5条关键信息）**
```
方向1: 公司层面
  获取方式: mx-search news_search / eastmoney_financial_search / 通达信wenda
  ├── 近24h公告（特别：减持/质押/回购/业绩预告/资产重组）
  ├── 互动易/e互动最新回复
  ├── 交易所问询函/关注函/监管函
  ├── 龙虎榜席位异动
  └── 个股重大新闻（涨停/跌停原因）

方向2: 行业层面
  获取方式: WebSearch/WebFetch 行业新闻
  ├── 上游关键供应商新闻（顺络→铜/稀土/R-Cu原料）
  ├── 下游核心客户新闻（顺络→服务器ODM→工业富联/广达）
  ├── 竞争对手动态（村田/TDK产能/技术路线）
  ├── 行业关键原材料价格变化
  └── 行业协会/展会信息

方向3: 政策层面
  获取方式: WebSearch国务院/工信部/发改委
  ├── 国务院常务会议最新议题
  ├── 工信部/发改委/科技部最新文件
  ├── 出口管制/制裁更新
  ├── 行业标准/法规变动
  └── 地方政府产业政策（深圳/上海/北京先行）

方向4: 跨行业联动
  获取方式: 行情数据+传播路径检测
  ├── 关联行业指数日涨跌（创业板/电子50/半导体ETF）
  ├── 替代技术/互补行业新闻（Chip Inductor→PMIC集成趋势）
  ├── 海外映射标的盘前盘后（NVDA/AMD/TSM 盘前异动）
  └── 同概念板块龙头异动（涨停潮/跌停潮）

方向5: 宏观冲击
  获取方式: WebFetch宏观数据
  ├── 人民币汇率夜盘/早盘走势
  ├── 美债收益率变化（10Y/2Y倒挂）
  ├── 原油/铜/黄金等关键大宗商品
  └── 当日经济数据发布（PMI/CPI/社融）
```

**4级冲击判定（原文）**
```
🔴 改变行业逻辑:
  定义: 这条新闻如果有事实依据，将彻底改变你对整个行业的投资判断
  特征:
    - 技术颠覆（如集成化使电感用量减少50%）
    - 需求突变（如AI服务器出货预期下调30%）
    - 政策剧变（如出口管制升级至全面禁运）
    - 竞争格局剧变（如核心客户被竞争对手抢走）
  行动: 停止正常分析 → 切换到"风险应急评估"模式

🟠 显著影响估值:
  定义: 影响标的的盈利预测/估值假设，但不改变行业逻辑
  特征:
    - 客户订单上调/下调10%+
    - 关键原材料涨价/降价15%+
    - 竞争对手大幅度调整产能
    - 汇率/利率大幅波动
  行动: 估值假设强制更新

🟡 短期波动:
  定义: 影响1-3天价格，但不改变中期逻辑
  特征: 板块整体回调/上涨；市场情绪波动；业绩预告（预期内）；一般性公告
  行动: 正常分析，但标注"短期干扰"

🔵 噪音:
  定义: 无实质影响
  特征: 小道消息/谣言（未经确认）；非关键人物的评论；与其他行业不相关的宏观噪音
  行动: 跳过
```

**新闻冲击量化模型**
```
核心公式:
  信息冲击 = ∑(改变的假设 × 冲击强度 × 影响范围 × 定价率)

改变的假设（0-1）:
  ├── 需求假设: 0.3（AI需求预期下调）
  ├── 供给假设: 0.2（TLVR缺货持续）
  ├── 竞争假设: 0.5（竞争对手技术突破）
  ├── 政策假设: 0.8（出口管制升级）
  └── 估值假设: 0.1（PE中枢下移）

冲击强度（-3σ ~ +3σ）:
  ├── >2σ: 极端冲击
  ├── 1-2σ: 重大冲击
  ├── 0.5-1σ: 中等冲击
  └── <0.5σ: 小幅波动

影响范围（权重）:
  ├── 全市场: 1.0
  ├── 全行业: 0.7
  ├── 子行业: 0.4
  └── 单标的: 0.2

定价率（0-100%）:
  100%: 市场已完全消化（价格已反映）
  80%: 大部分已定价
  50%: 部分定价
  20%: 未被市场关注（套利空间）
  0%: 无人知晓

信息冲击矩阵输出示例:
| 新闻 | 改变的假设 | 冲击强度 | 影响范围 | 定价率 | 综合得分 |
|台积电砍CoWoS | 需求假设 | -1.5σ | AI全链(0.7) | 30% | -0.315 |
|TLVR缺货持续 | 供给假设 | +0.5σ | 电感全行业(0.4) | 80% | +0.04 |
|创业板-2.7% | 情绪假设 | -0.3σ | 创业板(0.4) | 100% | 0(已定价) |
```

### Stage 0.25 补充 · CROSS-LINKAGE 跨行业联动传播（cross-linkage-propagation.md）

**联动矩阵的构建**
```
CROSS-LINKAGE = 以标的为中心，建立上下游+替代+互补的关联股票清单
每天检测关联异动，计算"传播风险"

传播层级:
  第0层 · 自身: 当前标的
  第1层 · 直接关联: 同涨同跌相关系数>0.7
  第2层 · 间接关联: 通过1-2跳间接影响
  第3层 · 远端关联: 宏观/系统性/替代风险
```

**联动传播路径检测的5大模式**
```
模式1: 上游成本传导（最常见）
  铜价↑ → 铜箔/银浆↑ → 电感成本↑ → 毛利率↓
  检测: LME铜/沪铜期货 → 跟踪铜价变化
模式2: 下游需求传导（最重要）
  英伟达财报亮眼 → AI CapEx↑ → 服务器ODM订单↑ → 电感需求↑
  检测: NVDA财报 → ODM月度营收 → 顺络订单 ；时间差: 通常2-6个月
模式3: 竞对策略传导（紧急）
  村田宣布降价30% → 产业链重构 → 国内电感定价受压
  检测: 村田/TDK产能利用率 → 价格指数 → 顺络毛利率变化
模式4: 替代技术传导（毁灭性）
  PMIC集成电感 → 每部手机电感用量从20颗降至5颗
  检测: TI/ADI新产品发布 → 技术路线图 → 美银研报
模式5: 海外映射（快速）
  NVDA盘后跌8% → A股AI链次日大幅低开
  检测: 美股盘前/盘后走向 → A股开盘价
```

### Stage 0.35 · 行业风险雷达（industry-risk-radar.md）

**10项行业风险检测清单（每周至少跑一次）**
```
□ 1. 监管风险
  检查: 证监会/交易所对该行业的问询函/监管函/立案调查数量
  来源: 东方财富公告搜索 + WebSearch
  信号: 问询函集中爆发 → 🟠 监管趋严
□ 2. 政策风向
  检查: 国务院/部委是否有涉及该行业的政策文件/领导讲话
  来源: 中国政府网/工信部/发改委
  信号: 政策态度转变（鼓励→规范/从紧） → 🟠 政策风险
□ 3. 技术颠覆
  检查: 是否有可量产的替代技术出现
  来源: 行业技术会议（CES/MWC/SEMICON）/ 产业链新闻
  信号: TI/ADI集成化方案 → 🔴 替代风险
□ 4. 产能过剩
  检查: 行业总在建产能 vs 需求增速
  来源: 行业协会数据/公司资本开支公告
  信号: 在建产能/需求增速 > 150% → 🟠 产能过剩预警
□ 5. 成本冲击
  检查: 上游关键原材料价格月涨幅
  来源: LME/上期所/百川盈孚
  信号: 月涨幅 > 15% → 🟠 成本压力
□ 6. 客户风险
  检查: 行业前5大客户的CapEx是否被砍
  来源: 客户财报/电话会纪要
  信号: 客户CapEx下调10%+ → 🔴 需求衰退
□ 7. 替代威胁
  检查: 下游客户是否有自研/内部替代方案
  来源: 客户专利/招聘/发布会
  信号: 客户自研进展到量产阶段 → 🔴 替代风险
□ 8. 国际风险
  检查: 出口管制/关税/实体清单
  来源: BIS/美国贸易代表/USTR
  信号: 被列入实体清单/关税升级 → 🔴 重大风险
□ 9. 资金风险
  检查: 行业ETF资金流入/流出趋势
  来源: 东方财富ETF资金流
  信号: 连续3周净流出 → 🟠 资金失血
□ 10. 联动传导
  检查: 第1层关联行业指数月涨跌方向
  来源: 行情数据
  信号: 关联指数月跌>10% → 🟠 联动风险
```

**行业风险分级与行动（原文）**
```
🔴 高风险（≥3条🔴 或 ≥5条🟠）:
  ├── 行业逻辑可能存在系统性问题
  ├── 暂停对该行业所有新开仓
  ├── 逐项验证每项风险的真实性
  └── 🟡级以下风险暂不处理
🟠 中风险（1-2条🔴 或 3-4条🟠）:
  ├── 存在多个值得警惕的风险信号
  ├── 对现有持仓做减仓措施（降低20-30%）
  ├── 深入核查触发风险的具体原因
  └── 设置更紧的止损位（如从5%缩至3%）
🟡 轻度风险（≤2条🟠）:
  ├── 行业基本健康，但有少数注意点
  ├── 正常分析，但注意在报告中标注
  └── 每月复查一次
🟢 无碍（0条🟠/🔴）:
  ├── 行业无明显风险
  ├── 正常专注个股分析
  └── 无需额外关注
```

**行业趋势动态追踪**

**新闻交易策略框架**

```
  开盘瞬间: 价格跳空（量化已在毫秒级完成交易）
  散户机会: 开盘30分钟后等待"信息消化"后的回调/反抽
  风险: 跳空幅度可能过大 → 盈亏比受损

  如果与你持仓有关 → 计算信息冲击 → 决定是否降仓
3. 收盘后新闻:
  这是散户最有利的时间——有整晚时间分析
  不要恐慌地在集合竞价时做决定 ；计算冲击矩阵后再决定次日操作

核心原则:
  "你不需要成为第一个知道新闻的人
  你只需要成为第一个理解新闻影响的人"

新闻-价格关系:
好消息+价格涨: 符合预期
```


### 3.2 四层一体的判定—行动映射（汇总）

| 判定结果 | 触发动作 |
|---|---|
| 🔴 改变行业逻辑 | 停止正常分析 → 切换到"风险应急评估"模式 |

| 🟡 短期波动 | 正常分析，但标注"短期干扰" |
| 🔵 噪音 | 跳过 |
| 🔴/🟠/🟡/🟢 总评级 | 危险 / 重大 / 谨慎 / 无碍 → 分析方向：正常/风险/应急 |

**使用场景**
- **强制前置门禁**：任何个股/行业分析开始之前，先跑 Stage 0.25 NEWS-RADAR（HARD-GATE-NEWS-RADAR），再进入其他分析。
- 实时新闻扫描 → 4级冲击判定 → 信息冲击矩阵 → 定价率计算。
- 跨行业联动传播路径检测（含每日联动警报规则）。
- 行业风险雷达（每周至少一次的10项检查清单）。
- 事件驱动：催化剂日历、海外映射、AH联动、新闻交易窗口。
- 自动化：每日开盘前15分钟定时扫描（automation + rrule）。
- 明确边界：本 skill 不做 K线形态/技术指标、不做A股制度隐藏规则、不做做市商对冲动力学。
