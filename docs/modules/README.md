# 十一个功能模块

> 体系由十一个功能模块构成。模块是**能力域**，八阶段是**时间轴** ——
> 一个阶段可能调用多个模块，一个模块也可能被多个阶段使用。

## 三条协作机制

| 机制 | 说明 | 典型场景 |
|---|---|---|
| **委托调用** | 主流程把某个子问题委托给专门模块 | 紫苏把治理审查委托给潜渊 |
| **信号注入** | 模块向主流程注入信号，不参与判断 | 天象注入环境评级，约束仓位 |
| **风险增强** | 模块为已有结论补充风险维度 | 潜渊为技术信号补充制度风险 |
