# 弓矢 · 风控仓位执行

> **模块定位**：本模块回答「买多少、什么时候卖、错了怎么办」。
> 它是整个体系的**出口** —— 前面十一个模块的所有结论，最终必须转化为可执行的动作约束。
>
> 完整方法论见 [12-执行体系与风控纪律](../12-执行体系与风控纪律.md)，本文补充模块视角。

## 二、Layer 1 · 仓位数学

### 多层约束取最小值

```
最终仓位 = min(
    凯利仓位 × 0.25,           ← 永不用全凯利
    波动率调整后仓位,
    回撤缩放后仓位,
    1% 风险限额对应仓位,
    单只上限 20%,
    环境评级上限
)
```

**为什么取最小值而非加权平均**：任何一个约束触顶都应限制仓位，
而不是被其他宽松的约束「平均」掉。

### 凯利公式与变体

```
Kelly = (胜率 × 盈亏比 − 败率) / 盈亏比

示例：胜率 60%、盈亏比 2:1 → Kelly = 40%
```

**40% 是危险的**：连亏 5 次本金损失 92%。因此体系默认使用**四分之一凯利**。

| 变体 | 系数 | 适用 |
|---|---|---|
| 全凯利 | ×1.0 | ⛔ 永不使用 |
| 半凯利 | ×0.5 | 成熟系统（跑通 100 笔后） |
| **四分之一凯利** | **×0.25** | **默认** |

### 1% 风险限额

```
仓位金额 = 账户总资金 × 1% / (入场价 − 止损价) × 入场价
```

含义：如果止损被触发，亏损恰好是总资金的 1%。**止损越近，可买的越多；止损越远，必须买的越少。**

### 三阶段建仓

| 阶段 | 加到 | 触发条件 |
|---|---|---|
| 试错仓 | ≤10% | 入场信号 + 环境 ≥C |
| 确认仓 | +20%（总 30%） | 试错仓浮盈 ≥3% + 结构未破 + 催化剂在 60 天内 |
| 主升仓 | +20%（总 50%） | 确认仓浮盈 ≥5% + 催化剂兑现 + 机构持续加仓 |

## 三、Layer 2 · 止损与止盈

### 三重止损

| 类型 | 判据 |
|---|---|
| 结构止损 | 关键结构位下方 1×ATR |
| 波动率止损 | 1.5×ATR |
| 分步止损 | 反向 1×ATR 平 1/3；1.5×ATR 平 1/3；2×ATR 全平 |

**取值**：取结构止损与波动率止损中**较近**的（先触发先执行）。

### A 股修正

```
□ 计算距离 × 0.7（考虑涨跌停导致的滑点）
□ 止损位 −7% 提前至 −5%（预留跌停空间）
□ 早盘波动大时，止损量减半执行
```

### 分步止盈

```
1/3 @ 1.5R  +  1/3 @ 3R  +  1/3 ATR 追踪
```

**动态止盈**：浮盈 ≥10% 启动，之后每涨 1×ATR 上移止损 1×ATR。

**时间止损**：持仓 3 天仍无浮盈 → 重新评估或退出。

### 八种退出场景与优先级

| 优先级 | 场景 | 动作 |
|---|---|---|
| 1️⃣ | **逻辑证伪** | **无条件清仓** |
| 2️⃣ | 结构破坏 | 减仓 ≥60% |
| 3️⃣ | 触发止损 | 全部退出 |
| 4️⃣ | 到达止盈 | 按分步计划 |
| 5️⃣ | 时间止损到期 | 重新评估 |
| 6️⃣ | 催化剂真空 | 减仓 50% |
| 7️⃣ | 重大负面新闻 | 立即评估，倾向退出 |
| 8️⃣ | 趋势反转确认 | 清仓 |

## 四、Layer 4 · 连续亏损协议

**自动执行，不依赖当天的情绪判断。**

| 状态 | 动作 |
|---|---|
| 连续亏损 3 笔 | 自动减仓 50% |
| 连续亏损 5 笔 | 停止交易，强制休息 3 个交易日 |
| 单月亏损 >10% | 停止所有交易，完成月度复盘后重启 |
| 最大回撤 >15% | 检查系统是否存在根本性问题 |

**为什么必须自动**：连亏状态下的人通常不认为自己需要休息。

## 五、Layer 5 · 组合硬约束

```
总仓位 ≤ 70%
单只标的 ≤ 20%（高确信 + 瓶颈 ≥4 级可至 25%）
单行业 ≤ 40%
最低现金 ≥ 15%
杠杆 = 无
```

**绝对亏损限制**：单日 ≤2% / 单周 ≤5% / 单月 ≤10%

## 六、Layer 6 · 风控评分矩阵

| 维度 | +1（通过） | 0（有风险） | −1（危险） |
|---|---|---|---|
| 仓位 | 单笔风险 <1% | 1-2% | >2% |
| 止损 | 预设技术止损 | 位置不合理 | 无止损 |
| 回撤 | <5% | 5-15% | >15% |
| 心理 | 平静 | FOMO/不安 | 报复/膨胀 |
| 执行 | 分批 + 限价 | 未分批 | 市价满仓 |
| 组合 | 现金 >15% | 5-15% | <5% |

```
≥4 分 → 可以入场
2-3 分 → 减仓 50%
≤1 分 → 放弃，等状态恢复
```

## 七、七条铁律

```
 1%  — 任何一笔的风险不超过总资金的 1%
2:1  — 盈亏比至少 2:1
 3   — 连续 3 笔亏损减仓，5 笔停止交易
15%  — 回撤 15% 警戒线（强制休息 + 完整复盘）
20%  — 单只标的仓位不超过 20%
70%  — 总仓位不超过 70%
 ∞   — 不预测 · 只应答 · 错过不亏钱
```

**最后一条最重要**：不做「明天会涨」这类预测，只做「如果 A 条件出现则做 B 动作」这类应答。
后者不需要预测能力，只需要纪律。

## 九、检查清单

```
□ 仓位是否由多层约束取最小值算出？
□ 是否使用了四分之一凯利（而非全凯利）？
□ 单笔风险是否 ≤1%？
□ 止损是否取结构止损与波动率止损中较近者？
□ 是否做了 A 股修正（滑点预留、跌停空间）？
□ 是否设定了分步止盈档位？
□ 组合约束是否满足（总仓≤70% / 单只≤20% / 现金≥15%）？
□ 风控评分是否 ≥4 分？
□ 连亏状态是否触发自动减仓协议？
```
