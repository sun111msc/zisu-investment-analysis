# 司书 · 研报解码与机构行为

> **模块定位**：本模块不替代基本面分析，只做一件事 ——
> **从研报的「字里行间」与「白空间」中，提取被市场忽略的信号。**

---

## 一、为什么研报需要「解码」

研报是**有立场的商业文本**，不是中性信息。原因有三：

1. **激励机制**：卖方研究收入来自机构佣金与关系维护，不是预测准确率
2. **语言惯例**：「持有」在卖方语境中常常等于看空，只是不便明说
3. **信息不对称**：研报写的是「能写的内容」，最有价值的信息往往在**没写的内容**里

因此研报必须被**解码**，而不是被**采信**。

---

## 二、八大解码模块

### 模块一 · 激励结构分析

先判断分析师为什么写这篇报告。

| 观察 | 推断 |
|---|---|
| 覆盖密度突然上升 | 可能有 IPO / 增发 / 解禁事件，机构有生意 |
| 长期不覆盖突然覆盖 | 公司关系维护，或真的出现了变化 |
| 评级与目标价不匹配 | 评级「买入」但目标价仅高于现价 3% → 实际态度中性 |
| 风险段落与正面段落字数比 | 比值极低 → 风险披露走过场 |

### 模块二 · 语言信号检测

| 信号 | 含义 |
|---|---|
| 「符合预期」反复出现 | 无新信息，报告是例行公事 |
| 「短期承压，长期向好」 | 短期问题比写的严重 |
| 「我们维持评级」 | 未做新的独立判断 |
| 「有待进一步观察」 | 分析师自己也不确定 |
| 风险段落占比 < 10% | 风险披露不充分 |

### 模块三 · 评级解码

| 卖方用语 | 实际含义 |
|---|---|
| 买入 / 强烈推荐 | 看多 |
| 增持 / 推荐 | 温和看多 |
| 持有 / 中性 | **通常等于看空**（不便直接下调） |
| 谨慎增持 | 暗示风险但不敢明说 |
| 减持 / 卖出 | 极少出现，出现即强信号 |

**关键判据**：卖方评级中「卖出 + 持有」占比高 → **分歧度大** → 该股票的定价可能存在显著乐观偏差（见 Miller 定价框架）。

### 模块四 · 一致预期逆向使用

```
一致预期 = 全市场分析师预测的中位数

使用规则：
  分歧度 > 历史均值  → 有信息价值（市场未达成共识）
  一致看多且分歧度低 → 拥挤的共识 → 反向指标
```

**为什么要逆向使用**：一致预期已经被定价。真正有价值的是**分歧**，
因为分歧意味着存在错误定价的可能。

**分歧度计算**：

```
分歧度 = EPS 预测的标准差 / EPS 预测的均值
```

### 模块五 · PEAD 与超预期分析

**PEAD（盈余公告后漂移）**：盈余超预期的股票，在公告后一段时期内倾向于继续同向漂移。

| 项 | 说明 |
|---|---|
| 超预期幅度 | 实际 EPS 相对一致预期的偏差 |
| 漂移窗口 | 公告后数周至数月 |
| 应用 | 超预期后有动量，低于预期后有反向动量 |

**Beat/Miss 模式识别**：观察公司历史上「超预期」与「低于预期」的分布 ——
如果连续多个季度都是「恰好超出一点点」，说明管理层在做预期管理。

**Earnings Whisper 检测**：市场私下流传的预期往往与公开一致预期不同。
当公开预期与市场行为（股价、期权隐含波动）背离时，说明存在未公开的预期。

### 模块六 · 外资 vs 内资差异

| | 外资 | 内资 |
|---|---|---|
| 分析框架 | 全球产业链比较、BOM 拆解 | 本土常识、政策敏感度 |
| 关注点 | 全球份额、技术代际 | 题材、资金、政策 |
| 定价影响 | 长线、大市值偏好 | 短线、弹性偏好 |

**利用方式**：两者共识的方向确定性高；两者分歧的方向往往是超额收益的来源。

### 模块七 · 白空间挖掘

**白空间 = 所有分析师都没提到、但可能很重要的信息。**

```
白空间来源：
□ 报告中未讨论的竞争对手
□ 未提及的客户集中度风险
□ 未分析的产能扩张计划
□ 未追踪的上下游变化
□ 未回应的市场质疑
```

**这是最大的 alpha 来源** —— 因为没人写过，所以没被定价。

### 模块八 · 覆盖密度与修正动量

| 指标 | 含义 |
|---|---|
| 覆盖机构数 | 研究关注度 |
| 近 3 月研报数 | 关注度变化速度 |
| 评级上调/下调数 | 修正动量方向 |
| 目标价修正幅度 | 预期变化强度 |

**修正动量**：连续上调 = 预期改善趋势；连续下调 = 预期恶化趋势。
**趋势比水平重要** —— 从「下调」转向「上调」的拐点最有价值。

## 三、研报解码的输出

```
## 研报解码

### 覆盖概况
| 项 | 数值 |
|---|---|
| 覆盖机构数 | X 家 |
| 近 3 月研报数 | X 篇 |
| 评级分布 | 买入 X / 增持 X / 持有 X / 卖出 X |
| EPS 一致预期 | X 元 |
| 分歧度 | X%（历史均值 X%） |

### 语言信号
| 信号 | 出现 | 解读 |
|---|---|---|
| 例行公事型表述 | 有/无 | |
| 风险披露充分度 | 高/中/低 | |

### 修正动量
| 时期 | 上调 | 下调 | 净动量 |
|---|---|---|---|

### 🎯 白空间（≥3 条）
1. [所有分析师都没提到但重要的事]
2. ...
3. ...

### 一致预期可信度评估
分歧度 [高/中/低] → [有信息价值 / 已被充分定价]
```

## 四、与其他模块的接口

| 接口方向 | 模块 | 传递内容 |
|---|---|---|
| 输入 ← | 02 经纬 | 研报文本、评级、一致预期数据 |
| 输出 → | 05 朝议 | 卖方分歧度 → 派系评审的输入 |
| 输出 → | 07 市场结构 | 分歧度 + 做空限制 → Miller 定价框架判定 |
| 输出 → | 04 紫苏 | 反方证据 → 完善排除矩阵 |
| 输出 → | 09 推演 | 一致预期 → 盈余惊喜模型的对比基准 |

**分工说明**：本模块**不做**基本面分析（由 03 财务、04 紫苏负责），
**不做**估值计算（由估值方法论负责）。只做「从研报中提取被忽略的信号」。

---

## 五、检查清单

```
□ 是否做了激励结构分析（分析师为什么写这篇）？
□ 是否解码了评级语言（持有 = 看空）？
□ 是否计算了分歧度并与历史均值对比？
□ 是否检测了修正动量的方向与拐点？
□ 是否输出了 ≥3 条白空间？← 最有价值的部分
□ 是否标注了证据等级？
```
