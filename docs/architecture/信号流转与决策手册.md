# 信号流转与决策手册

## 完整交易周期

### 【交易前——30分钟】

```
时间       动作                             工具/来源
08:50      检查隔夜新闻                       WebSearch / 东方财富
08:55      大盘环境评级 A/B/C/D               HARD-GATE-MACRO-GATE
09:00      检查持仓（止损/解禁/质押/减持）      ashare-insider
09:05      检查待交易标的（排雷+催化剂）        serenity + position-management
09:10      风控评分矩阵（≥4分才入场）            HARD-GATE-EXECUTION-LOOP
09:15      心理状态检查 + 今日铁律确认           Layer 4
09:20      挂条件单（预设入场/止损）            T+1时序（尾盘主力建仓）
```

### 【交易中——盘中监控】

```
信号类型        监控方法                    触发动作
止损触达        条件单自动触发              机器式平仓
结构破坏        每60分钟看一次15min K线      手动评估出场
重大新闻        突发推送通知                 重新评估逻辑
催化剂兑现      时间轴检查                   评估是否止盈
```

### 【交易后——30分钟内完成】

```
必须记录（不可拖延）：
  1. 入场理由（3句话以内）
  2. 心理状态（平静/自信/不安/兴奋/恐惧）
  3. 是否按计划执行（是/否→偏差原因）
  4. 纪律评分（1-5分）
```

## 信号冲突时的决策路径

```
收到冲突信号？
  │
  ├→ 检查一票否决权
  │   ├→ 宏观 D 级？         → 禁止交易，结束
  │   ├→ insider 致命排雷？  → 立即清仓，结束
  │   └→ PA 趋势破坏？      → 减仓60%+，结束
  │
  ├→ 无否决权触发 → 进入仲裁矩阵
  │   ├→ Serenity 看多 + PA 看多 + insider 无雷  → 全力做多
  │   ├→ Serenity 看多 + PA 看空                 → 等待买点（30%底仓）
  │   ├→ Serenity 看多 + insider 有风险           → 降级处理（降至30%）
  │   └→ 其他组合 → 查三向裁决矩阵
  │
  └→ 仲裁输出 → 凯利公式 → 1%铁律 → 三阶段建仓
```

## 每日问自己的5个问题

1. **今天是什么天？**（A/B/C/D——决定了你该做什么事）
2. **我有没有遵守仓位纪律？**（1%铁律 + 紫苏叶上限 + 环境上限）
3. **这笔交易的止损在哪里？**（没有止损就不交易）
4. **我现在的心态对吗？**（是不是FOMO？是不是在报复？）
5. **如果现在停盘一周，我的持仓让我安心吗？**

> **最后一个问题是最真实的——如果你不想持有一个股票一周，那你就不该持有它一分钟。**
