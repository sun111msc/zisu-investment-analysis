## 两种结构的区别

体系有两套正交的结构，容易混淆：

| | 六层漏斗 | 八阶段 |
|---|---|---|
| 回答 | 从五千只里选哪几只 | 选中一只后怎么分析 |
| 粒度 | 全市场 → 持仓 | 单标的 |
| 方向 | 筛选（逐步排除） | 展开（逐步深入） |
| 所属 | 架构层 | 流程层 |

```
六层漏斗（选股路径）
  Layer 0 环境 → Layer 1 初筛 → Layer 2 瓶颈 → Layer 3 印证 → Layer 4 仲裁 → Layer 5 执行
                                    ↓ 选中一只后
八阶段（分析流程）
  P0 画像 → P1 行业 → P2 穿透 → P3 财务 → P4 市场 → P5 估值 → P6 执行 → P7 裁决
```

## 三层协作机制

| 机制 | 定义 | 示例 |
|---|---|---|
| **委托调用** | 主流程把子问题委托给专门模块，拿回结论 | 紫苏委托潜渊做治理审查 |
| **信号注入** | 模块向主流程注入约束信号，不参与判断 | 天象注入环境评级，约束仓位上限 |
| **风险增强** | 模块为已有结论补充风险维度 | 潜渊为技术信号补充制度风险 |

## 数据流的三段式

```
原始数据  →  分析产物  →  裁决结论  →  执行方案
（经纬）    （各模块）     （司南）     （弓矢）

产物载体：
  第一阶段：结构化数值（带来源与时点）
  第二阶段：artifacts（各模块输出，含证据等级）
  第三阶段：裁决结果 + 仓位约束
  第四阶段：可执行的交易计划
```

**关键约束**：每一段都必须可追溯到上一段的输入。任何无法追溯的结论视为无效。

## 反馈闭环

```
执行 → 记录 → 复盘 → 参数校准
                ↓
         凯利参数调整 / 标的池更新 / 方法论迭代
```

复盘的价值不在于评价盈亏，而在于**评价是否守纪律** ——
因为盈亏可能来自运气，纪律不会。
