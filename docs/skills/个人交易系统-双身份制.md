## 核心哲学 v1.1（双身份投资者）

```
你是一个"双身份投资者"——
  🎭 身份 A（散户速度）: 占资金 60% · 信仰仓 · 信息稀疏期入场 · 逻辑止损
  🎭 身份 B（机构纪律）: 占资金 40% · 规则仓 · 信息密集期持有 · 价格止损

"60/40"不是固定比例·每笔交易在启动时决定分配比例。
"散户速度"让你在从零到一的阶段入场，
"机构纪律"让你在从一到十的阶段留住仓位。

永远不全买、永远不全卖。
```

## Step 0: 前置检查（v1.1 新增·永续久期+身份偏好）

### 0.1 永续久期优势识别

```
核心原则: 你的负债端是永续的。公募的止损必须在 15-20% 因为持有人会赎回；
你的止损可以由你自己定义，因为没有人能赎回你的仓位。

50% 的最大回撤容忍度在机构是天方夜谭·对你却是真实的战略资产。
```

### 0.2 双身份定位

```
🎭 身份 A（散户速度·信仰仓 60%）触发条件（符合以下 ≥ 2 项）:
  □ 标的处于"信息稀疏期"——卖方覆盖 < 3 家
  □ 上市不满 2 年
  □ 最近一份季报距今 > 45 天（信息真空）
  □ 主题处于"从零到一"阶段——有叙事但无可核验财务数据
  → 此时身份 A 占主导·快速入场·设逻辑止损

🎭 身份 B（机构纪律·规则仓 40%）触发条件（符合以下 ≥ 2 项）:
  □ 标的处于"信息密集期"——卖方覆盖 ≥ 8 家
  □ 连续发布 3 份以上超预期季报
  □ 已经进入公募前 50 大重仓股
  □ 已有明显价格趋势和量价结构
  → 此时身份 B 占主导·用价格止损+移动止盈管理

混合期（大多数情况）:
  标的处于从信息稀疏到密集的过渡段
  → 60/40 标准分配·双身份同时管理
```

### 0.3 🆕 永续久期权重检查（v1.1·v6.4·Lesson 1）

**动态止损宽度映射**:

| 紫苏叶等级 | 基础止损宽度 | 永续久期修正 | 说明 |
|-----------|------------|-------------|------|
| 🍃5（强瓶颈） | -20% | +15% → -35% | 信仰仓最宽容忍 |
| 🍃4（有壁垒） | -15% | +10% → -25% | |
| 🍃3（一般） | -15% | 0% → -15% | 不做特殊宽待 |
| 🍃2（弱势） | -10% | 0% → -10% | |
| 🍃1（放弃） | -5% | 0% → -5% | |

**关键修正逻辑**:
- 只有紫苏叶评级 ≥ 4 且有"强稀缺/强瓶颈"叙事支撑的标的·才获得永续久期宽待
- 普通标的仍然执行标准止损——永续久期不是"所有标的都不止损"
- 信仰仓（60% 部分）可使用宽止损·规则仓（40% 部分）仍执行原止盈止损规则

## Step 2: 移动止盈/止损线扫描

### 2.1 硬止损（优先检查·不可讲道理）

```
条件: 持仓亏损达 -20% 
→ 🛑 强制止损50%（信仰仓+规则仓各减一半）
→ 在输出中标注: 🔴 硬止损触发·立即执行

条件: 持仓亏损达 -30%
→ 🛑 全部清仓
→ 在输出中标注: 🔴 硬止损·全清·不讲道理
```

### 2.2 黑天鹅保护

```
条件: 当日跌幅 > 10%（非全市场系统性暴跌）
→ ⚠ 减仓50%
→ 标注: "如果是错杀，两天后确认再买回·亏手续费换安全"
```

### 2.3 移动止盈（规则仓专用）

```
以60日最高收盘价作为"高点"基准

浮盈区间        回撤阈值（从高点）  规则仓动作
──────────────────────────────────────────
浮盈 < 20%      不触发              规则仓不动
浮盈 20-40%     回撤 ≥ 15%         卖规则仓的50%
浮盈 40-60%     回撤 ≥ 10%         卖规则仓的70%
浮盈 > 60%      回撤 ≥ 8%          规则仓全清 + 信仰仓启动移动止盈(回撤20%卖50%/回撤30%全清)
```

**计算方式示例（深科技案例）**：
```
成本¥45.60 · 60日高点¥64.75 · 浮盈+42%（处于40-60%区间）
→ 回撤10%触发线 = ¥64.75 × 0.90 = ¥58.28
→ 若现价≤¥58.28，卖规则仓的70%
→ 剩余仓位 = 信仰仓60% + 规则仓30%×40% = 72%原仓
```

### 2.4 止盈线输出格式

```markdown
## 🎯 止盈止损扫描

| 标的 | 浮盈% | 60日高点 | 当前距高点 | 止盈区间 | 回撤阈值 | 触发线 | 是否触发 | 动作 |
|------|-------|----------|------------|----------|----------|--------|----------|------|
| 深科技 | +19% | ¥64.75 | -16.2% | 40-60% | 10% | ¥58.28 | ⚠已触发 | 🟡应减仓规则仓70% |
```

### 2.5 🆕 永续久期止损豁免（v1.1·v6.4·Lesson 1）

**触发条件**: 标的紫苏叶等级 ≥ 4 且 持有期 < 12 个月（仍在建仓验证期）

```
豁免规则:
  □ 紫苏叶 ≥ 4 且 信仰仓（60%部分）→ 硬止损从 -20% 放宽至 -35%
  □ 紫苏叶 ≥ 4 且 信仰仓 → 硬止损从 -30% 放宽至 -50%（匹配用户最大回撤容忍）
  □ 紫苏叶 = 3 或以下 → 不适用此豁免

豁免的约束条件:
  1. 豁免仅适用于"逻辑未破坏"的情况——核心催化剂仍在、基本面没有逆转
  2. 一旦紫苏叶评级下调至 ≤ 3·豁免自动撤销·恢复标准止损
  3. 豁免期间必须每季度跑一次浑天紫苏全量分析验证逻辑
  4. 每次跌破 -20% 时生成警告: ⚠️ "已进入宽止损区间·请在下次审视时手动确认逻辑"

输出格式:
## 🛡 永续久期豁免状态

| 标的 | 紫苏叶 | 止损类型 | 标准止损 | 豁免后止损 | 当前距止损 | 状态 |
|------|--------|----------|----------|------------|------------|------|
| 赛腾股份 | 🍃5 | 信仰仓 | -20%→-35% | -35%→-50% | -12% | 🟢安全 |
| 药明康德 | 🍃3 | — | -15% | —(不豁免) | -8% | 🟢安全 |
```

### 2.6 🆕 信仰仓·逻辑止损扫描（v1.1·v6.4·Lesson 3）

**执行频率**: 每周一次（周度审视时）+ 重大新闻/公告后立即触发

```
执行流程:
  1. 读取该标的的「逻辑止损锚」列表（来自 compound-position-system §3.5）
  2. 对每条逻辑止损条件执行验证:
     - L1/L2: wenda_news_query + wenda_notice_query + WebSearch 搜索对应事件
     - L3/L4: 如果该季度财报已出·检查营收增速和毛利率变化
     - L5: news-radar 扫描行业级冲击
  3. 输出逻辑止损检查表:

## 🔍 信仰仓·逻辑止损扫描

| 标的 | 逻辑条件 | 当前状态 | 证据 | 动作 |
|------|----------|----------|------|------|
| 赛腾 | L1: 长鑫 HBM 封装线暂停 | ✅ 未触发 | 2026Q2 订单继续交付 | 🟢继续持有 |
| 赛腾 | L2: KLA 替代认证 | ✅ 未触发 | 赛腾认证进度正常 | 🟢继续持有 |
| 赛腾 | L5: 美国对华出口管制升级 | ⚠️ 观察中 | 新实体清单草案流传·但未正式发布 | 🟡启动情景预案 |

总体结论: 🟢 逻辑未被破坏·信仰仓继续持有
```

**与价格止损的协调**:
- 价格止损（规则仓部分）：机械执行·不讲道理
- 价格止损（信仰仓部分）：不作为卖出信号·仅作为【预警信号】→ 触发后立即启动 §2.6 逻辑止损扫描
- 逻辑止损任一条件触发 → 信仰仓和规则仓全清（不讲道理）

## Step 3: 仓位数学

### 3.1 单票凯利仓位计算

```
标准凯利: f* = (p × b - q) / b
  p = 胜率（基于紫苏叶等级映射）
  b = 盈亏比（目标涨幅 / 止损跌幅）
  q = 1 - p

紫苏叶 → 胜率映射:
  🍃5: p=0.70  🍃4: p=0.60  🍃3: p=0.50  🍃2: p=0.35  🍃1: p=0.20

A股实战修正: 使用半凯利（half-Kelly）作为默认
  half-Kelly = f* × 0.5
```

### 3.2 波动率自适应仓位调整

```
ATR(14日) / 现价 = 日均波动率%

仓位调整系数:
  波动率 < 2%: 系数 1.2（低波·可加仓）
  波动率 2-4%: 系数 1.0（正常）
  波动率 4-6%: 系数 0.7（高波·需降仓）
  波动率 > 6%: 系数 0.4（极高波·谨慎）

调整后仓位 = half-Kelly × 波动率系数
```

### 3.3 多层约束（取最小值）

```
final_position = min(
  ① 半凯利仓位,
  ② 紫苏叶仓位上限(🍃5→20%·🍃4→15%·🍃3→10%·🍃2→5%·🍃1→0%),
  ③ 单笔最大亏损约束(总资产×2% / 止损幅度%),
  ④ 宏观环境仓位上限(A级→单票20%·B级→15%·C级→8%·D级→不新开),
  ⑤ 赚效约束(🔥→满·🟡→半·❄️→只守不攻·🧊→强制减仓)
)
```

| AAA | 25% | 12.5% | ×0.7 | 15% | 10% | **8.8%** | ¥3,730 |

### 3.5 🆕 双轨止损计算（v6.4·Lesson 3 — 信仰仓·逻辑止损）

> **来源教训**: 止损是拿不住十倍股的第一驱动力。中际旭创途中经历 5 次超过 20% 的回撤、3 次超过 30%、最深 62%。14% 的止损会被触发数次。止损在全市场范围内可能是正期望的规则，它只是与十倍股不兼容。

### 3.7 🆕 乘数修正系数（v6.5·Lesson 7 — 市值扩张效率检测）

> **核心问题**: "这只股票的市值增长，有多少有可见资金支撑？乘数是否过大？"
> **来源教训**: 寒武纪四段可追踪净流入合计约 108 亿元。四舍五入地说，这八千八百亿的估值里，看得见的资金只付过一百亿上下。海外文献对美股整体的估算是 1 美元被动流入大约推升 5 美元市值。寒武纪的读数比这个量级高出一个数量级，原因就在供给结构。

```
市值扩张乘数 = 同期市值增量 / 同期可追踪资金净流入

乘数解读:
  1-10x  → 🟢 正常定价效率·资金流入有支撑
  10-30x → 🟡 部分逼空/结构定价·需要警惕
  30-80x → 🔴 逼空明显·多数涨幅无资金支撑
  >80x   → 💀 近乎纯结构定价·极致 Miller 结构

可追踪资金口径（取底层数据容易获取的维度）:

  可追踪资金 =
    + 前十大流通股东中被动 ETF 的季度持股变化 × 季度均价
    + 北向资金期间累计净买入（东方财富数据）
    + 融资余额期间净增量
    + 显著牛散席位新进/增持金额（前十大名单）
    + 定增/配股现金
    = 合计净流入（下限估计·真实流入 ≥ 此值）

乘数修正系数（应用于仓位计算）:

| 乘数 | 仓位修正系数 | 含义 |
|------|-------------|------|
| <10x | 1.0 | 正常·不修正 |
| 10-30x | 0.8 | 轻度结构定价·减 20% 目标仓位 |
| 30-80x | 0.5 | 中度结构定价·减 50% 目标仓位 |
| >80x | 0.3 | 严重结构定价·只允许 30% 目标仓位 |

应用: 最终仓位 = 原凯利仓位 × 乘数修正系数

输出格式:
## 📐 市值扩张效率

| 项目 | 数据 |
|------|------|
| 期间市值增量 | +X,XXX 亿 |
| 可追踪净流入 | +XX 亿 |
| 扩张乘数 | ~XX 倍 |

判定: 🟢/🟡/🔴/💀
解读: "当前市值的上涨中·可见资金只支撑了约 X%·其余来自供给端结构（卖盘变薄+做空受限+乐观者追价）"
对照: 寒武纪四段 +8600 亿/108 亿 ≈ 80x；A 股正常约 5-10x；美股约 5x
```

## Step 4: 组合约束

### 4.1 风险预算分配

```
总风险预算 = 总资产 × 最大可接受回撤(默认15%)

单票风险预算 = 总风险预算 / 持仓数 × 集中度调整
  → AAA(紫苏4·权重1.2) vs BBB(紫苏2·权重0.5)
```

### 4.2 相关性检查

三只标的行业归属检查:
- 同行业 → 合并算风险暴露
- 同产业链上下游 → 注意连锁风险
- 完全独立 → 可满配

### 4.3 硬约束清单

| 约束 | 阈值 | 触发动作 |
|------|------|----------|
| 单票上限 | ≤ 总资产25% | 超配→强制减至25% |
| 单行业上限 | ≤ 总资产40% | 超配→均匀减仓 |

| 现金保留 | ≥ 总资产10% | 用于抄底/应急 |
| 最大回撤止损 | 日内 -15% | 全部减半仓·休息3天 |
| 连续亏损 | 连亏3笔 | 减仓50%·重新审视 |
| 连续亏损 | 连亏5笔 | 停止交易·全面复盘 |

### 4.6 🆕 市值扩张效率检查（v6.5·Lesson 7 — 与 §3.7 乘数修正联动）

> **核心原则**: 在所有传统组合约束（集中度/相关性/回撤）之外，必须检查每只持仓的"市值扩张乘数"是否仍处于健康区间。乘数过大意味着价格已脱离资金支撑·进入纯结构定价阶段。

```
执行流程:

Step 1 - 对每只持仓计算乘数（与 §3.7 公式一致）:
  □ 期间市值增量 = (当前市值 - 90日前市值)
  □ 期间可追踪净流入 = 被动ETF变化 + 北向净买 + 融资净增 + 牛散新进
  □ 乘数 = 市值增量 / 可追踪净流入

Step 2 - 乘数健康评级:
  🟢 <10x → 正常·不动
  🟡 10-30x → 轻度结构定价·已在 §3.7 减仓 20%
  🔴 30-80x → 中度结构定价·已减仓 50%
  💀 >80x → 严重结构定价·只允许 30% 目标仓位

Step 3 - 组合级乘数风险:
  □ 全组合加权乘数 = Σ(各标的乘数 × 仓位占比)
  □ 如果全组合乘数 > 30x → 整体组合处于结构定价风险中
  □ 触发动作: 暂停新开仓位·等待某一标的乘数回归 < 20x 后再考虑加仓

输出格式:
## 📐 组合级市值扩张效率

| 标的 | 仓位 | 乘数 | 评级 | 仓位修正 |
|------|------|------|------|----------|
| AAA | 13% | 8x | 🟢 | ×1.0 |
| BBB | 13% | 35x | 🔴 | ×0.5 |
| CCC | 16% | 12x | 🟡 | ×0.8 |

全组合加权乘数: 18.2x → 🟡 整体偏结构定价
建议: 暂停 BBB 加仓·优先观察 AAA 的乘数变化
```

### 5.5 🆕 B 计划调度引擎（v6.4·Lesson 6 — 价格追不上时的替代方案）

> **核心问题**: "如果股价不到预设入场区间就一路向上，我怎么办？"
> **来源教训**: 公募对中际旭创在 3 倍、7.4 倍、34 倍处分了三级台阶追认。如果你等"更好的价格"，风险是你可能永远等不到。对赛腾要有一个 B 计划：如果价格永远不回 70 怎么办？

```
场景树:

场景A: 股价回到预设入场区间
  → 执行原 A 计划 · 按预定节奏分批建仓
  → 仓位比例: 按预设执行

场景B: 股价不回头·但涨幅可控（< 预设 A 计划上限的 50%）
  → B 计划路线: 降低首批仓位·接受较高成本
  → 新入场价区间: [原目标上限] ~ [原目标上限 × 1.3]
  → 仓位比例: 原计划的 60%（留现金等回撤）

场景C: 股价涨幅已超过原定入场区间的 2 倍
  → C 计划路线: 放弃这一波·转向产业链相关标的
  → 替代方案: 寻找同产业链中"尚未被追认"的环节
  → 触发条件: 股价 ≥ 预设入场上限 × 2 且 无明确回调信号

场景D: 股价大幅上涨后回撤至原入场价
  → 这是最理想但少见的场景
  → 大胆执行 A 计划·甚至可以加大概率

输出格式:

|------|----------|--------|----------|----------|------|

| 替代方案 | — | — | — | 关注同链未涨标的: [XYZ] | — |

下次检查点: 股价达到 [¥XX] 或 出现 [本次回调 > 15%] 时重新评估

执行规则:
  □ 每周审视时·检查所有"待入场标的"是否进入 A/B/C/D 场景
  □ 进入场景 C 时·必须启动产业链替代标的筛选（调用 zisu-deep-analysis 的 §3 产业链映射）
  □ 进入场景 D 时·可调用额外风险预算（但不超过总资产 5%）
```

## Step 6: 复利引擎

### 6.1 核心理念

**复利不是"买了不动等它涨"，而是"每次盈利后让本金池变大，下一次下注时买更多"。**

```
初始本金: ¥42,405
第1笔盈利: +¥3,000 → 本金池: ¥45,405
第2笔下注: 按¥45,405 × 半凯利% = 比上次多买X%
第2笔盈利: +¥3,500 → 本金池: ¥48,905
...
```

### 6.2 资金池规则

```
资金池 = 现金 + 持仓市值

规则:
1. 所有盈利交易的利润 → 进入资金池（不取出消费）
2. 所有亏损交易的损失 → 从资金池扣除
3. 现金部分始终 ≥ 总资金池的10%（应急储备）
4. 每季度审视一次资金池增速 vs 目标增速
5. 若资金池增速连续2季度 < 目标 → 调整策略（可能需降低仓位·延长持有期）
```

### 6.3 利润再投资规则

```
当单票盈利达到 +15% 时:
  选择A: 止盈50% → 锁定利润·降低持仓成本·利润进入资金池
  选择B: 移动止损至成本价 → 让利润跑·零风险持有
  选择C: 全仓继续持有 → 仅当紫苏叶≥4且催化剂未落地

选择标准:
  🍃紫苏≥4 + 催化剂在2周内 → 选C（全仓持有）
  🍃紫苏=3 + 已涨15% → 选A（止盈一半）
  🍃紫苏≤2 → 选A（全部止盈）
  PA转空 → 选A（全部止盈·锁定）
```
