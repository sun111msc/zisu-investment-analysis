# Research Report & Institutional Analysis

## 核心原则

不做基本面分析（已有 skill 覆盖），不做估值计算。只做一件事：**从研报的"字里行间"和"白空间"中提取被忽略的信号**。

研报的使用方式应该是：**"看逻辑不看结论、看修正不看过往、看分歧不看共识、看隐藏不看明说"**。

---

## 一、分析师激励结构分析：先理解"为什么写"，再理解"写了什么"

每篇研报都应从"发表动机"维度评估。卖方分析师面临三个利益约束：

| 约束 | 对研报的影响 | 检测方法 |
|------|-----------|---------|
| **佣金约束** | 倾向多唱多、少唱空 | 检查该券商与标的公司是否有投行/做市关系；是否有反向评级历史 |
| **关系约束** | 看空研报接近消失 | 统计该券商对同行业标的的评级分布（若全部"买入"，可信度打折） |
| **职业约束** | 偏离一致预期面临职业风险 | 检查该分析师评级是否显著偏离同业均值；若是，那是最大价值信号 |

**硬规则**：
- "中性"评级在卖方语境下 = **警告信号**（相当于"卖出"）
- "长期覆盖中断后突然恢复" = **强信号**（可能是客户需求驱动或公司基本面突变）
- 若某券商1年内没有给出任何一次"减持"或"卖出"，其"买入"的边际价值接近于0

见 `references/incentive-analysis.md` 完整框架。

## 二、评级解码：每个词都有隐藏含义

### 2.1 评级的真实含义

| 研报说 | 实际含义 | 行动 |
|--------|---------|------|
| "强烈推荐/买入" | 标准看多 | 看背后的逻辑+数字是否支撑 |
| "增持" | 温和看多 | 可能在"买入"和"持有"之间骑墙 |
| "持有/中性" | **相当于看空** | ⚠️ 卖方语境下这是最负面的表达之一 |
| "谨慎增持/谨慎推荐" | 暗示有风险但不敢明说 | 🔴 强烈信号——看多但语言在退缩 |
| "推荐"（下调前是"强烈推荐"） | 在砍乐观预期 | 关注下次是否下调至"中性" |

### 2.2 评级调整方向

评级调整的意义 > 评级的绝对值：

| 调整 | 信号强度 | 原因 |
|------|---------|------|
| 买入→持有 | 🔴🔴🔴 | 卖方体系下极罕见，需要实质性恶化 |
| 持有→买入 | 🟡 | 常见于"终于有信心了"的上调 |
| 首次覆盖 | 取决于起点 | 首次"买入"价值中等；首次"持有" = 提前看到问题 |
| 停止覆盖 | 🔴 | 通常是：①公司前景无望 ②与投行业务冲突 ③合规风险 |
| 长期覆盖无变动 | 🟡 | 可能分析师已放弃跟踪或等待催化剂 |

### 2.3 语言信号检测

从研报文本中识别隐藏情绪：

| 语言模式 | 隐藏含义 | 检测关键词 |
|---------|---------|-----------|
| "符合预期"反复出现 | 没有惊喜，只有确认 | "in line" "符合" "延续" |
| "短期承压但长期向好" | 短期坏消息，不想承认 | "短期...但长期" "阵痛" "过渡期" |
| 风险段落的长度 > 正面段落的长度 | 分析师在委婉表达担忧 | 字数和段落数对比 |
| 使用"可能""有望""预计"代替"确认""已经" | 从确定性语言转向不确定 | 量化确定性词语的比例 |
| 目标价逻辑从"EPS×PE"变为"多情景分析" | 单一情景置信度下降 | 估值方法变化 |

见 `references/language-signals.md` 完整词典。

## 三、一致预期的逆向使用

一致预期不是"正确答案"，而是"市场的平均偏见"。

### 3.1 一致预期的五个信号

| 信号 | 含义 | 操作 |
|------|------|------|
| **高分散度 + 无共识** | 市场没有形成定价锚——潜在巨大alpha | 深入研究分歧根源 |
| **低分散度 + 一致看多** | 拥挤共识——反向指标概率上升 | 警惕"所有人都看好的股票" |
| **分析师数量骤减** | 覆盖退出 = 信息不对称加剧 | 可能有隐性问题 |
| **分析师数量骤增** | 公司成为热门 = 定价效率提升 | 早期发现窗口关闭 |
| **一致预期连续上调** | 动量推动，可能透支 | 关注何时首次下调 |

### 3.2 一致预期 vs 实际表现偏离度

```
偏离度 = (实际业绩 - 一致预期) / 一致预期的标准差

偏离度 > 2σ → 巨大预期差 → 重大重新定价事件
偏离度 1-2σ → 中等预期差 → 可能产生超额收益
偏离度 < 1σ → 市场已充分定价 → 无超额收益
```

### 3.3 一致预期的预测能力衰减

| 预测年份 | 准确度 | 原因 |
|---------|--------|------|
| FY1（当年） | 中等 | 已有3个季度的实际数据 |
| FY2（明年） | 低 | 关键变量太多 |
| FY3及以后 | 几乎无预测能力 | 更多是"期望"而非"预测" |

**规则**：FY2及以后的利润预测，准确度不高于用历史趋势线性外推。

## 四、分析师修正动量——最重要的研报信号之一

分析师的盈余修正行为本身就携带信息：

### 4.1 修正动量框架

```
第1阶段：下调期（分析师集体砍预期）
  → 股价通常已反映悲观 → 可能接近底部
  → 检测：分析师的修正幅度是否收窄（变小 = 悲观释放接近尾声）

第2阶段：稳定期（修正频率+幅度双降）
  → 悲观已充分定价 → 安全边际最高
  → 检测：连续2次季报不触发新的下调

第3阶段：上调启动期
  → 分析师开始修正预期 → 股价开始反映乐观
  → 检测：第一个上调的分析师是谁（券商质量 = 信号质量）

第4阶段：加速上调期
  → 动量最强但安全边际最低
  → 检测：PE扩张速度 > EPS上调速度 → 股价已透支
```

### 4.2 修正信号的权重

| 修正者 | 信号权重 | 原因 |
|--------|---------|------|
| 首次上调（独立于其他人） | ⭐⭐⭐⭐⭐ | 独立判断，非跟风 |
| 行业Top 3券商上调 | ⭐⭐⭐⭐ | 影响其他分析师跟进 |
| 跟风上调（别人上调后跟进） | ⭐⭐ | 从众行为，信号衰减 |
| 国外/独立研究机构上调 | ⭐⭐⭐ | 利益冲突较小 |
| 下调后迅速回调（<3个月） | ⭐ | 判断不稳定 |

### 4.3 修正与股价的领先关系

- **盈利修正领先股价** 约1-3个月（尤其在A股）
- **目标价修正滞后股价**（分析师倾向在股价已涨后再上调目标价）
- **评级修正最滞后**（评级上调通常是最后一个信号，此时安全边际已消失）

见 `references/revision-momentum.md` 量化框架。

## 五、研报覆盖的博弈分析

### 5.1 覆盖策略图谱

| 覆盖类型 | 含义 | 行动 |
|---------|------|------|
| **新覆盖（首次）** | 机构看好该赛道/标的 | 关注首次评级的级别（Buy→正常；持股→有问题） |
| **持续覆盖** | 正常跟踪 | 看覆盖频率和深度是否下降 |
| **覆盖退出** | 负面信号 | 🔴 通常因为：行情恶化/合规/投行冲突 |
| **多券商同时新覆盖** | 赛道共识形成 | 信息优势消失——早期发现窗口关闭 |
| **只有1-2家覆盖** | 定价效率低 | 可能存在被低估机会 |

### 5.2 分析师质量过滤

不是所有分析师的意见都一样重要：

| 过滤维度 | 优质信号 | 劣质信号 |
|---------|---------|---------|
| 覆盖数量 | 专注跟踪5-8只以内 | 覆盖20+只——浅度跟踪 |
| 预测准确度 | 历史预测vs实际的误差小 | 经常大幅修正 |
| 独立性 | 给出过反向评级（卖出/减持） | 永远只在"买入-持有"之间切换 |
| 深度 | 报告含一手调研/产业链验证 | 仅做数据整理，无增量信息 |

## 六、研报间的交叉验证——分歧即信号

### 6.1 多券商的四层对比框架

拿到3-5家研报后，按以下框架对比：

| 对比层 | 问题 | 信号 |
|--------|------|------|
| **评级层** | 多少家看多？有看空的吗？ | 一致看多 = 需警惕 |
| **利润层** | 净利润预测范围多大？分歧在哪？ | 预测Range>30% = 重大不确定性 |
| **估值层** | PE/PEG假设差多少？为什么？ | 方法差异揭示"用哪年EPS"的根本分歧 |
| **风险层** | 哪些风险某家提了别家没提？ | 只有一家提的风险 = 要么有独家信息，要么误判 |

### 6.2 外资 vs 内资的系统性差异

| 维度 | 外资行 | 内资券商 | 如何利用 |
|------|--------|---------|---------|
| 估值基准 | 更远期（FY2-FY3） | 更近期（FY1-FY2） | 外资的逻辑+内资的估值纪律=最优组合 |
| 利润预测 | 偏激进 | 偏保守 | 取两者中间偏外资方向（因外资有全球调研优势） |
| 风险视角 | 行业需求、技术 | 估值消化、政策、筹码 | 两者都看，特别关注"都没看"的风险 |
| 数据颗粒度 | BOM拆解到每GPU | 行业层面 | 外资的BOM逻辑 + 内资的A股常识 |
| 覆盖盲点 | 缺本地治理/政策风险 | 缺全球对标/产业链 | 互补使用，不做二选一 |

## 七、研报生命周期与时效管理

### 7.1 研报权重衰减

```
发布时间          权重      适用场景
< 1个月          100%        最新观点
1-3个月          70%         逻辑仍有效但需验证数字
3-6个月          40%         仅产业逻辑可参考
6-12个月         15%         首次覆盖的行业分析
> 12个月         0%          不采用

硬规则：
  ★ 季度财报后 → 研报自动降权（数字已变）
  ★ 重大事件后（丑闻/解禁/政策）→ 风险考量可能失效
  ★ 产业逻辑类（如AI PCB超级周期）→ 时效性>6个月仍可参考
```

### 7.2 研报新鲜度判断法

| 研报状态 | 判断 | 行动 |
|---------|------|------|
| 财报后3天内发布 | 通常质量最高 | 分析师准备了完整模型 |
| 财报后1周以上才发 | 可能是跟风或修改后决定 | 降权 |
| 没有财报触发、独立发布时间 | 调查驱动（如工厂参观、行业论坛） | 通常最有价值——增量信息 |
| 公司股价暴跌后突然发布"维持买入" | 防御性质——保护现有评级 | 看其论证是否令人信服 |

## 八、研报白空间——研报没写的东西往往最重要

### 8.1 白空间检测清单

每次读完一篇研报，必须问以下问题：

| 白空间维度 | 检测 | 含义 |
|-----------|------|------|
| **没回应的负面消息** | 近期有无重大利空没有被提及？ | 分析师可能在回避 |
| **没更新的风险提示** | 风险章节是否套用模板？ | 模板化 = 分析师不够认真 |
| **没提到的竞品动态** | 竞争对手的新动作是否被忽略？ | 可能有不利于目标公司的信息 |
| **没调整的假设** | 核心假设是否还成立？ | 比数字变化更早的预警 |
| **没解释的评级变化** | 上调/下调的逻辑是否自洽？ | 矛盾 = 隐藏议程 |

### 8.2 最常见的白空间信号

- "买入"研报中风险段只有3行 → 分析师不够认真或故意轻描淡写
- 连续多期研报风险段一字未改 → 模板复制，无独立分析
- 不对近期负面新闻做回应 → 可能在"等着看"
- 没有与管理层沟通的记录 → 可能是桌前研究（desk research）而非真正的调研
- 没有任何图表中显示下行场景 → 报告偏向乐观

## 九、实战工作流：从研报到决策

### 9.1 四阶段执行流程

```
Phase 1: 研报采集（30分钟）
  → 外资行：IMA知识库 + 雪球 + 百度百家号（2-3家）
  → 内资券商：同花顺F10 + 东方财富一致预期 + 雪球（3-5家）
  → 淘汰标准：无评级、无利润预测、发布日期>6个月、模板化风险段
  
Phase 2: 信号提取（20分钟）
  → 每篇填写"研报信息提取卡"（评级/估值方法/利润预测/风险/激励分析）
  → 语言信号检测（关键词扫描）
  → 评级历史追溯（分析师过去1年的观点变化）
  → 白空间扫描（少了什么）

Phase 3: 交叉对比（15分钟）
  → 建立目标价参照系（均值/中位数/极值）
  → 识别利润预测分歧根源（营收假设 vs 净利率假设）
  → 区分外资vs内资的系统性差异
  → 标记"所有分析师都没看到"的风险（= 最大价值）

Phase 4: 形成判断（10分钟）
  → 一致预期偏离度分析
  → 修正动量判断（处于四阶段中的哪个）
  → 综合：外资产业逻辑 + 内资估值纪律 = 最优判断
  → 标注"推荐"置信度（高/中/低）
```

### 9.2 研报信息提取卡

```
机构：[名称] | 日期：[YYYY-MM-DD] | 时长：[距今日数]天
评级：[评级] | 目标价：[¥XX] | 较现价：[+X%]
估值方法：[PE/PEG/DCF/SOTP] | 基准年：[FY1/FY2]
2026E 营收：[XX亿] | 2026E 净利：[XX亿] | 2027E 净利：[XX亿]
核心逻辑：[3-5个关键词]
风险提示：[原文摘录]
语言信号：[关键词检测结果]
白空间：[少了什么]
来源：[渠道] | 置信度：[高/中/低]
```

## 十、差异化的隐藏信号总结（速查版）

这些是普通分析师不常用、散户几乎不会、但能显著提升研报解读质量的信号：

| # | 隐藏信号 | 普通用法 | 高级用法 |
|---|---------|---------|---------|
| 1 | 评级语言密度 | 只看"买入" | 数"买入"报告中用了多少修饰词——越多修饰词=不确定性越高 |
| 2 | 目标价修正滞后 | 认为目标价是"应该到的价格" | 目标价是追随股价的——分析师往往在股价已涨20%后才上调目标价 |
| 3 | 一致预期分歧度 | 看平均预测 | 分歧度比平均值更有信息量——分歧大=市场没有共识=潜在alpha |
| 4 | 覆盖密度变化 | 看是否有覆盖 | 覆盖骤增=赛道过热/退出=隐性问题 |
| 5 | 调研驱动 vs 桌前研究 | 不区分 | 调研驱动的报告质量远高于桌前研究（看是否有实地调研记录） |
| 6 | 报告长度变化 | 不关注 | 某季报点评突然变短=分析师的注意力在下降 |
| 7 | 跨境比较 | 只看A股券商 | 外资利润预测长期比内资高出37%+；取外资逻辑+内资估值纪律 |
| 8 | 风险段落的字数 | 直接跳过 | 风险段字数/正面段字数比=分析师真正担忧的程度 |
| 9 | 分析师培训背景 | 不关心 | 工科背景的分析师比纯金融背景的分析师在技术股判断上更准确 |
| 10 | 首次覆盖评级 | 只看评级 | 首次覆盖给"持有"=已发现重大问题；首次"买入"=正常 |

## 十一、PEAD：盈余公告后漂移效应分析 🆕

### 11.1 PEAD概念

Post-Earnings Announcement Drift (PEAD)：公司财报发布后，股价持续沿着"超预期/低于预期"的方向漂移数周至数月。这是金融市场最古老且最稳健的异象之一。学术研究表明PEAD年化超额收益约6-8%。

### 11.2 PEAD信号生成规则

```
计算 Surprise = (实际EPS - 一致预期EPS) / |一致预期EPS| × 100

Surprise > +5%      → 正向超预期（强烈BUY信号）
Surprise +2% ~ +5%  → 温和超预期（弱BUY信号）
Surprise -2% ~ +2%  → 符合预期（中性）
Surprise -5% ~ -2%  → 温和低于预期（弱SELL信号）
Surprise < -5%      → 显著低于预期（强烈SELL信号）
```

### 11.3 PEAD强度判断矩阵

| 业绩超预期 | 分析师修正方向 | PEAD强度 | 预期漂移方向 |
|-----------|-------------|---------|------------|
| 超预期+上调 | 同步向上修正 | ⭐⭐⭐⭐⭐ | 强正向漂移 |
| 超预期+不上调 | 修正滞后 | ⭐⭐⭐ | 中等正向漂移 |
| 超预期+反向下调 | 冲突：可能一次性收益 | ⭐ | 弱/无漂移 |
| 低于预期+下调 | 同步向下修正 | ⚠️⚠️⚠️ | 强负向漂移 |
| 低于预期+不下调 | 修正滞后（分析师在犹豫） | ⚠️ | 中等负向漂移 |

### 11.4 PEAD的A股特征

A股市场中PEAD效应相比美股更强（因信息扩散速度更慢）：
- 正向PEAD持续约20-40个交易日
- 负向PEAD持续约15-25个交易日（投资者对坏消息反应更快）
- 中小市值股票的PEAD效应 > 大市值股票

## 十二、Beat/Miss 模式分析 🆕

### 12.1 Beat/Miss序列的统计意义

连续Beat不一定是好信号——可能意味着：
- 管理层的"预期管理"能力（在季报前刻意压低分析师预期）
- 实际增速并没有数字显示的高

```
检测规则：
  ★ 连续4个季度"beat"但beat幅度逐季递减 → 增长动能衰减
  ★ 连续"beat"但每次+1~2%（刚好超过） → 可能为"预期管理"而非真实超预期
  ★ 突然一次大beat（+>15%）→ 要么是业务质变，要么是一次性收益
  ★ 第一次"miss"打断连续beat序列 → 可能是趋势性拐点
```

### 12.2 Beat/Miss与分析师覆盖的相关性

```
分析师覆盖趋势 + beat/miss模式：
  覆盖增加 + 持续beat → 正向正反馈循环（最牛市情景）
  覆盖增加 + 首次miss → 重大信号——新覆盖的分析师发现原有乐观假设存在问题
  覆盖减少 + 持续beat → 可能被低估（市场不知道它在变好）
  覆盖减少 + 持续miss → 被遗弃的标的
```

### 12.3 Earnings Whisper 检测

Earnings Whisper = 市场真实的预期（非官方发布的一致预期）

检测方法：
- 对比"财报前2周的股价走势"与"一致预期方向"
- 如果一致预期是正增长，但股价在财报前2周持续走弱 → whisper偏负面 → 即使beat幅度小也可能被视为miss
- 如果股价在财报前2周异常走强 → whisper偏正面 → 普通的beat可能不够

信号规则：
```
实际EPS - 一致预期EPS > 0 AND 财报前2周股价下跌 > 5% → "真正的好消息"
（市场预期比公布的一致预期更悲观）

实际EPS - 一致预期EPS < 0 AND 财报前2周股价上涨 > 5% → "真正的坏消息"
（市场预期比公布的一致预期更乐观，但公司没达到）
```

## 十三、一致预期修正速度与领先滞后分析 🆕

### 13.1 修正速度量化

```
修正速度 = 最近30天内的修正次数 / 覆盖机构总数

快速的修正速度（>0.5） → 盈利趋势在加速变化（向上或向下）
  在向上场景中 → 可能存在"分析师竞相上调" → 关注何时出现首次下调
  在向下场景中   → 加速度最陡时可能是"最坏时刻"（是建仓时机吗？）

慢速修正（<0.2） → 盈利趋势稳定或分析师关注度低
```

### 13.2 领先-滞后关系

| 信号 | 领先性 | 使用方式 |
|------|--------|---------|
| 行业内公司修正联动 | 领先1-2个月 | A公司被上调后→关注同行业B公司是否也被上调 |
| 外资行领先内资 | 领先2-4周 | 外资先发现→内资跟进→散户涌入 |
| 上游修正领先下游 | 领先3-6个月 | 中复神鹰被上调→澳盛可能随后被上调 |
| Top分析师领先普通分析师 | 领先1-3个月 | 追踪"星级分析师"的修正 |

### 13.3 修正的"质量"判断

不是所有修正都有信息含量：

```
高质量修正信号：
  ✓ 独立修正（非跟风）
  ✓ 修正理由来自实地调研/产业链验证
  ✓ 修正后其他分析师跟进（信息得到确认）
  ✓ 修正方向与行业趋势一致（非孤立事件）

低质量/噪声修正：
  ✗ 跟风修正（别人已修正后1周内跟动）
  ✗ 小幅微调（<3%）——通常无信息含量
  ✗ 修正后马上被证伪（<3个月内反向修正）
  ✗ 修正理由仅为"调整模型参数"——无新增信息
```

## 十四、覆盖启动（Coverage Initiation）质量评价 🆕

### 14.1 首次覆盖的五步评价框架

首次覆盖报告是判断分析师质量和机构意图的重要窗口：

| 评价维度 | 优质信号 | 劣质信号 |
|---------|---------|---------|
| 公司深度 | 包含产业链/管理层访谈/实地调研 | 仅从公开信息整理 |
| 行业定位 | 波特五力/竞争图谱/市场份额量化 | 行业泛泛而谈 |
| 财务模型 | 自建模型，含敏感性分析 | 套用模板，数据来自Wind |
| 估值框架 | 多方法交叉验证+DCF+SOTP | 单一PE乘以一致预期EPS |
| 结论质量 | 明确评级+具体目标价+催化剂时间表 | 模糊、"等待更好买点" |

### 14.2 首次覆盖评级的信号强度

| 首次覆盖评级 | 信号强度 | 暗示 |
|------------|---------|------|
| 买入 | ⭐⭐⭐ | 正常看多——分析师被要求覆盖该标的且看好 |
| 增持 | ⭐⭐ | 温和看多——可能在"应该看好"和"有点疑虑"之间 |
| 持有/中性 | ⭐⭐⭐⭐⭐ | 极其罕见的首次评级——分析师可能看到了重大问题但不敢说"卖出" |
| 首次"持有"+3个月内下调至无评级 | ⚠️⚠️⚠️ | 可能发现了合规风险或造假嫌疑 |

## 十五、分析师准确度追踪与衰减函数 🆕

### 15.1 历史准确度评分卡

建立一个简单的分析师追踪系统：

```
分析师：[姓名] / [机构] / [学历背景]

追踪指标：
  近4季EPS预测准确度：平均偏差 [±X%] （实际EPS - 预测EPS）/ |实际EPS|
  近4季营收预测准确度：平均偏差 [±X%]
  目标价达成率：[%] （股价是否在12M内达到过目标价）
  修正领先性：[N]次领先同业修正
  
准确性评分（满分10）：
  EPS准确度(偏差<5%: 4分, 5-10%: 3分, 10-20%: 1分, >20%: 0分)
  营收准确度(同上) 
  目标价达成率(>50%: 2分, 25-50%: 1分, <25%: 0分)
  修正领先性(≥3次: 2分, 1-2次: 1分, 0次: 0分)

高准确度（8-10分）→ 该分析师的意见值得给更高权重
中准确度（5-7分）→ 中等权重
低准确度（<5分）→ 其意见无额外参考价值
```

### 15.2 分析师覆盖的衰减函数

分析师离开/不再覆盖后，其最后一次评级和建议的"保质期"有限：

```
最后报告距今：
  < 1个季度：仍部分有效（权值 0.7）
  1-2个季度：已过时（权值 0.3）  
  > 2个季度：基本失效（权值 0）
```
