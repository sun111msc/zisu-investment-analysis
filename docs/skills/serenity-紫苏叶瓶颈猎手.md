# 第一篇：哲学根基与理论体系

## 1. 核心哲学

### 1.1 利润即真理（Profit is Truth）
任何技术壁垒、产业链卡位、政策红利，如果不能映射为未来12个月内可验证的正经营现金流或扣非净利润，一律不予采信为持有理由。
- 利润兑现 = 唯一真实信号
- 见不到现金流的护城河是护城沟（moat vs trench）
- 12个月时间窗口强制约束
- 扣非净利润而非归母净利润

### 1.2 紫苏叶理论（Shiso-Leaf Theory）
核心隐喻：顶级寿司店里，食客追逐的是金枪鱼大腹（toro），但厨房真正离不开的是紫苏叶（shiso）。
工程语言翻译——紫苏叶必须同时满足三条硬约束：
1. 功能不可替代：不是更好，而是没它就违规/不安全/无法出货
2. 系统性风险节点：断供不是少赚，而是停线/罚则/重做成本极高
3. 体验/性能命门：最终产品关键指标由它决定

### 1.3 瓶颈核心公式
战略地位（不可替代性）x 估值错配（市值 vs 瓶颈控制力）x 时机（机构入场前）= 不对称收益

### 1.4 瓶颈点 vs 卖铲子
- 卖铲子：铲子相对通用，竞争会磨平超额利润
- 瓶颈点：河道本身收窄，供给被设备/认证/专利/材料/地缘锁死
- 比喻：霍尔木兹海峡——全球20%石油必经之路

### 1.5 投资第一性原理（五不预测）
1. 不预测宏观 2. 不预测大盘 3. 不预测行业增速 4. 只预测：客户离不开它+产能比需求慢12-24月 5. 不预测技术路线

### 1.6 A股 vs 港股定价基因
A股PEG<1.0，港股PEG<0.8。三大标杆：中际旭创PEG0.52、新易盛PEG0.37、兆易创新PEG2.2

## 2. 六层理论地基
1. 利润即真理 2. Rumelt症结诊断 3. Greenwald进入壁垒唯一论 4. Helmer 7 Powers 5. Morningstar五源护城河 6. 瓶颈拓扑学

### 2.1 Rumelt症结诊断三问
1. 这个行业的症结是什么？ 2. 如果只有一件事能让产业链断裂，那是什么？ 3. 目前的共识错在哪里？

### 2.2 Greenwald三问
1. 有进入壁垒吗？2. 壁垒形式？3. 无壁垒为何赚钱？
壁垒类型：供给侧（专有技术/资源）/ 需求侧（客户习惯/搜索成本）/ 规模经济 / 政府/管制

### 2.3 Helmer 7 Powers映射
- Scale Economies: 产能规模=准入门槛
- Switching Costs: 核心相关，认证=切换成本
- Cornered Resource: 最直接相关，专利/矿权/独家供应
- Process Power: 工艺诀窍/良率优势

### 2.4 Morningstar五源护城河评分（10分制）
无形资产/转换成本/网络效应/成本优势/有效规模。>=35分=宽护城河，20-34=窄，<20=无

### 2.5 护城河验证公式
护城河真伪 = 毛利率稳定性 x 现金流转化率 x 客户不可替代性 x Cornered Resource强度 x 时间持续性
五维全通过=真实护城河可重仓；3-4个通过=候选需深度验证；<=2个通过=画饼/周期股/伪瓶颈

## 3.5 瓶颈扩散理论（Chokepoint Diffusion）【v6.1新增】
AI 瓶颈不是静态的，会沿 BOM 自上而下、自核心向边缘迁移。超额收益随瓶颈迁移而迁移：
```
GPU(已定价) → HBM(已定价) → 光模块/CW激光(正在被定价) → 被动元件MLCC/电感(严重被忽视·下一站)
```

技术路线之争（CPO vs 可插拔 vs NPO）中，不赌路线，买"无论哪条路线胜出都用得上"的底层环节：

### 5.4 CW 激光完整瓶颈地图（SIVE chokepoint+bottleneck 双重身份）【v6.2新增】
Serenity 对 SIVE 的完整论证（原帖 2026-08-12）揭示了「瓶颈」与「卡点」的区别，是整个方法论最精密的样本：

**瓶颈（Bottleneck）— 供给侧物理约束**：
- CW 激光已被 LITE 财报证实瓶颈；激光 fab 重度分配给 EML（前 NVDA 合同）
- 三条 fab 瓶颈：Sumitomo/Furukawa（日本，被 NVDA 合同锁定）+ Win Semi（稳懋，被 SIVE 提前锁产能）
- SIVE 是 fab-lite 模式，但**早期就锁定了 Win Semi 等代工厂的产能分配 → 控制 CW 激光最终供给**
- 类比 Kioxia/Sandisk：SNDK 控制 NAND 输出 → 控制最终定价 → 是瓶颈。同理 SIVE 控制 CW 激光最终供给

**卡点（Chokepoint）— 生态结构锁定**：
- NVDA 用 COHR/LITE（从日本对手采购外部 CW），AVGO 垂直整合——**但这两家之外的所有玩家都绕不开 SIVE**
- ASIC 路线（Marvell Celestial / AlChip）+ merchant 路线（Ayar / Lightmatter / Lightelligence）全生态围绕 SIVE 设计
- Ayar 2022 曾尝试 multi-source MTSI/LITE，但激光不匹配 Sivers 阵列规格（最近从供应链网站移除 Lumentum/Macom）
- 1.6T LRO JBL 的性能"drastic moat"围绕 SIVE sole source 构建
- GFS 的参考激光设计默认 SIVE，AMD 走 GFS 路线
- **无法绕过**：不能热插拔单通道 CW 激光

**结论**：SIVE 同时是 bottleneck（控产能）+ chokepoint（锁生态），在 CPO 2027H2 规模化的最大架构迁移中（GS 预测 TAM 从 ~$0 → $81-91B，1.5 年内），是"下一个 $75B LITE"的候选。
**方法论提炼**：瓶颈标的要同时问两个问题——①供给侧物理上缺不缺？（bottleneck）②生态结构上绕不绕得开？（chokepoint）。两者兼具才是 4-5 叶级别。

## 10. 五因子x四硬标准主表
### 五因子：1.确定需求(巨头capex背书) 2.受限供给(全球<=3家+扩产>=18月) 3.低关注度(覆盖<=5人) 4.价值捕获(长协锁价+毛利率向上) 5.催化剂(6月内明确催化)
### 四硬标准(同时满足)：1.扩产>=18月 2.技术不可复制 3.物理不可替代 4.BOM<5%但缺了停摆
### 合并判定：五因子全通过+四硬标准全通过=紫苏叶4-5级(可重仓)；3-4通过=3级(中等仓位)；<=2通过=跳过
关键补刀：瓶颈地位不等于公司能赚钱。必查：谁出钱扩产？长协锁价？融资稀释？客户集中度？毛利率？

### 10.5 三条否决项（Disqualifier）【v6.2新增】
一票否决，触发即跳过（不看紫苏叶等级）：
1. **稀释/ATM 一票否决**：持续 ATM/大幅股权稀释是 disqualifier。反面教材 POET——Serenity 原话"我完全无法理解股东为何允许被稀释这么多"，POET 现金已堆到 ~$830M，但股本被大幅摊薄。原则：**瓶颈地位 + 高稀释 = 价值被股本摊薄吃掉，不投**。对照 SIVE 的 700M SEK 增发是"扩产超购"（正面），POET 是"无度稀释"（负面）——看资金用途而非金额。
2. **GAAP 利润率战争（GAAP Margin War）**：只认 GAAP/扣非，警惕挑肥拣瘦的非 GAAP。财报必做"GAAP vs non-GAAP 利润率差额"拆解，差额 >3pp 需查明一次性因素（LITE non-GAAP GM 50.4% 需对照 GAAP）。
3. **融资质量谱系（Financing Quality Spectrum）**：neocloud/资本密集型标的按融资质量分层——$104B backlog 的 CRWV（订单驱动）> NBIS（$8.04B 现金+$3.0-3.4B 指引）> 高稀释 POET。订单/现金/稀释三者加权排序，排末位的只在催化剂落地后小仓观察。

## 11. 六维深度验证
1.不可替代性(认证周期/强制认证) 2.产能上限(利用率/扩产周期) 3.客户结构(集中度/合同期限) 4.技术护城河(专利/工艺/成品率) 5.估值错配(市值vs控制力) 6.Cornered Resource强度(1-625分,>300极强)

## 12. Cornered Resource深度分析
判定=资源稀缺性 x 排他性 x 不可替代性 x 法律保护强度。子类型：专利独占/自然资源/频谱牌照/独家供应/人才锁定

## 13. 瓶颈排名算法

## 19. 周期vs成长预分类
| 指标 | 真成长 | 周期股 | 成长转周期 |

TAM=终端产品出货量 x 单机ASP x 瓶颈环节价值占比
| >$500亿 | PE不限 | | $100-500亿 | 80-120x | | $50-100亿 | 50-80x | | <$50亿 | <=50x |
TAM陷阱：<$10亿即便50%份额也只有$5亿营收

## 21. 三重定价框架

## 22. 估值错配类型判定
1.传统瓶颈(AXTI) 2.相对价值错判(RPI) 3.代码混淆(VLN) 4.机械性错位(NBIS) 5.时机期权(CPO早期) 6.反身性错价(绿的谐波PE500x) 7.Cornered Resource沉默折价(特种气体)
