# A股筹码峰实战分析 Skill

> **核心理念**：筹码分布 = 市场参与者持仓成本的**概率密度函数**。每个峰代表一群人"站在同一个成本位置"。交易本质：**判断筹码在谁手里、什么价进的、现在什么心理。**

## 输入方式

三种输入均自动进入分析流程：

| 触发 | 处理方式 |
|-----|---------|
| 用户说"分析XX股票筹码峰" | 尝试通过MCP获取筹码数据；若无API，提示用户截屏并提供提取指南 |
| 用户上传筹码峰截图 | 从截图中提取：现价、平均成本、90%成本区间、获利比例、各周前成本占比、集中度 |
| 用户粘贴筹码数据 | 直接解析数值 |

## 分析流程（7步）

### Step 1: 数据提取

从截图或用户提供的数据中提取（逐条提取，缺什么标注"N/A"）：

```
□ 现价: ___元
□ 平均成本: ___元
□ 90%成本区间: ___ ~ ___元
□ 90%集中度: ___%
□ 获利比例: ___%
□ 5周/10周/20周/30周/60周前成本占比: ___/___/___/___/___%
□ 成交量和换手率: ___手/___%
```

### Step 2: 定量计算

使用 `scripts/chip_metrics.py` 的核心逻辑计算：
- **90%成本集中度** → 解读主力控盘程度（<8%极度集中，8-15%较集中，>30%极度分散）
- **获利比例** → 解读多空心理位置
- **筹码穿透率** → 当日成交/当前峰厚度
- **活动筹码比率** → 近N日换手/峰占比（判断筹码"活性"）

### Step 3: 形态识别

对照 references/chip-system.md 第三篇·形态大全，识别当前形态：

| 形态 | 关键判定条件 |
|-----|------------|
| 低位单峰密集 | 集中度<15% + 获利比例40-70% + 上方无套牢峰 + 横盘>30天 |
| 高位单峰密集 | 下峰消失 + 获利比例<30% + 缩量 |
| 双峰密集 | 两个显著峰 + 中间有真空区 |
| 单峰上移 | 老峰变矮 + 新峰在上方变高（速度决定性质） |
| 单峰下移 | 高位峰消失 + 低位峰形成 |
| 筹码真空区 | 两峰之间稀疏区 → 无阻力快速移动 |
| 多峰分散 | 3峰以上 + 集中度>25% → 无趋势 |
| 锁仓峰 | 拉升中下峰不动 + 缩量 |
| 对倒峰 | 峰变高但换手率不匹配（小盘股警惕） |

### Step 4: 多周期交叉验证

**必须**检查日线+周线筹码峰的冲突/共振：
- 日线和周线方向一致 → 信号有效
- 日线和周线方向冲突 → 大周期定方向，小周期找买点

### Step 5: 主力行为推断

判断主力在哪个阶段：

**吸筹阶段判定**：
```
① 打压 → 高位峰崩塌，低位小峰出现 → 观望
② 横盘 → 低位峰变高变窄，集中度↓ → 关注
③ 试盘 → 放量拉升1-2天再回落 → 准备
④ 洗盘 → 跌破峰再拉回（峰不破）→ 准备买入
⑤ 启动 → 放量突破峰上沿 → 买入
```

**出货阶段判定**：
```
① 拉高 → 下峰不动，上方出现新峰 → 警惕
② 震荡 → 下峰变矮，上峰变高 → 分批减仓
③ 砸盘 → 下峰消失+高位单峰 → 清仓
④ 阴跌 → 高位单峰缓慢下移 → 远离
```

**核心铁律**：
- **下峰不灭，趋势不死**：主力底仓还在，行情没完
- **上峰不消，上涨没戏**：套牢峰还高耸，每次拉升都是出货机会

### Step 6: 风险与陷阱检查

对照 references/chip-system.md 第十篇，逐条检查以下陷阱：
1. 假底识别（集中度>25% + 横盘<15天 → 下跌中继）
2. 假突破识别（放量突破后3天内回落 → 对倒诱多）
3. 假锁仓识别（拉升放量+下峰不动 → 对倒）
4. 小盘股信号打折（<50亿市值，信号打五折）
5. 老峰衰减（>3个月，支撑/压力衰减50%）

## 数据获取指引

**筹码数据获取优先级**：
1. 通达信MCP (tdx-connector)：`tdx_security_deep_info` 可获取盘口数据
2. 用户截图（通达信/同花顺 筹码分布界面）
3. 东方财富筹码数据页面

**截图提取要点**：
从通达信/同花顺筹码分布界面提取：
- 图表标题含股票代码/名称
- 右侧面板：平均成本、90%成本区间、获利比例、集中度
- 底部时间矩阵：N周前成本占比

**配套数据获取**（提高分析质量）：
- `mx-data` 或 `westock-data` → 基本面（PE/PB/ROE/营收增速）
- `tdx-connector` → 技术指标（均线/MACD/KDJ/布林带）
- WebSearch → 近期消息面（公告/新闻/调研）

## 注意事项

1. **筹码峰不独立决策**：必须配合成交量、价格行为、大盘环境
2. **多周期必查**：日线筹码峰判断短期，周线筹码峰判断中期
3. **定性优先于定量**：筹码峰位置告诉"筹码在哪"，需推断"筹码是谁的"
4. **小盘股警告**：市值<50亿的股票，筹码峰信号打五折使用
5. **禁止用筹码峰替代基本面分析**：估值、业绩、竞争格局不可忽略
