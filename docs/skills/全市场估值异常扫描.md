# 全市场估值异常扫描引擎 · v2.0

> ⚡ **v2.0 核心修复（2026-07-06）**：从单一PEG轨道升级为**四赛道并行扫描**——按产业阶段自动切换估值锚。
> 解决v1.0把0→1阶段高PE牛股（PE200~300+）错误标注为"高估"的问题。
> 同步于 `zisu-deep-analysis/modules/10-valuation-rules.md v3.0` 的估值锚切换规则。

## 核心设计：四赛道并行

```
输入: 全A股列表
  │
  ▼
Phase 0: 赛道分类
  ├── 0→1赛道 (亏损/微利/营收增速>50%/渗透率<5%)       → PS+TAM 扫描
  ├── 1→10赛道 (利润为正/营收增速25-50%/利润验证中)      → 多阶段PEG 扫描
  ├── 10→100赛道 (营收增速<20%/渗透率>50%/稳定盈利)     → PE+PB+分红率 扫描
  └── 周期赛道 (利润随行业周期大幅波动/PB反向信号)         → PB分位+周期位置 扫描
      │
      ▼
Phase 1: 各赛道独立粗筛（不同的入口条件）
      │
      ▼
Phase 2: 深度过滤矩阵（赛道差异化权重）
      │
      ▼
Phase 3: 输出候选池（含赛道标签）
```

## Phase 0: 赛道分类

> 对每个标的，通过以下规则判定所属赛道。

```python
def classify_stage(stock):
    """
    判定产业阶段，决定用什么估值锚。
    规则映射到 zisu-deep-analysis 的估值锚切换逻辑。
    """
    # 0→1: 亏损或微利 + 营收高增
    if (净利率 < 5% or PE < 0) and 营收增速 > 30%:
        if 主题级别 >= B级:
            return "0→1"
    
    # 周期股: 利润剧烈波动 + 行业有周期性
    if 近5年净利润标准差/均值 > 100% and D&A/营收 > 15%:
        # 检查所属行业是否为周期行业
        if industry in ["有色金属","钢铁","煤炭","化工","航运","面板","存储","猪产业","养殖"]:
            return "CYCLE"
    
    # 10→100: 低速增长 + 稳定盈利
    if 营收增速 < 20% and PE > 0 and PE < 50:
        return "10→100"
    
    # 1→10: 正利润 + 中高速增长 (默认选项)
    if PE > 0 and 营收增速 >= 15%:
        return "1→10"
    
    # 其他 (低增长+低利润灰区)
    return "OTHER"
```

## Phase 1: 四赛道独立粗筛

### 赛道A: 0→1 (概念扩散/亏损期)

> **用PS+TAM，禁用PEG和PE判断**

```python
# 要用PS和TAM来找"有潜力但亏损"的标的
if Revenue增速 > 50%:
    PS = 市值 / 营收(TTM)
    if PS < 5:
        → ⭐ PS低位+高增长 → 标记"0→1 PS重估候选"
    elif PS < 15:
        → 📋 正常估值区间 (进一步验证TAM)
    # PS > 15但营收增速>100%+A级题材 → 不剔除(市梦率模式)
    
if 营收增速 > 80% and 题材级别 == A级:
    → PS容忍度无上限 (题材门禁规则)
    → 标记"A级题材高PS — 市梦率模式，非PEG适用"
```

**为什么PE 200-300+的牛股不会被误杀**：
- 0→1赛道**完全不进入PE/PEG过滤管道**
- 它们走的是PS+TAM过滤管道：只要营收高增且PS在合理范围内（相对于增速），就通过
- A级题材+0→1的PS容忍度自动设为无上限

**0→1赛道的异常信号**（不是高PE，而是这几个）：
```
🚩 营收增速 < 30% 但 PS > 10           → 营收不足以支撑PS
🚩 题材级别 ≤ C级 但 PS > 20           → 无题材支撑的高PS
🚩 营收增速转负 但 PS > 15             → 营收萎缩的高PS是陷阱
🚩 TAM < $10亿 且 PS > 10              → TAM天花板限制
```

---

### 赛道B: 1→10 (利润验证期)

> **用多阶段加权PEG v3.0，这是PEG唯一适用的赛道**

```python
# v1.0的PEG逻辑搬到这里——因为在这里它是对的
if Forward_PE 可用:
    PEG_multi = PE / (g1×40% + g2×35% + g3×25%)
    
    if PEG_multi < 0.5:
        → ⭐⭐⭐ 深度低估 (PEG套利机会)
    elif PEG_multi < 0.8:
        → ⭐⭐ 低估
    elif PEG_multi < 1.0:
        → ⭐ 边缘低估
    elif PEG_multi < 2.0:
        → 合理区间 (不输出)
    else: # PEG > 2.0
        if 题材级别 == A级:
            → 不标记高估 (A级题材有PEG容忍度)
            → 标注"A级题材高PEG, 容忍度放宽"
        elif 题材级别 == B级 and PEG_multi < 3.0:
            → 中性 (B级题材容忍度<2.0但接近)
        else:
            → 🟠 高估预警
```

**1→10赛道的入口条件**（防误杀）：
```
✅ PE > 0 且 PE < 150          # 放宽上限，因为1→10阶段的高增长
                                 可以消化高PE（英伟达PE 80进1→10赛道）
✅ 营收增速 > 15%               # 必须有增长
✅ 净利率 > 5%                  # 必须有利润（区别于0→1）
```

---

### 赛道C: 10→100 (成熟期)

> **用PE+PB+分红率**

```python
# 成熟期的异常信号
if PE > 50 and 营收增速 < 10%:
    → 🔴 成熟期高PE → 存量博弈溢价
elif PB > 10 and ROE < 15%:
    → 🟠 PB-ROE不匹配
elif 股息率 > 5% and 分红率 > 80%:
    → 🟢 高股息防守型
elif PE < 10 and 营收增速 > 10%:
    → ⭐ 低PE+有增长 → 检查是否为困境反转
```

---

### 赛道D: 周期/困境反转

> **用PB分位+行业周期位置，PE是反向指标**

```python
# ⚡ 注意: 这个赛道的PE信号是反的!
# PE最高(亏损最严重) → 应该买入
# PE最低(利润最丰厚) → 应该卖出

# 正确过滤:
PB分位 = 当前PB / 近10年PB中位数

if PB分位 < 0.5 and 行业中位数PE > 50:
    → ⭐ 周期底部+全行业亏损 → 买入信号
    → 标记"周期底 — 高PE买"
elif PB分位 > 1.5 and 行业中位数PE < 15:
    → 🟠 周期顶部+全行业高利润 → 卖出信号
    → 标记"周期顶 — 低PE卖"
elif PB分位 < 0.3:
    → ⭐⭐ 历史低位 → 深度周期底
elif PB分位 > 2.0:
    → 🔴 历史高位 → 周期顶部预警
```
