    产业链瓶颈方法论¶

    这是整个体系的核心方法。它回答一个问题： 这条产业链上，钱被谁赚走了？以及，那个赚钱的位置可不可以被替代？

    一、核心概念：什么是「瓶颈」¶

    1.1 定义¶

    瓶颈 = 产业链上那个「缺了它整条链就停摆」的物理环节。

    它有三个必须同时成立的特征：

    特征 含义 反面
    不可替代 找不到等效的替代方案 有两家以上能做 → 不是瓶颈
    供应集中 全球可供应商数量极少 供应商众多 → 不是瓶颈
    认证壁垒 客户切换供应商的成本极高 随时可换 → 不是瓶颈

    关键区分：瓶颈 ≠ 龙头。 龙头是市场份额最大的公司，瓶颈是技术上不可绕过的环节。一家公司可以是某个环节的龙头（份额 40%），但这个环节本身有 10 家能做 —— 那它不是瓶颈，只是竞争者中最大的一个。

    1.2 为什么瓶颈是「单一锚点」¶

    体系用多维度收集证据（产业链、财务、资金、情绪、制度），但最终收敛到一个判断锚点：这家公司是否占据了产业链上的一个真实瓶颈。

    原因：其他维度的信号都可以被解释成多种含义。

    • 毛利率高 → 可能是瓶颈，也可能是一次性涨价
    • 资金流入 → 可能是看好，也可能是被动配置
    • 技术领先 → 可能是瓶颈，也可能只是暂时领先

    只有瓶颈是结构性的：全球只有一家能做，这件事不随时间、情绪、资金流动而改变。

    所以瓶颈判断错了，其他判断再对也没用。 这是为什么它被放在链条的最末端作为收敛点。

    二、瓶颈分级：五级标准¶

    2.1 分级判据¶

    分级必须基于客观可核查的事实，不能是主观感受。

    等级 符号 判据 典型描述
    5 级 🍃🍃🍃🍃🍃 全球独家 + 认证壁垒 ≥2 年 + 空间足够大 实质垄断
    4 级 🍃🍃🍃🍃 全球 2 家 + 认证 ≥2 年 + 客户锁死 极强瓶颈
    3 级 🍃🍃🍃 全球 2-3 家 + 工艺或材料独家 强瓶颈
    2 级 🍃🍃 全球 3-4 家 + 单一产品领先 准瓶颈
    1 级 🍃 全球 4 家以上但有差异化优势 潜力瓶颈
    0 级 — 全球 5 家以上，无显著差异 充分竞争

    2.2 判据的逻辑¶

    主锚是全球可供应商数量，副锚是认证周期。

    n = 全球可供应商数量
cert = 认证周期（年）

n = 1 且 cert ≥ 2  → 5 级
n = 1              → 4 级（独家但壁垒未被时间验证）
n ≤ 2 且 cert ≥ 2  → 4 级
n ≤ 3              → 3 级
n ≤ 4              → 2 级
n ≤ 8              → 1 级
n > 8              → 0 级

    注意 n=1 但 cert < 2 的情况降为 4 级：独家供应但认证周期短，说明这个「独家」可能是暂时的 —— 技术门槛没有高到让客户愿意花两年去认证的地步。

    「全球可供应商」的定义必须严格：能大规模量产、且有客户认证记录的才算。实验室有样品、宣布了产能规划但未投产、能做出但良率过不了 —— 都不算。

    这一点极其重要。放宽标准会让所有公司都变成瓶颈。

    2.3 自动降级触发条件¶

    出现以下任一情形，瓶颈等级自动降一级：

    触发条件 含义
    出现可量产替代品，或第二供应商放量 不可替代性被打破
    客户合同到期未续约 客户锁死失效
    实控人减持，或质押率超过 40% 治理风险，可能被迫卖出
    行业资本开支同比增长超过 50% 扩产竞赛预警，未来供给将增加

    为什么要设自动降级：瓶颈是状态，不是属性。今天独家不代表明年还独家。自动降级机制让评级随事实变化，而不是随分析者的期望变化。

    2.4 配套的三项审查¶

    瓶颈等级评定后，必须再做三项审查。任一不通过即降级或否决。

    审查一：画饼预警¶

    如果 盈利质量 或 现金转化 任一项不通过
  → 红色预警
  → 严禁推荐

    逻辑：一家公司在实验室里做出了独家产品，但产品不赚钱或者赚的是应收账款 —— 这个瓶颈没有商业价值。

    审查二：空间天花板¶

    市场空间天花板 = 全球市占率上限 × TAM

示例：某工序全球市占率最高可达 50%，对应 TAM 为 5 亿
  → 该公司在该业务上的营收天花板 = 2.5 亿

如果当前市值已经反映了超过天花板的空间
  → 估值不成立

    为什么必须算这一项：瓶颈公司容易获得高估值，但瓶颈所在环节的市场规模可能很小。一个全球独家的特种材料，TAM 可能只有 10 亿。独家 ≠ 大生意。

    审查三：治理审查¶

    信号 触发后果
    实控人清仓式减持 否决
    审计非标意见 否决
    质押率 > 40% 且有平仓线 致命降级
    高管集体离职 降级
    关联交易频繁且不透明 降级

    三、十二步瓶颈狩猎法¶

    这是从终端需求出发，逐层找到瓶颈的完整流程。

    Phase 0 · 前置检查¶

    □ 资本开支周期验证（FY/CY 口径确认）
□ 反方研究搜索：查找真实存在的看空观点
  （不是假设的空头，是真的有人写过的看空报告）

    为什么要搜真实反方：假设的空头很容易写弱。真实的看空报告会给出你可能没想到的角度。

    Phase 1 · 绘制产业链地图¶

    从终端需求出发，逐层追问「这一层缺什么不可？」
目标：拆到 5-7 层（核心环节可到 10 层）

关键提问：
  → 这个东西的上游是什么？
  → 那个上游再往上是什么？
  → 哪一层如果断供，后面全部停摆？

    注意方向：从需求往上游拆，不是从原材料往下推。从需求出发才能保证每一层都是「为了做出最终产品而必须存在的」。

    Phase 2 · 数清全球真实玩家¶

    对每一层，统计「能大规模量产 + 有客户认证」的供应商数量

关键纪律：
  → 实验室有样品的不算
  → 宣布了产能规划但未投产的不算
  → 能做出但良率过不了的不算
  → 只有通过客户认证的才算

    Phase 3 · 五维深度验证¶

    对识别出的候选瓶颈环节，逐项验证：

    维度 检查内容
    不可替代性 有无等效替代方案？替代方案的成本差多少？
    产能上限 现有产能能否满足需求增长？扩产周期多长？
    客户结构 前五大客户占比？是否有长期协议？
    技术护城河 与全球第一的技术代际差距（<1 代才是候选）
    估值错配 当前估值是否反映了瓶颈地位？

    Phase 4 · 魔鬼代言人八问¶

    强制从空头角度攻击自己的每一个逻辑环节。

    □ 技术真的不可替代吗？替代方案进展如何？
□ 客户真的换不掉吗？切换成本到底多少？
□ 产能真的不足吗？行业扩产计划有多少？
□ 需求真的持续吗？下游景气度能维持多久？
□ 毛利率真的能维持吗？有无降价压力？
□ 管理层真的可靠吗？有无治理瑕疵？
□ 估值真的便宜吗？隐含什么假设？
□ 我做空的话，最强的三个理由是什么？

    判定：≥5 问无法有力反驳 → 终止（T3）。

    Phase 5 · 全球竞对深度对比¶

    标的 vs 全球第一：
  → 技术代际差距 < 1 代  → 瓶颈候选
  → 技术代际差距 ≥ 1 代  → 排除

对比维度：制程/精度/良率/产能/客户/成本

    Phase 6 · 资金周期阶段判断¶

    无人问津 → 早期发现 → 主流确认 → 拥挤共识

目标：买在「主流确认之前」

阶段判据：
  早期发现   ：卖方覆盖 <5 家，公募持仓极少
  主流确认   ：卖方覆盖快速上升，机构开始建仓
  拥挤共识   ：覆盖 20+ 家，成为公募前十大重仓

    Phase 7 · 另类数据挖掘¶

    不看 PE / ROE / 常见研报，看：
  □ 专利引用数据（技术积累是否真实）
  □ 海关进出口数据（实际出货量）
  □ 环评文件（产能扩张的真实进度）
  □ 招聘岗位（在招什么人，暴露技术方向）

    为什么这些数据更有价值：它们不在所有人的屏幕上。等一个信号出现在研报里，它已经被定价了。

    Phase 8 · 错误定价类型判定¶

    类型 含义
    传统瓶颈 市场未认识到瓶颈地位
    相对价值错判 与错误的可比公司比较
    代码混淆 市场把它归入错误的行业分类
    机械性错位 指数调整、被动卖出造成
    时机期权 市场未对未来的催化定价

    Phase 9 · 物理与地缘坐标¶

    □ 生产基地在哪里？（是否受地缘影响）
□ 关键原材料来源？（是否有断供风险）
□ 制裁/出口管制状态
□ 关键里程碑时点

    Phase 10 · 六维测试¶

    # 测试 检查内容
    T1 盈利质量 应计比率、M-Score
    T2 现金转化 经营现金流 / 净利润
    T3 真实增长 收入增长是否有现金支撑
    T4 估值消化 增长能否消化当前估值
    T5 竞争地位 相对全球玩家的位置
    T6 绝对规模 空间是否足够大

    T1 或 T2 不通过 → 红色预警（画饼），严禁推荐。

    Phase 11 · 三类情景框架¶

    情景 定价逻辑 适合
    A 动量 资金与情绪驱动 短线
    B 价值 基本面与估值驱动 长线
    C 催化剂 事件驱动 事件窗口

    同一只股票可能同时存在三种定价逻辑。 明确当前是哪一种，才能选对持有周期。

    Phase 12 · 风险矩阵与退出条件¶

    □ ≥8 类风险
□ 每类风险配量化监测指标
□ 止损/减仓阈值明确

    四、产业链 BOM 逆向拆解¶

    4.1 拆解方法¶

    「BOM」= 物料清单。 逆向拆解的意思是：从最终产品出发，逐层拆到最底层的原材料与工序。

    终端产品
  ↓ 由哪些部件组成？
第 1 层部件
  ↓ 每个部件由哪些零件/材料组成？
第 2 层
  ↓ ……
第 5-7 层（核心环节可到 10 层）

    4.2 每层的标注要求¶

    字段 说明
    层级编号 从 1 开始
    环节名称 必须是具体工序，不能是行业名称
    工序描述 具体制造步骤 + 技术参数
    全球供应商数 能大规模量产且有认证的
    认证周期 客户切换供应商所需时间
    单件价值 ASP（单台/单件价格）
    价值占比 占该环节资本开支的比例
    中国参与度 自给率 / 全球份额 / 技术代际差距

    4.3 合格与不合格对照¶

    ❌ 不合格 ✅ 合格
    制冷剂层 R32 合成工序：二氟甲烷 + 氯气 → R32，催化剂 SbCl₅，300°C
    检测设备层 HBM 堆叠后通孔对准检测：3μm 分辨率、10nm 对准精度、热应力补偿
    光学膜层 紫外固化硬化涂层：涂布 3-5μm、固化能量 800mJ/cm²
    半导体行业 12 英寸晶圆背面减薄工序：磨削至 50μm，TTV < 1μm

    判定规则：名称中含「行业」「领域」「板块」即不合格。

    4.4 利润池分析¶

    把各层按「利润规模 × 利润率」排序：

    利润池排序 = 各层利润规模 × 该层利润率

要回答：
  □ 标的在肥美层还是贫瘠层？
  □ 过去 5 年利润池迁移方向？
  □ 迁移的原因是什么？（技术变化 / 政策 / 需求结构）

    为什么这一项重要：产业链上不同环节的利润率差异可能达 10 倍。占据一个「低价值环节的瓶颈」和占据一个「高价值环节的瓶颈」，是完全不同的生意。

    五、客户锁定机制¶

    瓶颈的可持续性最终取决于客户能否换掉你。三个维度：

    5.1 认证周期¶

    具体化到：
  □ 客户认证了哪个型号？
  □ 良率测试持续了多久？
  □ 测试覆盖了多少数据量？

    不要说「认证周期长」，要说「某客户认证某型号，良率测试持续 14 个月，覆盖 2.3TB 测试数据」。

    5.2 替换成本¶

    替换成本 = 金钱成本 + 时间成本 + 供应链风险成本

示例：
  如果客户换回原供应商
  = 产线停机 15 天 × 日损失 X 万
  + 重新认证费用 Y 万
  + 重新验证期间的良率风险

    5.3 供应安全价值¶

    在地缘风险背景下，「有第二供应商」本身具有战略价值。

    双供应商策略 → 标的作为「备份供应商」获得溢价

    这一项容易被忽略但很重要：有时客户选择一家供应商不是因为它更好，而是因为需要一个备选。这种「备份溢价」是真实的商业价值。

    六、卡脖子矩阵¶

    用于判断产业链上的博弈关系。

    维度 检查内容
    产能 该环节的产能集中度
    技术 技术代际差距
    替代壁垒 替代方案的可行性
    政策博弈 出口管制 / 制裁状态

    最终判定：

    判定 含义 估值影响
    🔴 中国卡对方 我方掌握关键环节 可能有战略溢价
    🔵 对方卡中国 被动依赖进口 估值折价 + 断供风险

    七、技术路线图与演进¶

    7.1 必产出¶

    □ 当前 → 下一代技术跃升点标注
□ 每个跃升点的：检测难度变化 / ASP 变化 / 毛利率影响
□ 替代技术路径 ≥3 条，每条标注：
    → 技术成熟度（TRL）
    → 成本差距
    → 商业化时间
    → 威胁等级

    7.2 为什么必须列替代路径¶

    技术路线图最常见的错误是只画主线，不画分叉。但真正杀死一家瓶颈公司的往往是替代路线，而不是同路线上的竞争者。

    同路线竞争 → 瓜分市场（缓慢）
替代路线突破 → 现有产能归零（突然）

    八、上下游分析¶

    8.1 上游¶

    □ 关键部件的供应商、国产化率、卡脖子风险
□ 原材料价格趋势与成本传导能力

    8.2 下游¶

    □ 客户产能扩张计划
□ 设备/材料采购决策链（谁拍板、周期多长）
□ 客户集中度与议价力

    8.3 需求传导链¶

    必须画出完整的逻辑链，每个环节标注量化数据。

    示例：

    大模型参数翻倍
  → GPU 的 HBM 搭载量提升
  → HBM 产能紧缺
  → 堆叠层数增加、良率挑战加大
  → 检测需求指数级爆发
  → 检测设备供应商受益

    这条链的价值：它把「AI 很火」这个模糊判断，变成了「哪个具体环节的需求会增加多少」的可计算问题。

    九、方法论使用检查清单¶

    在完成产业链分析后，逐项检查：

    【拆解质量】
□ 是否拆到 ≥7 层？
□ 每层名称是否包含「行业/领域/板块」？（含则不合格）
□ 每层是否标注全球供应商数？
□ 每层是否标单单件价值量？
□ 每层是否标注认证周期？

【排除性】
□ 是否列出 ≥5 家被排除的玩家？
□ 每家的排除理由是否 ≥10 字且有实质内容？
□ 是否给出量化差距指标？

【量化桥梁】
□ 设备台数、ASP、交付率、验收率、单位五个字段是否齐全？
□ 是否推算了季度收入确认节奏？

【瓶颈分级】
□ 供应商数量是否严格统计（只算量产的、有认证的）？
□ 认证周期是否有具体证据？
□ 是否检查了四项自动降级触发条件？

【三项配套审查】
□ 画饼预警：盈利质量与现金转化是否通过？
□ 空间天花板：TAM × 市占率上限是否算过？
□ 治理审查：九条信号是否检查？

【可持续性】
□ 客户锁定机制是否具体化（认证周期、替换成本、备份价值）？
□ 技术路线图是否含 ≥3 条替代路径？
□ 是否画出需求传导链并标注量化数据？

    十、常见错误¶

    错误 表现 后果
    放宽「供应商」定义 把实验室样品、规划产能算作供应商 所有公司都变成瓶颈
    停在行业层 「上游材料行业」当作一层 无信息量，无法判断难度
    只列名字不排除 「竞争对手有 A、B、C」 无法验证「只有 2 家能做」
    跳过量化桥梁 「产能 10 万吨 → 收入 50 亿」 四个隐含假设全部未验证
    忘记空间天花板 只算瓶颈等级，不算 TAM 独家的小生意被当成大机会
    忽略替代路线 只画同技术路线竞争 被技术替代突然杀死
    瓶颈当永久属性 一次评级永久使用 忽视自动降级触发条件
