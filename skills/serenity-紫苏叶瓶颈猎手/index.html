    第一篇：哲学根基与理论体系¶

    1. 核心哲学¶

    1.1 利润即真理（Profit is Truth）¶

    任何技术壁垒、产业链卡位、政策红利，如果不能映射为未来12个月内可验证的正经营现金流或扣非净利润，一律不予采信为持有理由。 - 利润兑现 = 唯一真实信号 - 见不到现金流的护城河是护城沟（moat vs trench） - 12个月时间窗口强制约束 - 扣非净利润而非归母净利润

    1.2 紫苏叶理论（Shiso-Leaf Theory）¶

    核心隐喻：顶级寿司店里，食客追逐的是金枪鱼大腹（toro），但厨房真正离不开的是紫苏叶（shiso）。 工程语言翻译——紫苏叶必须同时满足三条硬约束： 1. 功能不可替代：不是更好，而是没它就违规/不安全/无法出货 2. 系统性风险节点：断供不是少赚，而是停线/罚则/重做成本极高 3. 体验/性能命门：最终产品关键指标由它决定

    1.3 瓶颈核心公式¶

    战略地位（不可替代性）x 估值错配（市值 vs 瓶颈控制力）x 时机（机构入场前）= 不对称收益

    1.4 瓶颈点 vs 卖铲子¶

    • 卖铲子：铲子相对通用，竞争会磨平超额利润
    • 瓶颈点：河道本身收窄，供给被设备/认证/专利/材料/地缘锁死
    • 比喻：霍尔木兹海峡——全球20%石油必经之路

    1.5 投资第一性原理（五不预测）¶

    1. 不预测宏观 2. 不预测大盘 3. 不预测行业增速 4. 只预测：客户离不开它+产能比需求慢12-24月 5. 不预测技术路线

    1.6 A股 vs 港股定价基因¶

    A股PEG<1.0，港股PEG<0.8。三大标杆：中际旭创PEG0.52、新易盛PEG0.37、兆易创新PEG2.2

    2. 六层理论地基¶

    1. 利润即真理 2. Rumelt症结诊断 3. Greenwald进入壁垒唯一论 4. Helmer 7 Powers 5. Morningstar五源护城河 6. 瓶颈拓扑学

    2.1 Rumelt症结诊断三问¶

    1. 这个行业的症结是什么？ 2. 如果只有一件事能让产业链断裂，那是什么？ 3. 目前的共识错在哪里？

    2.2 Greenwald三问¶

    1. 有进入壁垒吗？2. 壁垒形式？3. 无壁垒为何赚钱？ 壁垒类型：供给侧（专有技术/资源）/ 需求侧（客户习惯/搜索成本）/ 规模经济 / 政府/管制

    2.3 Helmer 7 Powers映射¶

    • Scale Economies: 产能规模=准入门槛
    • Switching Costs: 核心相关，认证=切换成本
    • Cornered Resource: 最直接相关，专利/矿权/独家供应
    • Process Power: 工艺诀窍/良率优势

    2.4 Morningstar五源护城河评分（10分制）¶

    无形资产/转换成本/网络效应/成本优势/有效规模。>=35分=宽护城河，20-34=窄，<20=无

    2.5 护城河验证公式¶

    护城河真伪 = 毛利率稳定性 x 现金流转化率 x 客户不可替代性 x Cornered Resource强度 x 时间持续性 五维全通过=真实护城河可重仓；3-4个通过=候选需深度验证；<=2个通过=画饼/周期股/伪瓶颈

    3. 适用边界¶

    适用：AI半导体、光通信、新能源、机器人、稀土材料、精密制造 v6.0新增：BBU电芯链、海上AI数据中心、人形机器人硬件供应链 v6.1新增：被动元件/MLCC（瓶颈扩散末端）、AI能源/数据中心地产（RIOT-Anthropic）、物理AI/人形机器人整机（Agility via CCXI）、测试/设备前置指标（AEHR） v6.2新增：玻璃基板/TGV 先进封装（LPKF/Absolics/三星电机）、neocloud（CRWV/NBIS）、数据中心 IPO 资产（Vantage/Switch/CyrusOne） 不适用：消费品牌、金融服务、内容平台

    3.5 瓶颈扩散理论（Chokepoint Diffusion）【v6.1新增】¶

    AI 瓶颈不是静态的，会沿 BOM 自上而下、自核心向边缘迁移。超额收益随瓶颈迁移而迁移： 

    GPU(已定价) → HBM(已定价) → 光模块/CW激光(正在被定价) → 被动元件MLCC/电感(严重被忽视·下一站)
    - 触发证据：Taiyo Yuden/MLCC（8/12 Leopold 重仓确认）、GB300 BOM「被动元件 4.9% 严重被忽视」 - 次级短缺传染：MLCC 厂把消费级产能转去 AI 高规格 → 中高容值消费级 MLCC 库存跌破 30 天、渠道涨价 → 瓶颈会"传染"出次级瓶颈（AI 挤压非 AI 供给） - 操作：在七层卡点地图外叠加一条「扩散时间轴」——当前资金已定价到哪一层？下一层被忽视瓶颈是什么？

    3.6 架构中性（Architecture-Neutral）标的优先【v6.1强化】¶

    技术路线之争（CPO vs 可插拔 vs NPO）中，不赌路线，买"无论哪条路线胜出都用得上"的底层环节： - CW 激光/DFB 阵列同时覆盖 pluggable / scale-out CPO / scale-up CPO / NPO（SIVE 6/21） - UHP 激光架构中性：单 CW laser 或 multi-emitter CW DFB array 都能实现（7/10） - 落地：把第 1.5 节「不预测技术路线」转化为可执行策略——只选跨架构通用的底层瓶颈

    4. BOM 逆向工程方法论¶

    4.1 核心原则¶

    Serenity的研究起点不是市场预期，而是物理现实。从终端产品BOM出发，逐层逆向拆解。 传统从巨头往下看，Serenity从物理原点层层向上溯源。传统第二层就停了，Serenity拆到第五层以下。

    4.2 BOM拆解标准流程¶

    Step1确定终端产品 -> Step2获取BOM数据 -> Step3逐层计算组件价值 -> Step4标注被忽视程度 -> Step5供应商集中度分析 -> Step6锁定紫苏叶候选

    4.3 BOM拆解铁律¶

    1. 不停留在第一层瓶颈——超额收益在第二三层
    2. 每层必问：如果这一层供应抖动10%，系统会不会停？
    3. 越深层定价漏洞越大——必须拆到第五层以下
    4. 区分已定价瓶颈和被忽视瓶颈

    瓶颈（Bottleneck）— 供给侧物理约束： - CW 激光已被 LITE 财报证实瓶颈；激光 fab 重度分配给 EML（前 NVDA 合同） - 三条 fab 瓶颈：Sumitomo/Furukawa（日本，被 NVDA 合同锁定）+ Win Semi（稳懋，被 SIVE 提前锁产能） - SIVE 是 fab-lite 模式，但早期就锁定了 Win Semi 等代工厂的产能分配 → 控制 CW 激光最终供给 - 类比 Kioxia/Sandisk：SNDK 控制 NAND 输出 → 控制最终定价 → 是瓶颈。同理 SIVE 控制 CW 激光最终供给

    卡点（Chokepoint）— 生态结构锁定： - NVDA 用 COHR/LITE（从日本对手采购外部 CW），AVGO 垂直整合——但这两家之外的所有玩家都绕不开 SIVE - ASIC 路线（Marvell Celestial / AlChip）+ merchant 路线（Ayar / Lightmatter / Lightelligence）全生态围绕 SIVE 设计 - Ayar 2022 曾尝试 multi-source MTSI/LITE，但激光不匹配 Sivers 阵列规格（最近从供应链网站移除 Lumentum/Macom） - 1.6T LRO JBL 的性能"drastic moat"围绕 SIVE sole source 构建 - GFS 的参考激光设计默认 SIVE，AMD 走 GFS 路线 - 无法绕过：不能热插拔单通道 CW 激光

    结论：SIVE 同时是 bottleneck（控产能）+ chokepoint（锁生态），在 CPO 2027H2 规模化的最大架构迁移中（GS 预测 TAM 从 ~$0 → $81-91B，1.5 年内），是"下一个 $75B LITE"的候选。 方法论提炼：瓶颈标的要同时问两个问题——①供给侧物理上缺不缺？（bottleneck）②生态结构上绕不绕得开？（chokepoint）。两者兼具才是 4-5 叶级别。
