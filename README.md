## 我在解决什么问题

股票分析最难的从来不是「找到好公司」，而是**在三件事上不自欺**：

**第一，把行业顺风误认为公司能力。** 一家公司收入增长 40%，看起来很强 —— 但如果整个行业都增长 45%，它其实是跑输的。所以必须先看行业，再看公司。

**第二，把叙事当成事实。** 「行业空间万亿」「技术全球领先」这类判断无法被证伪，因此它们不构成观点，只是姿态。所以我要求每个核心结论都能写成一个可以被事实推翻的句子。

**第三，把假设包装成结论。** 一个精确到小数点后两位的目标价，其中 70% 来自对永续增长率的假设 —— 这是把自己的假设穿上了客观的外衣。所以我用反向 DCF：不问「它值多少钱」，而问「当前市值要求它做到什么」。

这三条对治方式，构成了整套方法的骨架。

## 三条第一性原理

所有下游方法都从这三条推导。如果某条具体规则与原理冲突，改规则，不改原理。

### 一、利润即真理

股价的长期锚是企业创造现金的能力。所有叙事、题材、概念，最终必须落到利润和现金流上。

验证方式是三维乘法（不是加权平均，任何一项接近零则整体接近零）：

```
护城河真伪 = 毛利率稳定性 × 现金流转化率 × 客户不可替代性
```

| 维度 | 判据 | 红旗线 |
|---|---|---|
| 毛利率稳定性 | 近 5 年标准差 / 均值 | > 15% |
| 现金流转化率 | 经营现金流 / 净利润 | 持续 < 0.5 |
| 客户不可替代性 | 单一客户占比 | > 30% |

**为什么用稳定性而不是水平**：毛利率 20% 但十年稳定的公司，护城河往往强于毛利率 50% 但三年内从 60% 跌到 35% 的公司。前者说明它在这个价位掌握了定价权，后者说明它曾经掌握过。

### 二、覆巢之下无完卵

仓位上限不由个股质量决定，由市场环境决定。在系统性下跌中，所有个股的相关性趋近于 1，分散化失效，唯一的保护是低仓位。

| 环境 | 总仓位上限 | 开新仓 |
|---|---|---|
| A 进攻 | ≤100% | ✅ |
| B 中性 | ≤70% | ✅ |
| C 谨慎 | ≤30% | ⚠️ 瓶颈等级不足则跳过 |
| D 防守 | ≤10% | 🛑 禁止 |

### 三、没有催化剂的好股是死水

基本面优秀但缺少触发事件的标的，可能长期不涨。资金需要理由才能进入。

```
未来 60 天内无可识别催化剂      → 自动降权一档
催化剂已全部兑现且无新催化剂    → 标注真空期，建议减仓
催化剂逻辑被证伪                → 无条件清仓
```

## 核心锚点：产业链物理瓶颈

这是整套方法的收敛点。多维度收集证据，最终收敛到一个判断：

> **这家公司是否占据了产业链上一个不可替代的物理环节？**

### 什么是瓶颈

**瓶颈 = 产业链上「缺了它整条链就停摆」的环节。** 三个特征必须同时成立：

| 特征 | 含义 | 反面 |
|---|---|---|
| 不可替代 | 找不到等效替代方案 | 有两家以上能做 → 不是瓶颈 |
| 供应集中 | 全球可供应商极少 | 供应商众多 → 不是瓶颈 |
| 认证壁垒 | 客户切换成本极高 | 随时可换 → 不是瓶颈 |

**关键区分：瓶颈 ≠ 龙头。** 龙头是份额最大的公司，瓶颈是技术上不可绕过的环节。一家公司可以是某环节的龙头（份额 40%），但这个环节有 10 家能做 —— 那它不是瓶颈，只是竞争者中最大的一个。

### 五级分级

判据基于**客观可核查的事实**，不是主观感受：

| 等级 | 判据 | 单只仓位上限 |
|---|---|---|
| 🍃🍃🍃🍃🍃 | 全球独家 + 认证 ≥2 年 | 25% |
| 🍃🍃🍃🍃 | 全球 2 家 + 认证 ≥2 年 + 客户锁死 | 20% |
| 🍃🍃🍃 | 全球 2-3 家 + 工艺或材料独家 | 15% |
| 🍃🍃 | 全球 3-4 家 + 单一产品领先 | 8% |
| 🍃 | 全球 4 家以上但有差异化 | 3% |

**「全球可供应商」的定义必须严格**：能大规模量产、且有客户认证记录的才算。实验室有样品、宣布产能但未投产、能做出但良率过不了 —— 都不算。

放宽这个标准，会让所有公司都变成瓶颈。

### 四项自动降级条件

瓶颈是**状态**，不是**属性**。出现以下任一情形自动降一级：

```
□ 出现可量产替代品，或第二供应商放量
□ 客户合同到期未续约
□ 实控人减持，或质押率超过 40%
□ 行业资本开支同比增长超过 50%（扩产竞赛预警）
```

→ 完整方法见 [04-产业链瓶颈方法论](docs/04-产业链瓶颈方法论.md)

## 分析流程：八阶段正金字塔

```
        ┌──────────────┐
        │ P7 最终裁决   │  ← 可证伪的一句话结论
        ├──────────────┤
        │ P6 执行方案   │  ← 买多少、什么价、何时退
        ├──────────────┤
        │ P5 估值定价   │  ← 隐含预期反解 + 多锚交叉
        ├──────────────┤
        │ P4 市场认知   │  ← 市场在哪可能错了（只提问）
        ├──────────────┤
        │ P3 财务预测   │  ← 三表联动 + 盈余质量
        ├──────────────┤
        │ P2 深度穿透   │  ← 钱被产业链哪层赚走了
        ├──────────────┤
        │ P1 行业定位   │  ← 赛道多大、格局如何
        ├──────────────┤
        │ P0 公司画像   │  ← 这家公司靠什么赚钱
        └──────────────┘
             业务事实底座
```

**为什么是正金字塔**：早期版本把「市场认知偏差」放在最前面，结果后续所有分析都被先入的判断锚定 —— 你会不自觉地寻找支持既有结论的证据。改为业务事实先行后，P4 的「市场是不是错了」成为与前序分析**相互独立**的判断。

### 五条深度铁律

「深度」是报告里最容易滥用也最难检验的词。所以把它变成可检查的条件：

| 铁律 | 要求 | 检验方式 |
|---|---|---|
| **零** 业务事实先行 | 分业务拆解一次性完整呈现 | 加权毛利率偏差 < 2pp |
| **一** 市场只提问 | P4 禁止结论性表述 | 全文搜索「我们认为」 |
| **二** 工序级×价值量级×排除性 | ≥7 层工序 + 价值量 + ≥5 家排除 | 层级名含「行业」即不合格 |
| **三** 产能→收入量化桥梁 | 设备台数×ASP×交付率×验收率 | 五个字段齐全 |
| **四** 强制非共识 | ≥2 条可被事实推翻的非共识 | 与市场主流是否分歧 |
| **五** 估值切换条件 | 含隐含假设 + ≥2 个切换触发条件 | 是否只是循环论证 |

### 五个终止点

不是所有标的都值得完整分析。发现致命问题时及时止损分析资源：

| 终止点 | 触发条件 | 含义 |
|---|---|---|
| **T0** | 无法用一段话向外行解释这家公司 | 不理解 = 不投资 |
| **T1** | 周期判定为「反身性溢价」 | 估值与基本面脱节，无锚点可用 |
| **T2** | 产业链存在致命卡脖子且无替代方案 | 系统性风险不可控 |
| **T3** | 空头论证中 ≥5 问无法反驳 | 反方压倒性 |
| **T4** | 安全边际 < 10% | 当前不具备风险补偿 |

**终止 ≠ 否定。** 每个终止点都附**重新分析触发条件** —— 条件满足时可从终止点继续。

→ 完整流程见 [02-分析流程](docs/02-分析流程-八阶段正金字塔.md)

## 四个最有特色的方法

### 一、反向 DCF：不问「值多少」，问「要做到什么」

正向 DCF 的输出是一个价格，但其中 60-85% 来自对永续增长率的假设。把假设包装成数字，会产生伪精确与不可证伪两个后果。

```
正向：我认为它值 41.2 元              → 观点，无法检验
反向：当前市值要求永续增速 3.5%        → 事实约束，可以检验
```

**第二条立刻产生可检验的子问题**：3.5% 的永续增速可信吗？对照历史增速、同业水平、产能规划，这个问题有答案。

**三条硬约束**：

```
① 不产出目标价（输出隐含增速与折现率，没有价格字段）
② 不收敛就是结论（市值高于任何合理参数下的价值 = 现金流假设无法解释）
③ 不返回伪解（迭代不收敛即判定未收敛，不给「近似值」）
```

### 二、市场结构：价格是怎么形成的

基本面回答「公司值多少」，这一层回答「为什么价格不是那个值」。

**Miller 定价框架**：当分歧大 + 做空受限 + 供给薄同时成立时，价格**系统性**地由最乐观者决定，而不是市场均衡价。

| 维度 | 判据 |
|---|---|
| 分歧度 | 卖方评级分布、一致预期方差 |
| 做空受限 | 融券余额占流通市值比例、替代做空渠道 |
| 结构判定 | 高分歧 + 极度受限 → 显著乐观偏差 → 估值下修 10-20% |

**卖盘厚度五层拆解**：把可交易股份按「卖出可能性」分层。

| 层级 | 构成 | 典型占比 | 可预测性 |
|---|---|---|---|
| 🏔️ 不卖层 | 实控人、国有股东、上市前高管 | 25-55% | ★★★★★ |
| 🔒 锁定层 | 被动指数、战略配售、定增锁定 | 5-20% | ★★★★ |
| 🧊 长持层 | 长期机构、外资 | 5-15% | ★★★ |
| 🌫️ 浮筹层 | 主动公募、游资、量化、散户 | 15-40% | ★★ |

```
浮筹 < 20%  → 💀 近乎空转，价格严重脱离供需基本面
浮筹 20-40% → 🔴 卖盘极薄，小资金可撬动大涨幅
```

**追认台阶模型**：机构从「不认识」到「重仓」分三步，每步对应不同的风险收益比。

| 台阶 | 特征 | 处理 |
|---|---|---|
| 1 试水期 | 涨幅 2-3 倍，重仓基金 < 50 家 | ✅ 可入场 |
| 2 追认期 | 涨幅 5-10 倍，重仓基金 200-500 家 | ⚠️ 降速 |
| 3 拥挤期 | 涨幅 20-50 倍，成为前十大重仓 | ⛔ 不再新开 |

**边际买家更替**：一只长牛股由不同批次的买家接力完成，前一段的主力往往在下一段离场。跟踪方式：回溯过去 3 期的前十大流通股东名单，标注每期主力类型。

→ 完整方法见 [10-市场结构与定价机制](docs/10-市场结构与定价机制.md)

### 三、周期判定：识别「成长变周期」的拐点

同一家公司，判定为成长股还是周期股，会导出完全不同的估值方法，结果可能相差两倍。

**三维判定**：

| 维度 | 判据 | 真成长标准 |
|---|---|---|
| 行业渗透率 | S 曲线位置 | 5-30%（加速期） |
| 资本开支强度 | 资本开支 / 营收 | < 20% |
| 壁垒属性 | 壁垒类型 | 技术或认证壁垒 |

**五大预警信号（命中 ≥3 个 → 判定成长转周期，立即清仓）**：

```
① 渗透率 > 30% 且收入增速连续 2 季下滑
② 行业产能同比 > 20%
③ 毛利率连续 2 年下滑
④ 资本开支 / 营收 > 15%
⑤ 毛利率同比下滑 > 1 个百分点
```

**信号 ⑤ 是最早的信号**：新竞争者进入 → 先影响价格（毛利率）→ 再影响份额（收入）→ 最后影响利润。毛利率是领先指标。

→ 完整方法见 [05-周期与成长判定](docs/05-周期与成长判定.md)

### 四、执行纪律：判断对但仓位错 = 判断错

```
 1%  — 任何一笔的风险不超过总资金的 1%
2:1  — 盈亏比至少 2:1
 3   — 连续 3 笔亏损减仓，5 笔停止交易
15%  — 回撤 15% 警戒线
20%  — 单只标的仓位不超过 20%
70%  — 总仓位不超过 70%
 ∞   — 不预测 · 只应答 · 错过不亏钱
```

**仓位由多层约束取最小值，不是加权平均**：

```
最终仓位 = min(
    凯利仓位 × 0.25,      ← 永不用全凯利
    波动率调整后仓位,
    回撤缩放后仓位,
    1% 风险限额对应仓位,
    单只上限 20%,
    环境评级上限
)
```

**为什么不用全凯利**：胜率 60%、盈亏比 2:1 时 Kelly = 40%，但连亏 5 次本金会损失 92%。四分之一凯利是默认值。

→ 完整方法见 [12-执行体系与风控纪律](docs/12-执行体系与风控纪律.md)

## 工程实现（辅助材料）

上述方法中最容易被违反的部分 —— 不是「想不到」，而是「想得到但做不到」—— 被实现为可执行的检查。

**例如这一条**：

> 曾经我用通用网页检索去估一个滚动市盈率，得到的口径与结构化数据库相差 **+76% ~ +265%**。
> 事后复盘发现，提示词里其实明确写着「估值数据必须从数据库获取」——
> 约束是清晰的，但它是**提醒**，不是**门禁**。

改造后，数据源约束变成编译期登记：未登记的数据源直接拒绝进入分析计划。

```
$ python examples/gate_demo.py

✅ unauthorized_source   非结构化源被授权提供估值数据  → GATE-01 越权拦截
✅ unregistered_source   引入未登记数据源             → GATE-01 未登记拦截
✅ zero_fill             缺失数据填成 0               → GATE-41 零填充拦截
✅ single_line           跳过业务拆解直接给结论        → GATE-11 拆解不足拦截
✅ weak_bear             空头论据敷衍了事             → GATE-16 自我确认拦截
✅ no_market_cap         缺市值仍给估值结论           → GATE-50 反解不收敛拦截
✅ shallow_chain         产业链退化为行业口号         → GATE-12 深度不足拦截
✅ zero_peers            单锚估值下结论               → GATE-51 多锚校验拦截

拦截结果：8/8 全部挡下
```

## 适用边界

**明确的边界比模糊的普适更有价值。**

| 维度 | 适用 |
|---|---|
| 市场 | A 股为主，港股 / 美股可参照 |
| 行业 | 科技制造类：半导体、光通信、新能源、机器人、稀土材料、精密制造 |
| 持仓周期 | 1 个月 – 2 年 |
| 核心前提 | 标的存在可识别的产业链瓶颈 |

**不适用**：

| 类型 | 原因 |
|---|---|
| 短产业链行业（消费品牌、金融、内容平台、互联网平台） | 瓶颈概念不成立 |
| 期货 / 外汇 / 数字货币 | 无企业基本面 |
| 高频策略 | 时间尺度不符 |
| 日均成交额 < 500 万的标的 | 流动性不足，任何框架都不适用 |

**最后一条特别重要**：一个日均成交额 300 万的标的，即使基本面再好，也无法建立和退出一笔有意义的仓位。这类标的应该在分析之前就被跳过。
