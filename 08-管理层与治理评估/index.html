    管理层与治理评估¶

    同样的生意，一流管理层做出一流结果，三流管理层做出亏损。 本文的目的不是「评价人」，而是把对人的判断转化为可核查的证据。

    一、为什么必须评估管理层¶

    财务数据反映的是过去的结果。管理层决定的是未来的资源配置。

    一家公司过去五年毛利率稳定、现金流健康，只能说明它现在的生意好。未来这生意会变好还是变坏，取决于管理层把赚来的钱放在哪里。

    典型情形：

    管理层类型 行为 结果
    优秀 在核心业务上加码，退出不擅长领域 ROIC 持续高于资金成本
    平庸 维持现状，无重大错误也无建树 ROIC 接近资金成本
    危险 高价收购、盲目多元化、在股价高位增发 资本被毁灭

    关键在于：这三种管理层在财务报表面向过去时几乎无法区分 —— 差异会在三五年后显现。 所以必须主动评估。

    二、五维管理质量评分卡¶

    2.1 五维与权重¶

    维度 权重 评估什么
    D1 资本配置能力 30% 历史资金分配决策的质量
    D2 激励对齐度 20% 薪酬结构是否与长期价值创造一致
    D3 内部人信号 20% 增减持行为及其时机
    D4 沟通透明度 15% 业绩会与公告的语言信号
    D5 关键人风险 15% 对个人的依赖度与继任规划

    2.2 综合评级¶

    评分 评级 含义 对分析的影响
    9-10 A+ 卓越 与股东高度一致 估值可获 10-15% 治理溢价
    7-8 A 优秀 可靠，偶有小瑕疵 正常估值
    5-6 B 合格 平均，无明显问题 中性，持续跟踪
    3-4 C 警示 存在明显问题 估值折价 15-25%，瓶颈等级降一级
    1-2 D 危险 与股东利益冲突 ⛔ 禁止交易

    注意 C 级与 D 级的区别：C 级是「打折」，D 级是「否决」。D 级不需要进一步分析。

    三、D1 · 资本配置能力（权重 30%）¶

    3.1 历史决策评分矩阵¶

    对每一类历史决策打分（+2 到 −2）：

    决策类型 +2 +1 0 −1 −2
    收购兼并 整合后 ROIC > WACC 平价，协同可见 ROIC ≈ WACC ROIC < WACC 灾难性收购 / 商誉爆雷
    资本开支 新增产能满产且回报 > WACC 节奏合理，利用率 > 80% 与需求匹配 产能过剩 / 纪律松弛 巨额无效投资
    研发支出 转化率高，产品领先 有稳定技术产出 比例合理 烧钱不出成果 研发造假
    股东回报 低估时回购 + 稳定分红 回购节奏合理 无明显失误 高价回购 / 不合理分红 高位大幅增发
    资本结构 杠杆优化，信用合理 负债率在行业区间 中性 过度杠杆或过度保守 债务违约

    3.2 四问测试¶

    # 问题 回答
    Q1 是否将资本配置在最具竞争力的业务上？ Y / N
    Q2 是否诚实地承认并退出失败的配置？ Y / N
    Q3 是否在股价被低估时回购、被高估时融资？ Y / N
    Q4 过去 5 年每一块钱再投资是否创造了 > 1 块的价值？ Y / N

    判读：

    通过数 评级
    4 A+
    3 A
    2 B
    1 C
    0 D

    3.3 快速评估方法¶

    近 5 年 ROIC 走势  → 是上升、持平还是下降？
收购历史清单       → 每笔的金额与整合效果
回购 / 增发时机    → 回购价 vs 当前价、增发价 vs 当前价

    回购与增发的时机是最诚实的信号：

    行为 含义
    在股价低位回购 🟢 管理层认为股价被低估
    在股价高位回购 🔴 检查是否有减值风险
    在股价高位增发 🔴 稀释股东，且说明管理层认为股价高估
    举债回购 🟡 危险信号，可能是对业务信心不足

    四、D2 · 激励对齐度（权重 20%）¶

    4.1 五项检查¶

    检查项 🟢 绿灯 🟡 黄灯 🔴 红灯
    薪酬结构 长期激励 > 60% 40-60% 短期现金 > 60%
    股权持有 CEO 持股 > 3 年薪资 1-3 年薪资 几乎不持或全部质押
    绩效指标 与 ROIC / ROE / FCF 挂钩 与营收 + 利润挂钩 仅与 EPS / 营收挂钩
    解锁条件 多维度达标 + 3 年以上 简单业绩目标 仅时间解锁
    关联交易 无或极小且透明 有但经独立董事批准 频繁且不透明

    4.2 评分公式¶

    激励对齐分 = (绿灯数 × 10 + 黄灯数 × 5 + 红灯数 × 0) / 5

    为什么绩效指标挂钩什么很重要：

    挂钩指标 管理层会做什么
    ROIC / FCF 关注资本效率，谨慎扩张
    营收 + 利润 可能通过并购和放宽信用冲规模
    仅 EPS 可能通过回购和减少研发来推高 EPS

    五、D3 · 内部人信号（权重 20%）¶

    5.1 增持的解读¶

    情形 信号 含义
    实控人自有资金大额增持（> 1000 万） 🟢 极强 股价被严重低估
    董事长 / CEO 小额定增持 🟡 中等 也可能是公司施压
    高管集体增持（3 人以上） 🟢 极强 内部共识
    增持但使用杠杆 / 融资 🔴 危险 可能被迫平仓
    增持后立即质押 🔴 极危险 套利行为

    5.2 减持的解读¶

    情形 信号 处理
    实控人清仓式减持（> 50% 持股） 🛑 致命 立即清仓
    实控人大额减持（> 5%） 🔴 极危险 强烈警示
    高管集体减持 🔴 极危险 强烈警示
    小额定增减持（< 1%，股权激励交税） 🟡 中性 可忽略
    大宗交易折价减持 🟠 警惕 接盘方可能是代持机构

    5.3 时机评价¶

    内部人的买卖时机比买卖行为本身更有信息量。

    【增持时机】
增持均价 vs 当前价：
  当前价 < 增持价 + 20%  → 仍有安全边际 🟢
  当前价 < 增持价 + 50%  → 尚可 🟡
  当前价 > 增持价 × 2    → 已无安全边际 🔴

【减持时机】
减持价 < 当前价
  → 内部人在更低的价格卖了
  → 他们看到的风险你还没看到 🛑

    最后一条是最重要的信号：如果内部人在低于当前价的位置减持，说明他们认为那个价格已经足够高。而你现在买入的价格更高。

    六、D4 · 沟通透明度（权重 15%）¶

    6.1 业绩会语言信号¶

    核心前提：公告可以精心准备，但问答环节的语言细节会暴露真实想法。

    检测项 信号 判定
    回避问题 「这是个好问题，不过……」「不方便此刻讨论」 回避率 > 30% → 🔴
    过度自信 「毫无疑问」「100% 确定」「史上最强」 营销语言，非分析语言
    语言模糊 可能 / 也许 / 大概 / 有望 / 计划 模糊词占比 > 5% → 回避指引；> 10% → 🔴
    信息泄露 无意间确认竞对名称、产能利用率、未公开指引 🟢 重要情报
    语调倾向 积极 / 中性 / 防御 防御 = 缩短回答 + 打断 + 推责

    6.2 量化指标¶

    回避率 = 回避问题数 / 总问题数
模糊词占比 = 模糊词出现次数 / 总词数

    6.3 加分与减分项¶

    行为 判定
    用具体数字 + 时间表 + 「如果 A 则 B」 ✅ 加分
    主动承认错误并给出改进计划 ✅ 加分
    归咎宏观 / 行业 / 天气 ❌ 减分
    使用主观判断词（我们相信 / 我们认为） ❌ 减分
    有信息披露违规记录 ❌ 严重减分

    6.4 与 D4 评分的核对¶

    业绩会语言分析的结论必须与 D4 评分交叉核对：

    一致   → 置信度提高
不一致 → 重新检查，可能存在未发现的信号

    七、D5 · 关键人风险（权重 15%）¶

    7.1 五项评估¶

    评估项 🟢 低风险 🟡 中风险 🔴 高风险
    创始人同时是核心技术人员 团队已有独立运营能力 有继任培养中 创始人不可替代
    单一高管持股 < 20% 分散 20-50% > 50% 高度集中
    过去 3 年高管流失率 < 15% 15-30% > 30%
    继任计划 有正式流程 有名无实 无明确计划
    关键高管年龄 < 55 岁 55-65 岁 > 65 岁无继任

    7.2 危险信号¶

    □ 创始人长期同时在 3 家以上公司担任核心职务
□ 重大决策完全依赖一人
□ 继任试验均失败

    八、资本配置深度分析（司库六维）¶

    D1 是五维评分卡中的一个维度，但资本配置本身值得单独展开。

    8.1 增量 ROIC¶

    增量 ROIC = ΔNOPAT / Δ投入资本（过去 3-5 年滚动）
    增量 ROIC 评级 含义
    > 25% A 新增资本配置极为高效
    15-25% B 良好
    WACC – 15% C 平庸
    < WACC D 资本配置在毁灭价值
    负值 F 投入越多亏得越多

    为什么用增量 ROIC 而不是存量 ROIC：存量 ROIC 反映的是历史，增量 ROIC 反映的是现在的配置能力。一家公司可以历史 ROIC 很高（早期投资成功），但增量 ROIC 已经跌到资金成本以下（现在的投资都在浪费钱）。

    8.2 再投资率¶

    再投资率 = (CapEx + 收购 − 折旧 + 研发 + 运营资本增加) / NOPAT
    再投资率 含义
    > 100% 激进扩张（需外部融资或消耗现金）
    50-100% 高速增长期
    20-50% 均衡模式
    0-20% 成熟期
    < 0% 缩减业务规模

    黄金公式：

    预期增长 = 增量 ROIC × 再投资率

    示例：增量 ROIC 20% × 再投资率 60% → 预期 NOPAT 增长 12%

    这个公式的价值：它把「增长目标」变成了两个可独立检验的变量。如果一家公司的增长目标是 30%，但增量 ROIC 只有 10%，那它需要把 300% 的利润再投资出去 —— 这在财务上不可持续。

    8.3 六维综合评级¶

    维度 权重
    增量 ROIC 25%
    再投资率 15%
    杜邦质量 15%
    收购记分卡 20%
    股东回报 15%
    所有者盈余 10%
    总分 评级 对分析的影响
    8-10 A 估值上调 0-10%
    6-7 B 无调整
    4-5 C 瓶颈等级降一级
    0-3 D 瓶颈等级降两级，仓位上限减半

    8.4 所有者盈余¶

    所有者盈余 = 净利润 + D&A − 维持性资本开支

保守口径 = 净利润 + D&A − 总资本开支
    所有者盈余 / 净利润 判定
    > 1.0 🟢 利润质量高
    0.7 – 1.0 🟡 资本开支负担
    0.5 – 0.7 🔴 需要关注
    < 0.5 🛑 利润虚高

    核心逻辑：净利润是会计利润，但公司必须把一部分利润再投入才能维持现有产能。扣掉这部分之后的才是真正可以分配给股东的。

    十、常见错误¶

    错误 后果
    只看增减持行为不看时机 漏掉最强的信号（低价减持）
    用存量 ROIC 评价配置能力 忽略当前投资效率的恶化
    忽略股权激励的解锁条件 时间解锁 vs 业绩解锁差别巨大
    把业绩会的营销语言当分析语言 高估管理层可信度
    单一高管持股高就判高风险 需结合继任安排综合判断
    不做 D 级否决 与股东利益冲突的管理层不值得进一步分析
    评分卡算完不用 评分必须转化为估值溢价/折价与仓位调整
