    8 大顶级投行 + 顶级研究所 · 对标精华清单（v8.2）¶

    定位：浑天紫苏体系的对标样本拆解。本文档是《对标精华清单》的固化版本，供报告改造时逐项引用。 使用规则：生成研报时，每个"可借鉴点"必须落到具体章节，而非停留在口号。第一阶段应收集真实研报样本二次校准。

    一、海外四家¶

    1. 高盛 Goldman Sachs ——「预期差 + 框架先行」¶

    维度 精华 落到浑天紫苏
    方法论 GS SUSTAIN（ROIC 聚焦 + ESG 整合）、预期差（Expectation Gap）分析、行业先行指标（leading indicators） "非共识≥2"升级为"预期差量化"：市场预期 X → 我们认为 Y → 差值是 α 来源
    逻辑 每个结论对标市场共识，而非自说自话 第七章市场认知改为"预期差分析"
    格式 标题即结论（"Buy XX: 3 reasons"）、投资摘要一页纸、核心图表（Key Charts）前置 报告骨架第一部分"结论前置"

    2. 摩根士丹利 Morgan Stanley ——「三情景 + 催化剂日历」¶

    维度 精华 落到浑天紫苏
    方法论 Bull/Bear/Base 三情景、proprietary industry models、逐季度盈利拆解 "魔鬼代言人"升级为"Bull/Bear 结构化辩论"
    逻辑 多头空头各自陈述 → 基准情景 第九章风险改为 Bull/Bear 辩论格式
    格式 风险回报图（Risk-Reward）、催化剂日历（Catalyst Calendar）、估值敏感性表 新增三个缺失格式

    3. 摩根大通 J.P. Morgan ——「催化剂驱动 + 量化结合」¶

    维度 精华 落到浑天紫苏
    方法论 催化剂驱动（Catalyst-Driven）、事件研究（Event Study）、量化+基本面结合 "催化剂"升级为"催化剂驱动定价"
    逻辑 目标价 = 当前价 + 催化剂折现 估值与催化剂挂钩
    格式 目标价推导 Step-by-step 估值章节展示推导路径，而非结论数字

    4. 美银美林 BofA Merrill Lynch ——「宏观→行业→个股传导」¶

    维度 精华 落到浑天紫苏
    方法论 宏观→行业→个股三层传导、周期研究 §L-1 流动性 + macro_sector_stock_transmission 弹性系数
    逻辑 先定宏观 Beta，再选行业，后挑个股 自上而下 + 自下而上打通

    二、国内三家¶

    5. 中金公司 CICC ——「产业链深度 + 估值折溢价」¶

    维度 精华 落到浑天紫苏
    方法论 "中国深度"产业链研究、自上而下+自下而上、AH 溢价、国产替代逻辑 BOM 穿透升级为"产业链卡位估值"
    逻辑 产业链卡位 → 国产替代空间 → 估值折溢价 紫苏叶瓶颈论 + 国产替代测算
    格式 产业链图谱、国产替代测算表 新增"产业链图谱"可视化

    6. 中信证券 ——「盈利预测严谨性 + 政策研究」¶

    维度 精华 落到浑天紫苏
    方法论 盈利预测严谨性（分业务拆解 + 敏感性）、政策研究、主题投资 "分业务拆解"升级为"逐业务盈利模型"
    逻辑 政策 → 主题 → 标的 A 股政策市契合
    格式 三表预测表（分业务）、估值表 新增"完整三表预测 + 逐季度"

    7. 国泰君安 ——「行业景气度跟踪 + 晨会机制」¶

    维度 精华 落到浑天紫苏
    方法论 行业景气度指标体系、量化择时+基本面结合 "板块联动"升级为"行业景气度评分"
    逻辑 景气度 → 估值 → 择时 与 PA 技术面天然契合

    五、8 大投行精华 → 浑天紫苏能力映射¶

    浑天紫苏现有能力 对标投行精华 升级方向
    非共识 ≥2 高盛·预期差 升级为"预期差量化"（市场预期 vs 我方判断的差值）
    魔鬼代言人八问 大摩·Bull/Bear 升级为"Bull/Bear 结构化辩论"
    竞争者排除矩阵 中金·产业链 升级为"产业链卡位估值"
    三表联动 5 年 中信·盈利预测 升级为"逐季度 + 驱动因子分解"
    分类多锚估值 大摩·敏感性 升级为"SOTP+DCF+可比+敏感性矩阵"
    催化剂表 小摩·催化剂驱动 升级为"催化剂日历 + 目标价推导"
    板块联动 国君·景气度 升级为"行业景气度评分"
    BOM 穿透 中金·产业链图谱 升级为"产业链图谱可视化"

    机构 通识拆解（此前） 真实样本校准 校准结果

    摩根士丹利 — "关键预测"（Key Forecasts）、"全球宏观论坛"（Global Macro Forum） 🆕 新增

    国泰君安 晨会机制 "所长早读"（每日晨会纪要）+ 期货研究周报/晨报体系 ✅ 确认

    6.2 校准后的核心可借鉴点（最终版）¶

    1. 高盛标题三要素：标题必须同时含「公司 + 核心观点 + 目标价动作(上调/维持/下调) + 评级」，标题即可独立传达投资结论
    2. 高盛 GSe 盈利预测：建立自己的盈利预测体系（对标浑天紫苏财务模型），不直接引用一致预期
    3. 大摩风险回报更新：单标的报告的核心是"风险回报"——上行空间 vs 下行空间，而非单纯罗列观点
    4. 大摩关键预测：定期发布关键预测（宏观/行业/个股），形成可追踪的预测体系（对标浑天紫苏"预先错误登记+事后验证"）
    5. 内资首次覆盖标题：标题=公司+行业定位+成长逻辑（"XX龙头，YY打开成长增量"）

    6.3 后续补充建议¶

    知识库为日更百篇，建议后续按需检索具体研报全文（如盛合晶微、长电科技等半导体标的的券商研报），用 fetch_media_content 读取全文做更精细的章节结构校准。
